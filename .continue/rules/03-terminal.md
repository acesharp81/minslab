## 셸 호환성
- 터미널은 **Windows PowerShell 5.1** 이다.
- `&&` 와 `||` 를 **절대 쓰지 마라** (지원 안 됨 → ParserError 발생).
- 여러 명령은 세미콜론 `;` 으로 잇거나, 한 줄에 하나씩 실행한다.
- 조건부 실행은 `명령A; if ($?) { 명령B }` 형태를 쓴다.
- 파일 삭제는 `Remove-Item`, 내용 확인은 `Get-Content`, 목록은 `Get-ChildItem` 등 PowerShell 네이티브 명령을 사용한다.
- 경로는 따옴표로 감싸고, 필요 시 백슬래시(`\`)를 사용한다.

## 파일 생성/수정 (중요)
- 파일을 만들거나 고칠 때는 **반드시 `create_new_file` / `edit_existing_file` 도구**를 사용한다.
- `node -e`, `echo >`, `Set-Content`, `Out-File` 등 **셸 명령으로 파일 내용을 쓰지 마라** (따옴표·이스케이프가 깨진다).
- 터미널 명령에 **JavaScript 템플릿 리터럴(백틱 `` ` ``)을 절대 넣지 마라** — PowerShell은 백틱을 이스케이프 문자로 처리해서 코드가 깨진다.
- 파일 내용을 다루는 작업은 셸이 아니라 파일 편집 도구로만 처리한다.

## 터미널 최소화
- 불필요한 검증/확인용 명령(`curl`, `cat`, `head`, `ls`, `type` 등)을 남발하지 마라.
- 파일 생성 후 내용을 다시 확인하는 명령을 실행하지 마라.
- 꼭 필요한 명령만, 출력이 짧게 나오도록 실행한다.
