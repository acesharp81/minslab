---
name: 코드 및 프로젝트 구조 규칙
alwaysApply: true
---

- JavaScript는 ES6 모듈(import/export) 구조를 사용한다.
- 확장성과 유지보수를 위해 기능별로 모듈을 분리한다 (예: `components/`, `data/`, `utils/`, `services/`).
- 새 파일은 프로젝트 루트에 흩뿌리지 말고 알맞은 디렉터리에 만든다.
- 설정값과 데이터는 로직과 분리한다 (`config`, `data` 파일로).
- 한 파일이 지나치게 커지지 않도록 책임 단위로 나눈다.
- **파일을 만들 때는 전체 내용을 완결된 형태로 한 번에 작성한다** (중간에 자르지 않는다).
- **샘플 데이터가 많으면 하나의 거대한 파일에 몰아넣지 말고 여러 개의 작은 파일로 나눠 생성한다** (대용량 단일 출력이 토큰 한도에 걸려 잘리는 것을 방지).
