## 4. 이번 보완으로 갱신할 표준 답변

### [H-02] AI를 활용한 추출 알고리즘의 개선과 규칙 축적 — 추가 증빙

**① 검증 결론**

부분 확인. AI 진단→개발 검토 보정→시험·격리 승인→규칙 재사용은 확인. AI 단독 실행 규칙 생성 성공 및 운영 적용은 미확인.

**② 핵심 답변**

AI가 기존 HTML 본문에 실제 내용이 없고 PDF에 상세 내용이 있다는 점을 진단했다. 그러나 실제 응답 3회에서 실행 가능한 PDF 규칙을 정확히 제시하지 못해, 개발 검토자가 원문의 다운로드 링크를 확인하고 규칙 종류와 선택자를 보정했다. 동일한 검증·승인 코드를 격리 원장에서 실행한 뒤, 저장된 규칙으로 원문을 재수집하여 본문 1,535자를 확보했다. 이 반복 추출 경로의 추가 모델 호출은 0회이며, AI에 제시하지 않은 실제 문서 2건에서도 추출 검사를 통과했다.

**③ 소스코드 근거**

- `PoC/10-home/backend/ai_agent_workflows.py:43`의 `RuleProposal`, `:63`의 알고리즘 지침: HTML/PDF 규칙 계약과 실제 다운로드 링크 입력.
- `backend/attachment_rule.py:10`의 `extract_attachment`: 공식 출처, 한 개 PDF 링크, 같은 호스트, 실제 PDF 내용·추출 길이 검사.
- `backend/algorithm_review.py:63`의 `extract`: PDF 뷰어만 있고 본문이 없는 HTML을 성공으로 처리하지 않음. `:113` `validate`, `:171` `decide`, `:211` `extract_approved`: 시험·승인·판본 및 해시 확인·규칙 재사용.
- `backend/ai_collection.py`의 `process_run`: 기존 수집 경로에서 PDF 수집기를 승인 규칙 실행에 전달.
- 테스트: `tests/test_evidence_chain.py`, `tests/test_algorithm_review.py`, `tests/test_ai_agents.py`. 경로는 모두 `PoC/10-home/` 기준이며 최종 파일 해시는 버전 기록 참조.

**④ 운영 서비스 및 데이터 근거**

- 확인 일시: 2026-11-11 KST, 시연·검증 시각은 각 JSON의 `created`, `created_at` 참조.
- 배포 상태: 로컬 구현·격리 실제 실행 완료, 운영 미배포.
- 대상 문서 `DOC_87cca7787d542e5eb6512549`, 기존 판본 1.
- 규칙 검증 ID `15dd0e95-eaae-4ace-b2a4-a01bcdc7ebbb`; 격리 규칙 버전 1, 적용 범위 `ISOLATED_URL_ONLY`.
- 규칙: `a[href*="galleryDownload.es"][title*=".pdf"]`, 종류 `PDF_ATTACHMENT`.
- [rule-validation.json](../../../PoC/10-home/docs/evidence/AI_EVIDENCE_CHAIN_20261111/rule-validation.json), `case.json`의 `algorithm`·`rule_review`, [원래 모델 응답](../../../PoC/10-home/docs/evidence/AI_EVIDENCE_CHAIN_20261111/model-responses.json).

**⑤ 정량적 증빙**

대상 1건의 기존 51자와 재수집 1,535자를 비교했다. 별도 실제 문서 2/2건에서 추출 검사를 통과했다. 모델 진단 3회와 승인 규칙 재사용 시 모델 호출 0회를 실제 장부·실행 로그로 확인했다. 추출 검사 통과는 의미 정확성·다른 기관 적용성 검증과 다르며, 경로 전체 활성화도 수행하지 않았다.

**⑥ 심사에서 사용할 수 있는 설명**

더주택은 실제 LH 자료의 추출 실패에 대해 AI가 원인을 진단하고 담당자가 실행 규칙을 검토·보정하는 구조를 갖췄다. 공개 PDF 연결 규칙을 격리 환경에서 시험·승인한 뒤 추가 모델 호출 없이 본문을 재수집했으며, AI에 제시하지 않은 자료 2건도 추출 검사를 통과했다. AI 원응답과 사람의 보정 이력을 구분해 보존한다.

**⑦ 미확인 사항 및 반대 근거**

AI 원응답은 `BODY_SELECTOR`를 잘못 유지했다. 실행 규칙의 완전자율 생성 성공 사례로 제출하면 안 된다. 실제 적용은 단일 URL의 격리 원장이다. 추가 2건은 같은 LH 게시 형식에 대한 검사이며, 모든 기관·모든 PDF에 대한 보장이 아니다.

**⑧ 추가 검증이 필요한 사항**

다른 LH 게시 형식·복수 첨부·스캔 PDF에 대한 기존 자료 회귀검사부터 수행한다. 운영 활성화는 이 시연과 별도 작업으로 관리한다.

> 실제 LH 보도자료에서 상세 내용이 PDF에 있어 본문이 누락되는 문제를 AI가 진단했다. 개발 검토자가 실행 규칙을 보정하고 격리 환경에서 시험·승인한 결과, 기존 51자였던 본문을 1,535자로 복구했으며 추가 문서 2건에서도 추출 검사를 통과했다. 승인 규칙에 따른 재수집에는 추가 모델 호출이 없었다. 누락 착공 단계의 조사와 판단도 실제 AI로 실행했으나 관련 근거를 확보하지 못해 후보를 보류했으며, 원응답과 검증 사유를 그대로 보존했다.

추가 확산가능성 문구:

> 추출 규칙·검증·승인·재사용 경로를 분리해 동일 게시 형식의 자료에 재사용할 수 있도록 했다. 이번에는 동일 LH 형식의 실제 자료 3건에서 추출을 확인했다. 새로운 기관에 적용할 때에는 출처·첨부 방식·문서 형식에 맞춘 검증이 필요하며, 기관 간 범용 적용이나 운영 확산 완료를 의미하지 않는다.

| 사용하면 안 되는 표현 | 확인된 사실에 맞는 표현 |
|---|---|
| AI가 스스로 알고리즘을 완성했다 | AI가 원인을 진단했고 개발 검토자가 실행 규칙을 보정했다 |
| AI가 누락된 착공 단계 연결에 성공했다 | 실제 조사·판단을 실행했으나 착공 근거가 부족해 보류했다 |
| 3개 사업 단계를 자동 연결했다 | 공급 판단 후보가 중복 생성되어 3건 모두 보류했다 |
| 여러 자료를 종합해 연결을 실증했다 | 추출은 실제 문서 3건에서 확인했지만 단계 판단은 1건만 사용했다 |
| 규칙을 운영에 배포했다 | 로컬 구현과 격리 원장 적용을 검증했다 |
| AI 비용이 없다 | 승인 규칙의 반복 추출에는 추가 모델 호출이 없었다 |
| 비용·시간을 몇 % 절감했다 | 호출량·토큰·단가 환산액을 기록했으며 절감률은 미측정이다 |
| 인용 검사 11건으로 정확도를 검증했다 | 중복 포함 11개 인용 위치를 대조했으며 의미 정확도는 별도 검토다 |

## 9. 재현·패키지 관리

추가 호출 없는 재현 명령(저장소 루트, 프로젝트 의존성 설치된 Python 환경):

```bash
PYTHONPATH=PoC/10-home python PoC/10-home/scripts/replay-evidence-chain.py \
  --work-dir PoC/10-home/docs/evidence/AI_EVIDENCE_CHAIN_20261111 \
  --out-dir /tmp/home-evidence-offline-replay
```

기대 결과: `REPLAYED_WITH_HOLDS`, `linked=0`, `held=3`, `unique_stage_count=1`, `verified_citations=11`, `source_documents=1`, `actuals_added=0`. 재실행 사례 ID와 저장 시각은 새로 생성되지만 원래 실행 ID·원응답은 유지된다. `real_model_calls=5`는 과거 호출 기록의 수이며 이 재검증이 모델을 새로 호출했다는 뜻이 아니다.

- 승인된 5회 호출은 모두 사용했다. `run-evidence-chain-pilot.py`의 재실행은 이 오프라인 재현과 다르며 이번 승인 범위 안에서 추가 실행하지 않는다.
- 실제 시연 자료와 개발 테스트를 구분한다. 테스트에는 오류 차단을 확인하는 개발용 제안·손상 입력이 있지만 실제 AI 응답이나 사업 성과로 제시하지 않는다.
- 원본 증빙 폴더는 내부 재현용이다. 공개 원문에 포함된 담당자 이름·연락처와 보존 HTML의 일회성 폼 토큰 등이 있을 수 있으므로 폴더 전체를 심사 제출 ZIP으로 배포하지 않는다. 외부 제출에는 본 MD·표시 화면·필요한 최소 발췌를 사용하고, 기존 종합 보고서의 제출용 비식별 패키지와 구분한다.
- 이번 파일과 별도 세션의 국정온·문광위 개발 파일을 혼합하지 않는다. 변경 파일 해시는 `implementation-version.json`으로 확인한다.
