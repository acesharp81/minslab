# OpenRouter 실시간 모델 비교 · 2026-10-30

## 결정

GPT-5.4 mini와 OpenRouter의 병렬 경쟁 풀을 유지한다. 서로 다른 발언을 PostgreSQL 잠금으로 분배한다. Dots를 OpenRouter 무료 `nvidia/nemotron-3.5-super-vl:free`로 교체하고, 실시간 요약에는 추론 OFF를 적용한다. 통합·공식 대조 GPT 경로는 변경하지 않는다. 이는 NIM 플랫폼 호출이 아니다.

## 비교 방법과 결과

실제 운영 요약 프롬프트·JSON 계약·한국어/원문 근거 검증을 사용했다. 같은 가상 발언 12개(6회, 요청당 2개)를 각 모델에 입력했다. 요청/약속, 단순 질의/답변, 과거 요구와 부정, 숫자/미확정 의혹, 절차, 복합 주제를 포함한다. 기존 무료 호출 및 Mini 토큰 예산 장부로 예약·정산했다. 추가 실제 회의 원문은 전송하지 않았다.

| 모델/설정 | 검증기 통과 | 과제 유무 일치 | 전체 요청 시간 | 세부 내용 검토 |
|---|---:|---:|---|---|
| GPT-5.4 mini / 추론 없음 | 12/12 | 12/12 | 2.03~3.65초 | 복합 발언에서 제출 계획만 과제로 추출 |
| Nemo 3.5 / 추론 OFF, 최초 지시 | 12/12 | 12/12 | 2.27~4.08초 | 복합 발언 1개에서 즉석 설명 요구를 후속 과제에 혼입 |
| Gemma 4 26B / JSON 모드 | 평가 불가 | 평가 불가 | 호출 거절 | 공급자 429; 품질 실패로 집계하지 않음 |
| Gemma 4 31B / JSON 모드 | 평가 불가 | 평가 불가 | 호출 거절 | 공급자 429; 품질 실패로 집계하지 않음 |

원래 Nemo low reasoning의 동일 가상 4개 발언은 16.49/39.51초였고 OFF에서는 2.62/3.60초였다. 추론 OFF는 실제 응답의 reasoning_tokens=0도 확인했다. 다른 시점의 호출이므로 서비스 부하·라우팅 영향이 포함된다.

## 실패 사례와 저장 전 보완

Nemo 전용 지시를 보완한 뒤 기존 12개+새로운 2개를 시험했다. 14개 모두 형식·기존 검증을 통과하고 과제 유무도 일치했지만, 새로운 복합 요구 1개는 여전히 즉석 답변을 과제에 포함했다. 시간은 3.83~24.62초(중앙값 4.43초)였다. 따라서 검사 통과나 과제 유무만으로 전체 의미 정확도를 주장하지 않는다.

추가한 `mixes_immediate_reply_task`는 Nemo의 과제에 설명/답변이 들어 있고 원문에 서면·미래 후속조치가 아닌 즉석 답변 요청이 있으면 해당 발언 전체 결과를 저장하지 않는다. 요청 원문과 거절 사유는 기존 거절 기록에 보존한다. 기존 shared pool이 이 모델/발언을 1시간 보류하고 Mini가 이어받을 수 있다. 다른 정상 발언은 저장한다. 불확실한 과제를 단순 삭제하여 완료 처리하지 않는다. 이 규칙은 발견된 유형을 방어하며 모든 의미 오류를 탐지하지는 않는다.

캡처한 14개 출력에 규칙을 재적용하여 잘못된 복합 요구 1개만 차단됨을 확인했다. Mini로 새 2개를 비교하면 요청의 과제는 올바르게 서면 제출만 남겼으나 답변 쪽의 제출 약속은 별도 과제로 누락했다(과제 유무 1/2). Nemo가 정상 처리한 답변은 기존 풀에서 유지되므로 전체를 다시 덮어쓰지 않는다. Mini도 완전한 정답 판정자는 아니다.

## 운영 및 한계

- 31개 요약·예산·캐시 회귀 테스트 통과.
- Mini/OpenRouter 두 실행 경로 유지. 모델별 보류는 전체 OpenRouter 영구 비활성화가 아니다.
- 시험 초기의 키 누락·시험 로컬 게이트웨이 인증 오류는 시험 환경 오류이며 모델 성능 통계에서 제외했다. 운영 키를 변경하지 않았다.
- Gemma 두 모델의 JSON 모드 재시험도 429였다. Xing의 429, Flint의 503 역시 가용성 오류이며 품질 미달 판정이 아니다.
- 소규모 합성 시험이며 긴 회의 통합·장기 서비스 신뢰성·GPT mini 전반 동급을 입증하지 않는다.
- 현재 실제 방송은 종료 상태. 배포 후 자연 발생 실시간 요청의 장기 품질은 아직 확인하지 못했다.
- 두 운영 주소에서 보고서 탭 유지, 라이브 탭 유지, 브라우저 가상 첫 방송 자동 열기, 헤더 표시, JS 오류 없음을 확인했다. 가상 카드는 브라우저 내부에서만 사용했다.

## 근거 파일

`poc7-comparison.json`은 Mini 최초 결과, `poc7-nemo-comparison.json`은 Nemo 최초 결과, `poc7-gemma-comparison2.json`은 JSON 모드 재시험, `poc7-refined-comparison.json`은 지시 보완 후 출력, `poc7-mini-holdout.json`은 새 복합 발언 비교다. `guard-replay.json`과 `browser.json`은 저장 전 차단 및 화면 검증 결과다. 가상 원문만 포함한다.
