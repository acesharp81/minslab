# 국정ON 모델별 일일 처리 실적 · 2026-10-30

집계 범위: **한국시간 2026-10-30 00:00~21:44:17**, PoC7 국정ON만 포함. 입력+출력 토큰을 합산했다. 다른 프로젝트의 OpenAI 사용량은 제외했다. 신규 모델 호출 없이 읽기 전용 원장을 조회했다.

## 서비스 처리

‘건수’는 발언·보고서 수가 아닌 **API 호출 수**다. 같은 request_id가 발언·청크·보고서에 중복 저장돼도 한 번만 센다. 성공은 저장 또는 처리 검증 통과 기록이며 내용의 완전한 정확성을 보증하지 않는다. 부분 성공은 일부 발언 저장 후 나머지가 검증 탈락한 호출이다.

| 모델 | 호출 | 성공 | 부분 성공 | 실패 | 결과 미확인 | 사용 토큰 |
|---|---:|---:|---:|---:|---:|---:|
| GPT-5.4 mini | 434 | 427 | 0 | 5 | 2 | 1,590,380 |
| Dots3 Note | 259 | 107 | 3 | 149 | 0 | 760,785 |
| GPT-5.4 | 9 | 7 | 0 | 0 | 2 | 157,772 |
| GPT-6.1 Terra | 1 | 1 | 0 | 0 | 0 | 32,584 |
| Nemo 3.5 VL | 0 | 0 | 0 | 0 | 0 | 0 |
| Mistral Voxtral mini | 5 | 5 | 0 | 0 | 0 | 해당 없음(음성 232.2초) |

- Mini의 저장 발언은 **366개**, Dots는 **120개**다. 호출 수와 다른 이유는 한 호출이 여러 발언을 처리하거나 논의 분류·세부 요약·보고서 분석을 수행하기 때문이다.
- Dots 실패 149회: **HTTP 400 요청 거절 29회 + 출력 길이 제한으로 JSON 불완전 3회 + 저장 품질검증 전체 탈락 117회**. 일부 저장된 3회는 부분 성공으로 별도 분리한다. HTTP 400을 모델 의미 품질 실패로 단정하지 않는다.
- Mini 실패 5회: 세부 요약 검증에서 원문에 없는 숫자 4회, 언어 규칙 위반 1회. 후속 보완 상태와 해당 모델 호출의 검증 실패는 별개다.
- GPT-5.4의 `VERIFICATION_PENDING` 2개 중간 상태는 같은 제안 request_id를 재사용해 검증 완료되었다. 이를 추가 API 실패 2회로 중복 집계하지 않았다.
- Mini 2회와 GPT-5.4 2회는 예산 원장에는 호출·토큰이 있으나 개별 결과 메타데이터와 대응하지 않아 **미확인**으로 둔다. 성공/실패를 임의로 추정하지 않는다.
- Nemo의 이번 집계에 잡힌 호출은 전부 비교 시험이다. 자동 처리 경로는 배포되어 있으나 시험 호출을 서비스 발언 처리 실적으로 부풀리지 않았다.
- Voxtral mini의 음성 5건은 같은 예산결산특별위원회 방송 처리이며 모두 전사 완료, 총 232.2초다. 토큰 0과 다른 단위이므로 해당 없음으로 표시한다.

## 오늘 비교·설정 시험 (서비스 처리와 별도)

| 모델 | 호출 | 응답·형식 성공 | 오류 | 사용 토큰 |
|---|---:|---:|---:|---:|
| GPT-5.4 mini | 7 | 7 | 0 | 11,675 |
| Nemo 3.5 VL | 37 | 31 | 6 | 88,749 |
| Gemma 4 26B | 3 | 0 | 3 | 0 |
| Gemma 4 31B | 3 | 0 | 3 | 0 |
| Xing 4 | 1 | 0 | 1 | 0 |

- Nemo 37회 중 성공 31회, 시험 환경 인증 설정 오류(401) 6회. 401은 모델 품질 실패가 아니다. 성공 31회에는 사용자가 마지막으로 승인한 실제 발언 10회 비교도 포함된다.
- Gemma 두 모델은 각각 429 두 번·401 한 번, Xing은 429 한 번, Flint는 503 한 번이다. 이 결과로 모델 의미 품질을 판정하지 않는다.
- Mini 시험 7회는 앞서 진행한 가상 발언 비교이며, ‘실제 발언 Nemo 10회만’ 승인 이후 Mini를 재호출하지 않았다.
- 시험 토큰 0은 응답에서 기록된 사용량이 없다는 뜻이다. 공급자의 비용 청구를 별도로 확정하는 값은 아니다.
- Gemini·Groq·NIM의 오늘 처리 기록은 확인되지 않았다. Nemo의 시험은 NIM이 아닌 OpenRouter 경로다.

## 원장 대조 및 한계

화면의 OpenAI 예산은 UTC 일자(한국시간 오전 9시 리셋)·프로젝트 공통이다. 위 표는 PoC7로 분리했다. 개별 PoC7 기록은 오늘 오전 9시 이전에 확인되지 않았으며, 오전 9시 이후 예산은 다음과 같이 대조했다.

- Mini 공통 491회/2,158,293토큰 − PoC10·11 50회/556,238토큰 − 시험 7회/11,675토큰 = 서비스 **434회/1,590,380토큰**.
- 서비스 Mini 개별 기록은 432회/1,581,087토큰. 차이 2회/9,293토큰은 결과 미확인.
- GPT-5.4 공통 43회/372,921토큰 − PoC10 34회/215,149토큰 = 서비스 **9회/157,772토큰**.
- GPT-5.4 개별 기록은 7회/106,352토큰. 차이 2회/51,420토큰은 결과 미확인.
- Terra는 오늘 저장 결과에서 확인된 고유 요청 1회/32,584토큰 기준이다. 월 누적 공용 크레딧 금액을 오늘 서비스 실적으로 오인하지 않는다.
- 일부 OpenAI 경로는 개별 호출 결과 원장이 완전하지 않다. 이 표는 확인 가능한 기록·공통 예산 대조 결과이며, 기록되지 않은 성공/실패까지 확정하는 완전한 감사 로그는 아니다.

`metrics.json`에 집계값과 원장 대조식을, `request-audit.json`에 원문을 제외한 호출 식별자·토큰·상태 근거를 보관한다.
