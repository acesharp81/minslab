# Nemotron 요청당 10케이스 평가 — 2026-09-07

## 평가 결과

운영 DB를 읽거나 쓰지 않고 새로 만든 한국어 기사 18개와 서로 다른 합성 케이스 10개를 평가했다. 기존 운영 프롬프트·JSON 스키마·후처리 코드를 사용하고, 임베딩 영향을 배제하기 위해 합성 케이스의 LLM 가중치는 1로 설정했다. 사전에 작성한 기대 판정과 비교하며 이는 실제 기사 정답률이나 기존 모델 대비 성능을 뜻하지 않는다.

- 18배치 × 10케이스 = 180건
- JSON 결과 완결성: 18/18배치, 180/180건
- 각 배치 case_id 정확히 10개: 누락·중복·추가 ID 없음
- 기대 판정 일치: 180/180 (발송 27건, 제외 153건)
- 발송 근거 검증 실패: 0건
- 평균 API 응답: 12.223초 (최소 7.869, 최대 22.636초)
- 전체 10케이스가 관련되는 긴 출력 배치도 통과

디지털 행정, 지방재정, 재난안전, 기관 직접 비판, 공무원 교육, 개인정보, 주민등록, 지방소멸, 지방선거, 화재 예방을 포함했다. 기관 배경 언급과 타 기관·무관 기사도 검증했다.

재현:

```bash
PYTHONPATH=PoC/04-master-press .venv/bin/python -m master_press.nvidia_canary --batch-size 10 --output /tmp/nemotron-batch10.json
```

## 적용 범위

- `nvidia/nemotron-3-super-120b-a12b`의 요청당 배치 상한만 5→10으로 올렸다.
- 실제 worker claim과 관리 화면 상태가 같은 배치 크기 함수를 사용한다.
- 미검증된 다른 NVIDIA 모델의 상한은 5로 유지한다.
- 동시 API 요청은 1개, 기사 묶음별 제공자 유지 및 OpenAI 우선 대기시간은 그대로다.
- 출력 한도는 기존 로직대로 10케이스 요청에서 4,080토큰이며 추가 확대하지 않았다.
- Python 회귀 191개를 통과했다. 11케이스 대기 묶음이 중복 claim 없이 10+1로 처리되는 테스트를 추가했다.
- 08:25:40 KST 웹과 워커 9개 재기동 완료, 전체 active와 health 정상 응답을 확인했다.

요청당 최대 10건이라는 뜻이며 기사 하나에 판정할 케이스가 4개면 4개만 전송한다. 평가 당시 기존 대기 큐는 소진되어, 운영 데이터의 10건 배치 완료 여부는 별도 관측이 필요하다.
