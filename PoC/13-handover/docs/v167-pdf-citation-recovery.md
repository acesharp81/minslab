# v1.6.7 · Solar PDF 인용 줄바꿈 복구

## 확인된 장애

샘플1의 `r11.pdf` 분석 중 Solar가 `접수만\n으로`, `재시험 결\n과`, `뜻하지 \n않는다`의 시각적 줄바꿈을 제거했다. 단어 내용은 같지만 기존 원문 연속 인용 검증기가 문자 불일치를 거부했다. 최초 처리와 사용자 재시도가 각각 자동 재요청 후 실패했다. 중단 시 진행률은 27%, 문서별 완료 결과 5개와 업로드 원본 19개는 보존됐다. 이전의 샘플1 98개 검사는 규칙 기반이므로 실제 Solar 응답의 이 문제를 검출하지 못했다.

한 건의 Solar 진단 호출로 참고 사항·완료 기준·인계 산출물의 실제 인용 차이를 확인했다. 진단 응답을 저장해 추가 호출 없이 수정된 검증기로 재검사했다. 원문 안의 정확한 연속 구간을 되찾아 세 필드가 통과했다.

## 수정 범위

PDF 원문에 줄바꿈이 있을 때만 공백 정규화와 한글 음절 사이의 순수 줄바꿈을 대응시킨다. 위치 매핑으로 원래 블록의 문자열을 그대로 잘라 값과 인용으로 저장한다. 원문·블록 ID·인용 해시를 바꾸거나 가짜 인용을 만들지 않는다. 복구된 필드에 `citation_recovery` 기록을 남긴다.

숫자·부정어·단어·구두점 변경, 떨어진 구간의 결합, 모호한 다중 위치는 복구하지 않는다. 일반 공백이나 숫자 사이의 줄바꿈을 없애서 일치시키지 않는다. PDF 이외 형식에는 이 보정을 적용하지 않는다. 실제 내용 오류는 계속 실패한다.

모델 실패 감사 기록에 문서 ID와 파일명을 추가하고 사용자 오류에도 해당 파일명을 표시한다. 기존 작업의 모델·프롬프트·원본 범위는 그대로이며 재시도 시 완료된 문서의 결과를 재사용한다.

## 검증

줄바꿈 복구와 정확한 근거·해시 유지, 숫자/부정어/단어 변경 거부, 모호한 대응 거부, 다른 문서 형식 제외를 테스트한다. 실제 재현 응답 1건도 저장본으로 검증했다. 기존 보고서·확정본은 수정하지 않는다.
