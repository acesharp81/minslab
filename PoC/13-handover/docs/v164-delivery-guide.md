# v1.6.4 실제 화면 시작 가이드·의견 인계

## 변경 내용

- 시작 안내는 별도 축약 UI 대신 앱의 실제 자료 등록·초안 검토·보고서·인계하기 구성요소를 합성 데이터로 렌더링한다. 5단계에서 해당 영역을 강조하고 등록, 업무 묶기, 확정, 전달 의견 입력, 인수 확인을 가상으로 수행한다.
- 별도 프레임에서 합성 자료만 사용한다. API 호출 차단, 직원 선택 비활성화, 파일 입력·외부 업로드 차단으로 실제 인수인계함·선택 직원·잔액을 변경하지 않는다. 이전·다음·닫기를 제공한다.
- 자료 등록과 검토 자료는 배포한 4개 업무 상세실무편과 동일한 합성 원본/확정 판본이다. 이미 검증된 보고서를 재사용하며 모델을 재호출하지 않는다.
- 일정·연락망, 보고서에 질문, 확정 업무보드 탭을 제거하고 단계형 탐색을 적용했다. 보고서의 목차·차트·챗봇은 유지한다. 변경 이력 오른쪽에 인계하기를 배치했다.
- 인계하기에서 받을 직원·확정 판본을 확인하고 의견을 입력한다. 전달 기록은 보고서 판본과 해시, 인계자·인수자·의견·시각을 함께 저장한다. 같은 요청의 재시도는 중복 기록을 만들지 않는다.
- 새 초안·새 원본·진행 중 작업이 있거나 인수자가 달라졌으면 전달을 막는다. 기록된 의견은 덮어쓰지 않는다. 인수자는 같은 판본과 의견을 확인하고 인수 확인할 수 있다.
- 기존 확정본의 열람·인수 동작은 호환 유지한다. 이전 방식으로 공유된 보고서에는 새 전달 의견이 없을 수 있으며 이를 화면에서 명시한다. 직원 선택은 시연 기능으로 기관 인증을 대신하지 않는다.
- 인수인계함 내부의 모든 화면을 전체 가용 폭으로 통일했다. 낮은 높이에서도 인수 확인 영역을 숨기지 않는다.
- 웹 시작 가이드 및 다운로드 MD·DOCX·HTML·PDF 안내서를 최신 메뉴·수동 분석·그림 분석 예산 전환·의견 전달 절차와 일치시켰다. 가이드 재생성은 과거 보고서 사본을 덮어쓰지 않는다.

## 검증

- 전체 자동 테스트 84개 통과. Python 컴파일·웹 스크립트 구문 검사 통과.

- 전달 API: 미확정·잘못된 인수자·다른 직원·빈 의견 거부, 중복 요청 일관성, 의견 변경 거부, 판본 해시 고정, 신규 초안/자료 차단, 인수자 확인을 자동 검증했다.
- 로컬 실제 브라우저: 생성·검토·확정→전달 의견 입력→직원 전환→동일 의견 확인→인수 확인을 완료했다.
- PC 1600×1000과 모바일 390×844에서 실제 화면 가이드 총 10개 단계, 버튼 이동·닫기, 가로 넘침을 점검했다. 안내 중 API 요청 0건, 직원 선택·쿠키 변경 없음, 자바스크립트 오류 없음.
- 1600px 화면에서 인수인계 작업 영역 폭 1525px(좌측 메뉴 75px 제외)을 확인했다.
- 상세 브라우저 결과와 캡처: `test-results/delivery-guide/`.
- 이번 수정·검증은 외부 모델을 호출하지 않았다.
