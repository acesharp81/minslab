# 인수인계 보고서 보강 · 0.3.0

기존 출력은 업무 필드와 근거를 연속 나열해 보고서의 핵심인 진행 현황·후속 업무·현안을 읽기 어려웠습니다. 완료 실적·남은 업무·현안을 별도 추출·수정할 수 있게 추가하고, 양측이 동일한 확정 보고서를 열람하도록 바꿨습니다.

## 보고서를 보는 위치

1. https://www.minslab.kr/handover/ 에서 접속 코드로 로그인합니다.
2. 확정본이 있는 인수인계함을 열면 **인수인계 보고서**가 기본 표시됩니다.
3. 다른 탭에서도 상단 **인수인계 보고서 보기** 또는 **인수인계 보고서** 탭으로 이동할 수 있습니다.
4. **보고서 새 창**, **인쇄 / PDF 저장**, **HTML ↓**, **MD ↓**를 사용할 수 있습니다.

인계자가 확정하면 자동으로 보고서로 이동합니다. 인수자 역할로 바꿔도 같은 판본·본문을 표시하고, 인수 확인을 기록할 수 있습니다. 새 초안을 작성하더라도 다시 확정하기 전에는 양측의 기존 보고서를 바꾸지 않습니다.

## 본문 구성

| 순서 | 내용 |
|---|---|
| 1. 전체 업무 요약 | 업무 수, 전체 완료 명시 여부, 현재 단계, 다음 조치, 담당·기한 |
| 2. 당장 확인·처리할 현안 | 기한·담당 불일치, 확정일 기준 임박·경과 일정, 명시된 현안과 후속 조치 |
| 3. 업무별 상세 | 현재 어디까지 진행됐는지, 완료 실적·산출물, 남은 업무, 다음 행동, 미결 현안, 담당·일정, 유의 사항 |
| 4. 후속 실행 계획·일정 | 업무별 실행 조치·담당·기한을 모은 표 |
| 5. 남은 확인 사항 | 미확인 필드·부분 추출 등 인계 시 남기는 검토 항목 |
| 부록 | 원문 인용·파일 위치와 전임자 수정 이력 |

출처는 본문 각 항목의 번호로 연결하고 긴 인용은 접을 수 있는 부록으로 옮겼습니다. HTML과 MD도 같은 확정 판본에서 구성합니다. HTML 보고서 전용 보안 정책은 같은 사이트의 화면 내 표시와 서식만 허용하고 스크립트 실행은 허용하지 않습니다.

## 사실과 판단의 경계

- `completed_work`, `remaining_work`, `issues`를 모델·로컬 라벨 추출과 수정 화면에 추가했습니다. Solar는 해당 원문 구절을 선택하고 서버가 문자 일치를 검증합니다.
- 진행률 백분율, 완료 실적, 장애 해소 사실을 임의 생성하지 않습니다. 자료에 없는 내용은 미기재로 표시하고 전임자 보완을 요청합니다.
- 기한은 매번 현재 시각이 아니라 **확정 시각의 한국 날짜**를 기준으로 판정합니다. 같은 판본은 양측에게 같은 분류로 표시됩니다.
- 기한 임박·불일치·명시 현안을 우선 확인 대상으로 분류합니다. 이것은 시스템의 확인 권고이며 실제 긴급도·지연 확정 판정과 다릅니다.
- 구버전 확정본도 즉시 새 보고서 형식으로 볼 수 있습니다. 과거에 추출하지 않은 완료 실적·현안을 소급 생성하지 않습니다. 초안 검토에서 보완 후 다시 확정하거나, 원문을 새 추출 계약으로 재분석해야 합니다. 재분석은 과거 직접 수정값을 자동 병합하지 않습니다.

## 검증

- 자동화 시험 **24개 통과**: 양측 동일 보고서, 초안 공개 차단, 다른 사건 판본 차단, 새 초안 이후 확정 보고서 유지, 구버전 필드 보완, 원문·수정 이력 보존, 안전한 HTML 출력, 확정일 기준 분류를 포함합니다.
- 보강된 합성 자료 12개의 실제 Solar Pro 4 분석에서 예상 업무 **11/11**, 원문 인용 **86개** 일치를 확인했습니다. 모델 호출 11회, 9,769토큰, 평가 경과시간 43.28초였습니다. 이 실행에서 기본 업무 5개 모두 완료 실적·남은 업무·현안을 추출했습니다.
- 측정은 소규모 합성 자료의 단일 실행 결과입니다. 과거 0.2.0의 수치를 덮어쓰지 않고 [0.3.0 측정 JSON](report-v030-evaluation.json)으로 보존했습니다.
- [확대 자료 보고서 HTML](examples/report-v030-expanded.html) · [동일 판본 MD](examples/report-v030-expanded.md).

실제 웹 브라우저에서도 분석·수정·확정·양측 동일 보고서·인수 확인·다운로드가 통과했습니다. HTML 서식과 인쇄 버튼, 14쪽 PDF의 주요 본문도 확인했습니다. [배포 기록](DEPLOYMENT.md), [기계 판독 확인 기록](report-v030-deployment.json), [샘플 보고서 PDF](examples/report-v030-demo.pdf)를 함께 제공합니다.
