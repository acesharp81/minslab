# 보안·지원 한계

이 버전은 합성·공개 자료의 인수인계 체험용입니다. 기관의 비공개 자료를 보관·전송하는 운영 시스템으로 승인받았다는 의미가 아닙니다.

## 구현한 보호

- 파일당 20MB, 전체 업로드 80MB, ZIP 100개 항목, 사건당 최대 200개 자료 판본.
- ZIP 절대경로·상위경로·드라이브 경로·제어문자·암호화·심볼릭 링크·중복 경로 검사. 해제 총량·압축률 제한. 원본 경로에 파일을 직접 압축해제하지 않음.
- OOXML/HWPX 내부 구조와 HWP5/PDF 시그니처 검사. 매크로 포함 문서와 지원하지 않는 실행 형식은 미지원/실패 처리.
- PDF 200페이지, XLSX 10,000행·100열, 문서 4,000블록 제한. 이미지·수식 실행·매크로 실행·사용자 파일 코드 실행 없음.
- 원문·추출·모델 값은 HTML 삽입 전 이스케이프. CSP, MIME sniff 차단, 동일 출처 쓰기 요청 검사. 원본은 첨부 다운로드로 제공.
- 원문 근거·작업·판본의 사건 ID 검사. 수정/확정 시 해시 비교, SQLite 원자적 포인터 변경.
- 선택형 공유 접속 코드, HttpOnly/SameSite 쿠키. HTTPS 프록시 환경에서는 Secure 쿠키.
- 모델 JSON·인용·값 일치 검증. 문서 지시문을 도구 실행 명령으로 사용하지 않음. 모델에는 도구 실행 권한 없음.
- 프로젝트 전용 환경 설정과 Docker 영구 볼륨. 기존 PoC DB·설정·사용자 파일에 연결하지 않음.

## 남아 있는 경계

- 역할 선택은 클라이언트가 바꿀 수 있는 **시연 역할**입니다. SSO/RBAC·실명 확인·문서별 사용자 ACL이 아닙니다. 공유 접속 코드를 가진 사람은 워크스페이스 자료를 함께 봅니다.
- 접속 코드 기능은 기관 인증 대체물이 아닙니다. 공개망에서는 TLS·접속 제한·요청률 제한·모니터링이 별도로 필요합니다.
- 문서 파서는 앱 프로세스에서 실행합니다. 용량 제한은 있지만 악성 파서 취약점이나 CPU 소모에 대한 완전한 격리가 아닙니다. 컨테이너의 비루트·메모리/CPU 제한을 권장합니다.
- 문서별 의미 검토와 업무 누락률은 자료 유형에 따라 달라집니다. 원문 인용이 있다고 추출값의 의미까지 검증된 것은 아닙니다.
- 외부 모델 연결은 사용자 선택이며 외부 API 비용이 발생합니다. 보존 정책·개인정보·기밀 검토를 대신하지 않습니다.
- 원문은 계속 보존합니다. 삭제·법정 보존기간·암호화 백업·별도 감사 서버는 이번 버전에 없습니다.
- 운영 로그는 오류 유형을 기록하며 내부 경로·모델 키가 화면에 나오지 않도록 처리합니다. 완전한 침투시험·공식 보안 인증을 수행한 것은 아닙니다.

## 형식별 실제 지원

| 형식 | 추출 내용 | 빠질 수 있는 부분 |
|---|---|---|
| HWP5/HWPX | 본문 문단·표행, 병합 시작 셀 | 도형·그림 의미, 머리말·각주, 편집기 배치 |
| PDF | 페이지별 텍스트와 줄 | 스캔 OCR, 읽기 순서, 복잡한 표 구조 |
| DOCX | 본문 문단·표 | 머리말·꼬리말·주석·텍스트 상자 |
| XLSX | 시트/셀 좌표·값·날짜·수식과 저장 계산값 | 수식 재계산, 차트·도형·시각적 병합 의미 |
| TXT/MD | UTF-8 또는 CP949 줄 | Markdown 의미 구조의 완전 해석 |

지원 범위 밖의 텍스트나 이미지가 포함될 수 있는 HWP/HWPX·DOCX에는 보수적으로 부분 추출 경고를 남깁니다. 스캔 페이지는 텍스트가 없음을 표시합니다. 잘못된 형식을 성공으로 숨기지 않습니다.
