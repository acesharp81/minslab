## 제공 자료

샘플1 ‘종합 인수인계 실무 시연’을 원본 21개(HWPX 9, XLSX 6, 텍스트 PDF 6)로 확장했다. 사업 보고서 19개마다 진척·일정·미결 조치·예산·관계자 표 5개씩 총 95개를 배치했다. 별도 실적·예산 증빙대장과 담당 확인서의 표는 이 수에 포함하지 않는다. 자료는 합성 기관·인물·실적이며 실제 행정 기록이 아니다.

이전 인수 원본 2개, 최신 등록 자료 10개, 나중 등록하는 구판 5개, 마지막 등록하는 초안·제외 판본 4개로 나뉜다. 시연은 기존 직원 선택과 번호 부여 기능을 사용한다. 이미 만들어 둔 인수인계함은 변경하지 않으며 새로 ‘샘플1 → 시연 수행’을 누르면 확장 자료로 생성된다.

## 표 및 공통 정보

HWPX는 실제 표 5개, XLSX는 본문과 표 전용 시트 5개, PDF는 개조식 문단과 선 있는 표로 작성했다. PDF의 관리코드가 좁은 열에서 끊기던 문제는 표 첫 열 폭을 확보해 해결했다. PDF 원본을 화면으로 열어 페이지 분할과 표 가독성을 확인했다.

표에만 있는 관리코드 76개를 모든 사업 보고서에서 추출하고, 선택된 판본의 표 원문을 보고서 근거 API로 조회하는 테스트를 추가했다. 전체 실적·예산·연락처의 문서별 명시적 항목 추출과 최종 집계도 검증했다. 이는 표의 모든 셀 관계를 의미적으로 이해한다는 보증은 아니다. PDF의 다중 행 셀은 줄 단위 텍스트가 될 수 있으며 복잡한 병합 셀·스캔 OCR은 여전히 원본 확인이 필요하다.

최종 예산코드 6개: 편성 400,000,000원, 집행 259,000,000원, 지급예정 45,000,000원, 가용 96,000,000원. 합계가 편성과 일치하고 반복된 공통 예산은 중복되지 않는다. 연락처는 공통 회계 담당을 포함해 6명이다. 이전 안전점검 예산의 기준일을 q77.xlsx와 대조해 수정해야 합계가 확정된다.

## 검증 결과

- 전체 자동 검사 98개 통과. Python 컴파일·프런트 JavaScript 구문 검사 통과.
- 원본 21개 등록 → 계승 생성 → 최신본 선택 → 3개 후보 묶기 → 항목 수정 → 확정 → 의견 전달 → 인수 확인 → HTML/MD/DOCX 출력 통과.
- 초안·검토중·대체됨·폐기 문서를 먼저 올리고 최신본을 마지막에 올리는 역순 등록에서도 같은 최신 진척 선택.
- 실제 브라우저에서 데스크톱·모바일 메뉴, 실제 드래그, 예산 원문 대조 수정, 최종 보고서·직원 전환·인수 완료 검증. JavaScript 오류 없음.
- 최신 그림 1개 선택·구판 그림 2개 제외는 대체 판독기로 범위만 검증. 유료 Solar/GPT 호출 0건. 모델 답변 및 실제 그림 판독 정확도는 이번 검사에 포함하지 않음.

검증 결과 JSON은 `release/public/comprehensive-validation.json`, 재현 가능한 테스트는 `tests/test_comprehensive.py`에 있다. 전체 샘플 ZIP에는 원본 4개 단계 묶음과 점검 안내·정답·검증 결과·동일 최종본 HTML/PDF/DOCX/MD가 포함된다.
