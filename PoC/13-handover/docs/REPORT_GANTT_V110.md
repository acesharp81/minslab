# v1.1 간트와 업무별 보고 흐름

보고서 제목 다음에 항상 전체 업무 간트가 표시됩니다. 계획 기간·원문 달성률·기한 경과·확정 기준일·실제 완료일을 함께 표시하고, 바로 아래에 업무 현안·잔여 업무·다음 조치를 같은 순서로 배치했습니다.

- 단계별 보고서 11개: 3개 업무는 각 3개 보고를 자동 연결하고, 마지막 업무는 2개 보고를 담당자 확인 후 매칭합니다. 초기 5개 후보 → 최종 4개 업무입니다.
- 업무별 최신 원문 달성률: 65%·40%·100%·75%. 2026-11-09 확정 기준: D-3·3일 지연·완료·D-15.
- 날짜가 유일하게 명시된 보고만 시간순 최신 상태로 정리합니다. 이전 실적과 현안·원문 인용은 이력에 남습니다. 완료보고에서 해소된 과거 고장은 현재 우선 현안으로 재등장하지 않습니다.
- 기한 경과·기한 임박·진행 장애가 업무 현안입니다. 문서 불일치와 미확인은 사전 검토와 보고서 참고에서 확인합니다.
- 담당 확인·명칭 매칭은 원본 수정 없이 새 판본에 저장합니다. 인계자와 인수자는 같은 확정본을 봅니다.
- HTML/PDF는 SVG 간트와 추이 그래프, DOCX는 번호별 간트 이미지와 업무·이력 표, Markdown은 동일 사실의 표를 제공합니다.
- 공개 자료는 가상 문서와 그 분석 결과입니다. 개인 자료·키·운영 DB는 포함하지 않습니다.

## 검증

- 외부 모델 없이 자동 테스트 37개 통과.
- 실제 Solar Pro 4 분석: 새 샘플의 작성 정답 39개 조건, 과거 보고를 포함한 원문 인용 177개 일치. 합성 자료 한정이며 일반 자료 정확도를 보증하지 않습니다.
- 브라우저: 담당자 매칭 → 확정 → 같은 보고서 양측 열람 → 인수 확인 → HTML/MD/DOCX/PDF 출력, 모바일 가로 넘침 없음, JavaScript 오류 없음.
- GPT-5.4-mini는 다시 호출하지 않았습니다. 이전 7개 업무 샘플의 1회 평가와 프롬프트 개선을 별도 보존했습니다.
- 최종 예시 PDF는 본문 10쪽입니다. 펼친 원문 부록만 인쇄하며 HTML에서는 전체 근거를 열람할 수 있습니다.
