# v1.1.1 항목별 근거 확인·편집

초안 검토에서 업무 단위 수정 버튼을 각 항목의 연필 버튼으로 바꿨습니다. 업무명·담당·기한·상태·실적·남은 일·현안·다음 조치·협업·연락처·참고를 개별 수정할 수 있습니다. 미기재 보완 안내에도 항목별 연필을 제공합니다.

편집 창은 왼쪽에 현재 값·수정값·확인 사유·수정 이력, 오른쪽에 원문 파일명·인용·본문 위치·주변 본문·원본 다운로드·전체 추출 본문을 표시합니다. 같은 관리번호의 다른 업무 자료는 미매칭 참고 후보로 구분합니다.

저장 시 선택한 항목만 새 판본에 기록하며 이전 값과 근거를 보존합니다. 같은 값을 다시 저장해 담당자 확인을 기록할 수도 있습니다. 기존 확정 보고서는 재확정 전까지 유지합니다. 동시 변경 시 입력 내용을 유지한 채 오류를 안내합니다. 후임자·확정 업무보드에는 편집 버튼이 없습니다.

배포 이미지에서 기존 자동 테스트 37개 통과. 실제 HTTPS 브라우저에서 담당 원문과 관련 계획보고 대조, 선택 항목만 저장, 원본 판본·수정 이력 보존, 사유 누락 검사, 동시 변경 충돌 시 입력 보존, 업무명 취소, 근거 없음 상태, 모바일, 후임자 읽기 전용을 확인했습니다. JavaScript 오류 없음. 이번 검증은 합성 자료와 로컬 규칙을 사용하며 LLM을 호출하지 않았습니다.

사용 위치: 앱 새로고침 → 초안 검토 → 항목 오른쪽 연필 → 근거 확인 후 값·사유 입력 → 이 항목 저장. 최종 보고서 반영은 다시 확정합니다.
