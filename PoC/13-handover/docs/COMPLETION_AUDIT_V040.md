# 업무바통 최종 실행계획 대조 점검 · 0.4.0

사용자의 “더 남은 부분 확인 후 계속 진행” 요청에 따라 첨부 최종 실행계획의 Must/Should와 실제 코드를 대조했습니다. 날짜별 동결 조건은 사용자의 일정 무관 진행 지시에 따라 적용하지 않았습니다.

## 이번에 보완한 부분

| 발견한 공백 | 적용한 내용 |
|---|---|
| 후임자 자연어 질의 미구현 | Solar Pro 4로 관련 확정 필드 선택. 서버가 확정값을 그대로 응답하고 원문 보충은 미확정 배경으로 분리 |
| 일정·R&R·연락망 별도 화면 없음 | 현재 한국 날짜 기준 기한 경과 확인·7일 이내·이후·정기·미확인·완료 구분, 담당/협업/연락처 표 |
| 보고서의 빈 항목을 일괄 확인하기 어려움 | 초안 검토에서 미기재 업무·필드 목록과 보완 버튼 제공. 확정 대화상자에도 남은 항목 수 표시 |
| 여러 파일을 끌어 놓으면 첫 파일만 처리 | 여러 파일·폴더 입력 및 원자적 일괄 등록 API. 개수·용량·경로·중복 검사 후 전부 등록 |
| Compose와 CLI의 볼륨명이 달라질 가능성 | 두 실행 방식이 명시적 `poc13-handover-data` 볼륨을 사용하도록 일치 |
| 주소 링크·뒤로 가기 시 다른 인수인계함 화면이 반영되지 않음 | fragment 변경을 감지해 해당 인수인계함을 조회하고 확정 보고서로 연결 |

원문 기반 연락망에는 명시된 값만 넣습니다. 샘플의 `culture@example.invalid`는 시험용 합성 연락처입니다. 기존 확정본이나 사용자 자료를 새 모델로 일괄 재생성하지 않았습니다.

## 질의응답의 실제 동작

질문은 현재 확정 판본과 해당 판본의 원문 범위만 참조합니다. Solar에는 확정 필드 ID와 값, 최대 5개 관련 원문 블록을 전달하고 답에 필요한 ID만 선택하게 합니다. 서버가 ID의 소속을 검사한 뒤 실제 확정값으로 응답을 만듭니다. 모델이 새로운 기한·연락처·답변 문장을 생성하도록 맡기지 않습니다.

전임자가 수정한 기한은 원문 기한보다 우선하며, 원문 보충은 확정 사실이 아니라는 표시와 함께 접힌 영역에 표시합니다. 답이 없으면 확인 불가로 안내합니다. 이 방식도 관련 항목 선택의 의미 정확성을 보장하지는 않으며 근거를 함께 확인해야 합니다.

응답 중 확정 포인터가 바뀌면 409로 답을 폐기합니다. 질문·확정 자료 외부 전송 동의가 없으면 AI 조회를 차단합니다. 키워드 조회는 별도 로컬 방식이며 모델 실패를 자동 성공으로 대체하지 않습니다. 질문 이력은 화면에서 최근 10개만 유지하며 DB에는 질문 원문을 저장하지 않습니다.

## 실제 검증 수치

- 자동화 시험: **30개 통과**. 최종 Docker 이미지에서도 네트워크 차단·읽기 전용 환경에서 동일 30개 통과.
- 합성 혼합 문서: 12개, 예상 업무 11/11, 원문 인용 89개 일치.
- 문서 해석: 실제 Solar 호출 11회, 10,412토큰.
- 실제 질의응답: 4회, 16,261토큰. 수정된 최종 기한·정산 현안·협의/연락처·없는 생일 질문을 시험했습니다.
- 전체 평가 스크립트 경과시간: 56.02초. 문서 처리와 질의·확정·출력 확인을 포함한 단일 실행이며 평균 모델 응답시간이 아닙니다.
- [실측 JSON](v040-report.json), [합성 질의응답 기록](v040-questions.json), [확정 보고서 HTML](examples/report-v040-expanded.html), [MD](examples/report-v040-expanded.md).
- 실제 웹에서 질의·일정·다중/폴더 등록·보완 안내·보고서·인수·출력 검증 완료. 링크 이동·뒤로/앞으로 가기 통과, JavaScript 오류 0건. [웹 검증 기록](v040-deployment.json).

개별 모델 연결·개발 중 시험·실제 웹 브라우저 시연의 호출은 위 평가 합계에 포함하지 않습니다. 토큰 수는 청구 금액과 다릅니다.

## 현재 범위 밖 또는 별도 검증이 필요한 부분

기관 SSO·사용자별 ACL·실명 확인·전자서명, 비공개 업무자료 보안 승인, OCR, 자유 HWPX 양식 출력, ERP/전자결재 연계는 원 계획의 Later 또는 별도 운영 범위입니다. 이번 버전에 구현된 것처럼 표시하지 않습니다.

현재 남은 검증은 실제 기관의 다양한 문서로 의미 정확도·누락률을 평가하는 일과 타인의 설치 재현입니다. 공모 설명용 영상·신청서·외부 게시도 별도 제출 작업으로 남아 있습니다. 공유 접속 코드를 사용하는 체험 앱의 기능 검증을 기관 운영 승인으로 바꿔 해석하지 않습니다. 시연 역할의 인수 확인은 공식 전자서명이 아닙니다.
