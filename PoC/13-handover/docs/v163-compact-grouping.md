# v1.6.3 업무 묶기와 보고서 상단 작업 개선

- 후보 카드의 중복 제목·담당 표기를 줄이고 메타정보·원문 펼치기를 한 줄에 배치했습니다. 업무명·담당자는 바로 수정할 수 있습니다.
- 왼쪽 묶인 업무와 오른쪽 확인할 업무가 각자 스크롤됩니다. 팝업 제목·요약·저장 버튼은 고정입니다.
- 카드를 드래그한 채 목록 위·아래 끝에 머물면 해당 목록만 자동 스크롤됩니다. 놓을 대상은 강조되고, 놓은 후·닫기·드래그 취소 시 자동 스크롤이 종료됩니다.
- 선택 이동·되돌리기를 유지하고 화면을 다시 그릴 때 목록의 스크롤 위치를 보존합니다. 모바일도 양쪽 목록을 함께 보여줍니다.
- 초안 검토와 인계자용 확정 보고서 상단에 왼쪽 ‘업무 전체 보고 묶기’, 오른쪽 ‘검토 완료·확정하기’를 2열로 배치했습니다. 하단의 중복 확정 영역은 제거했습니다.
- 확정 보고서에서 작업을 시작하면 최신 초안을 불러옵니다. 저장은 기존과 같이 새 판본을 만들고 원문·과거 확정본을 보존합니다.

검증: 독립 합성 자료로 실제 드래그 3개 업무 합치기·저장·되돌리기, 26개 후보의 위/아래 자동 스크롤, 두 목록 독립성, 선택 후 스크롤 유지, 보고서 작업 버튼의 최신 초안 연결, 390px 모바일 양쪽 배치·가로 넘침 없음, JavaScript 오류 없음 확인. 결과는 `test-results/grouping-compact/browser.json`. 외부 모델 호출 없음.
