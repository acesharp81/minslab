## 원본 설계

기존 단계별 보고 11개를 유지하고 실무 기준정보, 공통 예산·연락망, 실행대장, 담당 확인 기록을 추가했다. 모든 금액·인물·연락처·대장은 명시적인 합성 자료다. 실제 영수증·결재문·사진을 제공한 것처럼 표현하지 않는다.

- 업무 1~3: 같은 업무명·담당의 진행보고 자동 연결.
- 업무 4: 별칭과 담당 미정으로 분리. 동일 전체 범위·진행률 기준을 확인한 기록을 사람이 대조하고 매칭.
- 문서역할 ‘업무기준정보’: 개요·목표·계획·절차 등을 유지하며 진행 상태·보고 진행률을 덮어쓰지 않음.
- 문서역할 ‘증빙대장’: 검색·열람 대상. 대장 항목 수만큼 업무를 생성하지 않음.

## 보고서 계약

확정된 한 판본에서 HTML·PDF·DOCX·MD를 만든다. 상단 일정·달성률·지연 간트 → 업무 현안 우선순위 → 각 업무 A(개요·목표·범위·추이·현재 실적·현안 경과) / B(추진·추후 계획·절차·완료 기준·자료·결재) → 공통 예산·관계자 → 원본 색인과 참고 순서다.

개요·목표 등은 원문 인용을 보존하고 모델이 빈 부분을 임의 작성하지 않는다. 실적/목표 비율, 예산 합계는 명시된 수치에서 계산하는 표시다. 전체 업무 진행률은 원문의 명시 값이다. 인수 확인 체크리스트는 시스템 권고로 표시한다.

동일 예산코드·관계자ID는 중복 제외한다. 같은 코드의 값이 충돌하거나 예산 산술·기준일이 맞지 않으면 전체 예산 합계를 확정하지 않는다. 미래 산출물과 실제 제공 자료를 구분한다. 과거 현안 해소는 후속 확인 기록이 있어야 설명한다.
