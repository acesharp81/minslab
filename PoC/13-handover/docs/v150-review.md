# 업무바통 v1.5 개선·검증 결과

## 적용한 변경

1. **동일 파일명 여러 판본**: 업로드 순서나 경로별 마지막 파일로 미리 줄이지 않는다. 모든 불변 원본을 본문 기준일·관리번호·차수·수정일시·문서상태로 비교한다. 기존 확정본은 보존한다. 미처리 판본이 있으면 확정·예전 작업 재시도를 막고 새 초안 생성을 안내한다. 같은 내용·같은 경로 재등록은 중복으로 재사용한다.
2. **직원 1~4**: 직원 1→2→3→4→1의 순환 관계. 직원이 각 건에서 인계자인지 인수자인지 서버가 판단한다. `X-Role`을 바꿔도 직원 관계보다 우선하지 않는다. 직원 선택은 시연이며 실제 기관 인증은 아니다. 기존 건은 직원 1→2의 이전 시연자료로 조회하며 기존 보고서에 적힌 이름·확정·인수 시각은 변경하지 않는다.
3. **나의 인수인계함**: 인수·인계 별도 그룹, 최신 생성순, 자료 등록→초안 검토→확정·전달→인수 완료 도식. 완료 목록은 각 그룹 아래 접어서 표시. 4개 진행 건과 2개 완료 이력을 제공한다. 시연 준비를 다시 눌러도 중복 생성·초기화하지 않는다.
4. **그림은 후처리**: 본문 파싱·업무 통합·최신본 선택을 끝낸 뒤 채택된 파일의 내장 래스터 그림만 GPT-5.4로 판독한다. 구판·초안·최신본 판단 보류 자료는 그림을 전송하지 않는다. 문서 본문·문서 전체 파일을 GPT에 보내지 않는다. 결과는 원본 그림과 함께 AI 판독 참고로 표시하며 본문 진행률·담당·최신본 결정값을 자동 덮어쓰지 않는다. 확정 보고서 HTML·MD·DOCX에 참고를 보존하고 PDF는 같은 HTML의 인쇄 결과다.
5. **한도·비용 관리**: Solar 독립 키 $100 추정 잔액 옆에 GPT-5.4 공용 일일 잔여 토큰을 표시한다. PoC7·10·11과 같은 원장에 호출 전 예약·호출 후 정산한다. 기존 허용 클라이언트 `poc7`으로 예약하고 실제 사용 주체는 `poc13-handover`, 용도는 `latest-document-image`로 기록한다. 그림 해시·모델·지침별 결과를 재사용한다. 통신 결과가 불확실하면 재호출을 막고 예약을 미확정 사용량으로 정산한다. 앱이 실제 제공사 결제 잔액을 조회하는 것은 아니다.
6. **여러 업무 묶기**: 전체 후보를 자동 매칭 묶음과 확인할 후보로 표시한다. 드래그 또는 ‘이동’으로 여러 업무를 한 묶음에 넣고, 저장 전 되돌리기·분리·업무명/담당 수정이 가능하다. 모든 묶음을 하나의 새 초안으로 원자적으로 저장한다. 원문·보고 흐름·수정·매칭 이력을 보존하며, 서로 다른 직접 확인값이 있으면 무시하지 않고 먼저 정정하도록 안내한다. 확정본은 재확정 전까지 유지된다.
7. **시작 가이드**: 사이드바는 인수인계함과 시작 가이드만 제공한다. 가이드 안에서 직원 선택부터 인수 확인까지 따라가며 샘플을 내려받는다. AI 모델 연결 메뉴 및 왼쪽 인수인계 목록을 제거했다.

## 비용 대비 효용을 고려해 남긴 제한

- **본문이 없는 스캔 PDF**는 본문으로 최신본을 판단할 수 없으므로 그림 후처리도 보류한다. 그림을 먼저 읽어 최신본을 추정하는 역방향 흐름을 만들지 않았다. 담당자가 내용 기준을 확인할 텍스트 자료를 함께 제공해야 한다.
- PDF 벡터 도형·복잡한 도식·수식·HWP 바이너리 그림은 이번 자동 판독 대상에서 제외. HWPX/DOCX/XLSX 내장 래스터와 PDF 이미지 객체를 지원한다. 작은 장식 아이콘은 건너뛴다.
- 문서당 최대 6개, 인수인계함당 최대 12개 그림, 원본 그림당 8MB·2천만 픽셀 한도. 초과·미지원·실패는 참고 안내로 남긴다. 동일 그림 재사용으로 반복 비용을 줄인다.
- 판독 결과를 자동 확정 사실로 승격하지 않는다. 한글 작은 글씨·표·그래프 판독은 사람이 원본과 대조한다. 기존 이미지 내용은 최신본 선택의 입력으로 역류하지 않는다.
- 한 문서에서 여러 업무를 추출해 개별 기준일을 확정할 수 없는 경우 최신본 판단이 보류될 수 있다. 업무별 문서와 기준일을 명확히 제공하는 것이 우선이다.
- 동일 제목·담당이지만 범위·연도가 다른 업무를 언제나 의미적으로 구분하는 보장은 없다. 관리번호 없는 자동 후보는 확인 대상이다. 대규모 의미 추론을 추가하기보다 전체 그룹핑에서 사람이 검토하도록 했다.
- 기존 자동 묶음은 해당 문서 묶음을 하나의 카드로 보여준다. 저장 전 사용자가 합친 후보는 다시 분리할 수 있으나, 이미 저장된 묶음을 문서 단위로 임의 해체하는 기능은 별도 구현하지 않았다. 이전 판본은 보존된다.
- 긴 본문 60,000자 이후 자동 의미 검토, 복잡한 비정형 예산·연락처 정규화, SSO·전자결재는 기존 제한을 유지한다.
- 기관명·참가자 정보·시연 영상·실제 출품 접수는 사용자 결정에 따라 추후 진행한다.

## v1.5.1 화면·샘플 정리

- 기본 순환 시연은 진행 4건(1→2→3→4→1) + 완료 2건(1→2, 3→4). 각 직원이 보는 기본 시연함은 인수·인계·완료를 합쳐 3건이다.
- 이전 시연자료와 제외한 완료 예시는 삭제하지 않고 ‘보관된 이전 자료 보기’에서 열람한다. 사용자가 새로 만든 인수인계함의 수를 임의 제한하지 않는다.
- PC 인수·인계 카드는 각각 2열. 상단 초록 홍보 박스를 없애고 문서·바통 그림을 소개 문구 앞에 배치했다. 소개·카드 높이를 줄여 인수 2건+인계 2건이 한 화면에 들어가도록 조정했다. 작은 모바일 화면은 가독성을 위해 1열이다.
- 헤더 제목은 Solar Pro 4 (문서분석·답변생성), GPT-5.4 (그림분석). 얇은 사용률 막대는 Solar 실제 기록 사용액/$100, GPT 공용 기록 사용 토큰/일일 한도로 계산한다. 예약·미확정 사용량은 실제 사용률에 섞지 않고 상세 화면에서 구분한다.
