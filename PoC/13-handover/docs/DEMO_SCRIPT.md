# 실제 체험 시연 순서

대상: 합성 자료 5개, 전임자와 후임자 역할 선택. 현재 웹 배포의 기본 시연은 연결된 **Solar Pro 4 실제 분석**입니다. 샘플 버튼은 합성 자료만 전송하며, 직접 올린 자료는 초안 생성 화면에서 외부 전송에 동의해야 합니다. 키 없는 별도 설치에서는 로컬 규칙 추출로 시작합니다.

| 순서 | 화면 조작 | 확인할 사실 |
|---|---|---|
| 1 | 홈 → 샘플로 시작하기 | 문서 5종을 API로 등록·추출한 결과이며 미리 만든 카드가 아님 |
| 2 | 업무자료 탭 → 본문 보기 | 파일별 성공/부분 추출, 파서 경고, 실제 원문 위치 |
| 3 | 초안 검토 → 생활문화 사업계획 기한 근거 | 서로 다른 문서의 11/20과 11/25 인용을 대조 |
| 4 | 본문 검색에 영수증 입력 | 파일명에 없는 표현으로 본문 검색 |
| 5 | 기한을 2026-11-27로 수정, 변경 사유 입력 | 새 판본, HUMAN_ENTERED 출처, 과거 원문 보존 |
| 6 | 수정 이력·과거 근거 열기 | 원문 기한을 수정값의 증거로 위장하지 않음 |
| 7 | 검토 완료·확정, 주의사항 확인 | 문서 확정과 미확인 사실의 구분 |
| 8 | 후임자 역할 선택 → 인수 확인 | 수정된 기한을 포함한 최신 확정본 우선 |
| 9 | MD/HTML 다운로드 | 판본·확정시각·근거·변경 사유·남은 주의사항 포함 |
| 10 | 전임자에서 새 초안 생성 후 후임자 재조회 | 새 초안이 이전 확정본을 자동 교체하지 않음 |

초안의 **모델 사용 기록**을 열어 모델 이름·호출·토큰 수를 확인합니다. 확대 샘플 ZIP 12개를 내려받아 새 인수인계에 등록하면 비정형 문장과 일반 엑셀 표도 시험할 수 있습니다. 무텍스트 PDF는 추출 실패로 표시되어야 정상입니다. 확대 검증 결과는 [SOLAR4_VALIDATION.md](SOLAR4_VALIDATION.md)에 있습니다.

HWPX 샘플은 최소 파서 시험용 구조입니다. 실제 한컴 편집기 출력 호환성 시험은 별도입니다. 형식 전체의 무오류 지원, 기관 인증, 전자서명, 의미검색을 시연 설명에 넣지 않습니다.

## 0.4.0 추가 시연

1. 확정 후 **보고서에 질문**에서 “생활문화 사업계획의 최종 기한은 언제인가요?”를 묻습니다. 원문의 과거 기한 대신 수정한 `2026-11-27`이 표시되는지 확인합니다.
2. “문화기획팀 담당자의 생일은 언제인가요?”를 물어 확정본에서 확인 불가로 표시되는지 확인합니다.
3. **일정·연락망**에서 정기 업무와 미정 일정을 구분하고 문화기획팀 담당·예산팀 협의·합성 이메일을 확인합니다.
4. 별도 합성 인수인계함에서 TXT 파일 여러 개 또는 폴더를 한 번에 등록합니다. 초안 검토의 **보고서 보완**에서 빠진 실적·현안을 확인합니다.
