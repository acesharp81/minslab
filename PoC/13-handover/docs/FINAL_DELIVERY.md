# 업무바통 PoC 13 · 체험 버전 최종 결과

**현재 배포는 0.4.0입니다.** 확정본 질의응답·일정/연락망·다중 파일/폴더 등록·보고서 보완 안내를 추가했습니다. [최종 요구사항 점검서](COMPLETION_AUDIT_V040.md)를 먼저 참고하세요.

**0.3.0에서 보고서를 보강했습니다.** 확정 시 양측에 공통 보고서가 표시되며 진행·완료·잔여 업무·현안·실행 계획을 읽을 수 있습니다. [보고서 보강과 보는 위치](REPORT_V030.md)를 먼저 참고하세요. 아래 0.2.0 실측은 이전 연결 완료 시점의 기록으로 보존합니다.

**Solar Pro 4를 연결한 0.2.0 웹 앱의 구현·배포·실제 흐름 검증을 완료했습니다.**

- 체험 주소: **https://www.minslab.kr/handover/**
- 프로젝트: `PoC/13-handover/`
- 문서: `PoC/13-handover/docs/` — 대문자 `DOC` 폴더가 아니라 이 경로입니다.
- 접속 코드: 프로젝트 전용 Git 제외 `.env`의 `HANDOVER_ACCESS_TOKEN` 또는 운영자가 전달한 코드.

## 직접 체험

1. 접속 코드를 입력하고 **샘플로 시작하기**를 누릅니다. 별도 API 키 입력 없이 Solar Pro 4가 합성 문서 5개를 분석합니다.
2. **초안 검토**에서 업무별 기한·담당·상태·다음 행동과 원문 근거를 확인합니다. **모델 사용 기록**에서 실제 호출·토큰 수를 볼 수 있습니다.
3. 기한을 수정하고 사유를 저장한 뒤 **검토 완료 · 확정하기**를 누릅니다.
4. **후임자** 역할로 바꿔 확정본을 확인하고 인수 확인·MD/HTML 다운로드를 실행합니다.
5. 확대 샘플 ZIP 12개로 비정형 문장·일반 표의 해석도 시험할 수 있습니다. 직접 올린 공개·합성 자료는 외부 전송 동의 후 AI 분석합니다.

## 완료한 범위

혼합 문서 등록·파싱, 문서별 실제 LLM 분석, 원문 인용 검증, 충돌·미확인 표시, 근거 조회·키워드 검색, 전임자 수정 이력, 불변 판본, 확정본 우선 조회, 후임자 확인, MD/HTML 출력, 중단 작업 복구, 접속 코드, 독립 Docker 배포를 포함합니다.

현재 모델은 `solar-pro4`이며 실호출 응답은 `solar-pro4-260806`입니다. 전용 환경 설정과 데이터 볼륨을 사용해 앱 재시작 후에도 연결·확정본이 유지되는 것을 확인했습니다. 기존 PoC 운영 코드·DB·컨테이너는 변경하지 않았습니다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| 자동화 계약·통합 시험 | 20개 통과 |
| 새 Docker 이미지 격리 시험 | 동일 20개 통과 |
| 실제 Solar 확대 평가 | 합성 자료 12개, 예상 업무 11/11 포함 |
| 원문 인용 검사 | 67개 일치 |
| 실제 모델 사용량 | 확대 평가 11회, 7,849토큰 |
| 실제 웹 브라우저 E2E | 분석·수정·확정·후임자·다운로드 통과 |
| JavaScript 오류 / 모바일 가로 넘침 | 0건 / 없음 |
| 재시작 영속성 | 모델 설정·확정 판본 유지 |

소규모 합성 자료의 단일 실행 결과입니다. OCR, 사용자별 ACL·기관 SSO, 전자서명, 자연어 Q&A, 자유 HWPX 출력, 공모 제출·편집 영상 제작은 포함하지 않습니다. 공유 코드를 사용하는 체험용 워크스페이스이며 기관 운영 제품의 보안 검증 완료를 의미하지 않습니다.
