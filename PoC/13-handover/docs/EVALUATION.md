## 주요 반례와 보존 시험

- 생활문화 사업계획의 `2026-11-20` / `2026-11-25`를 충돌로 표시. 전임자가 `2026-11-27`로 바꾸면 새로운 판본·직접 입력 출처·변경 사유·과거 근거를 보존.
- `11월 말`을 임의의 특정 날짜로 바꾸지 않음. `매월 5일`은 정기 표현으로 보존.
- 협의 부서를 담당자로 지정하지 않음. `사전 점검 완료`를 전체 업무 완료로 승격하지 않음.
- 두 동시 수정 중 1개 성공/1개 409. 오래된 판본으로 확정·수정 차단.
- 동일 생성 요청 ID를 완료 후 재전송해도 동일 작업·판본. 반복 확정 요청이 후임자 확인을 지우지 않음.
- 새 자료 등록 후 과거 초안 확정 차단. 새 초안을 만들어도 후임자의 이전 확정본 유지.
- 작업 2번째 문서에서 장애를 주입하고 재시도할 때 첫 문서 결과를 재사용. 재시작 중단 작업을 복원·재시도.
- 다른 사건의 원문·판본·검색 결과 차단. 원문에 없는 모델 인용·값 거절.
- ZIP 경로 위조·고압축 입력 거절. 손상 PDF·미지원 실행 형식·스캔 무텍스트 페이지의 실패 표시.
- 엑셀 빈 셀·확장자 없는 원문 저장·수식 캐시·날짜 위치 시험. 초기 통합에서 발견한 빈 셀/확장자 문제 수정 후 통과.
- HTML 태그를 전임자가 입력해도 다운로드 문서에서 실행 태그로 렌더링하지 않음.
- 모델 요청은 공개·합성 자료 외부 전송 동의가 없으면 차단. 모의 HTTP 모델의 정상 계약·사용량 기록을 검증하고 실제 모델 호출과 구분.

## 남은 범위

- 실제 기관의 다양한 문서로 누락·의미 정확도 확대 평가. 합성 문서 12개 실호출 평가는 완료했습니다.
- 검색 MCP/임베딩은 채택하지 않음. 일반 문서에서 키워드 검색 한계를 별도로 평가해야 함.
- 다른 사용자의 수동 설치 재현, 기관 인증·ACL·보안 시험은 미실행.
- 후임자 자연어 Q&A, 자유 HWPX 양식 출력, 운영 SSO·전자서명, 제출 신청·대회 영상 제작·외부 GitLab 게시 등은 현재 체험 구현 범위 밖.
- 공용 도메인 연결은 사용자 승인 후 완료. [실제 배포 기록](DEPLOYMENT.md) 참조.

기존 PoC의 운영 코드·DB·컨테이너·사용자 파일은 변경하지 않았습니다. 새 앱의 파일·이미지·컨테이너·전용 볼륨을 추가하고, 사용자가 명시적으로 허용한 공용 Nginx의 `/handover/` 경로만 연결했습니다. 기존 홈페이지 HTTP 200 응답을 재확인했습니다.
