# 상세실무편 E2E 시연

1. 자료실에서 practice-samples.zip을 내려받아 새 인수인계함에 등록한다. 15개 원본에서 진행보고 11개는 Solar Pro 4, 명시적 기준정보 3개는 원문 라벨 추출, 증빙대장 1개는 검색·열람으로 처리한다.
2. 초안 5개 후보를 확인한다. 앞의 3개 업무는 각 3개의 단계별 보고가 연결된다. 실무 상세 펼침 영역에서 개요·목표·절차·예산을 확인하고 연필로 원문을 대조한다.
3. 예약포털 접근성 보완 → 같은 업무로 매칭 → 문화시설 통합예약 개선. 09_업무동일성_담당확인.txt의 동일 전체 범위·진행률 기준·담당을 대조해 디지털지원팀으로 연결한다.
4. 4개 업무로 확정한다. 첫 장 간트에서 65%·40%·100%·75%와 기한 경과·임박·완료를 비교한다. 배포 예시는 2026-11-09 기준이다.
5. 공모사업 A면에서 개요·목표·실적·현안 경과를 읽고 B면에서 보완 2건 → 심사 → 결과 결재의 담당·기한·산출물·완료 기준을 확인한다.
6. 정산은 접수 10건과 검토 4건·승인 0건을 구분한다. 안전점검은 이전 유도등 고장의 해소 기록과 다음 점검 준비를 확인한다. 예약 개선은 구현 12건과 미해결 결함 2건을 구분한다.
7. 공통 예산에서 B-COM을 한 번만 합산한 편성 358,000,000원과 집행·지급 예정·가용 잔액을 비교한다. 관계자 11명과 공통 회계·자료 지원 담당을 확인한다.
8. 후임자로 전환해 동일 최종본을 읽고 인수 확인한다. HTML·DOCX·MD와 PDF 저장을 확인한다.

완성 예시는 practice-report.html/pdf/docx/md, 원본 정답은 practice-expected.json, 검증 기록은 practice-validation.json이다. 합성 자료이며 실제 결재·전자서명·영상 제작·대회 접수는 포함하지 않는다.
