# v1.2.0 상세실무편 배포 범위

4개 업무·15개 원본의 E2E 시연과 최종 13쪽 상세실무 보고서를 제공한다. 최상단 간트, 개요·목표·범위·보고 흐름·실적·현안 경과, 담당·기한·산출물별 추후 계획, 실무 절차·완료 기준·자료 위치·결재 경로, 공통 예산 5개·관계자 11명을 종합한다.

Solar Pro 4는 진행보고 11개를 분석했다. 명시적 기준정보 3개는 긴 표의 재작성 오류를 막는 원문 라벨 추출을 사용하고 증빙대장은 검색·열람 대상으로 보존한다. 실무 상세 56개, 최신 사실 28개, 고유 원문 인용 275개를 대조했다. 40개 자동화 테스트와 항목별 편집·양측 열람·모바일을 검증했다. 자체 수용 기준 100/100은 이 합성 사례의 정의된 요구사항 충족을 뜻하며 일반 정확도·외부 인증은 아니다.

기존 GPT-5.4-mini 1회 평가는 이전 7개 업무 샘플의 기록으로 보존하고 신규 샘플에는 그 정확도 수치를 적용하지 않는다. 이번 작업에서 GPT를 재호출하지 않았다.

공개 자료에는 합성 원본·가이드·최종 보고서·검증 기록·실행 소스만 포함한다. 운영 키·DB·사용자 제공 참조 PDF는 공개 ZIP에서 제외한다. 참가자 정보·기관 서류·영상·공공 GitLab 등록·대회 접수는 별도다.
