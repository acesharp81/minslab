# 보고서 목차·챗봇 화면 v1.3.2

인수인계함의 **인수인계 보고서** 탭에서 사용한다.

- **왼쪽 목차:** 실제 확정 보고서의 제목·업무·세부 항목을 읽어 생성한다. 처음에는 상위 주제만 보이며 화살표 또는 상위 제목으로 하위 항목을 펼치고 다시 누르면 접는다. 모바일에서 상위 제목을 눌러도 목차를 유지한다. 제목을 클릭하면 본문만 이동하고 스크롤 중 현재 항목을 표시한다. 이전 양식의 확정본에도 적용한다.
- **가운데 보고서:** 화면 높이 안에서 스크롤한다. 상단의 넓은 작업 통계는 다른 탭에서 볼 수 있으며 보고서 탭은 읽기에 집중한다. 새 창·출력·다운로드는 동일 확정본이다.
- **오른쪽 챗봇:** 확정 보고서의 값과 참고자료 원문을 근거로 질문에 답한다. 답변의 근거 버튼으로 원문을 확인해도 읽던 보고서 위치가 유지된다. 이전 질문은 최대 4개를 문맥으로 사용한다.
- **모바일·태블릿:** 위쪽 목차·챗봇 버튼으로 패널을 열고 닫는다. 목차에서 항목을 선택하면 패널을 닫고 본문을 보여준다.

AI 질의는 Solar Pro 4에 질문·이전 질문·확정본·관련 원문을 전송하는 데 동의한 뒤 사용한다. 키워드 검색은 외부 전송 없이 동작한다. AI는 질문에 대한 결론·이유·실행 행동을 문장으로 종합한다. 각 문단의 인용 ID가 현재 확정본·원문 안에 존재하는지 서버에서 검증한다. 근거 확인을 펼치면 실제 값·검토 상태·원문을 확인할 수 있다. 인용 ID 검증만으로 생성 문장의 의미까지 자동 보증하지는 않는다. 우선순위는 AI 판단으로 표시한다. 확정값과 참고자료의 과거 기록을 구분한다.

예: “보조금 정산 남은 업무는?” → “그럼 담당은?” → 원문 근거 열기. 원본만 있는 자료는 참고자료 영역에서 확인한다. 확정본에 답이 없으면 확인이 필요하다고 안내한다.

새 인수인계함·새 확정 판본으로 바뀌면 대화 범위를 초기화한다. 새 초안·추가 업로드는 기존 확정본 답변에 자동 혼합하지 않는다. 응답 도중 확정 판본이 변경되면 답변을 폐기하고 최신 보고서 조회를 안내한다.

## 검증 기록

이전 v1.3.0 검증: 1600×1000 화면의 본문 내부 스크롤·목차 이동과 현재 항목 표시, 1100×800·390×844 화면의 목차·챗봇 패널, 질문·근거 열람 전후 보고서 위치 유지, 다른 탭의 일반 스크롤 복원을 실제 브라우저에서 검증했다. Solar Pro 4 실제 질의 1회와 키워드 검색·후속 질문을 확인했고 JavaScript 오류는 없었다. 전체 기능 검사 41개를 통과했다. 상세 실행 기록은 test-results/reader/local/result.json에 보관한다. GPT 추가 호출은 하지 않았다.

## 상단 역할과 추정 잔액

상단은 스크롤해도 고정된다. 전용 키별로 문서 분석·재시도·챗봇·연결 시험의 토큰 사용량을 기록한다. 새 키는 별도로 집계하고 같은 키로 돌아오면 기록을 이어간다. $100에서 정가 기준 추정 사용액을 차감한다. 집계 시작 이전·외부 사용, 할인·세금은 반영하지 않으며 미확인 호출은 별도 표시한다. 실제 잔액은 잔액 버튼 안의 Upstage 콘솔에서 확인한다. 이 표시는 결제 한도 차단 기능이 아니다.

v1.3.1에서는 자동 검사 44개, 확장 목차, 상단 고정, 공개 주소의 PC·모바일 화면을 추가 검증했다. 실응답 검증 중 중복 근거 목록 불일치와 과도한 인용 수 제한을 수정했다. 존재하는 판본 내 근거인지 검증하는 조건은 유지한다.

## 실시간 답변 출력

보고서 오른쪽 챗봇과 ‘보고서에 질문’ 탭 모두 Solar가 생성하는 문장을 수신 즉시 커서와 함께 표시한다. 전체 답변이 끝난 후 출처를 검증해 근거 버튼을 붙인다. 생성 중에는 미완성 상태이며 연결 중단·검증 실패·확정 판본 변경 시 해당 미완성 문장을 제거한다. 화면을 이동하면 진행 중 요청을 취소한다. 스트림의 최종 토큰 사용량을 기록하고 최종 사용량을 받지 못한 중단 요청은 비용 미확인으로 남긴다.
