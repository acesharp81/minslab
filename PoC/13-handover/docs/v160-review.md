# 업무바통 v1.6.1 개선·검증 기록

## 사용자가 확인할 위치

- 홈 → **시연 및 샘플 데이터 다운**: 3개 시연을 실행하거나 같은 원본을 내려받습니다. 인계자·인수자를 선택하며 이름은 `4개 업무 복합 처리 시연 (1)`, `파일명, 버전 혼선 시연 (1)`, `업무연결 시연 (1)`처럼 시연별 번호가 붙습니다.
- **시작 가이드 → 시작하기**: 가상 화면에서 5단계 조작 위치를 밝게 강조합니다. 다음·이전·닫기를 지원하며 실제 역할·자료·보고서·모델에 변경을 일으키지 않습니다. 팝업 입력 오류는 모달 내부에 표시합니다.
- **초안 생성 → 이전에 인수한 보고서 이어서 작성**: 현재 인계자가 인수 완료한 확정본을 선택합니다. 샘플3은 이전 업무 2건에서 갱신 1건·유지 1건·신규 1건으로 최종 3건을 구성합니다.
- 보고서 상단에 이전 인수 완료 이력과 이번 인계가 표시됩니다. 이전 기록을 유지한 업무에는 최신 현황 재확인 안내가 붙습니다.
- **원문 기록 확인**: 팝업에서 인용·파일명·위치를 대조하고 닫으면 읽던 위치로 돌아옵니다. 원본 자료 색인·인계 범위 항목은 본문에서 제거했습니다. 내려받은 HTML에도 같은 팝업이 동작합니다.

## 기준본 계승 원칙

1. 서버에서 현재 인계자와 이전 보고서 인수자의 동일성을 확인합니다. 미확정·미인수 보고서와 임의 판본은 기준으로 선택할 수 없습니다.
2. 선택 순간의 확정 판본·해시·인수일·이력을 작업 설정에 고정합니다. 자료·블록은 새 인수인계함에 별도 식별자로 복제하므로 새 인수자가 이전 함 전체에 접근할 필요가 없습니다.
3. 본문의 사업번호 또는 충돌 없는 동일 업무명으로 연결합니다. 날짜가 명확한 새 자료에 기재된 항목만 갱신합니다. 빠진 항목·수동 보완은 이전 값을 보존합니다. 변경 전 값과 원문 근거도 보존합니다.
4. 미승인 초안·과거 자료·불명확한 최신본은 기존 확정 사실을 자동으로 덮어쓰지 않습니다. 애매한 후보는 검토 대상으로 남깁니다. 새 자료가 없는 기존 업무는 삭제하지 않고 유지하며, 신규 업무는 추가합니다.
5. 다시 확정·인수한 보고서를 다음 직원이 계승할 수 있습니다. 과거 이력은 누적되며 현재 인계일은 실제 확정일입니다. 시연의 2026-01-10은 명시적인 합성 완료일입니다.
6. 옵션을 해제하면 새로 등록한 자료만으로 생성합니다. 이전에 복제한 근거는 과거 판본 열람을 위해 보존하지만 신규 분석 대상으로 쓰지 않습니다.

## 화면·사용량·데이터 정리

- 문서·바통 아이콘을 제목 왼쪽에 배치하고 큰 녹색 소개 박스를 제거했습니다. 얇은 구분선·아이보리 배경·강조선을 사용한 컴팩트 헤더로 정돈했습니다.
- PC 1440×900, 1280×800, 1366×768, 1280×720에서 인수 2건·인계 2건의 2열 카드가 화면 안에 들어오는 것을 검증했습니다. 모바일은 1열입니다.
- Solar Pro 4(문서분석·답변생성), GPT-5.4(그림분석)의 막대는 **잔여량**입니다. 사용하면 줄어듭니다. 숫자는 사용률과 실제 잔여량을 함께 보여줍니다. GPT 예약·미확정량도 가용량에서 차감합니다. 사용량 팝업은 실측 입력+출력 사용 / 예약 / 미확정 / 내부 가용량을 구분하고 업무바통 자체 그림 호출량도 표시합니다. 제공사 대시보드의 확정 잔액과 완전히 대조된 수치가 아닙니다.
- GPT는 PoC7·10·11 공유 한도입니다. 앞선 v1.6.0 UI·계승·샘플 검증은 유료 모델을 호출하지 않았습니다. 해당 단계에서는 기존 GPT-5.4 이미지 검증 1회(입력 836, 출력 33토큰)를 재사용했습니다. 이후 사용자 승인에 따른 실제 자동 전환 검증은 아래 별도 기록했습니다.
- 사용자 요청에 따라 보관 목록의 사용자 생성 건을 포함한 22건을 삭제했습니다. 현재 직원 순환 시연 6건과 해당 판본은 유지했습니다. 삭제 전 비공개 복구용 DB 스냅샷이 있습니다. 빈 보관 메뉴를 제거했습니다.

## 검증 및 범위

- 전체 기존·추가 회귀 테스트 70개 통과. 이후 추가한 수동 보완값·구판 방지 회귀 테스트를 포함해 계승 관련 4개 테스트를 재검증해 통과했습니다.
- 브라우저: 시연 3종 메뉴·다운로드, 인계자·인수자 선택, 실제 계승 생성·확정·인수자 열람, 이력 표시, 원문 팝업/닫기 시 스크롤 보존, 오프라인 HTML 팝업, PC·모바일 가상 안내 5단계, 모달 내부 오류 표시 통과.
- 로컬 검증 기록: `test-results/employees/continuation-browser.json`, `compact-browser.json`, `tour-browser.json`.
- 직원 선택은 시연 기능이며 기관 인증을 대신하지 않습니다. 업무명·사업번호가 불명확하거나 중복된 입력은 사람이 그룹을 확인해야 합니다. 이전 내용 유지가 현재 상태의 자동 확인을 의미하지 않습니다. 보고서 계승은 이전 확정본의 사실과 원문을 보존하며 최신 사실은 새 자료와 검토로 확정합니다.

## 공유 토큰 우선순위 변경

사용자 지시에 따라 GPT 잔여량은 PoC7·10·11·13 공유 잔여 토큰으로 표시합니다. 모든 기본·신규 시연은 GPT 그림 분석을 자동 실행하지 않습니다. 그림 분석 체크박스는 항상 꺼진 상태로 시작하며 사용자가 직접 선택한 생성 요청만 그림을 처리합니다. 시연 준비·가상 안내·일반 초안 생성은 GPT를 호출하지 않습니다. 기존 1회 그림 판독 결과는 기록으로 보존하며 같은 그림은 저장 결과를 재사용합니다.

## GPT 그림 분석 자동 예산 전환 · v1.6.1

- 사용자가 그림 분석을 직접 체크한 경우에만 실행합니다. 기본 초안·시연 준비·사용 가이드는 그림 분석을 자동 실행하지 않습니다.
- GPT-5.4 공용 일일 토큰을 먼저 예약합니다. 1건 예약량 21,000토큰을 충족하지 못한다는 명시적인 거절에 한해 GPT-6.1 Terra로 전환하고 기존 공용 월 $100 원장에 예약·정산합니다. 일일 갱신 후에는 GPT-5.4부터 다시 시도합니다.
- 월 예산 부족·인증 실패·공용 서비스 장애는 호출 중단입니다. 모델 응답의 시간 초과·사용량 불확실에는 다른 모델로 재호출하지 않으며, 미확정 비용을 보수적으로 보류합니다.
- 상단 한 칸에 GPT-5.4 공용 잔여 토큰 / GPT-6.1 Terra 월 무료 예산 공용 잔액을 나란히 확인할 수 있습니다. 각각의 막대는 사용하면 줄어듭니다. PoC7·10·11·13이 함께 쓰는 내부 원장의 추정 가용액이며 제공사 확정 청구 잔액이 아닙니다.
- 운영 중인 공용 게이트웨이는 Luna를 아직 허용하지 않아, 이미 지원되는 Terra를 사용했습니다. 다른 PoC 코드·컨테이너·공용 한도 설정은 변경하지 않았습니다. 예약 명의는 기존 허용 클라이언트 poc7이며 이벤트의 실제 수혜 프로젝트는 poc13-handover입니다.

### 실제 비용을 사용한 검증

사용자가 허용한 총 $5 범위에서 합성 그림 3건을 검증했습니다. 일일 토큰 부족은 모의 조건이 아니라 실제 공용 예약 거절이며, 실제 Terra API 요청·월 원장 예약·정산까지 수행했습니다.

| 그림 | 확인 항목 | 결과 |
|---|---|---|
| 최신 HWPX의 그림 | 확인 완료 5건, 미서명 1건, 추가 요청 3건 | 모두 일치 |
| 기한·예산 현황 | 기준일·승인기한, 검토 수량, 누락 증빙 ID, 편성·집행액 | 모두 일치 |
| 업무별 달성률 차트 | 문화공모 65%, 보조금정산 40%, 시설점검 70%, 예약개선 80% | 모두 일치 |

- 총 3회, 입력 2,916 / 출력 207토큰. 공용 원장 정산액 **$0.009136**. 캐시 쓰기를 보수적으로 포함한 추정 비용입니다.
- 재요청 3건은 저장 결과를 재사용하여 추가 모델 호출 0회. 모든 완료 이벤트의 정산·공용 사용량 전송을 확인했습니다.
- 전체 회귀 테스트 82개 통과, 운영 모델을 Terra로 맞춘 후 관련 예산 테스트 10개 재통과. 최신 파일만 그림을 추출하는 검증과 수동 체크 없는 호출 0회 검증을 포함합니다.
- 결과: `test-results/vision-credit/report.json`. 합성 자료 3건의 회귀 검증이며 임의 문서 전체의 무오류를 보장하지 않습니다.
- 가격·영상 입력 지원 확인: [Terra 공식 문서](https://developers.openai.com/api/docs/models/gpt-6.1-terra), [공식 가격표](https://developers.openai.com/api/docs/pricing).
