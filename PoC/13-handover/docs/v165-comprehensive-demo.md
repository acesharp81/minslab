# v1.6.5 · 샘플1 종합 인수인계 실무 시연

## 구성

기존 시연을 2~4번으로 이동하고 첫 번째에 ‘종합 인수인계 실무 시연’을 추가했다. 직원 선택과 회차 번호는 기존 흐름을 사용한다. 시연 실행은 이전 완료 보고서를 비용 없는 규칙 추출로 준비하고 신규 원본만 등록한다. Solar 및 그림 분석은 사용자가 생성 창에서 직접 선택한다.

원본 13개는 HWPX 7개, XLSX 3개, 텍스트 PDF 3개다. 개조식 제목·대주제·소주제·상세 문단과 실적/후속조치 표를 포함한다. 이전 원본 2개와 현재 자료 11개를 4개 단계 ZIP으로 구분한다. 전체 KIT에는 점검 순서·정답표·검증 결과와 최종 HTML/PDF/DOCX/MD 예시도 포함한다.

## 검증에서 보완한 부분

- 자원 표의 예산 기준일이 보고서 판본 기준일과 섞이지 않도록 문맥을 구분했다. 실제로 상충하는 보고 기준일은 계속 보류한다.
- HWPX 명시적 문단·표 안 줄바꿈을 임시 파싱 사본에서 보존한다. 업로드 원본 바이트·해시는 변경하지 않는다. 파서 버전을 갱신하고 기존 자료 열람은 마지막 사용 가능 파싱 결과로 호환 유지한다.
- 명확한 상태값 ‘사업 완료’를 완료로 인식한다. 부분 완료·완료 예정 등은 완료로 확장하지 않는다.
- 업무를 묶은 뒤 계승 현황 집계를 최종 업무 수에 맞춰 다시 계산한다.

## 검증 범위

종합 자료의 생성·이전본 연결·최신본 선택·3개 후보 그룹·예산 및 항목 수정·확정·의견 전달·인수·출력을 규칙 기반으로 검증했다. 그림 후처리는 대체 판독기를 사용해 전송 대상 범위를 검증했으며 실제 유료 판독 정확도 평가는 하지 않았다. 기존 Solar/GPT 평가를 새 자료 평가로 표시하지 않는다. 새로운 유료 모델 호출은 없다.
