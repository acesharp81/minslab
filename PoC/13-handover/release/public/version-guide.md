# 파일명·버전 혼선 검증 시연

모든 기관·사업·인물·연락처·금액은 합성 시연 자료입니다. 실제 부처 공문이 아닙니다.

## 실행

1. 업무바통 홈에서 **파일명·버전 혼선 체험**을 누릅니다. 또는 새 인수인계함을 만들고 `version-samples.zip`을 등록합니다.
2. Solar Pro 4로 초안을 생성합니다. 비정형 개조식 본문을 읽는 샘플이므로 라벨 규칙 모드 대신 AI 모드를 사용합니다.
3. 업무가 4개로 묶이고 아래 최신 상태가 채택되는지 확인합니다. 항목별 연필 버튼에서 원문을 대조합니다.
4. 검토 후 확정하여 보고서 최상단의 간트·달성률, 각 업무의 기준본·흐름, 접힌 판본 채택 근거를 확인합니다.
5. 인수자로 전환하여 같은 보고서를 엽니다. 파일명·순서 변경 ZIP은 **별도 인수인계함**에서 시험합니다. 같은 함에 재업로드하면 내용 해시 중복 제거가 적용됩니다.

## 기대 결과

| 사업 | 최신 파일 | 본문 기준 | 진행률 | 검증 포인트 |
|---|---|---|---:|---|
| 지역생활서비스 통합지원 | 1234.pdf | 11/08, 3차 | 65% | 같은 날 2차의 80%를 하향 정정 |
| 공공시설 안전관리 고도화 | 붙임.xlsx | 11/08, 3차 | 70% | 11/06 기한 경과, 위험시설 조치 미완료 |
| 디지털 민원안내 표준화 | 새 문서.hwpx | 11/08, 3차 | 90% | 담당 이서준 → 정여울 변경 |
| 취약계층 돌봄연계 | abc.xlsx | 11/08, 3차 | 55% | 11/09 작성된 100% 초안 제외 |

본문 형식: 제목 → □ 대주제 → ○ (소제목) 내용 → - 상세 내용. 사업별 3개 판본에 초안 1개를 더한 13개이며 정답표는 입력 ZIP에 포함하지 않습니다.

## 예외 시연

각 ZIP을 새 인수인계함에 따로 등록합니다. `version-edge-conflict.zip`은 같은 날짜·차수·시간의 내용 상충, `version-edge-undated.zip`은 기준일 불명확, `version-edge-reversed.zip`은 차수와 시간 역전입니다. 최신 진행률을 임의로 고르지 않고 확인 필요로 남겨야 합니다.

## 판정 규칙과 범위

파일명·파일 저장시각·등록 순서는 최신성 기준으로 사용하지 않습니다. 본문의 사업명과 관리번호로 같은 사업을 연결하고, 내용 기준일 → 같은 보고서의 수정차수 → 수정일시를 비교합니다. 초안·검토중·폐기·참고본은 현재 사실에서 제외합니다. 기준일이 서로 다른 문서에서는 더 늦게 수정한 과거 실적보다 더 최신 기준일의 실적을 우선합니다.

사업명 또는 관리번호가 달라 동일 사업인지 모호하면 담당자 확인·매칭이 필요합니다. 메타정보가 누락·상충하면 최신본 선택을 보류합니다. HWPX는 정상 패키지·XML 검증과 본문 추출을 검사했으며 한컴오피스 GUI에서의 최종 인쇄 배치 검수는 별도입니다. PDF는 텍스트형이며 스캔 OCR을 시험한 것이 아닙니다.
