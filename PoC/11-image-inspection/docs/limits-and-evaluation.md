# 평가와 알려진 한계

## 현재 검증 범위

원문 보존, 결과 상태, 범위 밖 격자, 다중 인스턴스, EXIF 회전, 비율/crop 매핑, 권한, 업로드, 시연, 검토 이력, 캐시, 재검사, 보고서 및 API 장애를 자동 테스트한다. 합성 샘플의 고정 결과는 UI/상태 흐름 시험이며 모델 정확도 평가가 아니다. 실제 태극기 퀴즈 이미지로 전체 156개 행동 검사, 관찰 재사용 모델 변경, 화면 겹침과 다운로드 실패 복구를 검증했다. 이 한 사례는 일반적인 정확도 평가를 대체하지 않는다.

## 정확도 평가

첨부 요구사항 9.3의 25개 시나리오를 실제 정상/오류/가림/거울/주먹/캐릭터/복수 객체 이미지로 구성하고, 두 명 이상이 독립 라벨링 후 합의한다. 원문 규칙과 객체별 셀을 라벨에 포함한다. 문서 근거가 없는 경우 정답도 REVIEW로 분리한다.

JSONL 한 줄 예:

```json
{"rule_id":"D-02-e","expected":"FAIL","predicted":"REVIEW","expected_cells":["R02C03"],"predicted_cells":["R02C03","R02C04"]}
```

`python scripts/evaluate.py labels.jsonl`은 규칙별 정밀도·재현율·오탐·미탐·검토율·오류율·NA 정확도·셀 IoU·과도 표시율을 계산한다. 실제 FAIL에 REVIEW/ERROR/NOT_RUN인 경우 탐지 성공으로 계산하지 않는다. 표본 수를 항상 같이 보고한다. 아직 대표성 있는 실물 평가셋이나 정확도 수치는 없다.

## 제품/운영 한계

- 모델이 객체 자체를 놓치는 오류와 OCR 오류는 여전히 가능하다. 서버는 스키마·셀 범위·세부 행동 누락을 잡지만 보이지 않은 실제 객체 수를 확정하지 못한다.
- 기본 판독 이미지는 1536px 범위로 줄인다. 작은 한글·괘·손은 주변 포함 확대 재검사가 필요하다. 일반 모델 번호는 격자 근거 위치다. 4괘 로컬 비교는 서버가 계산한 객체 영역을 사용한다.
- 자동 crop 선택과 영상/PDF/다중 카드 일괄 업로드는 MVP 범위 밖이다. 단일 이미지와 수동 선택 crop을 지원한다.
- 참조자료는 텍스트 발췌와 정적 비교 이미지로 등록한다. 태극기의 정면 인쇄 도안은 공식 작도 규칙에 따른 4괘 획·배치를 로컬 비교한다. 일반 공식 도안 이미지의 자동 대조 및 태극 곡선·색도·치수의 전체 적합성은 아직 제공하지 않는다. 원문 문서 자동 파싱·실시간 법령 확인·라이선스 적법성 판단은 구현하지 않는다.
- 공동 검토실의 admin/reviewer 두 역할을 제공한다. 조직 SSO/개인별 계정과 부서별 자료 격리는 후속 범위다. 같은 역할의 사용자끼리는 동일 검토 자료를 본다.
- 비밀번호는 로컬 .env에 보관한다. 실제 키와 이미지·DB·로그는 Git/소스 ZIP에서 제외한다. 공유할 때 `.env`를 함께 전달하지 않는다.
- 개인정보 패턴 마스킹은 보조 수단이다. 이미지 원본 자체의 비식별 처리는 하지 않는다. 노출 위치 검토 목적 자료만 업로드하고, 보고서에는 가능한 최소한의 개인정보를 남긴다.
- 기본 보관기간 설정 30일은 운영 제안값이다. `scripts/cleanup.py`는 dry-run 기본이며 관리자가 기관 정책을 확인한 뒤 `--apply`한다. 원장은 비용 추적을 위해 삭제하지 않는다.
- 단일 worker 프로세스만 지원한다. 서버 재시작 시 미완료 행동은 ERROR로 전환하고, 자동 재과금하지 않는다.
- 중앙 집계/공용 예산 장애 시 live 실행을 중단한다. usage outbox를 동기화한 뒤 재검사한다. 공급자 응답 스키마 오류도 토큰을 소비할 수 있으므로 호출 기록은 유지한다.
- PoC7 PostgreSQL 주소/인증이 바뀌면 `connect_poc7.py`를 다시 실행한다. PoC7 코드/수집기에는 의존하지 않지만 공용 예산 원장은 연결이 필요하다. PoC7의 명시된 월말 갱신 설정을 함께 복사하면 같은 grant 규칙으로 갱신한다. 갱신 설정이 없으면 만료 후 호출을 차단한다.
- 비용은 Standard 요금 기반 보수적 추정치다. 캐시할인·리전·계약 차이에 따라 청구액과 다를 수 있다. 실패 시 비용 미확정 값을 0으로 표시하지 않는다.
