# 2026-11-01 자동 검수 재개 결과

Exploratory 3종을 제외한 14장·61개 정답 항목의 검사를 마쳤다. 오늘 실행·비교 기록 23개를 기존 검수 이력에 추가했고, 어제 기록을 포함해 이미지 14장에 63개 버전이 보존되어 있다. 자동 검사 작업은 종료되었으며 자동 재개하지 않는다.

## 한도와 실제 사용

시작 시점 GPT-5.4 1,000,000토큰, mini 10,000,000토큰을 이번 작업의 고정 상한으로 저장했다. 각 호출은 PoC7·PoC10·PoC11 공용 원장에서 먼저 예약하며, 이번 작업의 별도 원장에서도 예약한다. 일일 갱신이나 다른 서비스의 동시 사용으로 상한을 넘어가지 않도록 두 검사를 유지했다. 6.0·6.1은 이번 원장의 허용 모델에서 제외했다.

| 모델 | 입력+출력 확정 사용 | 미확정 호출에 보존한 상한 | 공용 잔량 |
| --- | ---: | ---: | ---: |
| GPT-5.4 | 747,781 | 15,636 | 236,583 |
| GPT-5.4 mini | 3,549,459 | 266,799 | 6,183,742 |

- GPT-5.4 73회, mini 155회, 총 API 시도 228회. 이 중 응답 미확정 4회는 실제 토큰 수를 알 수 없어 예약한 상한을 그대로 차감했다.
- 6.0·6.1, Solar, OpenRouter, NAVER 추가 호출은 모두 0회다. 로컬 한국어 OCR은 CPU에서 실행했다.
- 종료 시 진행 중 예약 0건, 미전송 사용량 기록 0건. 공용 원장의 잔량과 이번 작업 원장의 잔량이 일치했다.
- 평가 실행 세션 종료로 미확정 mini 호출 3건, OCR 재확인의 응답 미확정 GPT-5.4 호출 1건이 발생했다. 완료한 결과를 보존하고 미완료 행동만 복구했으며 사용량을 환급하지 않았다. 이후 남은 평가는 최대 실행 시간이 있는 별도 일회성 작업에서 완료했다.

잔량은 종료 시점 기록이다. 이후 다른 서비스 사용 및 일일 갱신으로 달라질 수 있다. 근거는 [closing-usage.json](closing-usage.json)과 [report.json](report.json)에 있다.

## 이번 보완

### 문양의 실제 구성 요소 비교

QA_10에서 모델은 기준 도안을 보고도 큰 문양의 막대 수를 잘못 세고, 정상 작은 문양도 다르다고 설명했다. 승인된 도안과 이미지의 정면 단색 원형 문양에 대해 내부의 분리된 도형을 측정하는 경로를 추가했다. 정답 위치를 입력하지 않고, 기존 관찰의 위치 후보와 원본 이미지에서 찾은 전체 원형 영역을 사용한다.

| 사례 | 기준 내부 도형 | 원본 내부 도형 | 측정 결과 |
| --- | ---: | ---: | --- |
| QA_10 큰 문양 | 4 | 3 | 구성 요소 누락 → 오류 의심 |
| QA_10 작은 문양 | 4 | 4 | 도형별 형태·상대 배치 일치 |
| QA_14 정상 문양 | 4 | 4 | 도형별 형태·상대 배치 일치 |

도형 수에는 삼각형과 막대를 각각 포함한다. 기준과 원본의 색상·원형 외곽·내부 구성 요소를 확인하고, 해당 형태의 비교가 가능한 경우에만 H-07-b 결과에 반영한다. 작은 이미지, 가림, 잘림, 다른 색, 다색·질감 문양, 복수 기준의 모호한 대응은 이 경로에서 확정하지 않는다. 복잡한 경찰 표장·견장 전체에 적용되는 범용 판독기로 해석하면 안 된다.

화면에는 원본과 기준 그림, 측정 개수를 함께 표시한다. 앞선 모델 의견은 보존하고 로컬 계산과 구분한다. QA_10의 보완 버전은 원본 관찰·분석을 재사용했으며 추가 API 호출이 없다. QA_14 정상 문양도 별도로 확인했다. [geometry-audit.json](geometry-audit.json)에 측정 위치와 기준 해시를 저장했다.

가상 문양 기준은 테스트 이미지에만 연결했다. 최초 QA_10 기준선에는 이 적용 범위 연결이 빠져 문양 비교가 생략된 문제가 있었으며, 후속 실행에서 바로잡았다. 가상 도안을 공공기관의 실제 공식 자료 목록에 등록하지 않았다.

### 검수 이력과 재개

평가 가져오기를 이어서 실행할 수 있게 수정했다. 같은 결과를 중복 등록하지 않으며 새 버전만 추가하고, 기존 사람 검토 기록과 이후 재분석을 유지한다. 검사 중인 사용자 기록은 덮어쓰지 않는다. 그림·규칙·기준 도안·모델 응답·소스 해시를 저장해 어떤 조건에서 나온 결과인지 추적할 수 있게 했다.

## 한국어 OCR 비교와 남은 문제

같은 관찰을 재사용한 QA_07·QA_10에서 로컬 PaddleOCR와 GPT-5.4의 독립 판독을 비교했다. 원본 문자 crop과 3배 픽셀 확대 조건도 비교했다. 확대는 원본 픽셀 반복이며 획을 새로 생성하지 않는다. API에는 `detail: original`을 사용했다. 공식 문서도 작은 글자에 확대·original detail을 권장하지만, 한국어 및 세밀한 시각 판독의 한계를 명시한다. [OpenAI 이미지 입력 안내](https://developers.openai.com/api/docs/guides/images-vision)

- `안젼한 하루`를 두 판독이 모두 `안전한 하루`로 복원하는 사례가 재현됐다. 판독 일치만으로 실제 철자가 정상이라는 보장은 없다.
- `비빔밤`은 전문 OCR과 GPT 사이에 불일치가 생겨 검토 필요로 남았지만, 실제 오탈자로 확정하지 못했다.
- QA_07의 흐린 문구는 원본 crop 조건에서 FAIL이었으나, 3배 확대에서는 REVIEW로 후퇴했다. 확대가 검출률을 높였다고 판단하지 않았다.
- QA_03의 기관명 오탈자와 본문 흐림은 검출됐다. 날짜의 기준 원고 불일치도 관찰했지만 정책 기준자료가 요구되는 행동에서는 REVIEW로 남았다.
- 손가락 분기와 관련된 이상은 표시했으나, 6개 손가락 사례는 놓쳤다. 띄어쓰기·기념전 오탈자도 남은 미검출이다.

OCR 1배/3배 비교 8개 정답 항목에서는 오류 6개 중 FAIL이 각각 1개/0개였고, REVIEW는 3개/4개였다. 각 조건 1회이며 모델 응답 변동도 있으므로 배율만의 인과 효과를 확정할 수 없다. OCR 전면 활성화나 3배 확대를 서비스 기본값으로 적용하지 않았다. 기본값은 GPT-5.4 그림 읽기 + mini 분석을 유지했다. 실험용 `OCR_VISION_SCALE`의 기본값도 1이다.

## 평가 수치 해석

최신 버전을 이미지별로 합친 기계적 집계는 오류 정답 24개 중 FAIL 7개(29.17%), 정상 정답 34개 중 PASS 10개(29.41%), 전체 REVIEW 16/61개, 위치 또는 해당 규칙 연결이 없는 항목 23/61개였다. 실행 오류 행은 최신 버전에서 모두 해소했다. 원본 판독·OCR 실험·로컬 측정이 섞인 최신 버전 집계이므로 동일 조건의 전체 모델 성능으로 일반화하지 않는다.

다음 이유로 이 수치를 그대로 정확도 또는 전체 오탐률로 부르면 안 된다.

1. 정답의 규칙 번호와 현재 관리 규칙의 의미가 다른 항목이 있다. H-04-n은 현재 국가명·국호 규칙이며 기관명은 D-02-l에서 검출됐다. H-03-b는 현재 OCR/시각 판독 행동이므로 해역 위치 오류를 이 번호의 FAIL로만 채점하면 부정확하다.
2. 지도·괘 오류를 다른 행동이나 넓은 객체에서 언급해도 정답의 세부 위치와 연결하지 못하면 NO_LOCATION으로 남긴다. 오류 의견이 전혀 없다는 뜻과 구분해야 한다.
3. QA_01의 색상 오류 판정에는 방향·단순화 도안의 차이를 섞은 설명이 있고, 정상 소형 태극에도 불필요한 FAIL이 있다. 단순 상태·위치 일치가 올바른 근거를 보장하지 않는다.
4. 정답에 지정된 PASS 영역에서는 같은 규칙의 FAIL이 0개였지만, 정답 밖의 불필요한 경고와 다른 행동의 오판은 별도로 존재한다. 전체 오탐률 0%라는 의미가 아니다.
5. 음식 기준 이미지 미제공, 정책 증빙 부족, 사람 검토가 필수인 규칙은 답안의 기대 PASS/FAIL과 달리 REVIEW를 유지한다. 정답에 맞추려고 실제 모델 결과를 수정하지 않았다.

전체 검출 품질이 충분하다고 결론 내릴 수 없다. 다음에는 한글의 실제 획 판독, 손가락 수, 세부 위치 연결을 우선하고, 현재 규칙과 답안의 의미 대응을 먼저 정리한 뒤 동일 조건으로 전후 비교해야 한다. 성공한 문양 측정은 지원 형태를 제한한 보완 결과로 분리해서 평가한다.
