다행이와 부리부리는 서로 다른 등록 ID와 원본 이미지를 가진다. 소개 PDF의 내장 JPEG를 각각 추출했으며 AI로 다시 그리지 않았다. 2026년 공식 사례에 3D 표현이 있으므로 화풍·자세 차이를 곧바로 오류로 단정하지 않는다. 특정 RGB 수치나 공식 비례를 임의로 만들지 않았다.

정부상징의 백색 Pantone 값은 웹 표와 원본 가이드가 일치하지 않아 채택하지 않았다. 확정되는 RGB 및 원본 도안만 기준에 담았다. 지도 자료는 명칭 확인 안내로 등록했으며 정밀 경계·좌표 비교용 지도라고 표시하지 않았다. 공공누리는 현재 확인된 0유형과 AI유형도 포함하며, AI 학습용 조건과 홍보물 이용허락을 구분한다.

## 범위와 필요한 추가 자료

- H-01·H-02: 개별 역사 사건의 시점·인용문·사진은 해당 기록물 원본이 필요하다. 하나의 공통 도안으로 모든 역사를 검증할 수 없다.
- H-03·H-05·H-06: 명칭 및 언어 공통 안내 외에 실제 지도 축척·장소·시대·의복의 비교 원본이 필요하다.
- H-04·H-07: 이번에 등록한 대한민국 태극기·경찰 계급장·정부상징·행안부 MI·두 캐릭터 범위다. 다른 국가, 군·소방 계급, 다른 공공기관 고유 CI는 해당 기관의 원본을 추가해야 한다.
- H-08·H-09·P-01~P-04·E-01~E-07: 개별 표현의 대상·의도·시점·수용자 맥락을 원문 체크리스트로 검토한다. 상징 도안 일치만으로 정치·윤리적 적합성을 보증하지 않는다.
- D-01: 홍보하는 사업의 현재 법령·공고·지침·금액·기간 원자료가 필요하다.
- D-02: 글자·인체·구조 결함은 실제 이미지 관찰을 요구한다. 공통 기준의 존재 자체를 정상 근거로 쓰지 않는다.
- D-03·D-04·P-05: 각 자산의 라이선스·초상권·개인정보 처리 근거는 프로젝트별 자료다. 공공누리 일반 안내나 공개된 캐릭터 도안으로 허락/동의를 대체하지 않는다.

기준의 텍스트 요약은 해당 부모 체크리스트가 포함된 분석 묶음에만 전달한다. 등록 이미지는 관리자/검토자의 원본 비교용이다. 등록만으로 모든 마크의 픽셀 비교 기능이 생기거나, 이미지 원본이 텍스트 분석 모델로 전달되는 것은 아니다. 기존 검사 보고서는 당시 기준 스냅샷을 유지하며 새 자료는 새 분석에 적용한다.

## 독립 설치와 재현

프로젝트 폴더 및 소스 ZIP에 검증된 카탈로그와 비교 이미지를 포함했다. 서비스 실행·관리자 암호 설정 후 다음 명령으로 별도 설치에도 등록할 수 있다.

```bash
.venv/bin/python scripts/install_reference_library.py --base-url http://127.0.0.1:18110
```

등록 전 전체 파일 해시와 검증 횟수를 검사하고, 인증된 API로 생성·이미지 첨부·사용 승인을 수행한다. 같은 이름·버전·내용은 재사용하며 기존 자료를 삭제/교체하지 않는다. 이 승인 상태는 검수에 사용할 기준 승인이고 홍보물 공개/사용권 승인이 아니다.

추가 점검에서 경찰 **계급장**과 **기관문양**이 다른 기준임을 확인했습니다. 경찰청/강원경찰청을 교차 확인한 기관문양 자료와 국토지리정보원 지도 및 해양수산부 설명을 대조한 대한민국 도서 위치 자료를 각각 추가했습니다. 현재 11건, 검증 기록 29건입니다. 도서 위치 자료는 제주도 본섬과 마라도, 울릉도와 독도의 관계를 비교하며 정밀 측량·법적 경계 기준으로 확장하지 않습니다. 자료별 해시/범위는 catalog.json에 기록되어 있습니다.
