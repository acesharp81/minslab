# 손 경고·문자 검사 1차 보완 적용

2026-11-04의 [개발 계획](../quality-improvement-plan-2026-11-04.md) 중 P0/P1을 적용했다. **LLM 실제 호출, NAVER 등 외부 OCR 실제 호출은 0회**다. 요청에 따라 실제 모델을 사용하는 성능 비교는 [보류 평가 목록](deferred-evaluation.json)에 남겼으며 자동 실행하지 않는다.

## 적용 내용

### 손과 기본 경고

- 주먹·브이·엄지·쥐기·가림으로 모든 손가락을 세지 못한 `D-02-c~i / READING_LIMIT` 의견은 기본 이미지 번호에서 제외하고 기존 상세 의견 목록에 보존한다.
- 여분 손가락·융합·분기·비정상 연결의 구체적인 이상 관찰은 계속 노랑/빨강으로 표시한다. 기존 오류 판정을 일괄 정상으로 바꾸지 않는다.
- 새 관찰과 확대 판독에 `hands`를 추가했다. 인물 기준 좌우, 자세, 전체/일부/가림, 보이는 구조, 가림 원인, 실제 이상 소견을 분리한다. 예전 기록은 빈 배열 기본값으로 호환한다.
- 실제 이상 관찰이 있는데 분석이 정상으로 처리한 경우는 관찰 근거가 있는 REVIEW를 보존한다. 자연스러운 가림만으로 FAIL이나 필수 REVIEW를 요구하던 분석 지침은 수정했다.

### 문자 후보·원본 재판독·철자

- 로컬 OCR을 기존 확대 검사보다 먼저 수행한다. 탐지 결과와 최초 관찰을 위치로 연결해 판독 일치·불일치·전사 없음·관찰 누락 후보·낮은 인식 신뢰도·연결 미확정으로 구분한다.
- 반복되는 동일 문구를 첫 번째 객체에 임의 연결하지 않는다. 위치가 구분되면 해당 객체로 연결하고 겹치면 미확정으로 보존한다.
- 중요한 누락·불일치 후보에 대해 기본 최대 **3영역/1묶음**의 GPT-5.4 원본 crop 재판독 경로를 연결했다. OCR 전사·예상 정답·사전을 이 독립 판독 입력에 제공하지 않는다.
- 새 경로는 기존 자동 확대의 **총 3호출·9객체 상한을 공유**한다. 문자 재판독에 사용한 호출·영역만큼 일반 확대의 남은 상한이 줄어든다. 새 상한을 기존 상한 위에 더하지 않는다. 별도로 선택 활성화할 수 있는 종전 전체 OCR 경로는 현재 `OCR_ENABLED=false`를 유지한다.
- 분석만 재실행할 때는 새 문자 이미지 호출을 하지 않는다. 선택 판독 실패는 재시도하지 않으며, 해당 영역 밖의 정상 결과까지 미확정으로 바꾸지 않는다.
- 원본 재판독과 OCR이 일치한 문구는 기존 mini 철자 검사로 보낸다. 전사 미확정 문구도 후보로 보존하지만, mini가 수정안을 냈다는 이유만으로 홍보물 오타 FAIL로 만들지 않는다.
- 실제 획 손상·오타와 도구 간 판독 불일치를 구별한다. 명확한 획 결함 근거 없이 엔진만 다른 결과를 낸 경우는 기본 경고보다 진단 목록에서 확인한다.
- 픽셀 측정의 제외·미지원·영역 상한 사유를 각 탐지 영역에 기록한다. 상세 실행 정보에 ‘문자 검사 대상 · 누락·미처리 사유 보기’를 추가했다. 로컬 형태 일치는 철자·획 정상의 최종 인증이 아니다.

### 승인 원고와 명칭 기준

- 승인 원고 템플릿에 객체 ID를 포함한다. 동일한 라벨이 여러 곳에 있어도 `object_id`로 구분할 수 있고 선택적인 `rect`로 대상 영역을 제한할 수 있다. 이미지 해시·원문 라벨·위치가 맞지 않으면 대조를 보류한다.
- 기존 행정안전부 기준의 적용 문맥에 책등·표지석을 추가했다. 새 기관명 사실을 자동 등록하지는 않았다.
- 언어 기준자료에서 `chekmi-term-dictionary-v1` 구조를 지원한다. 항목별 출처·별칭·대상 문맥·적용 기간·규칙 범위·심각도를 검증하고 승인된 스냅샷만 사용한다. 기존 일반 설명형 언어 자료도 계속 허용한다.
- 매칭용 유니코드·대소문자 정규화와 원문 표기를 구분한다. 전각·분해형 문자를 매칭하더라도 표시하는 OCR 원문을 고쳐 쓰지 않는다.
- 역사적 인용·옛 명칭·잘못된 표현을 설명하는 문맥은 진단 REVIEW로 분리하며, 별도로 확인된 실제 결함 FAIL은 유지한다.

## 운영 설정

`.env.example`에 다음을 추가했다. 실제 키나 공용 할당량 설정은 바꾸지 않았다.

```dotenv
# 기존 AUTO_VERIFY_MAX_CALLS=3 / AUTO_VERIFY_MAX_OBJECTS=9와 함께 집계
TEXT_ROUTING_RECHECK_ENABLED=true
TEXT_ROUTING_MAX_REGIONS=3
```

새 GPT-5.4 보조 판독은 향후 사용자가 직접 검사할 때 조건에 맞는 경우에만 실행된다. 기존 PoC7 공용 일일 예산 예약·차단을 그대로 통과한다. `TEXT_ROUTING_RECHECK_ENABLED=false`이면 로컬 후보·누락 기록만 남기고 해당 재판독 호출은 하지 않는다. 전체 OCR을 일괄 활성화하거나 월 크레딧 모델로 자동 승격하지 않는다.

## 사용 가능한 용어 사전 형식

관리자 기준자료에서 **언어** 유형을 선택하고 출처 URL·버전·적용 상위 항목을 입력한 뒤 아래 형식의 JSON을 내용에 넣어 등록·승인한다. 예시는 형식 설명이며 자동 등록된 자료가 아니다. 출처와 사용 시점은 관리자가 확인해야 한다.

```json
{
  "schema": "chekmi-term-dictionary-v1",
  "version": "내부-검토-버전",
  "terms": [{
    "id": "기준-식별자",
    "canonical": "승인된 표기",
    "aliases": ["검토할 다른 표기"],
    "context": ["기관명", "간판"],
    "sources": ["https://공식출처의-실제주소"],
    "rule_ids": ["D-02-l"],
    "valid_from": "2026-11-04",
    "valid_until": "2026-12-31",
    "severity": "REVIEW"
  }]
}
```

결정적 문자 대조는 기존 일반 오탈자 행동에만 적용한다. 정책·사회적 표현의 의미 판단은 기존 원문 규칙과 문맥 분석의 범위다. `severity=FAIL`도 이미지의 전사 독립 확인과 대상·규칙 범위 조건을 통과해야 하며, 단어 포함만으로 오류를 확정하지 않는다.

- 저장 결과 재생에서 다음처럼 표시가 바뀌었다. 의견 자체나 저장된 모델 판정은 수정하지 않았다.

| 자료 | 기본 이미지 번호: 직전 → 이번 | 기본 번호에서 제외하고 상세에 보존한 손 판독 한계 의견 |

| Exploratory 01 | 8 → 5 | 12 |
| Exploratory 02 | 8 → 5 | 3 |
| Exploratory 03 | 9 → 6 | 10 |

이 수치는 화면 재생 결과이며 실제 이미지의 결함 검출률·오탐률 향상을 입증하는 수치가 아니다. 새 관찰 스키마·원본 재판독·mini의 실제 응답 품질은 보류된 모델 평가에서 확인해야 한다. 일반화된 정상 손 경고율을 측정하려면 별도의 정상 자세 라벨 표본도 필요하다.
