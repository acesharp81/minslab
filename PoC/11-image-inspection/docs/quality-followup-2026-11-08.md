# 2026-11-08 손·문자 검수 보완 및 일일 한도 평가

## 적용 범위

이 보고서는 11월 6일 통합 검사에서 남은 손 중복, 한북/한복 판독, 미완료 대조 평가의 후속 기록이다. 기존 25개 원문/156개 행동과 검수 이력·공용 사용량 체계를 유지한다. 정답 JSON은 사후 평가에만 사용하며 이미지 판독 요청에 기대 문자열·정답 ROI를 넣지 않는다.

### 한글 자모를 먼저 읽는 경로

독립 음절 판독의 GPT-5.4 요청을 초성·중성·종성 및 모음 획 방향 판독으로 바꿨다. 완성 음절은 서버가 유니코드 조합식으로 만든다. 읽은 모음과 획 방향이 모순되거나 자모가 미확정이면 `□`로 남긴다. mini는 같은 음절을 별도로 읽어 비교한다. 기존 2회 요청을 유지하며 세 번째 문자 요청을 추가하지 않는다.

순서·단어·이전 OCR 문자열은 두 요청 모두에 보내지 않는다. 원근 보정은 분할 위치 측정에만 사용하며 실제 판독에는 원본 픽셀을 보낸다. 두 모델의 판독 차이는 위치가 있는 REVIEW 근거이며, 특정 오탈자의 정답을 확정하는 FAIL로 승격하지 않는다. 실제 획 손상은 문자 정체와 별도로 유지한다.

초기 11음절 묶음은 medium 추론/출력 5,000토큰에서 출력 한도에 걸렸다. low 추론으로 바꾼 뒤 같은 원본 11음절의 두 독립 판독이 완료됐다. 실패 호출도 사용량에 포함한다. 운영 경로에는 무한 재시도나 유료 모델 전환을 넣지 않았다.

### 손 구조와 제한된 로컬 도안 측정

손 끝뿐 아니라 접힌 끝마디·손톱·관절도 별도로 추적하도록 했다. 관찰된 추가 손가락은 `EXTRA_DIGIT`로 기록하여 D-02-e에 연결한다. mini와 GPT-5.4를 비교했으며 기본 손 구조 모델은 GPT-5.4를 유지한다.

정면으로 펼친 단색 손 도안에 한해서 색상 마스크, 외곽, 여러 높이의 연속 단면을 측정한다. 상단 돌출부와 옆 돌출부를 세며, 6개 이상이면 추가 형태 확인을 요청한다. 사진·음영 있는 삽화·주먹·잘린 외곽·복잡한 배경은 이 방법에서 제외한다. 측정 불가를 경고로 만들지 않으며, 5개가 측정돼도 정상 인증을 하지 않는다. 로컬 측정과 모델 의견은 별도 근거로 표시한다.

외곽 및 오목한 지점 계산에는 OpenCV의 contour/convexityDefects를 사용했다. API가 인체 오류를 판단하는 것은 아니며 도안 적용 조건과 돌출부 계산은 이 프로젝트의 제한된 구현이다. [OpenCV 공식 구조 분석 문서](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)

### 실제 전체 실행에서 확인한 결과 병합 오류

그림 단계가 `복 ↔ 북` 충돌과 위치를 저장했으나, 분석 단계가 같은 GLY 객체에 일반적인 REVIEW를 먼저 만들면 독립 판독의 구체적인 이유·표출 분류를 복사하지 않는 오류가 있었다. 기존 구현은 PASS/NOT_APPLICABLE 또는 획 결함 FAIL일 때만 이를 교체했다. 따라서 판독에 성공해도 최종 결과에는 “문자가 또렷함, 사람 검토 필요”만 남을 수 있었다.

구체적인 판독 충돌이나 위치가 확인된 원본 결함은 기존 REVIEW에도 병합하도록 수정했다. 원래 분석 의견은 `before_glyph_audit`로 보존하며, 결과 행을 중복 생성하지 않는다. 단순 미판독은 이 조건에서 제외하여 경고를 무조건 확대하지 않는다. 같은 보호 함수를 여러 번 적용해도 원래 의견을 보존하는 회귀 검사를 추가했다.

음절 확대에서 다른 글자의 판독 차이가 추가되면 앞서 남긴 영역 OCR/줄 판독 차이의 이유·위치가 사라지는 문제도 수정했다. 두 독립 판독으로 해소되지 않은 기존 충돌은 유지하고, 음절 수가 일치할 때 기존 차이의 음절 좌표를 연결한다. 정답을 주입하거나 미확정 전사를 확정하지 않는다.

### 설정·이력

- `JAMO_ISOLATED_ENABLED=true`: 기본 독립 음절 경로에 자모 판독 적용. 기존 문자열 방식은 false로 선택 가능.
- `HAND_AUDIT_MODEL=gpt-5.4`: 무료 일일 모델인 5.4/mini만 허용. 비교 실험에서 mini로 바꿨지만 운영 기본은 유지.
- `HAND_GEOMETRY_ENABLED=true`: 조건에 맞는 단색 손 도안의 로컬 측정.
- 새 자모 호출은 결과 상단의 2단계 그림 정밀 확인 토큰에 포함한다. 문자 상세에서는 자모와 실제 획 근거를 표시한다.
- 새 경로를 실행하려면 그림부터 읽어야 한다. 분석 재실행은 저장 관찰을 재사용한다.

## 실제 평가

평가 시작 공용 잔량은 GPT-5.4 431,177토큰, mini 10,000,000토큰이었다. 미확정 사용량을 제외하지 않은 잔량이다. 이번 평가 별도 상한은 300,000/2,000,000토큰이며 시간대가 갱신돼도 이 작업 상한은 늘리지 않는다. 모든 요청은 공용 원장의 원자적 예약을 거친다. NAVER 및 월간 유료 크레딧 모델은 사용하지 않는다.

### 기본 그림→전체 분석

Exploratory_01과 QA_03은 그림을 새로 읽고 156개 행동의 전체 분석까지 완료했다. 그 과정에서 발견한 REVIEW 병합 오류를 수정한 뒤 같은 새 관찰을 재사용하여 문자 관련 2개 규칙만 mini로 다시 분석했다. 나머지 154개 결과는 유지한다.

QA_08은 그림 읽기와 OCR을 마쳤지만 추가 확대 확인 중 외부 테스트 프로세스가 SIGTERM(종료 코드 143)으로 종료됐다. API가 실패했다고 단정할 수 없으므로 미확정 GPT-5.4 요청의 41,800토큰 예약을 환급하지 않고 UNKNOWN으로 정산했다. 중단 버전을 보존하고 저장된 새 관찰로 mini 전체 분석을 완료했다. 따라서 이 사례는 정밀 확인 전체 경로를 완료한 대조 검사로 계산하지 않는다. QA_08의 손 자체는 앞선 독립 집중 검사에서 GPT-5.4/mini 모두 추가 이상을 보고하지 않았고, 로컬 측정은 5개였다.
