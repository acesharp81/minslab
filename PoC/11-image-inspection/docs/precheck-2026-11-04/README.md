## 처리 경로와 비용 제어

1. 최초 그림 읽기에는 자료 주제의 짧은 목록만 참고합니다. PDF 전체와 사례 사진을 매번 모델에 보내지 않습니다.
2. 코드는 실제 관찰된 객체·문자와 요청 규칙을 기준으로 요령을 선택합니다. 지도나 국기가 없으면 해당 요령의 시각 비교를 새로 호출하지 않습니다. 대상이 발견되지 않았다는 라우팅 상태는 검출 성공/PASS로 집계하지 않습니다.
3. 기존 mini 분석 묶음에 필요한 요령만 추가합니다. **210개 요령별 호출은 하지 않습니다.** 기존 확대 비교에도 해당 대상의 요령만 연결하며, 사례 사진을 정상 도안으로 선택할 수 없게 막았습니다.
4. 원본 획이 독립 확인된 전사와 OCR 전사를 구분해 철자를 검사합니다. 새 판독은 같은 일일 mini 풀을 사용하고 결과를 캐시합니다. 정상 단어로 문맥 복원된 OCR을 우선하지 않습니다.
5. 결과에 `official_tip_ids`, `precheck_references`를 추가합니다. 이는 참고 지침 연결이며 기존 `reference_ids`/`evidence_status`의 공식 증빙 확인과 별개입니다.
6. 자료 내용·버전·이미지 해시·규칙·플래그가 캐시 키에 반영됩니다. 규칙 본문이 매핑 당시와 달라지면 해당 세부 매핑을 제외하고 재검토 필요로 남깁니다. 과거 검사에는 당시 자료 스냅샷이 보존됩니다.

새 참고 계층 자체의 **추가 모델 호출은 0회**입니다. 원본 획 비교와 철자 보조 검사의 기존 호출 상한은 유지하며, 전사가 바뀌면 mini 보조 검사를 새로 수행할 수 있습니다. NAVER 월 100회 원장과 외부 OCR 동작은 변경하지 않았습니다.

## 실측 비교와 한계

기존 회귀 이미지 중 7장(QA_01·02·03·04·06·08·10)의 **같은 저장 판독, 같은 정본·공식 도안·규칙**으로 A/B를 각각 한 번 실행했습니다. 전체 156개 행동을 재분석했으며 새 이미지 읽기는 수행하지 않았습니다. 정답 30개는 FAIL 15, PASS 14, REVIEW 1입니다. 정답은 오프라인 점수 계산만 읽었습니다.

A는 기존 입력, B는 내부 참고 요령 추가입니다. 지침 추가만 한 raw B에서는 오류 정답 검출이 **9/15 → 7/15**로 떨어졌습니다. 이를 성공으로 채택하지 않고 원본 획 전사의 철자 연결과 기존 FAIL의 위치 보정을 추가했습니다. 공통 철자 근거는 동일 입력으로 이미지당 한 번만 생성하여 A/B 양쪽에 똑같이 적용했습니다. raw 점수와 보완 점수를 [비교 JSON](comparison.json)에 모두 보존했습니다.

| 최종 A/B의 위치·규칙 의미 대응 평가 | A | B |
|---|---:|---:|
| 오류 정답 검출 | 9/15 (60.0%) | 9/15 (60.0%) |
| 정상 정답 오탐 | 1/14 (7.1%) | 1/14 (7.1%) |

B의 토큰은 약 7.6% 증가했습니다. 공통 철자 검사 7회의 토큰·비용은 위 분석 표와 별도 기록되어 있으며, 이 작업의 실제 호출 원장에는 한 번만 반영했습니다. 전송량 절감은 무조건적인 성능 향상과 같지 않습니다.

마지막으로 요령별 대상 범위를 좁힌 C를 **정상 QA_08과 문양·오타 QA_10 두 장**에서 확인했습니다. 실행 오류 0, 분석은 각각 8회였고 `안젼한 하루` 오류와 정상 문구 구분을 유지했습니다. 의미 대응 기준 8개 정답은 8개 일치했으며, 예전 rule_id를 그대로 요구하는 엄격 기준은 7/8입니다. 이 두 장은 선택된 회귀 사례이며 미공개 평가나 전체 210개 요령의 정확도 100%를 뜻하지 않습니다.

점수 해석:

- 기관명 정답의 예전 `H-04-n`을 현행 오탈자 `D-02-l`에 대응한 의미 점수입니다. 엄격 ID 점수도 JSON에 제공합니다.
- 원문 규칙·위치·판정이 모두 맞아야 성공으로 계산합니다. NO_LOCATION에는 실제 미검출과 위치 연결 실패가 섞여 있습니다.
- 필수 REVIEW 1건은 B에서 장소 배경 대신 제목 위치에 연결되어 정답 ROI와 매칭되지 않았습니다. 따라서 REVIEW 비율 감소 전체를 개선으로 주장하지 않습니다.
- 정상으로 라벨된 소형 태극기의 수평 괘 방향에 대한 오탐, 손가락 수·지도 해역/독도 위치·정본 날짜 대조의 미검출/위치 문제가 남습니다.
- 라벨 밖 FAIL도 `comparison.json`과 원시 결과에 보존합니다. 라벨 정답만 맞았다는 이유로 이미지 전체가 정상 판정되었다고 주장하지 않습니다.
- p95는 7개 샘플의 분석 단계 측정이며 업로드부터의 전체 지연이나 통계적 유의성을 뜻하지 않습니다. 최초 그림 읽기 품질은 이 비교에서 다시 측정하지 않았습니다.
- 표준 단가 환산액은 기존 보수적 비용 추정값입니다. 과거 응답의 캐시 내역은 소급 생성하지 않습니다. 새 응답의 캐시/추론 토큰은 구분 저장하며 실제 결제 내역과 대사하기 전 청구액으로 표현하지 않습니다.
