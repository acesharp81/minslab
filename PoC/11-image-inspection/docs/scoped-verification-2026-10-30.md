## 520

이전 Sol 그림 읽기 요청이 약 20.8초 후 HTTP 520으로 끝났다. 이 실행에서는 객체 관찰이 없었고 mini 분석도 시작되지 않았다. 같은 이미지의 후속 실행은 성공했다.

520은 프록시가 원본 서버에서 예상하지 못한 응답을 받는 경우의 오류다. 이전 로그에는 응답 본문/요청 식별자가 없어 그 요청의 서버 내부 원인을 특정할 수 없다. 일시적인 중계·공급자 장애라는 설명은 추론이다.

공식 설명: https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-520/

실패 단계/모델을 화면에 표시하고, 제한된 5xx 재시도 시도마다 예산을 확인한다. 후속 오류에는 경과 시간과 허용된 요청 ID 헤더만 저장한다. 쿠키·응답 본문·비밀값은 기록하지 않는다. 응답 사용량 미확정 예약은 임의 환불하지 않는다.

**수동 검증 한계:** Sol 음절 이미지에는 로컬 OCR 사각형의 원근 보정과 수동 분리가 사용됐다. 일반 목적의 자동 음절 분할 기능을 배포한 것이 아니다. 분할로 자모가 잘리거나 다른 음절로 인식될 수 있다. `북` 판독은 의미 있는 개선이지만 전체 전사를 정답으로 채택할 수 없다. 음절/문구 불일치를 REVIEW로 표시하고 근거를 공개한다. 남성 손 오류는 여전히 미검출이며 정상으로 입증된 것도 아니다.

원본 실행은 수정하지 않았다. 마지막 버전은 완료된 3회 호출의 근거를 반영한 이력이며 156개 규칙을 새로 호출한 실행이 아니다. `scripts/attach_diagnostic_evidence.py`는 이미지 해시, 원본 버전, 객체/규칙 식별자 및 실제 사용량 장부를 확인한다. 실제 API는 호출하지 않는다. 사용자가 이미 검토한 판단과 기존 FAIL은 덮어쓰지 않는다.

체험 안내판의 원문 H-06-b / D-02-l에는 OCR_MISMATCH REVIEW가 표시되고 원본 영역과 음절별 판독 근거를 볼 수 있다. 손 관련 행동에는 Astra 관찰을 추가했다. 항공기 꼬리는 일장기 유사 표식과 KOREA AIR 문구의 맥락 확인 대상으로 표시한다. 추가된 위치 때문에 번호가 바뀔 수 있다.

실험적 전체 OCR 파이프라인은 기존 `OCR_ENABLED=false` 상태를 유지한다. 이번 개별 이미지 검증으로 전체 테스트셋 정확도 개선이나 손 구조 검출 해결을 주장하지 않는다.
