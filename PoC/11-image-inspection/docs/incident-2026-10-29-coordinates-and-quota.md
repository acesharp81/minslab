# 좌표 실패, 번호 가시성, GPT-5.4 공용 토큰 수정

## 원인과 처리

- 이미지 관찰에서 R13~R15 셀이 반환됐는데 허용 범위는 12×12였다. 한 객체의 잘못된 위치를 전체 관찰 실패로 처리해 원문 156개 행동까지 ERROR로 바뀌었다.
- 응답 스키마에 실제 격자의 셀 열거값을 넣었다. 공급자가 이를 따르지 않아도 잘못된 셀만 제외하며 객체/OCR 내용과 판독 품질은 보존한다. 위치 제외 기록은 `observation.location_warnings`에 남긴다. 위치 신뢰도와 문구 판정은 별개다.
- 실패한 사용자의 실행은 공용 게이트웨이에 남은 원래 응답을 이벤트 ID로 대조해 복구했다. 기존 실패 이력·결과는 유지하고 복구 출처와 응답 해시를 추가했다. 새 분석 버전에서 이미지 재호출 0회, 분석 5회로 전체 156개 행동이 완료됐다.

## 화면

- 위치가 분리된 객체에도 번호 하나와 모든 검토 의견을 유지한다. 이미지 오른쪽 가장자리에 의견을 여는 번호를 표시하고 결과 상단에서도 접근한다.
- 가상 셀을 글자 경계처럼 표시했던 사각형을 제거했다. 직접 픽셀로 측정된 구조 영역에만 사각형을 표시한다. 이는 글자 위치 정밀화가 완료됐다는 뜻이 아니다.
- 원형 번호의 크기는 고정이다. 상태색 배경과 대비되는 숫자, 흰색/짙은색 테두리를 사용한다. 선택 시 확대 효과는 제거했다.

## 공용 한도

- GPT-5.4는 사용자가 지정한 일 1,000,000 입력+출력 토큰을 PoC7의 `openai_group_daily_usage`, `main` 그룹과 공유한다. UTC 자정(한국시간 09시) 초기화한다.
- SQL 조건부 예약으로 동시 호출의 초과를 막는다. 사용량 미확정은 예약 한도만큼 보수적으로 잡고, 정산 이력으로 재시도 중복 차감을 막는다.
- GPT 6.0/6.1은 기존 공용 크레딧 원장을 유지한다. GPT-5.4 기존 25개 호출, 351,358 토큰을 날짜별 공용 원장으로 옮겼고 로컬 크레딧 추정 차감 1.809045 USD를 정정했다. 공급자 청구서 변경이 아니다.
- 독립 프로젝트는 다른 PoC 소스를 import하지 않는다. 초기 연결 스크립트가 PoC11 전용 토큰 예약 이력 테이블만 추가한다.

## 검증

관찰/제공자/전체 분석 회귀, 유효 셀 스키마, 단일 잘못된 좌표 후 156개 분석 지속, 번호 묶음 테스트를 통과했다. PostgreSQL 임시 테이블로 기존 공유 사용량, 초과 차단, 중복 정산 방지, 미확정 유지, 거절된 요청 예약 반환을 확인했다. 운영 사이트 PC·모바일에서 4번 클릭, 두 의견 표시, 부정확한 문구 사각형 0개, 번호 선택 전후 동일 크기, 태극기 비교표 및 공용 토큰 카드 표시를 확인했다. 검출 정확도 전체를 입증하는 테스트는 아니다.
