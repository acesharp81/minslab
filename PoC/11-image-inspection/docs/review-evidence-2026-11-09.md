## 구현

### 번호와 추가 확인 의견 구분

- 구체적인 관찰 차이, 기준 도안 불일치 근거, 독립 음절 판독 차이, 위치가 확인된 문자 획 손상은 번호로 유지한다.
- 진단 전용, 분석 누락, 문자·객체 연결 미확정 항목은 모델이 관찰 이상으로 분류했더라도 번호로 승격하지 않는다.
- D-03 이용권 검토와 D-04-d/e 동의·예외 증빙 REVIEW는 문서 확인으로 분류한다. 기존 FAIL과 사람 검토 기록은 변경하지 않는다.
- 단순 미판독·원근·가림·비교 미확정은 번호 없는 검토 의견에서 사유를 볼 수 있다. 번호가 없는 이미지 영역 클릭과 선택 팝업도 유지한다.
- 실제 손의 이상 구조, 한복/한북처럼 구체적인 판독 차이, 원본 획 손상은 별도 회귀 검사로 표시 유지 여부를 확인했다.

### 미완료 안내

결과 상단에 `분석 종료 · 일부 정밀 확인 미완료`를 표시한다. 확대·도안 미완료 객체, 문자 정밀 확인 수/후보 수, 손·OCR의 미확인 범위와 이유를 펼쳐 볼 수 있다. 실행 중 실패와 저장 검사에서 재사용한 실패 기록을 구분하며, 정상 판정으로 대체하지 않는다. 안내 열기에는 모델 호출이 없다.

각 검사의 후보 수는 서로 겹칠 수 있으므로 전체를 합쳐 하나의 완료율로 만들지 않는다. 이 사례의 4/24는 별도 문자 정밀 확인 경로의 범위다.

### 인접 문자 연결

측정한 문자 영역과 한 객체의 거친 격자만 맞지만, 영역 일부가 겹치는 인접 객체에도 동일한 OCR 문자열이 있을 때 단일 객체 연결을 확정하지 않는다. 문자열이 같다는 이유로 인접 객체를 정답으로 선택하지도 않는다. 정확한 측정 사각형, 단순 오탈자 비교, 멀리 떨어진 반복 문구는 이 보수적인 격자 예외와 구분한다.

저장된 잘못된 비교에는 `TARGET_UNRESOLVED` 상태를 남겼다. 상세 화면은 이를 “위치 연결 미확정 · 이전 비교 기록”으로 설명하고, 오탈자 근거로 사용하지 않는다고 표시한다. 이전 판독 문자열과 원래 의견을 보존한다.
