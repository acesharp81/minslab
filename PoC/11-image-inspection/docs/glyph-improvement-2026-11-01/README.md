# 문자 획 검사·위치 검증 보완 결과 — 2026-11-01

추가 비용 없이 기존 독립 확대 판독을 재사용하는 **문자 위치 검증은 서비스에 적용**했다. 별도 획 검사와 문맥 없는 음절 판독은 구현·실험했지만, 오류 검출 개선을 확인하지 못하고 정상 글자의 오인도 발생해 **기본 비활성**으로 유지했다. 기존 25개 상위 규칙·156개 세부 행동, 모델 선택, 공유 한도, 검토자 권한은 유지한다.

## 적용한 위치 보완

- 지적한 원문을 기존 독립 확대 판독에서 정확히 찾았을 때 그 위치를 사용한다. 제안 교정어와 유사 문자열로 위치를 추측하지 않는다.
- 같은 문구가 여러 곳에 있거나 해당 영역에서 원문을 확인하지 못하면, 판정·의견은 보존하고 좌표를 제거해 **위치 확인 필요**로 남긴다. 판독되지 않은 영역까지 근거 없이 숨기지 않는다.
- 기존에 확인한 세부 획 위치가 화면에서 큰 객체의 대략적인 셀 위치로 덮이던 경로를 수정했다. 같은 객체의 여러 세부 위치는 함께 보존한다.
- 이미지 클릭과 확대 재검사도 보정된 위치를 사용한다. 저장된 과거 결과의 셀 ID가 오래됐어도 화면에서 검증된 사각형으로 재검사 셀을 계산한다.
- 기존 판정을 바꾸지 않은 로컬 보정 버전 8개를 추가했다. 위치 근거를 보강한 결과 16개 중 5개는 위치 미확정으로 남겼다. 이 16개가 모두 픽셀 단위 정답 위치로 검증됐다는 뜻은 아니다. 원본 확대 격자에서 찾은 위치는 여전히 격자 수준의 근사치다.

## 실험한 문자 검사

1. 전문 OCR이 탐지한 원본 영역만 사용하고, 기존 전사·교정안·정답은 별도 획 검사에 전달하지 않았다. 읽힌 문자열과 획 품질을 분리해 저장했다.
2. 원본 줄과 서로 겹치는 부분 영역을 묶어 보냈다. 최대 8개 영역, 4개씩 2묶음으로 제한했다.
3. 짧은 한글 단어에는 로컬 픽셀 투영으로 음절을 분리했다. 단어 또는 예상 음절 수를 이용하지 않고, 모호한 분할은 보류했다.
4. 음절 순서를 섞어 GPT-5.4와 mini에 각각 독립적으로 판독을 요청했다. 작은 음절은 원본 크기와 3배 픽셀 반복 조건을 비교했다. 획 생성·선명화·인페인팅은 하지 않았다.
5. 모든 새 이미지 호출은 `detail: original`을 사용했다. 원본 픽셀 보존과 API의 지원 범위는 [OpenAI 공식 이미지 입력 문서](https://developers.openai.com/api/docs/guides/images-vision)를 확인했다. 해당 문서는 한국어·작은 글자·정밀 위치 판독의 한계도 명시한다.
6. 별도 획 검사는 단독 PASS를 만들지 않는다. OCR 전사, 전체 줄 판독, 분리 음절 판독이 충돌하면 REVIEW 근거를 보존한다. 실제 원본 획 손상과 인식 엔진 실패를 구분한다.

실험 뒤에는 두 분리 판독이 일치하더라도 전체 줄 판독과 다르면 확정 전사로 승격하지 않는 보호 규칙을 추가했다. 공백을 생략한 음절 전사를 띄어쓰기 판정에 쓰지 않도록 표시했고, 같은 영역·규칙의 중복 의견 생성도 줄였다. 이 후처리 보호 규칙의 오프라인 테스트는 통과했지만, 아래 실제 호출 점수를 이 변경으로 다시 좋게 보정하지 않았다.

- QA_03: 기관명 오탈자·본문 흐림의 기존 FAIL, 정상 안내의 PASS를 유지했다.

- QA_06: 대피 안내 띄어쓰기는 여전히 놓쳤다. 음절 판독과 공백 판정은 별개다.

원 답안의 H-04-n 기관명 항목은 현재 국가명·국호 규칙과 의미가 달라 D-02-l로 대응한 수치를 별도로 제시했다. 원 규칙 번호 그대로의 점수도 `text-comparison.json`에 함께 보존했다. 완전한 문자별 정답 전사가 없으므로 문자 오류율이나 전체 OCR 누락률을 산출했다고 주장하지 않는다.
