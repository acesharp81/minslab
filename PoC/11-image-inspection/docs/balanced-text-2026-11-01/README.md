# 문자 검사 후속 보완 · 2026-11-01

## 기본 서비스에 반영한 사항

- 일부 OCR 영역을 읽었다는 전역 카운터 때문에 **모든 문자 객체의 확대 검사를 생략하던 조건** 제거. 해당 객체의 완전한 독립 판독 기록이 있을 때만 중복 생략하며, 사용자가 요청한 재검사는 실행한다. 기존 최대 3회·9객체 한도 유지.
- 제목/기관명/본문/작은 안내별 `확인/탐지` 개수 표시. 부분 확인은 전체 확인 수에 포함하지 않는다. 탐지되지 않은 글자까지 검사했다고 주장하지 않는다.
- 승인 원고의 문자별 대조. 해당 이미지 SHA-256에 묶인 승인 `source-data`만 적용하며, 저장 객체 이름이 유일하게 일치해야 한다. 서로 다른 승인 원고가 충돌하면 보류한다.
- 원고는 독립 판독 **이후** 비교한다. 비교 자체는 API 0회. 기존 검사 예산 안에서 원고와 다른 후보의 순위를 높일 수 있지만 OCR 프롬프트에는 원고/교정 후보를 넣지 않는다.
- Unicode NFC 적용 후 문자 치환/삽입/삭제 및 내부 공백 차이를 기록한다. 판독 불가를 오탈자로 확정하지 않으며 원고 일치로 획 결함을 지우거나 PASS를 만들지 않는다. 독립 판독이 일치하더라도 같은 오독이 가능하므로 결과는 최종 공개 승인이 아니다.
- 기준자료 관리에서 **선택한 이미지의 원고 양식 만들기** 지원. 검수 이력에서 이미지를 선택한 뒤 양식을 생성하고 각 `text`에 해당 영역 **전체의 승인 원고**를 입력한다. 필요 없는 항목은 삭제한다. 빈 칸에 기존 OCR 문자열을 정답처럼 자동 복사하지 않는다. 원본 데이터 종류, 적용 ID, 출처와 버전을 기재해 초안 등록 후 기존 관리자 승인 절차로 사용한다. 이름이 바뀌거나 중복되는 대상은 추측 연결하지 않는다.
- 기존 25개 원문/156개 세부 행동, 좌표·재검사·이력·공용 사용량 흐름 유지. 실험 결과 3개와 이전 판정 유지 기록 3개를 이력에 추가했다. 기존 기록·사람 검토는 삭제하지 않았다.

## 기본 적용하지 않은 사항

`TEXT_BALANCED_SELECTION=false`: 제목·기관명·본문·작은 안내의 순환 선택을 구현했지만 아래 실측에서 검출률 개선이 확인되지 않았다. `.env.example`에만 설정을 안내하고 실제 `.env`는 변경하지 않았다. 새 검수 기본 경로에 활성화하지 않았다. 별도 획 검사와 문맥 없는 음절 판독도 계속 비활성이다.

실험용 획 검사 선택기는 큰 문자 영역도 확보하도록 보완했다. QA_10의 `안젼한 하루`가 기존 8개 선택에서 빠지던 현상은 해결되었다. 이는 **선택 범위 개선**이며 문자 인식 정확도 개선은 아니다. 14개 저장 이미지의 선택 결과는 `selection-audit.json`에 기록했다. 별도 탐지/OCR/API 호출 없이 저장된 관찰만 이용했다.

## 실제 모델 검증

QA_10, QA_03, QA_08에 각 GPT-5.4 독립 확대 판독 3회 + mini 문자 규칙 분석 1회. 저장된 최초 관찰과 다른 규칙 결과는 재사용했다. 정답/평가 ROI는 추론에 넣지 않았고 이후 오프라인 채점만 수행했다. QA_07은 이번에는 저장 자료의 영역 선택 감사만 수행했으며 모델을 다시 호출하지 않았다.

| 지표 (문자 정답 영역 7개) | 이전 | 실험 |
|---|---:|---:|
| 오류 3개 중 FAIL 검출 | 2/3 | 1/3 |
| 정상 4개 중 PASS | 3/4 | 4/4 |
| 정상 영역의 FAIL 오탐 | 0/4 | 0/4 |
| REVIEW | 2/7 | 1/7 |

- QA_03 기관명 오류: FAIL 유지. 흐림 오류: FAIL → REVIEW로 후퇴. 정상 신청 안내: PASS 유지.
- QA_08 기관명·날짜 정상: PASS 유지.
- QA_10 `안젼한 하루`: 실제 검사 대상으로 들어갔지만 GPT-5.4가 여전히 `안전한 하루`라고 전사해 REVIEW → PASS로 후퇴. 원본 픽셀 확대에서도 문제 음절을 확인했으며 답안을 바꿔 성적을 보정하지 않았다. 정상 `안전한 동행`: REVIEW → PASS.

이 때문에 실험을 기본 채택하지 않고 **3장의 이전 판정을 최신 표시로 유지**했다. 실험 원본은 이전 이력/보고서에 남겼다. `comparison.json`은 실험 원본끼리 비교한 결과이며 유지 기록으로 성적을 부풀리지 않는다.

승인 원고 기능은 별도의 스코프·충돌·불확실성·공백·획 손상 보존 회귀 테스트로 검증했다. 테스트 답안에서 기대 문구를 뽑아 승인 원고로 등록하지 않았다. 제공된 MASTER_COPY에는 QA_10 문구의 전체 승인 원고가 없으므로 이 사례를 원고 대조의 실제 개선 성과로 세지 않는다.
