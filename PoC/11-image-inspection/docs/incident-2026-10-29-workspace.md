# 통합 작업 화면과 위치 표시 복구

사용자 요청에 따라 첨부와 미리보기를 왼쪽 한 패널로 합쳤다. 파일 선택 즉시 해당 영역에서 로컬 미리보기를 표시하고, `그림 + 분석 실행` 시 등록과 전체 검사를 수행한다. 오른쪽 상단에는 정보·모델·두 실행 버튼, 하단에는 원문별 결과·위치별 확인·선택 재검사를 배치한다. 실행모드 선택과 기존 설명/동의 체크박스 줄은 삭제했다.

기본값은 OpenRouter `nvidia/nemotron-3.5-super-vl:free` 이미지 읽기와 `gpt-5.4` 분석이다. API 기본 모드는 live다. 샘플 버튼의 고정 기능 시연만 명시적으로 mock을 사용한다. 실제 검사에 시연 모드가 이어지지 않는다. 새 이미지·모델 조합의 외부 전송 동의는 실행 시 확인창에서 받는다. 거절·취소는 모델 요청을 만들지 않으며 동의는 현재 화면 메모리에만 보관한다.

사용자의 최근 GPT-5.4 실제 실행에서 태극기 4개와 01·03·04의 괘 구조 차이는 저장돼 있었다. 하지만 UI가 REVIEW를 위치 없는 문서 확인으로 일괄 분류해 번호를 숨겼다. 서버 측정 영역이 있는 경우에는 해당 객체별 위치 번호와 H-04 관련 의견을 연결한다. 측정 차이는 AI 최종 판정과 구분하고, 퀴즈 의도를 고려한 REVIEW를 강제로 FAIL로 바꾸지 않는다. 일치한 도안은 정상 영역 표시를 켠 경우에만 추가 표시한다. 전체 이미지의 측정 좌표는 확대 이미지에 적용하지 않는다.

검증: Python 69개, 위치 묶음 Node 테스트 2개. 브라우저에서 1600×1000·1366×768 화면 배치, 모바일 가로 넘침/번호 겹침, 원문 25개, 차이 위치 3개와 각 4괘 비교, JSON 다운로드를 확인했다. 업로드와 실제/재분석 POST는 가로채기 방식으로 검증하여 추가 모델 호출을 만들지 않았다. 전송 취소 시 요청이 없고 동의 후 올바른 모델·관찰 재사용 옵션이 전송됨을 확인했다.
