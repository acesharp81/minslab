# 태극기 재실패 원인과 수정

이전 완료 기준은 API/스키마 성공에 치우쳤고 실제 획 검출을 검증하지 못했다. 기존 관찰 재사용에는 138개 중복·일반 문맥 객체가 남아 있었고, 분석 모델은 픽셀을 다시 보지 못했다. 공식 도안 직접 비교도 없어 전부 REVIEW로 낮추는 흐름이었다.

수정: 독립 로컬 4괘 comparator를 H-04-h/i에 연결, 실제 원본의 모서리별 패턴/공식 기준/영역 기록. 중립 REVIEW에 기본 위치 핀을 생성하지 않음. 신규 규칙 편집은 관리자 인증, Markdown 문법 검증, 원자적 버전 저장 및 검사별 스냅샷 사용.

검증: 합성 정상·감리 교환, 축소·JPEG, 가림/로고/회전 사례와 제공된 퀴즈 네 원본 비교. 편집 권한, 누락/중복 ID, 동시 수정 충돌, 저장 후 실제 분석 프롬프트 반영, 이전 검사 보존. 브라우저에서 파일 다운로드·규칙 저장/이력·3개 위치 번호·4모서리 비교·모바일 겹침·보고서 저장 확인.

한계: 정면 평면 인쇄 후보 전용이며 모든 변형에 대한 범용 태극기 판독기는 아니다. 규칙 MD 수정이 영상 알고리즘을 재작성하지 않는다. 법적/정책적 최종 공개 승인을 제공하지 않는다.

실제 Solar 재검증에서 target_presence 추가 후 중복 ID 및 서로 다른 부모의 ABSENT 묶음이 반환되었다. 이를 묶음 전체 ERROR로 만드는 제약을 제거했다. 각 규칙으로 전개하여 근거 요건을 별도 검증하고 중복/상충만 정규화한다. 대상 부재를 PASS→REVIEW로 부풀리지 않도록 ABSENT를 NOT_APPLICABLE로 먼저 처리한다.

후속 수정: 위 전용 비교가 원문 검수를 대신하는 문제가 있어, 원문 25개 질문을 이미지 관찰·분석 양쪽에 전달하고 H-04-h/i도 AI 분석에 포함했다. 구조 비교는 H-04 안의 보조 근거로 이동했다. 전체 관찰 재사용은 마지막 부분 검사 범위를 상속하지 않고 156개 전체를 평가한다. 원문 25개별 결과·근거·분석 완료 범위를 화면과 JSON으로 제공한다.
