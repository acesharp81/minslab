# ImageGen_Exploratory_02 누락 원인과 보완

대상: `8875e0c75ae0433d8bebfc8a7ffffcec`, 원본 실행 `ef95d4410a754f5e8d5c284f306838e8`.
같은 제목의 10월 29일 자료 `f97158e3b0ea47028d951d1047f7b890`는 별도 기록이다. 이전 자료의 HTTP 400을 최신 검사의 원인으로 사용하지 않는다.

## 확인한 원인

- 기관명: 첫 관찰은 `행정안정부`를 정확히 전사했다. 부분 재판독은 `행정안전부`로 자동 보정했고, mini는 이 충돌에도 H-06-b / D-02-l을 PASS로 판단했다. 부분 판독을 원문과 합치는 단계는 원문을 보존했지만, 최종 판정의 정상 처리 방어가 부족했다. 별도 OCR 비활성화 시 일반 시각 재검증 충돌을 보호하지 않았다.
- 지도: 나침반이 지도 재검증 후보로 분류됐다. 실제 지도 crop은 우측을 잘라 제목·주변 육지의 강조 범위를 충분히 비교하지 못했다. 모델은 지명 존재·상대 위치만 근거로 정상에 가까운 판단을 했으며, 색칠 범위와 제목의 의미를 검사하지 못했다.
- 태극: 깃대가 공식 국기 대조 후보로 들어가 대형 국기 본체의 검증 우선순위를 빼앗았다. 기존 로컬 픽셀 검사는 평면 인쇄 국기의 4괘만 대상으로 하고 태극 곡선을 검사하지 않았다. 모델은 빨강 위·파랑 아래와 괘 배치에 치우쳐 중앙 곡선의 거울상을 놓쳤다.

## 구현

- 기관명 우선순위와 지도/국기 객체 분류 수정. 나침반·지명·깃대는 지도 본체/국기 본체의 공식 도안 대조 대상으로 쓰지 않는다. 지도 지명 문자 재판독은 유지한다.
- 지도 본체 재검증은 전체 원본을 유지하여 제목·범례·주변국을 함께 본다. 구조화 응답에 강조 육지 범위/영토 문맥/태극 돌출 방향을 별도로 기록한다.
- 부분 또는 상충하는 전사가 PASS로 덮이지 않도록 보호. 누락된 문자 규칙의 검토 항목도 보존한다. 공백 차이만으로 충돌을 만들지 않는다.
- 기관명 공식 용어집 대조 추가. 기관명 객체에 한해 공식명과 한 글자 차이 후보를 검사한다. 선명한 원본과 독립 판독이 같은 오표기를 확인하면 FAIL, 불일치·불확실하면 REVIEW. 일반 문장을 일괄 자동 교정하지 않는다.
- 중앙 태극 적·청 영역을 연결성분으로 찾아 승인된 원본 도안과 비교한다. 제한된 회전 보정과 거울상 대조를 수행하며, 고정 테스트 좌표를 사용하지 않는다. 거울상 유사만으로 뒷면을 제작 오류로 확정하지 않는다. 기존 모델 PASS와 충돌하면 최소 REVIEW로 보존한다.
- 기존 25개 원문 및 156개 세부 규칙, 원본 검사 이력, 검토자 권한 제한은 유지한다. 개선된 비교를 숨기지 않도록 상세 화면에 공식명 출처와 색상 영역 비교값을 표시한다.

## 한계

색상 일치율은 오류 확률이 아니다. 심한 가림·작은 도형·큰 회전·색상 왜곡·여러 후보가 겹치는 경우 로컬 비교는 판정을 보류한다. 지도에 주변국이 존재하거나 육지 색이 같다는 사실만으로 영토 오류를 확정하지 않으며 제목·범례·경계를 함께 확인한다. 이번 이미지의 개발 재검증 결과는 독립 테스트셋의 검출률/오탐률 개선 증명이 아니다.
