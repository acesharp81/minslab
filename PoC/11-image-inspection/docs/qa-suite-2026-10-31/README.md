# 2026-10-31 합성 QA 평가 및 이어서 진행할 항목

사용자 요청에 따라 자동 검사를 종료했다. 토큰 갱신 후에도 자동 재개하지 않으며, 다음 요청 때 저장된 기록에서 이어서 진행한다. 이력 등록과 로컬 검증은 외부 모델을 호출하지 않는다.

## 범위와 기록

- `docs/테스트용.zip`의 문제 이미지 14장, 정답 항목 61개. Exploratory 3종 제외.
- mini 읽기 + mini 분석으로 14장 기준선을 만들고, GPT-5.4·Sol·Astra·Nemotron·Solar는 대표 이미지에서 비교했다. 모든 모델로 전체 14장을 검사한 것은 아니다.
- 총 40개 실행 기록, 실제 API 시도 427회. 모델에 정답 JSON·정답 위치·정답 표시 이미지를 제공하지 않았다. 제작자 기준 원고와 가상 문양 원본만 비교 자료로 제공했다.
- 검수 이력에는 `자동평가 · QA_...`로 이미지별 등록한다. 원래 판정, 실행 오류, 한도 중단과 모델별 실행 기록을 보존한다. 가상 문양 기준은 해당 실행의 스냅샷에만 포함한다.
- `report.json`: 모델·실험별 집계와 한계. `cases.csv`: 항목별 예상/실제 결과와 이유. `history.json`: 검수 이력 ID. `closing-usage.json`: 종료 시점 잔량.
- 원본 실행과 재현 정보는 Git 제외 경로 `data/qa-20261031`에 보존한다. 사용량은 이미 공용 원장에 반영했으며 이력 가져오기로 재차 차감하지 않는다.

## 보완 및 결과

문자 확대 영역의 좌우 여백과 손 영역의 주변 여백을 늘렸다. 잘린 글자와 원본 글자 결함을 구분하고, 불확실한 확대 판독이 이미 확인된 오탈자의 판정·위치를 덮어쓰지 않게 했다. 조사와 붙은 기관명 오탈자를 비교하고 국가명 전용 규칙이 일반 문구에 잘못 적용되는 경로를 제한했다. 모델이 필요한 객체 판정을 누락하면 검토 필요로 남긴다. 출력 길이 초과는 실패한 묶음만 작게 나누며, 예산을 늘리거나 불확실한 네트워크 오류를 자동 재시도하지 않는다.

QA_03에서 GPT-5.4 읽기 + mini는 기관명 오탈자와 뭉개진 글자를 서로 다른 근거로 잡았다. 손가락 개수도 대표 비교에서 검출했다. Solar의 출력 잘림은 실패 항목 재처리로 156개 행동을 끝까지 처리했지만, 완료가 정확성을 보장하지는 않는다.

전체 검출률이 개선되었다고 결론 내릴 수는 없다. mini 기준선은 오류 24개 중 위치·규칙·상태의 기계적 일치가 7개(29.17%)였으나, 이유가 다른 위치나 결함을 설명하거나 현재 규칙과 매칭이 어긋난 사례가 포함된다. 정성 검토상 명확한 일치는 3개이고, 기관명 인식 1개는 규칙 매칭이 부정확했다. 정상 정답 34개에서 FAIL은 0개였지만, 정답 밖의 불필요한 표시를 모두 검증한 수치가 아니므로 전체 오탐률 0%로 해석하면 안 된다.

동일한 5장 mini 비교에서도 오류 검출은 1/12에서 0/12, 정상 PASS는 4/9에서 5/9, REVIEW는 4/21에서 8/21로 바뀌었다. 불확실성을 더 안전하게 처리했지만 오류 재현율 개선은 입증하지 못했다. 이후 QA_03 개별 보완 결과는 별도로 기록했다. 기준선 문자 정답 영역 16개 중 3개가 위치 매칭에서 누락되었다. 이는 문자 영역 검출 누락률 18.75%이며 글자 단위 인식 정확도나 전체 OCR 누락률이 아니다.

식문화·정책의 기준자료가 부족하거나 현행 관리 규칙이 사람 검토를 요구하면 REVIEW로 유지한다. 원 답안지의 기관명 항목이 현행 국가명 전용 규칙에 묶인 사례도 있어, 단순 상태 일치와 올바른 규칙 적용을 분리해서 봐야 한다. QA_07의 `비빔밤`, QA_10의 `안젼한`처럼 문맥상 자연스러운 단어로 복원되어 놓치는 문제가 남아 있다. 문양 부분 비교도 실제 구조를 잘못 읽는 사례가 남았다. 기본값은 GPT-5.4 읽기 + mini 분석을 유지했다.

이번 평가의 NAVER 호출은 0회다. 평가에서는 모델 직접 판독 또는 기존 관찰 재사용을 사용했고 NAVER 호출을 명시적으로 껐다. 일반 서비스도 확인 당시 `OCR_ENABLED=false`여서 키·URL이 있어도 OCR 경로가 실행되지 않는다. 따라서 카운터가 줄지 않은 것은 이번 검사에서 호출하지 않았기 때문이다. 월 100회는 검사 이미지 수나 토큰이 아닌 앱의 API 요청 시도 수이며 한국시간 매월 1일 초기화한다. 실패·미확정 요청도 보수적으로 포함한다. 이번에 설정을 임의로 켜거나 추가 호출하지 않았다.
