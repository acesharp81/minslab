## 반영 내용

1. 독립 한국어 OCR + 원본 픽셀의 글자 획·번짐 비교를 기본 활성화했습니다. 단어 복원과 실제 글자 모양을 분리합니다. 동봉 글꼴 자산의 해시·라이선스를 확인하며, 정답지/정답 좌표/특정 오타 사전을 런타임에 제공하지 않습니다.
2. 형태가 다른 후보에 한해 최대 6글자를 GPT-5.4 **1회로 묶어** 확인합니다. 단어와 교정문을 숨긴 원본/후보 이미지 비교이며, 미확정 후보는 REVIEW로 남깁니다. 이 호출은 일일 한도만 사용합니다.
3. OCR과 원본 관찰의 글자가 일치한 최대 48개 문구를 mini **1회로 묶어** 별도 철자 검사합니다. 이미지 재전송이 없습니다. 공백 판독도 일치해야 띄어쓰기 오류로 표시합니다. 큰 문장 재작성·숫자 변경·미확정 고유명사는 확정 오류로 받아들이지 않습니다.
4. 원본 비교와 분석 판정이 충돌하면 REVIEW로 보존합니다. 독립 OCR과 정확히 일치한 문구는 탐지 사각형으로 위치를 보정합니다. 같은 문구가 여러 곳이면 임의로 한 곳을 찍지 않습니다.
5. 결과 상세에 원본 글자, OCR 전사, 획 후보, 철자 수정 후보, 추가 모델 호출/재사용을 표시합니다. 재분석은 이미지 읽기와 획·철자 근거를 재사용합니다.
6. GPT-5.4 계열의 이미지 예약 토큰은 실제 이미지 크기를 반영한 보수적 상한으로 계산합니다. 사용량 정산은 계속 API 응답의 실측 토큰을 사용합니다. 전송 전 로컬 실패는 0, 전송 후 사용량 미확정은 예약 상한을 유지합니다.

기본 모델은 **그림 읽기 GPT-5.4 + 분석 GPT-5.4 mini**입니다. 별도 보조 검사도 이 두 일일 풀을 사용하며 6.0/6.1로 자동 전환하지 않습니다. NAVER 호출은 새 로컬 OCR 경로와 별개입니다.
