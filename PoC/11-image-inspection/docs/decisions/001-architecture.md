# 췤미! 구현 결정 · 2026-10-29 (수정)

- 독립 FastAPI + SQLite + 정적 HTML/JS. 부모 저장소나 PoC7 Python 모듈을 런타임에 import하지 않는다. 공용 서버는 URL 프록시와 관리자 서명만 담당한다.
- 첨부 브리프의 원문 25개와 세부 156개를 데이터 파일로 보존했다. 원본 HWPX 자체는 받지 않았으므로 별도 원본 대조는 미실시다.
- 그림 읽기: GPT-5.4 / Sol / Astra / OpenRouter Nemotron 3.5 VL 무료. 원본 1회에서 객체·문구·시각 단서·불확실성을 추출한다. 분석은 Solar / GPT-5.4 / Sol / Astra가 저장된 관찰만 참조한다. 이력의 run ID로 관찰을 재사용하며 기존 버전은 변경하지 않는다.
- 비용: 이미지 관찰은 1회, 분석은 원문 항목을 쪼개지 않는 최대 40개 행동·6개 원문 묶음(현재 전체 5회)으로 실행한다. 최대 두 요청을 공용 예산 예약 후 동시에 실행한다. 관찰 재사용 시 이미지 호출은 0회다. 각 행동은 독립된 판정·근거·조치를 반환한다. 자동 유료 폴백/재시도는 없다.
- 위치: 깨끗한 원본에 가상의 12×12 셀을 정의한다. 모델은 객체 핵심부 1~4개 셀을 반환한다. 이미지를 144개로 잘라 보내거나 격자선을 덧씌워 전송하지 않는다. 확대에는 주변 1셀을 더하고 전체 원본과 깨끗한 확대본을 보낸다. 확대 셀은 원본 비율로 변환한다.
- 표시: 같은 객체의 여러 규칙을 단일 번호로 모은다. 모바일에서 가까운 번호는 하나의 묶음으로 합친다. 선택된 묶음만 탐색 테두리로 표시한다. 문서 증빙 부족/최종 판단은 위치 표시와 분리한다. 객체 ID와 선택한 규칙 ID를 별도로 유지한다.
- 경계: 원본 전체의 문맥을 읽으며 경계에 걸친 객체를 분할하지 않는다. 번호는 대략적 위치이며 정밀 객체 외곽이 아니다. 객체 누락과 OCR 오류는 여전히 가능하며 필요 시 사람이 확대 재검사한다.
- 진행: 백엔드 비동기 단일 실행 큐, 1.7초 폴링, 묶음 완료마다 결과 저장·표시. 스캔 선은 상태 표현이며 실제 위→아래 판독 순서가 아니다. 개별 토큰·미완성 JSON을 결과로 노출하지 않는다.
- 공용 사용량: PoC7 `/internal/usage-events`에 고유 event_id로 전송. SQLite outbox 후 전송·재전송. 게이트웨이 UTC 날짜는 수신일 기준이며 원래 발생 시각은 PoC11에 별도 보존.
- 공용 예산: OpenAI 유료 모델은 PoC7 `openai_credit_grant_usage`의 동일 grant에서 원자적 예약·정산. `poc11_credit_reservations`로 중복 정산 방지. 무료 mini/main 토큰 배정과 혼합하지 않는다. Solar는 중앙 보고 대상이며 OpenAI 크레딧에서 차감하지 않는다. 타임아웃·사용량 누락은 unknown 또는 미정산 예약으로 남겨 예산을 임의로 복구하지 않는다.
- 사용자 요청에 따라 PoC 목록과 `/imgscan`을 연결했다. 같은 출처 iframe만 허용한다. 외부 자료 전송은 건별 체크박스 및 서버 차단 설정을 모두 확인한다.
- 규칙의 사회·정책·법률 해석은 HUMAN_REQUIRED로 보수 처리한다. 필수 기준자료가 없으면 REVIEW. 참조 이미지는 등록·승인 후 제공. URL만으로 그림 대조를 수행했다고 주장하지 않는다.

- 장애 원인 수정: 모듈 import 때 앱을 만들던 전역 초기화를 제거했다. 운영 앱은 uvicorn factory로만 생성한다. 따라서 테스트 수집이 운영 DB의 RUNNING 상태를 INTERRUPTED로 바꾸지 않는다. 운영 작업 유무는 서비스 API에서 확인한 뒤 배포한다.
- 보고서: 현재 URL로 이동하지 않고 인증된 fetch → Blob 다운로드. HTTP 오류/네트워크 실패가 작업 화면을 대체하지 않는다.
- 잔여량: OpenAI는 단일 공용 비용 예산 카드. 무료 토큰 혜택 참여/잔여량을 자동 확정하지 않는다. OpenRouter는 공식 key API의 무료 요청 카운터만 사용하고 누락/오류는 미확인으로 둔다. 실제 키는 공유에서 제외한다.

- 추가: 공용 무료 OpenRouter 요청은 PoC7 gateway에서 사전 예약한다. 표시 잔여는 공식 잔여와 운영 잔여의 최솟값이다.
- 추가: 4괘 패턴을 직접 읽는 로컬 비교는 정면 인쇄물에 한정하여 H-04의 보조 측정을 제공한다. H-04-h/i를 포함한 원문 세부 행동은 분석 모델이 모두 평가한다. 실제 픽셀 유래 영역만 정밀 위치로 사용한다. 중립 REVIEW는 위치 번호 없이 추가 확인 목록으로 제공한다.
- 추가: 관리자 Markdown 규칙은 append-only rule_versions로 저장하고 각 실행의 rule_pack은 불변 스냅샷으로 보존한다. 동시 변경은 base_version 비교로 차단한다.
- 추가: 분석 JSON은 target_presence를 필수로 반환한다. ABSENT는 NOT_APPLICABLE로 정규화하고 UNCERTAIN의 PASS/FAIL은 REVIEW로 제한한다.

- 분석 응답 계약: `assessments`의 필수 키는 요청한 전체 rule_id이며 각 값은 독립된 판정이다. 그룹 하나를 여러 규칙에 배정하면 정상 형식이어도 내용이 섞이는 실제 실패가 있어 group/assignment 최적화를 제거했다.
