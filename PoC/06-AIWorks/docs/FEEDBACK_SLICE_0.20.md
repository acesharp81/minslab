# AIWorks 0.20 양식 MCP 피드백 가이드

> 구현일: 2026-08-14
> 상태: 체험 가능
> 목적: 생성·편집 중인 HWPX에 필요한 양식 MCP를 동적으로 로딩하고 같은 RHWP 세션에 적용하는 흐름 검증

## 권장 체험 순서

1. 첫 화면에서 `우리부 예산 현황을 확인하고 싶어`를 입력한다.
2. 답변 후 `분석 내용에 시사점을 추가해서 보고서로 작성해줘`를 입력한다.
3. RHWP에서 문구를 선택하고 `이 문구에 대해서 당위성을 강조하는 문구로 바꿔`를 입력해 적용한다.
4. 선택 영역을 해제하고 `행안부 보고서 양식으로 바꿔줘`를 입력한다.

## 양식 적용 예상 결과

- `document.rhwp@1.0.0`과 `template.mois-report@0.1.0`이 로딩된다.
- 모델 호출이나 외부 전송 없이 현재 HWPX를 로컬에서 읽는다.
- 제목과 기존 본문 문구를 유지하면서 보고 구분, 큰 제목, 작성일·담당부서, 문단·불릿 체계를 재구성한다.
- 새 문서나 HTML 편집기로 이동하지 않고 현재 RHWP 세션의 다음 revision으로 저장한다.
- 결과 파일명은 `_행안부보고.hwpx`로 끝난다.
- 공식 배포 원본이 연결되지 않은 상태이므로 문서 하단에 AIWorks 체험 양식임을 표시한다.

## 등록된 양식 계약

- MCP: `template.mois-report@0.1.0`
- Template ID: `mois.internal-report.v1`
- 명칭: 행정안전부 내부보고형
- 입출력: HWPX → HWPX
- 내용 정책: 본문 텍스트 보존
- 권한: `document.read`, `document.write`
- 외부 전송: 없음
- 공식 원본 연결: 아직 없음

실제 행정안전부 배포 HWPX 양식을 확보하면 해당 파일을 기준 자산으로 등록하고, 고정 필드·표·결재란·쪽 설정을 Template ID의 새 버전으로 제공한다. 현재 체험 양식을 공식 서식이라고 표시하지 않는다.

## 현재 한계와 다음 구현

- 현재 양식 변환은 생성형 보고서의 제목·문단·불릿 텍스트를 보존하는 범위다.
- 원본 표·그림·수식·각주를 새 양식으로 옮기는 구조 매핑은 후속 버전 대상이다.
- 양식 검색·미리보기·버전 선택 UI와 사용자가 HWPX를 등록해 양식 MCP를 만드는 Studio 흐름이 다음 대상이다.
- 부처별 공식 양식은 출처, 시행일, 적용 업무와 필수 필드 계약을 함께 등록해야 한다.
