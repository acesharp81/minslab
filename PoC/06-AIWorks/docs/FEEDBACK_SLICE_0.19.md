# AIWorks 0.19 RHWP 피드백 가이드

> 구현일: 2026-08-14
> 상태: 체험 가능
> 목적: 동적 MCP로 만든 파생 보고서가 HTML 초안이 아니라 실제 HWPX/RHWP 흐름으로 이어지는지 검증

## 파일 없이 시작

첫 화면에서 다음 순서로 요청한다.

1. `우리부 예산 현황을 확인하고 싶어`
2. `분석 내용에 시사점을 추가해서 보고서로 작성해줘`
3. RHWP에서 문구를 선택한 뒤 `이 문구에 대해서 당위성을 강조하는 문구로 바꿔`

예상 결과:

- 의도 분석 MCP → 예산 MCP → 텍스트 표출 MCP가 동적으로 로딩된다.
- 다음 요청에서는 보고서 MCP → HWPX 산출 MCP → RHWP 편집기 MCP가 로딩된다.
- 생성 파일은 `분석 및 시사점 보고서.hwpx`이며 HTML 보고서 편집기로 전환되지 않는다.
- 선택 문구 제안을 적용해도 첫 화면으로 이동하거나 RHWP iframe을 다시 로딩하지 않는다.
- 적용 결과는 같은 문서 세션의 새 revision으로 저장되고 파일명에는 `_AIWorks`가 붙을 수 있다.

## 파일을 첨부해서 시작

HWPX, PDF, Markdown 또는 TXT 자료를 첨부한 뒤 다음 순서로 요청한다.

1. `첨부된 문서를 기준으로 올해 결산 보고서 양식으로 작성해줘`
2. 생성된 RHWP 보고서에서 문구를 선택한 뒤 `이 문구에 해당되는 법조항을 찾아줘`

예상 결과:

- 첨부 원본은 먼저 로컬 문서 어댑터로 읽는다.
- 결산 양식 MCP → 보고서 MCP → HWPX 산출 MCP → RHWP 편집기 MCP 순서로 파생 보고서를 연다.
- 확인할 수 없는 수치나 필수 항목은 추측하지 않고 `확인 필요`로 표시한다.
- 법률 MCP는 선택 문구만 문맥으로 사용한다. 권위 있는 법령 원문 커넥터가 없으면 조항을 지어내지 않는다.

## 모델과 데이터 정책

- 빠른 기본 모델: `upstage/solar-pro-3`
- 외부 실행 조건: `AIWORKS_OPENROUTER_LIVE=1`, API 키, 사용자 승인 모두 충족
- 외부 전송 기본값: 거부
- 첨부 원본 전체가 아니라 승인 화면에 표시한 로컬 추출 발췌만 전송 후보가 된다.
- `confidential` 등급은 외부 모델 라우팅을 차단한다.

## 현재 한계

- 예산 MCP는 체험용 프로젝트 데이터이며 기관 재정시스템과 연결되지 않았다.
- 결산 양식 MCP는 체험용 구조이며 실제 최신 기관 양식 등록이 필요하다.
- 법률 MCP는 흐름만 연결되어 있으며 국가법령정보센터 등 권위 있는 원문 커넥터가 필요하다.
- 생성 HWPX는 기존 문서 세션 호환 계층에 저장된다. 프로젝트 Artifact 계보는 로드맵 18~19단계에서 구현한다.
- 프로젝트 Fact Registry와 영속 Workflow Runtime은 로드맵 20~22단계 대상이다.

## 피드백할 항목

1. 채팅 답변에서 RHWP 보고서로 전환되는 시점이 자연스러운가?
2. 생성된 HWPX의 제목·문단·표현 품질이 업무 초안으로 충분한가?
3. RHWP 선택 문구를 좌측 채팅이 정확히 인식하는가?
4. 수정 적용 후 현재 페이지와 편집 위치가 유지되는가?
5. 가장 먼저 연결할 실제 데이터·양식·법률 MCP는 무엇인가?
