# AIWorks 0.18 사용자 피드백 가이드

> 구현일: 2026-08-14
> 상태: 체험 가능
> 목적: 특정 업무를 Core에 고정하지 않고, 파일·선택 영역·요청 산출물에 따라 MCP를 조합하는 흐름 검증

## 이번 버전에서 확인할 것

### 1. 파일 없이 시작

첫 화면에 다음 요청을 입력한다.

```text
우리부 예산 현황을 확인하고 싶어
```

예상 결과:

- 의도 분석 MCP → 예산 MCP → 텍스트 표출 MCP 순서가 채팅에 표시된다.
- 현재 체험용 프로젝트 예산 요약을 채팅으로 답한다.
- 실제 기관 전체 자료가 연결되지 않았다는 범위를 함께 표시한다.

이어서 다음 요청을 입력한다.

```text
분석 내용에 시사점을 추가해서 보고서로 작성해줘
```

예상 결과:

- 보고서 MCP와 보고서 편집기 MCP가 로딩된다.
- 이전 답변을 바탕으로 파생 보고서가 생성되고 편집기에서 열린다.

보고서 문구를 드래그한 뒤 다음 요청을 입력한다.

```text
이 문구에 대해서 당위성을 강조하는 문구로 바꿔
```

예상 결과:

- 보고서 MCP가 선택 영역만 변경하는 제안을 만든다.
- 적용하면 현재 문서와 스크롤 위치를 유지하고 선택 문구만 교체한다.

### 2. 파일을 첨부해서 시작

첫 화면에서 HWPX, PDF, Markdown 또는 TXT 자료를 첨부하고 다음 요청을 입력한다.

```text
첨부된 문서를 기준으로 올해 결산 보고서 양식으로 작성해줘
```

예상 결과:

- 첨부 문서는 먼저 로컬 문서 어댑터로 읽는다.
- 결산 양식 MCP → 보고서 MCP → 보고서 편집기 MCP 순서로 파생 보고서를 연다.
- 확인할 수 없는 수치나 필수 항목은 추측하지 않고 `확인 필요`로 표시한다.

생성된 보고서의 문구를 드래그한 뒤 다음 요청을 입력한다.

```text
이 문구에 해당되는 법조항을 찾아줘
```

예상 결과:

- 법률 MCP와 텍스트 표출 MCP가 로딩된다.
- 법령 원문 커넥터가 연결되지 않은 현재 환경에서는 조항을 지어내지 않고 연결 필요 상태를 답한다.

## 모델·데이터 전송 정책

- 기본 모델: `upstage/solar-pro-3`
- 선택 이유: 한국어 업무 응답을 빠르게 받기 위한 저지연 기본값
- 대체 모델: 등록된 무료 모델 중 요청 Capability와 맞는 모델
- 외부 실행 조건: 운영 환경의 `AIWORKS_OPENROUTER_LIVE=1`, API 키, 사용자 실행 승인 모두 충족
- 외부 전송 기본값: 거부
- 첨부 원본 전체는 모델에 보내지 않고 로컬 추출 발췌만 실행 계획에 표시한다.
- `confidential` 등급은 외부 모델 라우팅을 차단한다.

## 현재 의도적으로 남긴 한계

- 예산 MCP는 체험용 프로젝트 데이터만 제공하며 기관 재정시스템과 아직 연결되지 않았다.
- 결산 양식 MCP는 체험용 구조이며 실제 부처별 최신 원본 양식을 등록해야 한다.
- 법률 MCP는 Capability 흐름만 연결되어 있고 국가법령정보센터 등 권위 있는 원문 커넥터가 필요하다.
- 생성 보고서는 아직 범용 Artifact/계보 테이블이 아니라 기존 작업 문서 호환 계층에 열린다.
- 프로젝트 귀속, Fact Registry와 영속 Workflow Runtime은 로드맵 18~22단계에서 구현한다.

## 피드백 질문

1. 첫 요청에서 승인 화면이 이해하기 쉬운가?
2. 로딩된 MCP 순서가 실제 업무 흐름과 맞는가?
3. 채팅 답변에서 편집기 보고서로 전환되는 시점이 자연스러운가?
4. 선택 문구 변경 후 보고서 위치가 유지되는가?
5. 실제로 먼저 연결할 예산·양식·법률 데이터 소스는 무엇인가?
