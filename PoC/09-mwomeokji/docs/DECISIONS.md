# PoC 09 결정 기록

팀 공유 후 확정한 제품·기술 결정을 기록한다. 각 항목에는 날짜, 결정, 검토한 대안, 근거, 담당자를 적는다.

## 열린 결정

- 데모 매장과 메뉴 정보 확인 책임자
- 팀 역할과 발표 범위
- 배포 HTTPS 주소와 QR 시연 방식
- 실 LLM·Jev·OCR의 발표 포함 여부

## 확정된 기본 원칙

- 실제 결제는 구현하지 않고 Mock 결제만 사용한다.
- 메뉴·가격·옵션·알레르기 상태·총액·주문 확정은 서버 도메인 로직과 검증된 데이터가 결정한다.
- 루트 `.env`의 API 키는 서버에서만 사용하고 PoC 09 폴더에 복사하지 않는다.
- 룰 단독·키 없는 Mock 모드로 핵심 주문을 완수할 수 있어야 한다.
