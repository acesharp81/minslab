# data — 주택파동 상황판용 데이터 (2026-10-02·03 수집)

공공데이터포털(data.go.kr), 국방부 공공데이터 개방 도구, 국토교통 통계누리에서 **CSV 그대로** 내려받은 원본(`raw/`)과,
V-World에서 받은 건물 윤곽 자료(SHP), LH 입주자모집공고 PDF, 읽기 쉽게 정리한 표(`processed/`), 정리 스크립트(`tools/`)로 이루어져 있습니다. 인증키 같은 비밀값은 이 폴더에 없습니다.
**`board/`(종합상황판이 읽는 자료 3개, `tools/boarddata`가 `raw/`·`processed/`에서 만듦)만 배포에 올라가고, `raw/`·`processed/`·`tools/`는 배포하지 않습니다**(`.vercelignore`).

```
data/                                (이 폴더)
  board/      종합상황판이 읽는 자료(molit.json·lh-completion.json·sources.json). 배포에 올라감
  raw/        내려받은 원본 (수정하지 않음). 기관별로 묶음
    datagokr/   공공데이터포털 파일데이터(번호_기관_제목_기준일.csv) 10개
    molit/      국토교통 통계누리 5개
    lh/         notices/ 입주자모집공고문 PDF · pamphlets/ 팸플릿 PDF · cwstt/ 청약플러스 공사현황 · public/ 사전정보공표
    vworld/     GIS건물통합정보 인천 zip, 인천계양 용지 윤곽 geojson
    gh/  osm/   경기주택도시공사 목록·계획표, OpenStreetMap 역·학교
  processed/  통계누리 5개 정리본 + 건물 요약 json(gyeyang_buildings_summary.json) + 단지 표(gyeyang_projects.csv)
  tools/      paths.py  (모든 도구가 쓰는 경로. 폴더를 옮기면 여기만 고침)
              molit_tidy.py  (raw/molit → processed/)
              vworld_buildings/  build_buildings.py, tm.py  (raw/vworld → legacy/gyeyang_buildings.js)
              lh_projects/  build_projects.py, extract_plans.py  (LH 팸플릿·V-World·공정율 → legacy/gyeyang_projects.js)
              context/  build_context.py  (raw/osm → legacy/gyeyang_context.js)

legacy/                              (옛 계양 운영 데이터 3개. 지도는 루트 regions/ 번들을 읽는다 — tools/regiontools/migrate_legacy.py 로 옮김)
  gyeyang_buildings.js  gyeyang_projects.js  gyeyang_context.js
```

- **연도별 '계획' 칸이 비어 있습니다.** 지역별 연간 표에 `계획` 행이 있지만 2021~2025년 모두 값이 없습니다. 이 통계로는 "계획 대비 실적"을 만들 수 없습니다.
- 구분 값 `합`은 원본 표기 그대로입니다(`합계`의 잘린 표기로 보이나 미확인).

### 원본 CSV의 문제와 정리 방법

통계누리 CSV는 천 단위 쉼표(예: `388,362`)를 따옴표 없이 써서 **숫자 하나가 여러 칸으로 쪼개집니다.** 그대로 읽으면 열이 어긋납니다.
`tools/molit_tidy.py`는 쪼개진 조각을 다시 합치고, 다음 검사를 통과해야만 결과를 씁니다.

- 월간 3개 표: 같은 기간·구분·부문에서 `전국 = 시도 합`이 **1,200건 모두 일치**
- 분양 표: 각 행에서 `합계 = 분양 + 임대 + 조합`(순계·누계 각각)이 성립하는 해석이 정확히 하나 (1,198행 모두)
- 지역별 연간 표: `실적 = 시도 합`이 5개 연도 모두 일치

실행: `python3 data/tools/molit_tidy.py` (표준 라이브러리만 사용)
