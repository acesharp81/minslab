## Intent

현재 프로덕션인 「주택파동」(주택공급 디지털 상황판 PoC)을 소개하는 15초 오프닝 영상.
발표자료(docs/주택파동_발표자료.html)의 첫머리에 넣어 발표 시작 때 재생한다.
네이비·골드 '도면형' 톤을 발표자료와 맞춘다. 내레이션은 없고(발표자가 직접 말한다),
화면 글자와 배경음악으로 끌고 간다.

사용자 요청 원문: "현재 프로덕션을 소개하는 영상을 15초짜리로 만들어 발표자료와 html 영상포함해"
→ "발표자료는 html로 만들어", "배경음악 포함해서 진행"

## Assets

- docs/주택파동_3D지형_테스트.html — 현재 프로덕션의 인천 계양 3D 공급 지도. 헤드리스 Chrome으로 화면을 캡처해 영상 소재(assets/footage/)로 쓴다.
- docs/주택파동_발표자료.html — 기존 9장 HTML 발표자료. 원본은 건드리지 않고 복사본에 영상 슬라이드를 추가한다.
- data/README.md — 영상에 쓰는 수치의 근거.

## Customizations

- 배경음악: HeyGen 로그인과 로컬 음악 엔진(MusicGen)이 모두 없어서, 128 BPM 8마디(=15.000초)로 직접 합성한 오리지널 곡을 쓴다. 장면 전환이 마디선(0 / 3.75 / 5.625 / 11.25 / 15.0초)에 맞는다. HeyGen에 로그인하면 카탈로그 곡으로 바꿀 수 있다.
- 산출물 3종: ① 15초 composition(HTML 영상) ② 렌더한 mp4 ③ 영상을 오프닝으로 넣은 발표자료 HTML 복사본.

## Notes

- 영상에 쓰는 수치는 지도 화면과 data/README.md로 확인된 값만 쓴다: 6개 단지·3,173세대, 분양중 972·건설 단계 1,095·준공 임박 1,106, A2·A3 공정율 100%.
- 쓰지 않는 값: 발표자료 6·7장의 100,000호 등 '예시' 수치, 공사금액('억원' 단위 미확정), 입주시기 보기(추정), D-n 같은 날짜 상대값.
- '준공 임박'은 이 프로젝트가 정한 분류(공정율 90% 이상이면서 입주 3개월 안)이며 LH 공식 구분이 아니다.
- 지도 화면은 LH 인천계양 단지와 국토교통부 건물 자료만 보여 준다. SH·국방부 자료는 수집돼 있지만 이 지도에는 아직 없으므로, 영상은 '한 화면에 통합됐다'고 단정하지 않는다.
- 출처 표기: 건물 © 국토교통부 GIS건물통합정보(V-World), 역·학교 OpenStreetMap contributors(ODbL), LH 공사현황.
- docs/vworld-key.js(개발키)는 산출물에 넣지 않는다.
- 렌더는 최종 미리보기 확인 뒤에만 한다.
