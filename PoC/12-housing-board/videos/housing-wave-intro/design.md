# 「주택파동」 15초 오프닝 — 디자인 스펙

브랜드 기준(brand truth)은 `docs/주택파동_발표자료.html`의 '도면형' 슬라이드다. 값은 그 파일의 CSS 변수를 그대로 옮겼다.

## 컨셉 한 문장

도면(blueprint) 위에서 정책에서 입주까지 6단계가 켜지고, 흩어진 기관 자료가 하나로 모여 한 장의 상황판(지도)이 된다.

## 팔레트

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--navy` | `#0B2B5A` | 배경 |
| `--blue` | `#123E7C` | 보조 면 |
| `--card` | `#0F3568` | 카드 면 |
| `--ink` | `#EAF2FF` | 본문·제목 |
| `--mute` | `#BBD3F3` | 보조 글자·테두리 |
| `--gold` | `#FFC247` | 강조(유일한 강조색), 마지막 장 배경 |

지도 상태색은 지도 화면과 같게 쓴다: 분양중 주황 `#FF8A3D`, 건설 단계 파랑 `#5AA9FF`, 준공 임박 초록 `#3FD0A0`(네이비 위 대비를 위해 밝게 조정한 값).

## 글꼴

- 한글·숫자: Gothic A1 (400 / 600 / 800). 발표자료와 같은 글꼴. 쓰는 글자만 부분 내려받아 `assets/fonts/`에 내장.
- 라벨·숫자 보조: Space Mono (400 / 700). 렌더러에 내장된 글꼴.
- 산세리프 + 모노 조합이라 서로 겹치지 않는다. 제목은 800, 본문은 400~600으로 굵기 대비를 크게 둔다.

## 배경 처리

- 60px 간격 도면 격자(2px, 불투명도 10%), 48px 안쪽 테두리(2px, `--mute`).
- 마지막 장은 발표자료 마지막 장처럼 금색 바탕 + 네이비 글자.
- 호흡하는 금빛 글로우 하나(느린 주변 움직임).
