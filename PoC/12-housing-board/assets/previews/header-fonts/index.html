주택파동, 로고 글꼴을 바꿔 보면

각진 제목체부터 둥근 글꼴, 명조까지. 같은 심벌에 서로 다른 글꼴로 ‘주택파동’을 조합했습니다.
큰 크기에서 형태를 비교하고, 선택한 글꼴을 실제 64px 헤더 크기에서도 확인해 보세요.

맥북에서도 웹폰트가 로딩되면 서로 다르게 보입니다. 앞선 5종은 형태가 비슷한 UI 고딕이며, 기존 로고의 글자는 SVG 도형이라 글꼴 설정에 따라 바뀌지 않았습니다. 이번 시안은 심벌과 실제 글자를 분리했습니다.

실제 헤더에서 보기 · Do Hyeon

로고는 기본 30px, 메뉴는 16px입니다. 선택한 글꼴을 로고와 모든 메뉴명에 함께 적용합니다. 기존 SVG 로고 선택 시 메뉴는 Pretendard로 표시합니다.

이 프로젝트에는 Pretendard를 우선 추천합니다

제 디자인 판단으로는 Pretendard가 메뉴와 숫자를 균형 있게 보여줘 상황판의 기본 글꼴로 가장 무난합니다. 조금 더 날렵한 인상을 원하면 SUIT, 브랜드 개성을 더하고 싶으면 Wanted Sans를 비교해 보세요. 선택 후에는 실제 상황판의 작은 표와 차트에서도 확인하는 것이 좋습니다.

비교 조건 기본 메뉴 16px / 400, 활성 메뉴 700, 자간 0, 헤더 높이 64px. 이 섹션의 로고 텍스트도 각 후보 글꼴로 표시합니다. 상단의 기존 로고는 SVG 원본 비교용입니다. 아래 제목과 수치는 글꼴 비교용 샘플입니다. 현재 앱은 Noto Sans KR을 우선 선언하지만, 별도 웹폰트 로딩 없이 시스템 대체 글꼴이 보일 수 있습니다.

굵기 주의 LINE Seed Sans KR은 Thin / Regular / Bold를 제공하며 Medium은 없습니다. 500 선택 시 실제 Regular(400)로 표시합니다. 모든 후보는 로컬 웹폰트를 로딩하고 합성 굵기를 사용하지 않습니다.
