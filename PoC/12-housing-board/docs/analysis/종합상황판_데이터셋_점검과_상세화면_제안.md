# 종합상황판 — 데이터셋 존재 여부 점검과 상세 화면 제안

기준일 2026-10-08. 대상 시안: `docs/design/주택파동_종합상황판_최종.html`(수치는 전부 SAMPLE, 성북구 3개 사업만 실데이터).
이 문서는 **새 데이터를 받지 않고**, 저장소에 이미 있는 것과 시안이 요구하는 것을 대조한 결과다. 직접 열어 센 값만 적었고, 확인하지 못한 것은 "미확인"으로 표시했다.

## 결론

1. 시안 위젯 10개 중 **지금 숫자를 채울 수 있는 것은 월별 실적 흐름·원천 목록 2개와, 일부만 채우는 2개**(LH 준공 예정, 시행주체별 호수)다. 나머지는 전국 사업 단위 적재가 먼저이거나(B), 원천 자체가 없다(C).
2. 시안의 핵심인 **지연·주의·정상 신호판은 데이터가 없다.** 사업 레지스트리 77건 중 `schedule`(당초·변경·현재 예정)이 있는 건이 0건이다. 신호판은 "전국 인허가 적재 + 예정일 확보"가 끝나야 의미가 생긴다.
3. 상세 화면은 이미 고정된 계약(AreaRef 코드, `PRJ-…` id, `resolve`, `?project=`, 원천 카탈로그, 기획서 4.3 사업 상세)을 **그대로 재사용**하는 5계층으로 제안한다.

**읽는 법.** "지금 채울 수 있다"(A)는 호수 통계와 LH 준공 예정이다. "지연"이라는 말이 붙는 위젯은 모두 일정 비교가 필요해서 B 이하다.

### 막힌 원인 3가지
- **예정일이 없다.** 준공예정일은 주택인허가에만 있고(성북 82건, 54%), 건축인허가는 0%다. 레지스트리 `schedule` 0/77.
- **계획 숫자가 없다.** 통계누리 `계획` 비어 있음. 계획 대비 실적은 정책 문서(보도자료) 수작업 입력이 아니면 불가.
- **사업 단위 키가 끊긴다.** 청약홈·정책 후보는 지번·PNU가 없어 인허가와 이을 수 없다. 레지스트리 `refs`로 잇는 일은 수집 이후 단계다.

### 묵은 자료 주의
- 행복주택 공급계획(15043330)의 공급시기는 2022~2025뿐이다. 향후 예정으로 쓰면 안 된다.
- SH 공공재개발·재건축 현황(15124798)은 2023-11 기준 16행이다.

## 2. 상세 화면 제안

### 2.1 계층과 이동

```
L0 전국 종합 (시안 홈)
 ├─ 시도 타일 클릭 ───────▶ L1 시도 상세
 │                           └─ 시군구 행 클릭 ─▶ L2 우리 동네 사업 (시군구)
 │                                                   └─ 사업 행 클릭 ─▶ L3 사업 상세
 │                                                                        └─ '지도에서 보기' ─▶ L4 지도 팝업 (?project=PRJ-…, 구현됨)
 ├─ 단계 막대 클릭 ───────▶ S  단계(병목) 상세
 ├─ 기관 막대 클릭 ───────▶ A  기관 상세
 ├─ 파동 차트 월 클릭 ────▶ M  월 상세
 └─ 모든 숫자의 '출처' ───▶ D  데이터 원본(카탈로그)
```

- 원칙: 전국→사업은 **클릭 3번**, 어디서든 위 계층 경로(빵부스러기)로 한 번에 올라온다. 기획서의 "선택 5번 이내"를 지킨다.
- 이동 식별자는 새로 만들지 않는다: 지역은 AreaRef 코드(`sgg`·`bjd`), 사업은 `PRJ-{시군구5}-{일련4}`. 폐기된 id(`supersededBy`)도 열린다.
- 데이터가 없는 칸은 숨기지 않고 **등급 표지**(원천 없음 / 적재 전 / 샘플)를 붙인다. 시안의 SAMPLE 태그 방식을 상세까지 이어간다.

### 2.2 L3 사업 상세 (기획서 4.3 확장)

```
┌ 사업명 · PRJ-11290-0001 · 성북구 장위동 · 시행자 ──────────────┐
│ ① ② ③ ④ ⑤ ⑥  6단계 스테퍼 (현재 단계 강조)     [신호: 정상│주의│지연] │
├───────────────────────┬─────────────────────────────────────┤
│ 일정 타임라인           │ 위치 미니맵 + [지도에서 보기]          │
│ 허가→착공→사용승인        │ (pnus 없으면 "위치 미연결")           │
│ 당초·변경·현재 예정 겹쳐 표시│                                     │
├───────────────────────┼─────────────────────────────────────┤
│ 규모: 호수·동수·유형      │ 같은 구역의 다른 사업 / 변경허가 이력     │
├───────────────────────┴─────────────────────────────────────┤
│ 근거: 원천기관 · 데이터셋 · 기준일 · 갱신일 · 관리번호(refs) · 원문 링크 │
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 데이터 | 시각화 | 등급 | 근거 |
|---|---|---|---|---|
| 머리 | `name` `id` `sgg` `bjdCodes` 시행자 | 텍스트 | A | 레지스트리 77건 전부 |
| 6단계 | `stageCode` | 6칸 스테퍼 | A | 77건 전부 |
| 일정 타임라인 | `events`(permit_approved·construction_start·completion_inspection) | 가로 타임라인, 오늘선 | A(번들·HUB 이벤트) / C(당초·변경·현재) | 광산·나주 번들은 이벤트 보유. `schedule` 0/77 |
| 신호 | 지연 개월 = 현재 예정 − 당초 | 3색 배지 + 개월 수 | C | 기준(0/1~6/6개월)은 제안 단계, 담당자 설정 필요 |
| 규모 | `units` | 숫자 + 동수 | A | 75/77 보유 |
| 위치 | `pnus` | 미니맵, 지도 팝업 | A | 75/77 연결, 2건 "위치 미연결" |
| 근거 | `refs` `source` `asOf` | 표 + 원문 링크 | A | 스펙 9.1 |

### 2.3 L1 시도 상세 / L2 시군구

| 영역 | 데이터 | 시각화 | 등급 |
|---|---|---|---|
| KPI 4칸 | 사업 수·호수·지연율·다음 3개월 예정 | 큰 숫자 + 전월 대비 | B |
| 월별 실적 | 인허가·착공·준공·분양(시도) | 작은 선 4줄, 잠정치 빗금 | **A** |
| 6단계 분포 | 단계별 사업·호수 | 가로 막대(깔때기형) | B |
| 시군구 비교 | 시군구별 지연율 | 정렬 가능한 표 + 막대 | B |
| 지연 TOP 10 | 지연 개월 큰 사업 | 표, 행 클릭 → L3 | C |
| 시행주체별 | LH·지자체·민간 호수 | 누적 막대 | **A** |

L2는 사업 목록(이름·단계·호수·신호)과 "이 동네 지도" 버튼(`?sgg=`)만 둔다. 지도는 새로 만들지 않고 기존 지도 모듈을 팝업으로 연다.

### 2.4 곁가지 상세
- **단계(병목) 상세**: 그 단계에 머문 사업 목록 + 머문 기간 분포 막대. 기간은 단계 진입일이 있는 사업만(B).
- **기관 상세**: 기관의 사업 목록·호수·단계 분포. 국방부는 수작업 입력 칸이 비어 있음을 명시.
- **월 상세**: 그 달의 인허가·착공·준공·분양 호수(시도별, A)와, 예정 월이면 LH 준공 예정 블록 목록(A).
- **데이터 원본**: 스펙 9.3 스키마 그대로. `collectedAt`(받은 날)과 `sourceAsOf`(원천 기준일)를 반드시 나눠 보인다.

### 2.5 착수 순서 제안
1. A 등급만으로 열리는 화면부터: 시도 월별 실적, 시행주체별 호수, LH 준공 예정, 데이터 원본, 사업 상세(머리·6단계·규모·위치·근거).
2. 전국 건축HUB 인허가 적재(주택인허가 먼저) → 시도 KPI·6단계 분포·시군구 비교.
3. `schedule` 확보 방식을 정한 뒤 신호판·병목·지연 TOP.
4. 월별 수집 이력은 **지금 시작해야** 6개월 뒤 추이 차트가 생긴다. 데이터가 없는 위젯 중 시간이 걸리는 건 이것뿐이다.

## 3. 열린 점
- 시안 "M3"가 가리키는 대상을 이 저장소에서 찾지 못했다(`docs/design/` 6개 파일에 M3 라벨 없음).
- "현재 기준 로고"가 주택파동(남색 지붕+주황 리본)인지 주택한눈(눈+집)인지 확정이 필요하다.
- 사업 단계 대표 규칙(한 사업의 단지들이 서로 다른 상태일 때)은 스펙 9.2의 미결 사항 그대로다.
