# 화면 배색·지도 화면 개선 계획 (2026-10-09)

라이트·다크 두 모드의 배색과 지도 화면의 어색한 부분·픽셀 깨짐을 고친다. 근거는 같은 날 찍은 화면(1440·390 폭, 라이트·다크, 지도는 레티나 2배)과
실제 토큰 값으로 계산한 대비(WCAG)·색상각(OKLCH)이다.

**지킬 것**
- 종합상황판(`/`)의 구성(위젯 종류·순서·칸 배치)은 바꾸지 않는다. 색·그림자·글자색 같은 디자인만 바꾼다.
- 의미가 같은 것은 같은 색, 의미가 다른 것은 다른 색. 색 값은 의미 이름의 토큰 한 곳에서 정한다.
- 글자는 바탕 위 4.5:1, 차트 면·선·기호는 3:1 이상(WCAG 1.4.3·1.4.11). 바꾼 값은 시험으로 고정한다.
- 커밋·배포는 하지 않는다(요청이 있을 때만).

## 2. 실행 단계

각 단계는 끝날 때 `npm test` 를 돌린다. 화면 확인은 5단계에서 한꺼번에 한다.

### 1단계 — 토큰(app/tailwind.css)
1. 단계색을 의미 이름으로: `--st-{plan,permit,build,sale,soon,move,priv}`(차트·면 채움, 3:1 이상)와 `--st-*-ink`(글자·칩, 4.5:1 이상). `--s-blue…--s-amber` 는 없앤다.
   - 라이트 채움: 계획 #5C7FAF · 인허가 #43958F · 착공 #B07434 · 모집 #7F8C9E · 준공 #73884F · 입주 #9183AD · 민간 #8C99AB
   - 다크 채움(채도 완화): #6F96E6 · #3BB5A9 · #E08A3C · #A3AEBF · #8CC45C · #B98BE0 · #8A95BD
   - 글자(ink)는 지도의 기존 값: 라이트 #365F99 · #327F79 · #8E541D · #536278 · #526E35 · #795B9E · #53637A / 다크 #7BA7FF · #45D3C4 · #FF9F43 · #C7D0DA · #A5E56D · #D9A6FF · #98A3C9
2. 라이트 `--warn` #A56818 → #7F6300 (흰 바탕 5.7:1, 색상각 89° — 착공과 23° 떨어짐).
3. 라이트 `--mute` #778599 → #5F6E82, 리본 축 `--rb-axis`·`--rb-yr-off` 도 같은 값.
4. 시행주체: 공공 3주체는 서로 다른 색(라이트 #2F7A73·#3D63A0·#8160A8 / 다크 #3FB8AA·#6F96E6·#B98BE0), 민간은 낮은 강조 중립색(라이트 #B9C3D0 / 다크 #3A4C7A).
5. 지연율 바탕색 6단계를 한 색상(로즈) 밝기 단계로 다시 잡는다. 밝기가 단계마다 한 방향으로 변하게 한다.
6. 면·그림자 토큰: `--shadow-card`(라이트 옅은 그림자 / 다크 위쪽 1px 하이라이트), `--shadow-pop`(라이트 rgb(15 23 42/14%) / 다크 현행). 라이트 바탕 #F5F7FA → #EEF2F6.
7. shadcn 기본 `--chart-1..5` 는 새 채움 값과 맞춘다.

확인: `tests/js/tailwind.test.cjs` 에 시험 추가 — 채움 3:1, 축 글자 4.5:1, 주의·착공 색상각 20° 이상, 지연율 단계 단조, 두 테마 토큰 이름 일치.

### 2단계 — 대시보드 컴포넌트
1. `lib/board/sample.ts` 단계색 `C` 와 `components/charts/palette.ts` 를 새 토큰으로.
2. `Board.tsx`: 추이 선 주의 = `--warn`, 병목 행 = 옅은 주색 면 + 주색 배지, 시도 타일 칩 불투명도 70% → 90%, 타일 '상세' 글자 = `ink2`, 툴팁 그림자 = `--shadow-pop`.
3. `components/ui/card.tsx` 카드 그림자 = `--shadow-card`(종합상황판 PC 의 2% 그림자 규칙도 같은 토큰).
4. `TopNav` 모바일 메뉴 그림자 = `--shadow-pop`.

확인: 종합상황판 DOM 구조가 같은지(위젯 수·순서) 촬영 전후 비교.

### 3단계 — 지도(assets/css/app.css · assets/js/app.js · index.html)
1. 다크 지도 강조색 `--acc` 를 대시보드 주색(#9DBCE9 / 글자 #10243D)으로.
2. 라이트 지도 `--warn` 과 기반시설 주의색 #895516 → #7F6300.
3. 단계색 단일 원천: 지도 셸의 `--sale…--plan` 은 `var(--st-*-ink)` 를 가리키고, `app.js` 는 지도 셸에서 CSS 변수를 읽는다(독립 지도 index.html 은 지금의 다크 값을 대체값으로 유지).
4. 라이트 3D 단지 동 색의 높은 층 끝을 글자용 진한 색 → 채움 색으로, 민간 블록 면도 채움 색으로(덩어리감 제거).
5. 라이트 배경 V-World `Base` → `white`(장소 글자가 박히지 않은 지도, 글자는 벡터 지명만 → 일그러짐·이중 표기 제거).
6. 블록 무늬를 2배 해상도·8px 주기로 다시 그리고 축소 단계에서 옅게(무아레 제거).
7. 숨긴 구역이 실제로 숨게(`.sec[hidden]`), 해당 레일 점도 숨김.
8. '입주·준공 예정' 이 비면 축 대신 안내 한 줄, 패널 SVG·합계 막대의 고정 다크 색을 CSS 변수로.
9. 축척·출처 컨트롤을 유리 토큰으로, HUD·카드 그림자를 테마 토큰으로.
10. 900px 이하: 지도 머리 줄과 지도를 상단 메뉴 바 높이만큼 내려 가림 해소.

확인: `glass.test`·`shell.test` 갱신, 지도 2배 캡처 전후 비교(무늬·글자 확대 crop).

### 4단계 — 시험
- 1·3단계의 시험 추가·갱신. 전체 `npm test` 통과.

### 5단계 — 화면 검증
- 13개 화면 × 라이트·다크(1440) + 종합상황판·지역 상세(390) 촬영, 지도 개요·근접·평면(2배)·패널·모바일 촬영.
- 전후를 나란히 놓고 확인. 종합상황판은 위젯 순서·칸 수가 같은지 DOM 으로도 확인.

### 6단계 — 2차 분석·보완

- **7단계(기록)**: 이 문서와 `Tailwind-shadcn-전환.md`(라이트 주색·차트 토큰 이름 문구) 갱신. 최종 `npm test` 468건 통과, `tsc --noEmit` 오류 없음. 커밋·배포는 하지 않았다.

## 4. 남은 일·보류
- 다크 지도 배경(`midnight`)의 확대 17 이상에서 그림에 박힌 장소 글자 — 시안이 고른 배경이라 유지.
- 단계 이름 체계가 화면마다 다르다(종합상황판 ①계획~⑥입주, 사업·단계 화면 1정책~6입주). 색이 아니라 정보 구조 문제라 손대지 않았다.
- 종합상황판 모바일(390)의 리본 차트 글자가 너무 작다 — 구성 변경이 필요해 범위 밖.
- 쓰이지 않는 지도 배지 그림(`badgeImage`·`bd-*`)이 남아 있다(원래부터 있던 죽은 코드, 지우지 않음).

## 10. 카드 호버 (2026-10-10, 사용자 요청 "카드 호버시 인터렉션 효과도 같이")

- 누를 수 있는 카드(`card-lift`: 링크 카드·지시 카드·시도 타일·계단 칸·우리 동네 지도 링크): 2px 떠오름 + `--shadow-hover` + 테두리 주색 45%(배경 hover 는 기존대로). 눌린 카드(aria-pressed)·현재 단계(aria-current)는 고리를 지키고, 테두리 색이 뜻을 가진 계단 칸(`keep-border`)은 공개 범위 색을 지킨다. 누르는 순간(active)은 내려앉는다.
- 누를 수 없는 카드(`card-soft`: 패널·KPI·원천·종합상황판 패널·우리 동네 달력 달): 떠오르지 않고 `--shadow-hover-soft` + 테두리 `--line2` — 떠오르면 누를 수 있는 것처럼 보이기 때문. 지시가 가리키는 패널의 주색 고리(`is-ringed`)는 덮지 않는다.
- 지도 패널의 단지 카드·다음 일정·점검 요약도 1px 떠오름 + `--card-hover-shadow`(지도 위 가로 요약 줄은 제외).
- 손가락 기기에는 호버가 남지 않게 `@media (hover: hover)` 안에서만, 움직임 줄이기면 떠오르지 않는다(색·그림자만).
- 함정: 등장 동작(q-*)의 `animation-fill-mode: both` 는 끝난 뒤에도 `transform: none` 을 붙잡아 호버의 떠오름을 막아서 `backwards` 로 바꿨다.
- 확인: 링크 카드(라이트·다크)·지시 카드·시도 타일·계단 칸(현재 단계 포함)·패널의 호버 전후를 찍고 계산 스타일(transform -2px·그림자·테두리)을 확인. 시험 `motion.test.cjs` +3. 전체 통과.
