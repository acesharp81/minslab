## 1. 배경과 목표

2026-09-30 제3차 범부처 주택 신속공급 점검회의에서 '주택공급 디지털 상황판'을 조속히 구현해 사업별 진행상황과 앞으로의 변화를 알기 쉽게 설명하라는 지시가 있었습니다. 「주택파동」은 이 상황판을 **실제 데이터 구조·정책 시각화·국민 공개 방식으로 구현하는 PoC**입니다. 차별점은 모든 수치에 **원천기관·기준일·갱신일·원문**을 붙이는 것입니다.

| 6단계 | 코드 | 현재 확보한 데이터(신청 API·파일 기준) |
|---|---|---|
| 정책 | 01 | 없음(통계 목록 URL뿐) |
| 사업화 | 02 | 파일로 받은 SH 공공재개발·재건축 현황 |
| 인허가 | 03 | 건축HUB 주택·건축인허가 |
| 건설 | 04 | 건축HUB 착공·사용승인, 행복도시 준공계획, LH 준공예정 파일 |
| 공급 | 05 | 마이홈 모집공고, LH 공급정보, 청약홈 2건 |
| 입주 | 06 | 청약홈 입주예정월, LH 단지정보 파일 |

### 1.1 상황판 전체와 지도 모듈의 관계

이 저장소의 지도 앱(MapLibre, V-World 건물 3D, 공공주택 단지, 입주 전 점검, 버스)은 상황판의 **'지도 현황' 상세 화면**에 해당합니다.

| 구분 | 상황판 본체 | 지도 모듈(이 저장소) |
|---|---|---|
| 역할 | 6단계·신호판·현황표·보고자료·데이터 원본·국민 공개 메뉴 | 위치·건물 3D·단지·입주 전 점검·버스 |
| 기술 | Next.js(App Router, TypeScript), 예정 | 정적 HTML + MapLibre + `api/*.js`. 이식 가능하게 순수 함수·계약 중심으로 둠 |
| 연결 | 사업을 고르면 **팝업**으로 지도를 연다 | 코드를 받아 열린다. 상황판과는 **코드·API 계약만** 공유 |
| 데이터 | 통합 DB(사업 레코드, 6단계, 출처·기준일) | 지역 번들(`regions/<slug>/`)과 요청 시 조회 |

### 1.2 목표

| # | 목표 | 확인 지표 |
|---|---|---|
| G1 | 표준코드 하나로 지도가 상황판의 상세 화면으로 열린다 | 성공 기준 1·2 |
| G2 | 모든 수치에 출처·기준일을 붙인다 | 성공 기준 3 |
| G3 | 공공 API 한도 안에서 운영한다 | 성공 기준 4·5 |
| G4 | Next.js로 옮길 수 있게 계약을 먼저 고정한다 | 스펙 8절 |

**하지 않는 것**: 분양·임대·전세 자격의 자동 판정(대상이 될 수 있는 서비스 목록과 설명만 보이고 **판단은 본인**이 한다, `request.md`), 민간 건설사 정보(공공 부문이 1순위), 03 자연어 브리핑·04 페르소나 에이전트(추후 확장).

## 2. 사용자와 시나리오

| 사용자 | 흐름 | 지도 진입점 |
|---|---|---|
| ① 정책 담당자 | 신호판(정상·주의·지연 **호수**) → 지연 사유를 단계별로 → **사업 열어 보기** → 일정 변경 입력 | 신호판·목록에서 사업 클릭 → 팝업 지도 `?pnu=` 또는 `?bjd=`(사업 id 발급 후 `?project=`) |
| ② 일반 국민 | **내 지역** → 사업 선택 → **6단계 위치와 다음 일정** → 공급 캘린더 | '우리 동네' 선택 → (행정동이면 법정동 집합으로 변환) → 팝업 지도 `?bjd=` |

| 시나리오 | 단계 |
|---|---|
| A. 지연 사업 점검(담당자) | 1) 신호판에서 지연 호수 확인 → 2) 지연 호수를 눌러 사유(인허가·사업승인·착공·기타) 확인 → 3) 사업 열어 보기 → 4) '지도에서 보기'로 팝업을 열어 위치·주변 기반시설 확인 → 5) 기관 입력으로 일정 변경(PoC는 가상 기관) |
| B. 우리 동네 사업(국민) | 1) '우리 동네 사업' → 2) 시도·시군구·동 선택(**선택은 한두 번, 많아도 5번 이내**) → 3) 행정동을 골랐다면 법정동 집합으로 변환 → 4) 사업 목록에서 하나 선택 → 5) 6단계 위치와 다음 일정, 지도 보기 → 6) 공급 캘린더 |

| 출발 | 여는 방법 | 지도에서 보이는 것 |
|---|---|---|
| 신호판 사업 클릭, 사업 상세 '위치 보기' | `openMapPopup({ pnu })` 또는 `{ bjd }` | 필지 강조. 번들이 있으면 단지·건물 3D |
| '우리 동네' 선택 | `openMapPopup({ bjd: "a,b,c" })` | 경계 합집합. 번들이 없으면 "공급 사업 정보 없음 · 경계만(준비 중)" |
| 데이터 원본 화면의 조회 조건 | `openMapPopup({ bjd })` | 그 원천을 받은 법정동 경계 |

신호판 기본값 **제안**: 정상 = 지연 없음, 주의 = 지연 1개월 이상 6개월 미만, 지연 = 6개월 이상. 근거는 정책 매트릭스 5절의 "착공 6개월 이상 지연 = 즉시 점검", "3개월 이내 일정 변경 = 주의"이며 3~6개월 구간은 매트릭스에 없어 합의가 필요합니다. 기준은 담당자가 바꿀 수 있어야 합니다.
