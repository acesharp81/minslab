## 요약

- 활용신청 37건 모두 **승인, 개발계정**입니다. 신청 대기·보류·반려·기간만료·중지는 0건입니다.
- 이 프로젝트와 관련된 것은 **8건**이고, 모두 2026-10-02에 신청했습니다. 활용목적은 '웹 사이트 개발', 활용내용은 '내부 PoC'로 되어 있습니다.
- 이용허락범위는 8건 모두 '제한 없음'입니다. 활용기간은 만료예정일이 표시된 4건(건축HUB 2건, 마이홈, LH)이 2028-10-02까지입니다. 나머지 4건(통계누리, 행복도시, 청약홈 2건)은 목록에 만료일이 표시되지 않습니다.

| 정책 | 없음 | 통계누리 목록은 표 URL뿐 |
| 사업화 | 없음 | 파일로 받은 SH 공공재개발·재건축 현황(`data/raw`)이 유일 |

## 주의

- 개인 API 인증키는 마이페이지 화면에 평문으로 표시됩니다. 화면 공유·캡처 때 노출되지 않게 주의하세요. 코드에는 환경변수로만 넣고 저장소에는 올리지 않는 것을 권합니다.
- 건축HUB·마이홈은 포털 약관에 회원의 복제·제공 제한 문구가 있고 포털 이용허락은 '제한 없음'이라 서로 어긋납니다. 제공기관 확인이 필요합니다.
- 이 문서의 한도·주소는 포털 상세 화면 기준입니다. 실제 호출은 하지 않았으므로 응답 필드는 검증되지 않았습니다.
