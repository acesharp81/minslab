국정ON 핵심 기능 한 장 안내

상단 메뉴를 고르고, 아래 버튼 순서대로 이용하세요.

1

알람·실시간

진행 중인 방송 보기 · 관심 문구가 나오면 알림받기

  1. 방송 보기

    방송 카드의 ‘상세보기’를 선택 → 영상·실시간 발언·초안 확인. 방송이 없으면 지난 회의는 ‘회의 보고서’에서 봅니다.

  2. 알림 등록

    ‘＋ 새 알림 주제 추가’ → 주제 이름 ‘재난 안전’, 감지 문구 ‘재난, 안전, 대피’ 입력 → 범위·카카오 여부 선택 → ‘알림 주제 저장’.

  3. 감지 내용 확인

    문구가 감지되면 ‘최근 알림’의 항목 선택 → 관련 발언 확인. 카카오 수신은 ‘나에게 보내기 연결’ 후 ‘카카오로도 받기’를 선택해 저장.

확인할 결과 방송 내용과 관심 문구가 언급된 발언을 확인합니다.

방송·알림 상세 3~7쪽 →
2

회의 보고서

회의 한 건의 논의 요약·후속 과제·근거 발언 읽기

  1. 회의 선택

    상단 ‘회의 보고서’ → 원하는 회의 카드 선택 → 대주제 펼치기. 소주제별 묶음 요약·화자별 요약·도출 과제를 읽습니다.

  2. 원문 대조

    소주제의 ‘근거 발언 N개’는 묶음 전체, ‘발언 확인’은 개별 요약, 과제의 ‘원문 보기’는 요구가 나온 발언을 보여 줍니다.

  3. 문서 저장

    ‘요약 문서 · 인쇄/PDF’ → 대주제·소주제·발언 요약 확인 → ‘인쇄 · PDF 저장’ → 프린터 또는 ‘PDF로 저장’ 선택.

확인할 결과 이 회의에서 무엇을 논의했고 어떤 과제가 남았는지 파악합니다.

회의·근거·출력 상세 8~11쪽 →
3

주제별 보고서

여러 회의를 기관·주제·기간으로 모아 보고서 만들기

  1. 조건 입력

    상단 ‘주제별 보고서’ → 소관 부처 ‘행안부’, 기간 ‘2026-10-01~2026-10-20’ 입력. 특정 쟁점만 보려면 주제도 입력합니다.

  2. 검색 후 작성

    ‘자료 검색’ → 관련 자료 목록 확인 → ‘보고서 작성’. 카카오 연결 안내가 나오면 연결 후 진행합니다. ‘외부도구 사용’으로 자료를 내보낼 수도 있습니다.

  3. 결과 확인·보관

    전체 요약·정책적 시사점·논점·후속 과제를 읽고 ‘세부 논의와 요구 과제 전체’ 확인 → ‘Markdown 다운로드’ 또는 ‘인쇄·PDF’.

확인할 결과 선택한 기간의 관련 논의와 요구 과제를 한 보고서로 모읍니다.

검색·작성·내보내기 상세 12~16쪽 →
4

인사이트

정책 흐름·쟁점 변화·회의 일정·분류 지도 살펴보기

  1. 정책 흐름 비교

    상단 ‘인사이트’ → 정책 흐름 타임라인, 쟁점 추세, 논의→제도화 항목 선택 → 상세 요약과 연결 근거 확인.

  2. 일정 찾기

    아래 일정 달력에서 이전·다음 월 이동 → 날짜 선택 → 해당 날짜의 회의·의안 목록 확인 → 공식 출처 열기.

  3. 분야별 분류 보기

    ‘3D 온톨로지’ → 정책 영역 또는 분류 선택 → 관련 키워드·적용 주제·연결 근거 확인. 닫으면 인사이트로 돌아옵니다.

확인할 결과 회의별 결과를 넘어 정책의 변화와 다음 일정을 살펴봅니다.

정책 흐름·달력·지도 상세 17~19쪽 →

화면 구성과 메뉴 이동하기

상단 메뉴 · 오늘 일정 · 사용법 팝업

  1. 상단 네 가지 메뉴로 이동

    ‘알람·실시간’은 방송과 관심 문구 감지, ‘회의 보고서’는 회의별 결과, ‘주제별 보고서’는 기관·주제·기간별 작성, ‘인사이트’는 일정과 정책 흐름을 보여 줍니다.

  2. 오늘 일정과 방송 상태 구분

    상단 ‘오늘 예정’의 화살표로 일정을 넘겨 봅니다. 예정 일정이 있다는 것과 현재 방송 중이라는 것은 다릅니다. 현재 방송 상태는 ‘알람·실시간’ 표시도 확인하세요.

  3. 읽던 화면으로 돌아오기

    다른 창을 다녀와도 읽던 보고서는 유지됩니다. 회의 목록에서 다른 회의를 선택하거나 주제별 보고서의 최근 이력을 선택하면 원하는 자료로 이동할 수 있습니다.

  4. 사용법 팝업과 홈 이동

    ‘사용법 알아보기’는 현재 화면 위에 열립니다. 목차·이전·다음으로 이동하고 ‘닫기 ×’ 또는 Esc로 닫습니다. 국정ON 로고는 홈으로 이동합니다.

처음에는 회의 보고서에서 요약을 읽고, 관심 분야가 생기면 주제별 보고서나 알림 기능을 이용해 보세요.

방송·수집·정리 상태 구분하기

알람·실시간 · 방송이 없거나 정리 중일 때 확인할 것

  1. 진행·종료 상태부터 확인

    ‘알람·실시간’에는 현재 방송과 최근 24시간 내 진행·종료 방송이 표시됩니다. 방송 카드를 누르면 해당 방송의 기록 화면으로 이동합니다.

  2. 영상과 저장 상태를 나눠 보기

    영상이 재생되는지와 자막이 기록되는지는 별도로 확인합니다. 저장된 발언과 마지막 갱신 상태를 함께 보세요. 방송이 없더라도 지난 회의 보고서는 읽을 수 있습니다.

  3. 종료 후 정리는 기다리며 기록 보기

    ‘완료 + 정리중’이면 방송은 끝났지만 보고서가 아직 작성 중입니다. 카드를 열어 저장된 발언과 실시간 초안을 먼저 확인할 수 있습니다.

  4. 보고서로 이어서 보기

    결과가 준비되면 ‘회의 보고서 보기’로 이동합니다. 읽던 초안이 열려 있는 경우 완료 안내가 나타나면 그 링크를 선택하면 됩니다.

항목·상태뜻과 사용 방법
진행중·기록 중생방송 진행 또는 실시간 자료 저장
완료·정리중방송 종료 후 결과 작성 단계
비공식 정리AI 잠정 보고서 열람 가능

‘방송없음’은 현재 대상 생방송이 없다는 뜻입니다. ‘정리중’은 처리 단계이며, 회의가 계속 방송 중이라는 뜻이 아닙니다.

방송 영상과 실시간 발언 읽기

방송 진행 시 · 영상, 발언 묶음, 초안 보고서 조작

  1. 방송 카드로 영상과 발언 열기

    진행 중인 방송 카드를 선택합니다. 생방송이 있을 때 영상과 발언 패널, 실시간 초안이 나타납니다. 촬영 화면은 현재 방송이 없는 실제 상태입니다.

  2. 이전 발언과 최신 발언 이동

    발언 패널의 ‘이전’이나 스크롤로 앞선 기록을 읽습니다. 위로 이동하면 최신 따라가기가 잠시 해제됩니다. ‘최신으로’를 누르면 다시 자동으로 최신 발언을 따라갑니다.

  3. 원문·화자 경계 읽기

    ‘원문 전체 보기’를 펼쳐 발언 전체를 읽습니다. 같은 화자의 자막은 같은 묶음에 누적됩니다. 이름이 확인되지 않은 경우 ‘화자 미확인’으로 표시될 수 있습니다.

  4. 영상 넓히기와 초안 탐색

    ‘시네마 모드’는 발언 패널을 숨겨 영상을 넓히고 ‘기본 보기’는 원래 배치로 돌립니다. 영상 아래 초안에서 주제·과제를 선택하거나 키워드로 찾아볼 수 있습니다.

표에 한 번에 일부 항목만 보여도 내부 스크롤로 이어서 볼 수 있습니다. 회의 종료 후에는 임시 초안과 최종 보고서의 자료 상태가 달라질 수 있습니다.

관심 문구 알림 만들기

주제명 · 감지 문구 · 기관 범위 · 3단계 알림

  1. 새 알림 입력

    ‘＋ 새 알림 주제 추가’를 누릅니다. 주제 이름은 목록에서 알아볼 이름이며, 실제 감지에는 아래 ‘감지 문구’가 사용됩니다.

  2. 감지 문구와 범위 지정

    ‘재난, 안전, 대피’처럼 문구를 쉼표로 구분합니다. 범위는 국회·정부 전체, 국회, 정부·국무회의 중 고릅니다. 너무 넓은 문구는 알림이 많아질 수 있습니다.

  3. 추가 옵션 선택

    최초 감지, 주제 전환 후 5분 유예 요약, 정회·종료 누적 요약을 자동으로 받습니다. 카카오로 받으려면 먼저 카카오 연결을 완료하고 ‘카카오로도 받기’를 별도로 선택합니다.

  4. 저장하고 목록 확인

    ‘알림 주제 저장’을 누르고 새 주제의 문구·범위·3단계 알림·카카오 표시를 확인합니다. 동일한 조건을 중복 등록하면 안내가 표시됩니다.

항목·상태뜻과 사용 방법
1차 · 최초 감지진행 중인 주제에서 같은 키워드가 반복돼도 재발송하지 않음
2차 · 주제 완료다른 주제로 전환 후 관련 발언이 5분간 없고 요약이 준비되면 발송
3차 · 정회·종료회의 누적 주제와 주요발언을 모아 상위 5개까지 안내
카카오 상세 보기짧은 본문 아래 전체 요약 보기에서 발송 당시 요약·근거 확인
수정한 조건은 이후 발언부터 적용됩니다. 수정 전에 지나간 자막을 새 조건으로 다시 알림하는 기능은 아닙니다.

알림 수정·삭제와 감지 기록 관리

지금까지 보고서 · 수정 · 삭제 · 읽은 기록 정리

  1. 기존 주제 수정

    주제 옆 ‘수정’을 누르면 현재 값이 입력 폼에 채워집니다. 문구·범위·카카오 여부를 바꾸고 ‘수정 내용 저장’을 누릅니다. 취소하려면 ‘수정 취소’를 선택합니다.

  2. 주제 삭제

    ‘삭제’를 누르면 확인 창이 나타납니다. 삭제하면 해당 관심주제와 과거 알림 기록도 함께 정리되므로 내용을 확인하고 선택하세요.

  3. 감지 기록과 근거 보기

    ‘최근 알림’에서 기록을 누르면 감지 문구와 관련 발언 흐름·요약·원문을 확인할 수 있습니다. 개별 기록의 ×는 해당 기록을 지웁니다. ‘읽은 기록 정리’는 읽은 기록을 정리합니다.

  4. 현재까지 모인 주제 보고서 보기

    ‘지금까지 보고서’는 그 주제에 현재 모인 발언을 정리합니다. 새 요약이 필요하면 생성 상태를 보여 주고, 같은 근거의 저장 결과는 재사용합니다. 팝업에서 MD·인쇄/PDF를 이용할 수 있습니다.

항목·상태뜻과 사용 방법
새 알림 표시읽지 않은 알림 수 안내

카카오 연결과 다른 기기에서 이어 보기

계정 연결과 메시지 수신은 별도 선택입니다

  1. 연결 시작

    ‘알람·실시간’의 ‘카카오 나에게 보내기’ 영역에서 연결 버튼을 누릅니다. 카카오 화면의 계정과 동의 항목을 확인하고 서비스로 돌아옵니다.

  2. 주제별 전송 여부 설정

    연결됐다고 모든 주제가 카카오로 전송되는 것은 아닙니다. 원하는 주제를 추가하거나 수정하면서 ‘카카오로도 받기’를 선택하고 저장해야 합니다.

  3. 새 PC·브라우저에서 이어 보기

    같은 카카오 계정을 연결하면 저장된 관심주제와 기록을 이어 볼 수 있습니다. 로그인 전 설정과 로그인 후 설정이 다를 때는 먼저 연결 계정을 확인하세요.

  4. 연결 해제와 내부 알림 구분

    연결 상태에서 해제 동작을 선택하면 카카오 연결을 해제할 수 있습니다. 화면의 관심주제 감지와 외부 메시지 전송 여부는 구분해 확인하세요.

‘주제별 보고서’의 내부 AI 작성은 카카오 연결이 필요합니다. 로그인이나 메시지 전송 동의는 본인 계정에서 직접 진행해야 합니다.

    상단 ‘회의 보고서’를 누르고 회의 카드를 선택합니다. 좌우 화살표나 가로 스크롤로 목록을 이동해 다른 회의를 고를 수 있습니다.

  2. 상태와 회의 제목 확인

    선택한 회의 제목, 날짜와 공식·비공식 상태를 확인합니다. ‘공식대조중’이면 공식 자료 비교가 아직 진행 중인 상태입니다.

  3. 주제·과제 표에서 이동
