# Changelog

## 2026-08-27 — 국무회의 LIVE를 국회 공통 처리 수준으로 확장

- KTV 공식 HLS 음성을 60초 단위로 원본 보존하고 Mistral Voxtral 화자 분리 전사를 공통 LIVE 자막 revision에 저장합니다.
- HLS 녹음과 전사를 producer/consumer로 분리해 전사 응답을 기다리는 동안에도 방송 음성이 연속 저장되며, 종료 후 남은 청크를 모두 처리할 때까지 `POST_PROCESSING` 상태를 유지합니다.
- 공식 결과와 병합된 과거 국무회의 카드에도 `LIVE 감지` 이력을 표시하고, 전사 기능 배포 전에 감지만 된 기록은 상세에서 자막 미수집 상태를 구분합니다.
- 회의 카드 태그를 `진행중/완료`, `기록 중/정리중/비공식 정리`, `공식정리`, `국회/국무회의`로 통일하고 진행·기록은 빨강, 처리·비공식은 노랑, 완료·공식·기관은 파랑으로 구분합니다.
- 국무회의 종료 후처리 중 워커가 재시작돼도 `POST_PROCESSING` 방송과 저장 청크를 다시 claim하고, 미해결 청크가 있으면 완료로 오인하지 않도록 복구·실패 상태를 보존합니다.
- 각 MP3 청크의 실제 재생시간과 누적 시작 시각을 사용해 마지막 부분 청크의 자막 타임라인과 음성 비용이 과대 계산되지 않도록 보정합니다.
- 국무회의도 화자 전환 요약, 실시간 주제·과제, 종료 후 전체 회의 브리프를 기존 국회 워커에서 함께 처리합니다.
- 종료 방송과 공식 정책브리핑을 회차·서울 날짜로 서버 검증 매칭하며 애매한 후보는 자동 연결하지 않습니다.
- 음성 전사 비용을 텍스트 요약 비용과 합산해 월 USD 10 한도를 적용하고 상단 사용량 API에 별도 전사 모델·시간·비용을 제공합니다.
- 방송 ID 기준 snapshot/delta 조회를 추가해 다른 동시 방송 자막이 섞이지 않도록 했습니다.
