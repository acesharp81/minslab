## 적용 범위와 방식

[검토 계획](STRUCTURING_REVIEW_20261019.md)에 따라 저장된 보고서 43건에 `discussion-structure/1.1`을 적용하고 API·기존 종료 보고서 worker·화면에 배포했다. 원본 보고서 43건의 변경 전후 해시는 모두 동일하다. 모델 요청, 응답, 실패 시도와 구조화 당시 근거 스냅샷을 별도로 보존한다.

- 상위 주제 → 세부 쟁점 → 질의·답변·입장·요구 → 원문 구간으로 표시한다. 세부 쟁점에는 기존 요약의 24개 상한을 적용하지 않는다.
- 실시간 묶음과 기존 보고서의 주제·화자·과제가 참조한 근거 발언을 대상으로 재분류한다. 회의 전체 발언을 빠짐없이 분석했다는 의미는 아니다.
- 혼합 묶음은 여러 쟁점으로 분리하고, 다른 사건·법원·인물의 무리한 통합은 제한한다. 자료 제출 요구는 공통 과제 아래 개별 요구와 근거를 보존한다.
- 원문 인용은 모델이 다시 작성하지 않고 저장된 원문 구간에서 추출한다. 근거 패널은 구조화 당시의 `LIVE_STRUCTURE_SNAPSHOT`을 조회한다.
- 원래 요약과 공식 대조본을 계속 열람할 수 있다. 공식 보고서는 공식 보기가 기본이며, 새 구조화 보기는 항상 잠정 자료다.
- 새 종료 보고서는 기존 worker에서 자동 처리한다. NIM 우선, OpenRouter, 기존 예산 제한을 적용한 OpenAI 경로를 사용한다. OpenAI는 UTC 00시 기준 일일 650,000토큰 예약·정산을 유지한다.
