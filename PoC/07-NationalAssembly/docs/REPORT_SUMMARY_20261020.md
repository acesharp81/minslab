# 회의 보고서 요약 표시 복원 — 2026-10-20

## 원인과 적용

구조화 결과는 분류 근거를 보존하기 위해 발언 원문을 `speaker_points.summary`에 담았다. 기본 보고서 화면은 이를 AI 요약과 같은 방법으로 펼쳐 표시했고, 첫 주제의 원문 패널도 자동으로 열었다. 공식 대조본에서도 화자별 원문이 펼쳐져 있었다.

- 보존된 AI 주요 논의 요약을 `report_summary` 읽기 투영으로 본문에 표시한다.
- 제목을 반복하는 임시 문장과 원문 인용은 AI 요약 목록에서 제외한다.
- 재분류된 세부 쟁점·발언 원문은 기본 접힘이며 사용자가 선택하면 열린다.
- 요약의 근거 버튼은 해당 요약이 참조한 저장 원문 스냅샷을 연다.
- 주제별 자료 제출 과제와 실제 요청·약속 문장의 직접 연결은 유지한다.
- Markdown은 요약 우선·원문 부록 접힘으로 저장하며, PDF에서는 발언 원문 목록을 제외한다.

기존 AI 요약을 재사용하는 표시 개선이다. 재분류된 세부 쟁점 전체를 새로 요약한 것은 아니다. 분류 결과와 보고서 원본을 덮어쓰지 않았고 추가 LLM 호출은 없다. 적합한 요약이 없는 신규 보고서는 생성 대기 상태를 명시한다.
