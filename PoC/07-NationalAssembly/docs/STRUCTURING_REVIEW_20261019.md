## 원인

1. **요약의 24개 상한이 세부 쟁점 보존에도 적용된다.** 합성 결과 20개에 로컬 보완 4개가 붙어 상한에 도달했다. 보완은 발언 개수 순으로 선택하며 ‘국정감사 증인 선서 절차 안내’도 자리를 차지했다. 대표 요약의 분량 제한과 세부 논의 보존을 분리해야 한다.
2. **미연결 묶음끼리 다시 구조화하지 않는다.** 의미 연결은 기존 최종 주제 중 한 곳을 선택하거나 미해결로 남기는 방식이다. 빠진 쟁점의 신설, 같은 쟁점에 대한 여러 미연결 묶음의 통합, 잘못 합쳐진 묶음의 분리를 표현하지 못한다.
3. **의미 연결 입력에 실제 근거 발언과 대화 순서가 없다.** 최종 주제 요약과 묶음의 제목·별칭·기관·과제를 전달한다. 한 발언이 앞선 질문에 대한 답인지, 다른 입장인지, 새로운 사건인지를 판별하기 어렵다.
4. **지난 보완은 제목의 온톨로지 키워드에 의존한다.** UNMAPPED 중 분류 가능한 제목을 각각 보완 주제로 추가한다. 원문을 보고 기존 주제와 합치거나 후보·보류 상태를 재검토하는 기능은 아니다.
5. **초기 묶음에 서로 다른 사건이 섞인다.** `build_live_topic_clusters`는 누적 단어 집합과 일부 겹치는 단어를 기반으로 합치며, 첫 제목을 유지한다. 새 발언이 누적된 주변 단어와 겹쳐 계속 붙을 수 있다. 같은 기관·사법부라는 공통점만으로 다른 사건이 모이는 현상을 방지할 필요가 있다.
6. **실행 완료와 연결 품질을 구분하지 않는다.** 현재 버전의 자동 연결을 마치면 남은 미연결이 있어도 같은 버전의 일반 재처리 후보에서 제외된다. 화면의 ‘자동 연결 검토 완료’는 연결 완성을 뜻하지 않는다.

## 권장 개선 순서

적용 후 실제 결과는 [전체 적용 결과](STRUCTURING_APPLIED_20261019.md)에 기록했다. 아래 내용과 위 수치는 적용 전 검토 이력이다.

1. **발언 단위 재분류와 혼합 묶음 분리:** 대표 근거와 앞뒤 질문·답변, 회의 구간, 사건·기관 정보를 이용한다. 동일 쟁점의 찬반·질의·답변을 분리된 입장으로 보존한다. 한 발언에 여러 쟁점이 있으면 문장 구간 근거를 사용할 수 있어야 한다.
2. **2단계 출력:** 상위 주제 → 세부 쟁점 → 입장·답변·과제 → 근거 발언. 상위 요약의 수는 제한하되 세부 쟁점의 보존 개수에 동일한 24개 상한을 적용하지 않는다. 독립적인 단일 발언도 내용이 구체적이면 보존한다.
3. **미연결 전체에 대한 후처리:** 38개뿐 아니라 후보·보류 14개를 포함한다. 결과 유형은 기존 쟁점 연결 / 동일 상위 주제의 하위 쟁점 / 새 쟁점 / 혼합 묶음 분리 / 절차·일반 과제 / 근거 부족으로 구분한다.
4. **근거 기반 검증과 이력:** 후보 연결의 원문 구간, 사건 일치, 연결 이유, 거절 사유를 기록한다. 원본 보고서를 덮어쓰지 않고 별도 구조화 버전으로 저장한다. 변경된 입력이나 실패 유형에 한해 횟수·예산을 제한하여 재검토한다.
5. **지표와 문구 수정:** ‘미연결’, ‘연결 후보’, ‘판단 보류’, ‘절차·일반 과제’, ‘독립 쟁점’을 구별한다. 실행 완료 여부와 품질 충족 여부를 따로 표시한다. 대표 주제와 보완 주제의 개수도 분리한다.

자료 제출 요구는 공통 과제로 모을 수 있지만 제출 자료·요청자·대상 기관·기한·관련 세부 쟁점·근거를 각각 보존해야 한다. 서로 다른 자료를 요구하는 문장을 하나의 모호한 문장으로 축약하지 않는다.
