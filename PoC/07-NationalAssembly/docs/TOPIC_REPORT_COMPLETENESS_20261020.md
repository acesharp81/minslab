# 주제별 보고서 전체 논의·과제 보존 점검

점검일: 2026-10-20. 사용자가 작성한 8·9·10월 행안부 보고서를 운영 API·화면·Markdown·PDF로 대조했다.

## 원인과 적용

시사점 5개는 화면 slice가 아닌 모델 스키마의 2~5개 제한이었다. 이 숫자만으로 전체 내용 반영을 판단할 수 없다. 별도로 검색 기본40건, 근거별 과제8개, 입력60,000자 예산 초과 시 뒤 자료 제외, 생성 문장 길이 제한 시 slicing 경로를 확인했다.

검토한 기존 5개 보고서에서 실제 입력 예산 탈락이나 필드 경계 잘림은 발견되지 않았다. 다만 10월 동일 조건은 현재52건인데 저장은40건이었고, 저장40건 중 전체 보고서의 명시적 인용은18건, 본문 절 인용은8건이었다. 인용되지 않았다는 사실만으로 의미상 미반영을 단정하지 않는다. 실제 정책별 본문 대조에서도 일부 논의의 구체성이 빠져 있었다.

핵심 시사점 수는 유지하며 모든 근거의 저장 요약·요구 과제를 상세 내역에 제공한다. 검색 기본 상한과 과제 배열 절단을 제거했다. 모델 입력 초과는 생성 전에 알리며 일부 자료로 조용히 생성하지 않는다. 신규 생성은 전체 근거의 본문 인용을 검증하고 생성 문장을 잘라 저장하지 않는다. 원 응답과 검증 정보를 감사 기록으로 보존한다.
