# 과거 90% 이상 연결률과 현재 수치 비교

검증일: 2026-10-19. 이전 수치는 실제로 90% 이상이었다. 이전 자료를 현재 분류 규칙으로 다시 계산해 연결 손실 여부를 확인했다.

| 집계 대상 | 과거 기록 | 현재 규칙으로 같은 자료 재계산 |
|---|---:|---:|

| 같은 보고서에 실시간 보완 쟁점 포함 | 1,247 / 1,270 = 98.19% | 1,247 / 1,270 = 98.19% |
| 현재 43건: 공식 17건 + 전체 구조화 잠정 26건 | 과거와 집계 대상이 다름 | 2,327 / 3,163 = 73.57% |

과거 보완 포함 자료의 주제별 공통 분류를 비교한 결과 **분류 변경·연결 손실 0건**이었다. 단순히 합계만 같음을 확인한 결과가 아니다. 과거 자료 해시는 10월 16일 감사 기록과 일치한다. [계산 결과와 입력 해시](ONTOLOGY_COVERAGE_COMPARISON_20261019.json).

## 낮아진 이유

1. 과거 요약에는 주요 주제의 개수 상한이 있었다. 전체 구조화에서는 질의·답변·요구를 더 세분화하여 정책 주제가 3,163개로 늘었다. 당시 요약 주제와 현재 세부 쟁점은 일대일 관계가 아니다.
2. 기존 분류 규칙은 정책 대상이 드러난 요약 제목에서 높은 연결률을 보였다. 세부 쟁점의 짧은 답변·후속 조치 등은 제목만으로 정책 대상을 특정하기 어려운 경우가 있다.
3. 새 쟁점의 원문·문맥 연결을 보완했지만 836건은 아직 보류다. 이는 전체 쟁점의 공통 분류가 충분히 완성되지 않았다는 뜻이다. 과거와 분모가 다르다는 설명만으로 현재 품질 문제가 해소되지는 않는다.

64.08→73.57%는 **같은 현재 분모 안에서의 개선**이다. 이를 과거 97.55%보다 완성도가 높다는 의미로 해석하면 안 된다. 화면에 현재 대상·계산식·과거 집계와의 차이를 표시했다. 과거 수치로 현재 지표를 대체하거나 보류 항목을 분모에서 제외하지 않았다.

## 추가 보완에 필요한 범위

현재 분모에서 90%에 도달하려면 2,847건 이상이 연결되어야 하므로 **최소 520건의 추가 연결 근거**가 필요하다. 이번 비교 작업에서는 분류 규칙이나 기존 판정을 바꾸지 않았고 추가 모델 호출도 하지 않았다.

- 311건의 짧거나 약한 원문 근거: 같은 쟁점의 질의·답변 관계를 복원할 수 있는지 확인해야 한다. 같은 발언에 있다는 이유만으로 다른 쟁점의 근거를 가져오면 안 된다.
- 487건의 판단 불일치·보류: 분류 체계의 경계 문제와 실제 근거 부족을 나눠 재검토해야 한다.
- 31건의 인용 불일치: 원문 인용 위치를 다시 확인해야 한다.
- 공식 대조본 7건: 공식 근거에 맞춘 별도 검토가 필요하다.

위 수치는 검토 사유별 분류이며, 모든 항목이 해결 가능하다는 보장은 아니다. 자동 검토 대기 0건은 현재 자동 검토가 끝났다는 의미이고 보류 836건이 해결되었다는 의미는 아니다.
