# 주제별 자료 제출 과제 복원 — 2026-10-19

## 요구사항과 원인

자료 제출 요구는 해당 사건·정책 주제의 **도출 과제**다. 제출이라는 행위가 같다는 이유로 서로 다른 주제의 과제를 한곳으로 모으지 않는다.

이전 분석 지시문과 통합 단계가 `공통 후속 과제 / 자료 제출 요구`로 모으도록 요구했고, 화면에서도 해당 과제를 주제별 행에서 제외했다. `related_topic_ids`로 여러 쟁점에 연결된 과제도 화면은 단일 `topic_id`만 확인해 누락했다. 의사진행 발언에 포함된 실제 자료 제출·열람 요구가 PROCEDURE로 제외된 사례도 확인했다.

## 적용 내용

- 향후 분석·통합 지시문을 해당 사건·정책의 REQUEST로 연결하도록 변경했다.
- 기존 결과는 읽기 시 투영 버전 1.3으로 보완한다. 원본 보고서·모델 응답을 덮어쓰지 않는다.
- 공통 묶음에 잘못 들어간 구체적 쟁점은 원래 상위 주제와 기존 사건별 분류를 이용해 복원한다. 기존 쟁점 ID는 보존한다.
- 일반적인 `자료 제출 요구`는 독립 주제를 만들지 않고 과제로 생성한다. 절차·판단 보류 중 실제 요구가 확인되는 발언도 원문 구간을 보존해 과제로 복원한다.
- 요청 원문에 등장하는 대상과 기존 쟁점을 대조한다. 짧은 제출 독촉은 바로 앞 근거 발언에서 구체적 대상이 확인될 때만 연결하며, 그 맥락 원문도 과제 근거에 포함한다.
- 주제별 도출 과제와 상세 과제는 `related_topic_ids`를 함께 확인한다. 첫 과제 아래 ‘추가 도출 과제’를 펼쳐 나머지를 확인할 수 있다. Markdown도 주제별로 출력한다.
- 대상이 명확하지 않은 요구도 과제로 남기고 ‘주제 연결 확인 필요’에 표시한다. 선서·PPT 표시 요청·단순 과거 언급을 절차 발언에서 과제로 자동 승격하지 않는다.
