## 검색 누락 원인과 수정

10월 26일 행안위 방송 `a242709a-df14-437f-a2bd-65f298d95eb0`의 기존 요약은 24개 쟁점이며 ‘신분증’을 포함하지 않았다. 화면은 최신 구조화 보고서의 349개 세부 쟁점·46개 대주제를 표시하고 있었다. 검색은 구조화 자료를 읽지 않아 같은 날 또는 날짜를 넓혀도 0건을 반환했다.

검색도 화면과 같은 현재 구조화 읽기 투영을 사용한다. 완료 요약은 세부 쟁점 ID로 연결하고 과제의 복수 연결도 포함한다. 공식 통합 자료와 구조화 잠정 자료의 권위는 분리한다. 원문·저장 분석·기존 보고서를 덮어쓰거나 새 요약을 생성하지 않는다.

- 신분증 + 2026-10-26 + 국회: **7건**.
- 행안부 + 신분증 + 같은 날짜 + 국회: **7건**.
- 같은 날짜 + 국무회의: **0건**. 자료 범위를 유지한다.
- 첫 구조화 조회 1.187초, 같은 날짜 캐시 재사용 0.180초. 두 경우 모두 추가 LLM 호출 0회.
- 선택 저장본의 제공사 우선순위·본문 복원 방식을 화면과 맞추고, 날짜는 시작 감지 시각의 한국 날짜를 사용한다.
