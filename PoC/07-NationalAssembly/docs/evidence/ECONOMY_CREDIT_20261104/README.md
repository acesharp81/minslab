# 일일 한도 소진 뒤 가성비 월 크레딧 예비 경로 (2026-11-04)

## 선택과 적용 범위

무료 Mini·OpenRouter가 모두 소진된 일반 작업에 GPT-6 Luna를 투입한다. 통합·공식자료 대조·주제별 보고서는 기존 GPT-5.4 → GPT-6.1 Terra 경로를 유지한다. Luna는 무료 일일 토큰 대상이 아닌 월 크레딧 경로다. 다음 일일 리셋 뒤에는 무료 Mini를 먼저 시도한다.

[공식 가격](https://developers.openai.com/api/docs/pricing)의 표준 단문 컨텍스트 기준 백만 토큰당 Luna 입력 $0.10·출력 $0.50, Mini 입력 $0.75·출력 $4.50이다. 캐시 쓰기·긴 컨텍스트는 별도이며 이 비율을 전체 청구액 절감률로 해석하지 않는다. [공식 Luna 설명](https://developers.openai.com/api/docs/models/gpt-6-luna)은 집중된 대량 작업과 구조화 출력을 지원한다. 실제 계정 모델 목록의 사용 가능 여부도 조회했다.

## 실제 발언 10건 평가

- `evaluation.json`: 법사위·예결위의 종료된 공개 발언 10건을 5건씩 Luna 2회로 평가했다. 각 요청은 7.188초·7.401초, 검증 통과는 4/5·5/5였다. 입력 14,075·출력 1,726토큰, 보수적 비용 추정 $0.00438085다.
- `mini-repair-evaluation.json`: 검증에 실패한 발언 1건만 Mini로 보완했다. 2.075초, 입력 2,008·출력 187토큰, 추정 $0.0023475다. 전체 10/10이 기존 검증을 통과했다.
- 전체 평가 3회, 추정 $0.00672835. 캐시 할인은 제외하고 캐시 쓰기를 보수적으로 반영한 서비스 장부 추정값이다. 공급자의 확정 청구액이 아니다.
- 운영 보고서를 이 평가 결과로 덮어쓰지 않았다. Mini의 동일 입력 전체 재측정은 하지 않았다. 10건의 작은 표본이므로 Mini와 동급 품질이나 전 작업의 성공률을 입증하지 않는다.

## 비용 보호와 재개

`OPENAI_REALTIME_CREDIT_ENABLED=true`이며 Luna와 보완 Mini는 기존 공용 월 $100 장부를 쓴다. 일반 작업 최대 월 $20, 공용 장부의 통합용 잔액 $20 보호를 적용한다. 소한도는 별도 무료 금액이 아니다. 원자적 예약으로 동시 방송의 중복 차감을 막고, 각 결과에는 실제 생성 모델을 남긴다. 승인된 상한을 넘거나 공급자 조직 한도에 걸리면 다른 OpenAI 모델로 우회하지 않는다.

[크레딧 안내](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)에 따라 공급자가 무료 크레딧을 먼저 적용하더라도 서비스 장부는 조직의 실제 무료/현금 잔액 조회가 아니다. 연결되지 않은 다른 프로젝트 지출은 Billing에서 확인해야 한다.

한도 보류는 부분요약의 `BUDGET_WAIT`와 분류 이력의 `_budget_wait.retry_after`로 기록한다. 다음 KST 09:00 이후 종료 후 1시간이 지난 방송도 미완료 발언만 복구 대상으로 선택하고 완료 결과를 재사용한다. 정상 분류가 저장되면 해당 발언 해시의 보류를 해제한다.

## 검증·배포

- 관련 예산·요약·분류 워커 검사: 57 통과, 게이트웨이 인증의 기존 이미지 불일치 2건은 제외했다. 별도 종료 방송 재개 통합 검사 1건 통과.
- 화면 잔액 검사 7건 통과. 월 예비 모델을 중앙 일일 잔액으로 덮어쓰지 않으며 다음 리셋 때 Mini로 돌아오는 표시를 확인했다.
- `poc07-economy-credit:20261104`를 API·요약 워커·회의 정리 워커에 적용했다. 정회 판정 모니터는 `poc07-recess-api:20261104`다.
- `usage-api.json`은 조회 당시 운영 잔량이다. 평가 이후에도 사용량은 변한다. 예비 경로의 실제 발동을 확인하려고 운영 일일 잔액을 임의로 소진하거나 변경하지 않았다.

## 추가 확인: Mini와 Terra 보완 비교

사용자 요청에 따라 Luna가 거부했던 동일 원문 해시 1건을 Terra에도 전송했다. 기존 Mini 시험과 같은 발언 구성·주변 문맥 생성 방법을 사용했고, 입력 토큰도 2,008개로 같았다. 이전 Mini 요청의 바이트 해시는 남기지 않았으므로 바이트 동일성을 입증하지 않는다. 기존 원문·보고서·요약을 바꾸지 않고 비교 결과만 저장했다. 모델 호출은 Terra 1회이며, Mini 재호출은 하지 않았다.

| 항목 | 기존 Mini | Terra 추가 시험 |
|---|---:|---:|
| 기존 내용·형식 검증 | 1/1 통과 | 1/1 통과 |
| 소요 시간 | 2.075초 | 4.651초 |
| 입력/출력 토큰 | 2,008 / 187 | 2,008 / 192 |
| 캐시 쓰기 토큰 | 없음 | 2,005 |
| 비용 추정 | $0.0023475 | 30분 쓰기 요율 $0.00346925 / 12시간 쓰기 상한 $0.0059755 |

Terra는 reasoning=none으로 시험했다. 캐시 보존 시간이 응답에 없어서 30분과 12시간 시나리오를 구분하며, 서비스 월 장부에는 12시간의 보수적 상한을 기록했다. 30분 쓰기 기준도 Mini보다 약 48% 높고, 보수적 장부는 약 2.55배다. 이는 공급자의 확정 청구액이 아니다. 실제 두 모델의 출력은 모두 발언자의 주장을 요약하고 자료 제출/정책 과제를 만들어내지 않았다. Terra가 기소 사실 관련 문장을 더 명시적으로 남겼지만 이 한 건에서 전반적인 품질 우위는 입증하지 못했다.

결론은 **기존 Luna→Mini 보완을 유지**한다. 무료 Mini의 경제성과 유료 보완의 기존 검증 근거를 유지하고, 표준 단가 차이만으로 Terra를 보완 기본 모델로 바꾸지 않는다. 기존 통합·보고서의 GPT-5.4→Terra 경로는 유지한다. 이번 평가는 런타임에 Terra 자동 보완 경로를 추가하지 않았다. 추가 호출이나 배포 없이 시험용 코드 허용만 원복했다.

상세: `terra-repair-evaluation.json`, `mini-terra-comparison.json`. 1건·서로 다른 호출 시점의 관측이므로 속도/성공률의 일반적 우열을 의미하지 않는다.
