# 비공식 보고서 대주제 정리 검증 (2026-10-31)

대상: 제439회 국회(정기회) 제02차 예산결산특별위원회 (`8809d5e4-13bc-41dd-a9b4-291afca60c0c`).

| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| 근거 구조 대주제 | 47 | 22 |
| 주요 논의 요약 대주제(기존 추가 요구 과제 포함) | 48 | 23 |
| 미래대응기금 대주제 | 16 | 1 |
| 세부 쟁점 | 120 | 120 |
| 과제 | 27 | 27 |

미래대응기금 하위 세부 쟁점 35개를 보존했다. 운영 API의 topics, tasks, live_topic_lineage, structure_review_items, narrative_coverage, report_summary.topics 전체 객체가 변경 전후 동일하다. 통합 기금 대주제 근거 조회 HTTP 200, 원문 83개를 확인했다. 그룹별 원래 제목은 audit.json에 남겼다.

구조화·서술·보고서 표시·새 대주제 테스트 75개 통과. API와 회의 정리 워커에 세 모듈만 기존 이미지 위에 배포했다. 공용 모델 사용량 응답과 서비스 정상 기동을 확인했다. 기존 저장 자료와 모델 응답은 수정하지 않았으며, 추가 모델 호출 없이 읽기 변환으로 적용했다.

같은 기금으로 확인할 수 없는 미래투자기금 등은 이름만 비슷하다고 합치지 않았다. 새로운 정책 전반에 대한 의미적 통합은 기존 모델 통합 단계를 유지하며, 정책 대상과 세부 논점을 구분하도록 프롬프트를 보완했다.

## 운영 화면 확인

두 주소(kjon.aigov.go.kr, www.minslab.kr/poc/national-assembly/)에서 주요 논의 요약 대주제 23개, 미래대응기금 1개와 하위 35개, 인쇄 미리보기의 미래대응기금 제목 1개를 확인했다. JavaScript 오류는 없었다. browser.json과 각 사이트 화면 캡처를 참조한다.
