# 실시간 과분할 보완 — 2026-11-04

사용자가 명시적으로 승인한 현재 방송 두 건만 기존 주제·범위·대표 AI 요약을 GPT-5.4에 보내 각각 한 번 통합했다. 전체 원문·MD는 전송하지 않았다. 주기적인 별도 LLM 재검토는 추가하지 않았다.

| 회의 | 기존 묶음 | 통합 결과 | 모델 호출 | 실제 토큰 |
|---|---:|---:|---:|---:|
| 제11차 법제사법위원회 | 37 | 20 | 1 | 10,022 |
| 제03차 예산결산특별위원회 | 123 | 39 | 1 | 26,483 |

예결위는 기존 정책 묶음 규칙만으로 먼저 123→117개가 됐다. GPT 응답에서 G032(세수 결손과 예산 집행 차질) 1개가 누락되어 처음에는 적용을 거절했다. 저장된 응답을 재호출하지 않고 누락 묶음을 기존 제목·범위 그대로 보존한 후 39개를 적용했다. 그 사이 새로 처리된 13개 발언도 최신 상태에 재결합해 보존했다. 원래 실패 응답과 이후 로컬 보완 이력은 모두 남는다.

통합 전후 모든 기존 발언 ID와 fingerprint/content_hash/cursor가 동일함을 저장 이력으로 비교했다. 발언 요약·과제·원문은 변경하지 않았다. `audit.json`을 참조한다.

추가 모델 호출 없이 기존 정책 부모 규칙을 실시간 조회·분류에 공유하고 퇴역 ID를 현재 ID로 연결한다. 기존 분류 호출이 동일 제목·범위의 새 ID를 제안해도 기존 ID를 재사용한다. 기존 분류 지시문은 1,952→1,941바이트로 간결하게 유지했다. 등록되지 않은 새 정책의 의미상 중복까지 로컬 규칙이 완전히 판단한다고 가정하지 않는다.

운영 검증 시 법사위 신규 발언 18개 중 11개, 예결위 신규 발언 10개 모두가 통합된 기존 주제에 배정됐다. 법사위에서는 다른 사건에 대한 신규 주제도 발생했다. 방송이 진행 중이므로 최종 주제 수는 이후 달라질 수 있다.

두 도메인의 실시간 화면에서 법사위 25개, 예결위 39개 주제 표시를 확인했고 브라우저 오류가 없었다. `browser.json`과 화면 캡처를 참조한다. 신규 로컬 보완·기존 분류·부모 묶음 검사는 통과했으며, 보존 및 누락 원본 유지 테스트를 포함한다.
