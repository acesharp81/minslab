## 발견한 대형 입력 보완

예결위 520개 쟁점의 기존 저장 요약은 평균 약 336바이트이며, 같은 평균이라면 요약만 약 174KB다. 제목·구조가 더해지므로 기존 180KB 상한에서 INPUT_LIMIT로 편집을 건너뛸 위험이 있었다. 이는 완료된 전체 입력의 정확한 크기가 아닌 현재 표본의 추정이다.

입력을 512,000바이트까지 허용하고 이 schema만 출력 최대 20,000토큰·요청 300초를 적용한다. 입력을 자르거나 나눠서 여러 번 보내지 않는다. 모든 출력 여유를 기존 일일 예산에 먼저 예약하고 사용량으로 정산한다. GPT-5.4의 공식 문맥 1,050,000토큰·최대 출력 128,000토큰 범위 안이며, 여전히 서비스의 일일 예산으로 제한한다. [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4)
