# 국무회의 공식·비공식 보고서 전환 — 2026-11-04

## 원인과 적용

공식 자료가 매칭되면 회의 카드가 `expandExecutiveBriefing`을 열지만, 해당 화면의 LIVE 저장본 버튼은 항상 비활성화돼 있었다. 비공식 요약 데이터는 보존되어 있었다.

보고서 상단에 `공식 자료 / 비공식 정리` 선택 버튼을 추가했다. 비공식 정리는 기존 구조화 보고서를 우선 표시하고 기존 요약·발언 근거·인쇄/PDF·Markdown 저장을 재사용한다. 공식 배포 자료와 AI 잠정 자료의 범위 안내를 구분한다. 연결된 방송 저장본이 없으면 비공식 버튼을 비활성화하고 이유를 표시한다.

로딩·오류·재시도와 내부 요약 전환에도 선택 버튼을 유지한다. 공식 자료로 돌아간 뒤 늦은 비공식 응답이 화면을 덮어쓰지 않는지 기존 요청 세대 검증을 확인했다. 기존 매칭 기준·저장 데이터·API·모델 호출 경로는 변경하지 않았다.
