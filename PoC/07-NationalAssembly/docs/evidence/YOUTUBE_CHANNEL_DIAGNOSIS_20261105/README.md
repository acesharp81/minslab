## 기존 시스템과 결합 시 필요한 작업

1. 유튜브 채널/영상 ID 전용 어댑터와 실제 시작·종료 상태 감지. 현재 유튜브 설정·수집기는 없다. 공개 페이지 파싱은 구조 변경 영향이 있으므로 신규 영상 알림과 공식 videos.list 상태 조회를 조합하는 방식이 적절하다. 공식 Data API 키 설정은 추가로 필요하다.
2. 유튜브 음성 주소 추출·만료 후 갱신·재접속·시간 오프셋 보존. KTV의 고정 HLS 주소를 전제로 한 현재 수집기를 그대로 지정할 수 없다.
3. 전용 수집 워커 또는 방송별 동시 작업 슬롯. 기존 executive-caption-worker는 하나를 claim한 뒤 해당 방송 수집이 끝날 때까지 처리하므로 단순 채널 추가 시 기존 방송과 대기 충돌이 생긴다.
4. 기존 Mistral 전사와 Mini/OpenRouter 실시간 요약, 5.4/Terra 통합 경로 재사용. 전사 워커의 Mistral 키 준비 여부만 확인했다(키 값 미출력). 서비스 설정 단가 $0.003/분 기준 전사 1시간 약 $0.18이며 실제 청구 보장이 아닌 설정값 산정이다. 요약 토큰은 별도다.
5. 출처를 ‘이재명 유튜브’로 보존하고 국무회의·연설·간담회·기타 행사를 구분한다. 기존 기관 필드가 EXECUTIVE/LEGISLATURE만 허용하므로 모든 채널 콘텐츠를 국무회의로 처리하는 방식은 부적절하다. AI 결과는 잠정으로 유지한다.
6. KTV 등과 같은 회의의 중계이면 날짜·행사 식별자·시간 일치를 검증해 기존 회의에 연결하고 음성 수집은 우선 출처 한 곳만 수행한다.
