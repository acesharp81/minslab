# 검색 결과의 쟁점 위치 이동·중복 상태 줄 제거

2026-11-05 두 운영 주소의 정적 화면에 반영했다. API·DB·모델 호출 정책은 변경하지 않았다.

## 원인과 처리

검색 링크가 회의 ID만 전달하고 쟁점 ID·자료 보기를 전달하지 않아 보고서 머리에서 멈췄다. 기존 검색 근거 ID에서 해당 쟁점·공식 안건을 식별해 URL에 함께 보존한다. 전체 보고서 렌더 뒤 완성 요약과 세부 쟁점의 저장 연결 ID를 사용해 해당 카드로 이동한다.

- 해당 대주제 펼침, 요약 카드 강조, 키보드 포커스, 근거 발언 선택.
- 완료 요약이 없으면 같은 ID의 세부 쟁점으로 이동.
- 국무회의 공식 결과는 해당 공식 안건으로 이동.
- 다른 회의 선택 시 이전 쟁점 URL 제거. 이후 자동 갱신에서 스크롤 위치 유지.
- 오래된 ID를 찾지 못하면 최신 결과 재검색을 안내하며 다른 제목에 강제 연결하지 않음.

## 중복 줄 검토

회의 권위·진행 상태는 카드와 제목에 이미 표시되며 최신 구조화 결과가 기본 보기다. ‘LIVE 잠정 결과 / 공식 자료 게시 대기 / 요약·쟁점·과제 / 기존 요약’ 줄은 중복이므로 완료/처리 화면에서 제거했다. 저장된 초기 요약과 원문은 삭제하지 않았다.

공식 대조본과 비공식은 근거가 다르므로 공식 대조본이 있는 경우에만 상단 인쇄·저장 도구 옆에 자료 전환을 제공한다. 비공식 선택은 최신 구조화 결과를 사용한다. 자료가 아직 없을 때는 불필요한 전환 줄을 만들지 않는다.

## 검증

- Node 29건 통과: 쟁점 ID·자료 권위·특수문자·URL 대상 회의 제한, 기존 사용량·진행·국무회의 연결 검사.
- 두 주소 각각 10월 26일 ‘신분증’ 검색 7개를 모두 클릭해 **정확한 요약 제목·펼침·강조·포커스·헤더 아래 스크롤** 확인.
- 대상 링크 재열기와 다른 회의 선택 시 이전 쟁점 초기화 확인.
- 실제 제47회 국무회의 공식 `report-1` 안건 이동 확인.
- 모바일 390px의 위치 이동·가로 넘침 없음 확인.
- 공식 대조본 전환은 브라우저 안에서만 만든 fixture로 양방향 동작과 상단 배치를 확인. 운영 저장 내용은 변경하지 않음.
- 중복 상태 줄과 기존 요약 버튼이 없으며 페이지 오류 0건. 새 보고서 생성·모델 호출 없음.

`browser.json`, `extra-browser.json`과 캡처에 결과를 보존했다. `kjon-selected-topic.png`, `minslab-selected-topic.png`는 정확한 쟁점 요약 카드의 선택 상태다.
