# 세부 요약 무기한 대기 복구 — 2026-11-06

## 원인

3개 종료 회의의 구조화·발언 검증·정책 분류는 완료됐으나 세부 요약이 각각 0/281, 0/88, 0/66이었다. 다른 본회의 LIVE 활동으로 `background_defer_reason=LIVE_OR_RECENT_MEETING`이 계속 발생해 finalization이 `LIVE_DEFERRED` 상태를 5분마다 갱신했다. 이 단계는 모델 호출 이전에 중단됐다. 별도의 과거 보완 큐는 비어 있었다.

## 변경

최종 정리 호출만 `finalizing=True`로 구분한다. 종료 회의만 처리하는 기존 생명주기 검사, 보고서 잠금, 저장 배치 재사용, 품질 검증과 모델 예산을 유지한다. 실시간 또는 예정 방송 우선권이 있으면 회차당 한 배치(일반 묶음 최대 8쟁점)를 처리한다. 과거 보고서 보완 큐는 계속 실시간에 양보한다. 원문이나 원문 연결을 삭제하거나 완료 상태를 강제로 지정하지 않는다.

## 검증

관련 테스트 35건 통과. 생방송 중 제한된 진척, 과거 보완 양보, LIVE 자체 최종 정리 금지, 부분 성공 보존, 중복 호출 방지, 일일 한도 재시도 검증 포함. `before.json`은 복구 전 진행률이다. 적용 후 실제 자동 처리 상태는 `after.json`으로 기록한다.
