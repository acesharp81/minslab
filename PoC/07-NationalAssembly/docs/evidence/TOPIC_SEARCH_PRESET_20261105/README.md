# 보고서의 주제 검색 조건 이동

2026-11-05 운영 화면 적용.

- 보고서 오른쪽 통계 위 빈 공간의 가로·세로 중앙에 ‘주제 검색’을 배치했다. 버튼은 기존 약 95×34px에서 192×68px로 확대했다.
- 클릭하면 주제별 보고서로 이동해 회의 날짜를 시작일·종료일에, 자료 범위를 국회 또는 정부·국무회의로 설정한다.
- 사용자의 정정에 따라 자동 검색하지 않는다. 이전 검색어·결과를 비우고 주제 입력칸에 커서를 둔다. 주제/부처 입력 후 기존 자료 검색 버튼으로 검색한다.
- 늦게 도착한 이전 검색/보고서 응답이 새 조건을 덮지 않도록 보호했다. API·DB·모델 호출 변경은 없다.

## 확인

두 운영 주소 각각 국회·국무회의·모바일(390px)을 확인했다. 날짜·자료 범위 설정, 입력칸 포커스, 검색어 초기화 정상. 자동 검색 요청 0회, 페이지 오류 0건, 가로 넘침 없음.

`browser.json`에 6개 경우의 결과가 있으며 `*-header.png`와 `*-preset.png`에 버튼 배치와 이동 후 조건을 보존했다. JavaScript 문법 검사와 기존 사용량/진행 태그 19개 회귀 검사도 통과했다.
