# 요약 기반 대주제 재편 검증 — 2026-11-04

대상: 제47회 국무회의, 방송 ID `a9dadf73-b838-46e1-b0df-090758a11042`.

## 원인과 적용

기존 분할 통합은 공통 대주제 목록을 지키지만 그 목록 자체의 과분할을 다시 편집하지 않았다. 완료된 세부 요약 뒤에 GPT-5.4의 상위 묶음 편집 단계를 추가했다. 이 단계는 전체 원문 MD를 전송하지 않는다. 대주제 제목과 저장된 세부 논의 요약, 서버에서 확인한 짧은 문맥 표시만 사용한다.

신데렐라·구두 관련 발언 앞에는 영상 시청 안내가 있고 뒤에는 영상 평가·박수 요청이 있다. 별도 정책 논의가 아닌 K브랜드 영상 시연으로 재편했다. “다른 AI”, “조류도감”은 가축방역 주변 문맥을 확인해 인공지능 정책 묶음에서 제외했다. 해당 세부 발언·기존 요약 자체를 임의로 고치지는 않았다.

## 적용 범위와 한계

최신 국무회의 1건을 명시적으로 재편했다. 다른 완료 보고서는 일괄 호출하지 않는다. 이후 새 보고서의 자동 최종 정리에는 세부 요약 다음 단계로 적용한다.

재편은 부모 묶음과 순서의 개선이며 원문 인식 오류나 기존 요약 자체의 사실관계를 모두 고치는 기능은 아니다. 입력 크기 초과·반복 실패 시 유효한 기존 보고서를 보존하고 관리용 사유를 기록한다. 영상 구간 판정에는 시작·종료 안내가 모두 필요하다. 문맥 근거가 없는 구간을 영상이라고 단정하지 않는다.
