## 전체 적용

- 모든 현재 보고서에 기존 묶음 ID와 구조화 묶음의 원문 발언 집합을 대조하는 읽기 전용 연결 정보를 제공한다. 다른 보고서 버전, 중복 ID, 원문 집합 불일치, 존재하지 않는 쟁점은 연결 완료로 표시하지 않는다.
- 공식 요약과 공식 근거의 기존 연결을 덮어쓰지 않는다. 새 연결은 별도 `live_topic_resolution`, 권위는 항상 `PROVISIONAL`이다.
- 공식 대조본에서 잠정 구조화 연결 결과·절차성 발언·남은 판단 보류를 확인하고 연결 쟁점으로 이동할 수 있다. Markdown에도 두 기준을 함께 기록한다.
- 보고서 캐시는 1분 후 다시 열 때 새로 조회하여 후속 검토 결과가 오래 남지 않도록 했다.
- 원본 보고서 기준 전수 대조: 43건, 실시간 2,872묶음 중 연결 2,696 · 절차 109 · 추가 검토 67. 기존 연결 확인 상태 1,510묶음 중 구조화 연결 1,437 · 절차 50 · 추가 검토 23이다. 기존 연결 상태였어도 부분 검토가 발견된 묶음은 전체 추가 검토 67건에 포함한다.
