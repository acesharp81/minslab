# 기관명·약어 검색 기준 (2026-10-20)

검색어와 자료의 비교용 복사본에 동일한 기관명 정규화를 적용한다. 원문·기관 태그·과제 원문은 변경하지 않는다. 공백이 끼어 있는 기관명도 동일하게 처리한다.

현재 기관의 공식 약칭은 [정부조직 약칭과 영어 명칭에 관한 규칙 별표](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201&flSeq=160665721)를 기준으로 확인했다. 과거 명칭의 약칭은 [종전 약칭표](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201&flSeq=128545915)를 참고한다. 검색 편의를 위한 통용 약어와 사용자 요청 오기도 추가한다.

- `행정안정부`는 `행정안전부`로 처리하는 명시적 오기 대응이다. 임의의 유사 기관명을 추측해 합치지 않는다.
- 기획재정부/재정경제부/기획예산처, 산업통상자원부/산업통상부 등 조직 개편 전후 이름은 각각 유지한다.
- 기관 조건으로 검색하더라도 별도로 지정한 주제의 관련성 조건은 그대로 적용한다.
