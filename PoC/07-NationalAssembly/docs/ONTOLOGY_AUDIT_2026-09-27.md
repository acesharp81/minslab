# 국정 온톨로지·공식 화자 최종 점검 (2026-09-27)

## 집계 기준

- 공개 회의 보고서와 같은 범위: 행정안전위원회·예산결산특별위원회·법제사법위원회·본회의 및 실제 국무회의. 격리 테스트·데모·재생 출처와 현재 범위 밖 국방위원회 보고서는 제외한다. 원본 보고서는 삭제하지 않는다.
- 방송별 최신 저장 보고서가 현재 공식 문서 ID에 대한 동일 보고서의 `READY` 통합본을 가지면 공식 통합본을 사용한다. 그렇지 않으면 보존된 LIVE/STT 초안을 사용한다.
- 온톨로지는 사용자가 열 때 저장 자료에 로컬 규칙을 적용한다. 외부 모델 호출과 분 단위 반복 재생성은 없다.

## 화자와 운영 상태 (1차 점검)

- 현재 문서의 공식 발언을 원문으로 보여주는 보고서 19건을 API로 전수 조회했다. 이름이 있는 공식 발언 항목 905개, 공식 발언과 안전하게 연결되지 않은 초안 전용 항목 92개다. 92개는 확정 화자로 표시하지 않고 별도 검토 영역에 보존한다.
- LIVE/STT 초안에서 온 주제 요약 37개는 숫자 화자 코드를 공식 인명으로 단정하지 않고 `한 참석자` 등 중립 표현으로 표시한다. 원래 문장은 `provisional_summary`와 초안 보고서에 보존하며, 공식 화자·원문은 개별 발언 항목에서 확인한다.
- 운영 DB의 공식 통합 작업은 `READY` 2,172건이며 대기·실패 상태가 없다. 자막 조각별 현재 문서 대조 3,000건은 19개 문서에 연결돼 있다. 점검 시 국회 LIVE 방송 0건, 종료 방송 38건이다. API·공식 대조·회의록·LIVE 감시·보고서·자막 worker 최근 2시간 로그에서 예외·OOM은 확인되지 않았다.

## 원인 정정과 후속 조치

1차 점검의 ‘본회의 5건 미게시’ 판단은 잘못됐다. `official-minutes-worker`가 본회의 방송까지 위원회 회의록 API만 조회한 것이 원인이었다. 본회의 전용 `plenary_minutes` 원본을 직접 대조한 결과 제439회 제5~9차는 각각 `N054451`, `N054455`, `N054457`, `N054459`, `N054488`로 이미 게시돼 있었다. 2026-09-27에 소스별 수집 경로를 분리해 5건을 소급 적재·방송 연결했고, 임시회의록 발언 6,464개를 저장했다. 제9차 공식 의안목록 73행도 별도 적재했다. 회의록 원본 78행 가운데 완전히 동일한 1행은 raw에 남겨 77개 고유 행만 정규화했다.

공식 발행 대기 조회는 종료 후 2일 이내 시간당, 7일 이내 6시간당, 30일 이내 하루당, 이후 180일까지 주간으로 줄였다. 발행 이후에는 임시 본문 변경만 시간 단위로 확인하고 정본 확인 시 중단한다. 서로 같은 날짜의 방송이라도 재확인 대상 방송만 상태를 갱신한다.

공식 발언을 대조한 확실한 오기·주제만 화면용 파생 표현에서 수정했다. 정책펀드, 감천댐, 관세협상, 유실지뢰, 가뭄, 검찰 수발신 문서, 교도소 내 마약사범 분리 등이 해당한다. 저장된 원본 보고서와 LIVE 자막은 유지했다. 2026-09-27 운영 API에서는 온톨로지 분류가 528/537개(98.32%), 미분류 9개, 절차 산출물 분리 10개, 자료 미연결 산출물 검토 보고서 2개로 측정됐다. 나머지 미분류 9개 가운데 6개는 공식 원문은 연결됐지만 외부 모델 기반 주제 요약 대조가 실패한 두 본회의의 LIVE 초안에 있다. [건별 온톨로지 검토 목록](ONTOLOGY_REVIEW_QUEUE_2026-09-27.csv)에 원문·공식 근거 ID·보류 사유를 기록했다. 근거가 없는 요지는 새 공식 본문과 대조한 후 재판정한다.

공식 브리핑과 연결된 제38회 국무회의는 `executive_official_matches`에서 공식 ID `148971004`가 확인된다. 다만 공식 브리핑은 회의의 발언별 전문이 아니므로 LIVE 보고서 내용을 공식 발언으로 승격하지 않는다. ‘채불’은 문맥상 체불의 표기 오류로만 파생 화면에서 고쳤다.

기존 19개 공식 통합 보고서의 미연결 화자 요지 92개에 새 본회의 5건의 미연결 36개가 더해져 128개다. [건별 검토 목록](SPEAKER_REVIEW_QUEUE_2026-09-27.csv)에 방송·보고서·공식 문서·자막 근거 ID와 대조 방식을 함께 보존했다. 본회의 5건의 공식 원문 발언 6,464개에는 화자 이름 누락이 0건이지만, 초안 요지 36개는 공식 원문 한 화자에게 안전하게 연결되지 않아 `화자 미확인`으로 남긴다.

임시회의록 안정화 뒤 5건의 모델 기반 요약 변경 대조는 외부 게이트웨이의 120초 시간초과·비정상 JSON으로 실패했다. 동일한 실패 요청을 계속 반복하지 않도록 `SOURCE_ONLY_TIMEOUT` 상태로 공식 발언·화자 원문만 반영했고, 주제 요약은 LIVE 초안 기반임을 API·화면에서 표시한다. 이 5건은 본문 변경 확인이 완료되지 않았으므로 온톨로지 공식 통합본 19건에 더하지 않으며, 별도 공식 변화 간단 보고서도 표시하지 않는다. 이 제한은 모델 대조가 성공한 다른 19건에는 적용되지 않는다.
