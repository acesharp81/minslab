# POC Evaluation

## 필수 통과 조건

- 공식 사실과 AI 해석이 DB, API, UI에서 분리됩니다.
- 노출된 구조화 정보와 AI 결과를 원문으로 역추적할 수 있습니다.
- 동일 원본을 다시 수집해도 canonical 중복이 생기지 않습니다.
- 원본 변경 시 이전 버전을 유지합니다.
- 외부 API 없이 adapter와 normalizer test를 실행할 수 있습니다.
- 이 폴더만으로 개발·실행·테스트가 가능합니다.

## 측정 항목

- 공식 기준 목록 대비 회의 누락률
- source별 수집 성공률과 게시 지연
- meeting reconciliation precision/recall
- 발언자·기관·안건·질의답변 연결 정확도
- 업무 질문 30~50개의 검색 적합도
- 기존 국회 사이트 대비 과업 완료시간
- 일일 저장 증가량과 모델/API 비용

목표 수치는 실제 source 표본과 정답셋을 만든 뒤 확정합니다.
