## 원인

기존 분류와 원문을 대조하면 두 문제가 함께 있었다. 위치추적 정확도 개선 문답처럼 분류 가능한 발언을 모델이 보류한 사례가 있었고, 기존의 넓은 쟁점명이 다른 발언에 잘못 붙은 사례도 있었다. 잘못된 제목을 재분류 프롬프트에 다시 제공하면 모델들이 같은 오류를 답습했다.

## 적용

- 통신 실패 원문 배치는 정상 결과를 재사용하고 실패 배치만 30분 간격·총 9회 상한으로 재시도한다. 보완된 원문을 포함하지 않는 과거 통합 응답은 현재 처리 완료의 근거가 되지 않는다.
- 일부 통합 대상 ID가 없거나 순환하면 해당 쟁점을 원래 제목의 독립 쟁점으로 보존한다. 정상 통합 결과는 유지하며, 원본 모델 응답과 병합하지 않은 ID 목록을 함께 저장한다.
- 보류 발언은 전체 발언 창과 앞뒤 문맥으로 다시 분류한다. 오류가 있는 기존 제목·묶음 힌트를 정답 후보로 반복 주입하지 않는다. 기존 확정 facet은 보존한다.
- 자료 요구의 주제가 빠진 경우도 자동 모델 처리에 포함한다. 일반 자료 제출 주제에 모으지 않고 해당 정책·사건의 요구 과제로 연결한다.
- 원문이 충분한데 UNCERTAIN으로 남긴 결과는 다른 모델의 추가 판단을 한 번 받는다. 정확한 사건명이나 법률명이 불확실해도 원문에서 드러나는 논점을 중립적으로 분류한다.
- 모델 결과는 기존 원문 위치·해시·버전으로 검증한다. 원문에 없는 주제명을 붙인 결과는 그대로 채택하지 않는다. 원본 보고서와 모델 응답은 덮어쓰지 않는다.
- 기존 meeting worker가 자동 처리하며 보고서별 동일 잠금과 배치 번호 구간을 사용한다. NIM 최초 처리, 추가 판단/장애 시 OpenRouter·OpenAI 사용, 기존 UTC 일일 토큰 한도를 유지한다.
- 화면은 자동 재분류 대기·분석 지연·재분석 후 원문 불명확·회의 진행을 구분한다. 보조 목록은 기본 접힘이며 사용자에게 연결 판단을 요구하지 않는다.
