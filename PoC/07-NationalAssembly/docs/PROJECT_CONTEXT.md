# Project Context

## 문제

청와대·국무회의의 발언·지시·부처보고와 국회의 일정·회의록·의안·표결은 서로 다른 시스템과 공개 시점을 가집니다. 사용자는 하나의 정책이 행정부에서 어떻게 제시되고 어느 부처가 맡으며 국회에서 어떻게 논의·의결되는지 확인하려고 여러 공식 사이트와 긴 원문을 직접 탐색해야 합니다.

## 목표

공식 국무회의와 국회 자료를 시간, 회의, 주제, 발언, 부처, 위원회, 의안과 표결 단위로 연결해 다음 질문에 빠르고 검증 가능하게 답합니다.

- 최근 국무회의에서 어떤 주제가 논의됐는가?
- 특정 주제의 소관·관련 부처와 근거 발언은 무엇인가?
- 특정 부처와 관련된 국무회의 발언·보고·지시는 무엇인가?
- 특정 정책이나 기관이 국회 어느 회의에서 논의됐는가?
- 특정 의원이 누구에게 무엇을 질의했고 어떤 답변을 받았는가?
- 의안이 어떤 과정으로 논의·의결됐는가?
- 국무회의의 정책 주제가 국회의 어느 위원회·의안과 연결되는가?

## 초기 범위

국무회의 최근 10건과 국회 행정안전위원회·예산결산특별위원회·법제사법위원회를 우선 범위로 합니다. 국무회의는 공개 발언·브리핑·속기자료만 사용하며 비공개 발언을 추정하지 않습니다.

이 프로젝트는 뉴스 요약 서비스가 아니라 원문 근거를 중심으로 행정부의 정책 방향과 입법 진행을 함께 보는 국정활동 지식관리 시스템입니다.
