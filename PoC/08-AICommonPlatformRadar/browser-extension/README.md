# 조달체크 나라장터 의견 도우미

빌드 도구나 외부 라이브러리가 없는 Chrome Manifest V3 확장프로그램입니다. 이 폴더만 복사해도 동작합니다.

1. `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`에서 이 폴더를 선택합니다.
4. PoC 8의 `설정`에 관리자로 로그인해 담당자 정보, 의견 구분, 기타의견과 나라장터 의견 비밀번호를 저장합니다.
5. PoC 8에서 `나라장터 의견 등록`을 누릅니다. 설정하지 않은 값은 빈칸으로 남습니다.
6. 의견 등록 후 `나라장터 등록 의견 확인`을 누르면 같은 등록번호의 사전규격 상세 화면을 찾아 등록 의견과 답변 현황을 보여줍니다.

검색·상세 이동 후 담당자 정보, 의견 구분, 기타의견과 본문 입력까지만 자동화하며 나라장터의 최종 `저장`은 사용자가 직접 누릅니다.
