CHROME EXTENSION · v0.1.8

나라장터 의견 도우미 설치

모든 공지·안내창을 먼저 닫고 검색기간을 확인한 뒤, 발주목록에서 사전규격 검색과 의견 입력 또는 등록 의견 현황 확인을 자동으로 진행합니다. 자동입력 값과 의견등록 비밀번호는 조달췤! 설정에서 관리하며 최종 저장은 사용자가 확인합니다.

설치 파일 다운로드
1

ZIP 압축 풀기

다운로드한 jodalcheck-g2b-helper.zip의 압축을 원하는 폴더에 풉니다.

2

Chrome에 한 번 등록

주소창에 chrome://extensions를 입력하고 개발자 모드를 켠 뒤, 압축해제된 확장 프로그램을 로드합니다에서 압축을 푼 폴더를 선택합니다.

3

자동입력 값 설정

조달췤!의 설정 메뉴에 관리자로 로그인하여 담당자 정보, 의견등록 비밀번호와 문구 템플릿을 저장합니다. 설정하지 않은 값은 빈칸으로 남습니다.

HOW IT WORKS

사용 흐름

  1. 설정 메뉴에 관리자로 로그인하고 담당자 정보를 저장합니다.
  2. 대시보드에서 나라장터 의견 등록을 누릅니다.
  3. 확장프로그램이 공지창을 닫고 발주 → 발주목록 → 사전규격공개 → 상세 → 의견등록까지 이동합니다.
  4. 자동 입력된 내용을 확인하고 나라장터의 저장을 누릅니다.
  5. 성공이 감지되면 PoC 8 조치 상태가 자동으로 조치중이 됩니다.
  6. 이후 나라장터 등록 의견 확인을 누르면 같은 사전규격 상세 화면에서 의견과 답변 현황을 확인할 수 있습니다.

Chrome 보안 정책상 웹페이지가 확장프로그램을 자동 설치할 수는 없습니다. 최초 1회만 위 3단계를 수행하면 이후에는 PoC 8 버튼 하나로 실행됩니다. 새 버전을 받은 경우 압축을 다시 풀고 chrome://extensions에서 확장프로그램의 새로고침 버튼을 누르세요.
