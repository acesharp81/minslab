# 인천부평 중복 집계 수정 및 이관 설명 기준

기준일: 2026-10-20

**운영 반영 완료: 2026-10-20 14:03 KST 검증.** 실제 공급지도 API에서 부평은 3개 원천을 묶은 지도 항목 1개·350호로 반환됐고, 정책 API의 비교 지표도 수정 전과 동일했다. 배포 코드의 SHA-256과 작업 코드의 일치, health 정상도 확인했다.

**인천부평의 공사·임대계획·공정률 자료를 동일 A블록으로 연결해, 전체 공급지도에서 700호로 계산되던 목표량을 350호로 수정했다. 원천 자료와 승인 기록은 보존했다. 공공 여부 미분류와 위치 공란에 대해서는 ‘모든 통계에서 제외’, ‘관련 자료가 전혀 없음’이라고 설명할 수 없다.**

## 1. 중복 제외 결과

| 항목 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 인천부평 전체 공급지도 목표량 | 700호 | **350호** |
| 전체 공급지도 목표량 합계 | 289,583호 | **289,233호** |
| 인천부평 9·7 정책 관리량 | 350호 | **350호** |
| 9·7 집계용 관리 묶음 | 172개 | **172개** |
| 원천 사업 기록 | 448건 | **448건** |

같은 읽기 전용 DB 스냅샷에서 수정 전후 집계 코드를 실행하여 비교했다. 9·7 정책의 목표·실적·연말 계획 등이 포함된 `yearly_comparisons.policy` 전체가 동일했고, `project`·`execution_schedule`·`project_profile`의 비교 해시도 동일했다. 위 합계는 검증 스냅샷의 값이며 자동 수집으로 이후 달라질 수 있다.

### 반영 방식

- 문자+숫자 블록뿐 아니라 **숫자가 없는 A 단독 블록**도 원천의 지구·블록 또는 제목 끝의 명시적 블록으로 식별한다.
- `인천부평(도시재생뉴딜) A`, 지구 `인천부평`·블록 `A`, 공사명과 별도 필드에 담긴 지구·블록을 동일 키 `(인천광역시, 인천부평, A)`로 연결한다.
- 공급계획의 350호를 선택하고 같은 현장의 공정률 350호를 추가 목표량으로 더하지 않는다. 공사 자료도 기존 제외 규칙을 유지하되 관련 증빙으로 연결한다.
- 원천 이름·호수·ID와 담당자 승인 기록은 삭제하거나 바꾸지 않는다.
- 숫자 없는 블록의 단순 문자 일치로 모집공고까지 자동 연결하지 않는다. 기존 검토·저장 연결을 사용한다.
- 다른 지역·다른 지구·A/B/A1은 구분한다. 같은 블록의 국민임대·영구임대처럼 겹치지 않는 유형별 물량은 구분 합산한다.

현재 448개 원천 기록을 수정 전후 블록키로 비교했을 때 키가 달라진 대상은 아래 인천부평 3건뿐이었다.

| 원본 ID | 역할 | 중복 제거 후 전체 목표량 기여 |
| --- | --- | ---: |
| `PRO_9a256c5d211050be9f0814ff` | 임대계획·행복주택 350호 | **350호** |
| `PRO_4b859c7f4b18222558932b97` | 같은 현장의 공정률 기록 | **0호 — 증빙 보존** |
| `PRO_0e5b836fdd9670216e60ee53` | 같은 현장의 건설공사 기록 | **0호 — 증빙 보존** |

수신측 0065·0068은 원본 `PRO_...` ID와 대조해야 한다. 이관받은 원천 테이블을 그대로 합산하면 수정된 조회 코드의 중복 제외가 적용되지 않는다. **기존 DB 덤프를 유지하더라도 동일 현장 집계 규칙을 함께 반영해야 한다.**

## 2. 공공 여부 미분류는 통계에 반영되지 않았는가?

**모든 통계에서 제외된 것은 아니다.**

| 통계·표시 범위 | 현재 동작 |
| --- | --- |
| 공공 시행기관 소계 | 공공 시행기관으로 판정된 물량만 포함. 미분류는 이 소계에 넣지 않음 |
| 시행기관 미분류 소계 | 별도 분류로 포함 |
| 전체 정책·사업 관리량 | 정책 연결·집계 선정 조건에 따라 미분류 사업도 포함될 수 있음 |
| 정책 필터 없는 전체 공급지도 | 검토 후보와 시행기관 미확인 사업도 포함 가능 |

실제 검증 스냅샷에서 9·7 관리 묶음의 시행기관 분류는 **공공 시행기관 107,674호 / 시행기관 미분류 43,494호**였다. 이는 관리 묶음 계획 규모의 유형별 분포이고 현재 착공·공급 실적과는 다른 지표다. 미분류가 전체 데이터에서 제외되어 있었다는 주장을 지지하지 않는다.

전체 공급지도 목표량 선정에는 시행기관 값이 비었거나 ‘시행기관 확인 필요’인 **198개 원천 기록**이 포함됐고, 그중 호수가 있는 기록의 계획량 합계는 **162,546호**였다. 이 범위는 수신측의 106건과 분모·산식이 같다고 확인한 것이 아니다.

공공 시행기관·공공주택 해당 여부·정책 대상 여부는 서로 다른 속성이다. 특히 `availability=PUBLIC`은 자료 공개 여부이며 공공주택 분류에 사용하면 안 된다. 이번 중복 수정에서는 미분류 사업을 임의로 공공 또는 민간으로 바꾸거나 전체 통계에서 삭제하지 않았다.

**전달 가능한 표현:** “공공 시행기관으로 확인되지 않은 사업은 공공 시행기관 소계에 합산하지 않고 미분류로 구분한다. 다만 정책 연결과 관리 범위가 확인된 사업은 전체 관리량에 포함될 수 있다.”

## 3. 위치가 비어 있는 이유가 관련 자료 부재인가?

**그 이유만 있는 것은 아니다.** 원천 사업 행의 좌표가 비어 있어도 별도 `project_location`·`block_location`·지구·시군구 자료에 위치가 있을 수 있다. 원문에 주소가 있어도 좌표 변환이나 사업 연결이 완료되지 않았을 수 있다.

위치 조회는 LH 공개 블록 대표점, 사업 위치 보완, 지구·시군구 대표점 등을 구분해서 사용한다. 시군구 대표점으로 지도를 표시할 수 있다는 사실은 현장의 정확한 위치가 확인됐다는 뜻이 아니다.

**전달 가능한 표현:** “위치값은 확인·연결된 위치 근거가 있는 범위에서 제공한다. 현장 위치 근거가 부족하거나 기존 위치 자료와 연결되지 않은 항목은 공란일 수 있다. 행정구역 대표점은 현장 좌표와 구분한다.”
