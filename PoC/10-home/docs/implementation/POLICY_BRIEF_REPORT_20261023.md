# 정책 추진현황 자동보고서 적용 기록

2026-10-23. 정책 화면의 **추진현황 보고서 만들기** 버튼에 적용했다. 첨부 작업지시서의 7개 본문과 붙임 3개를 구조화된 보고서 모델로 생성한다. 프로그램 보고서와 개별 사업 보고서는 기존 경로를 유지한다. 저장된 사업·실적·목표·승인·매핑 값은 변경하지 않는다.

## 사용 방법

1. 정책 추진현황에서 **추진현황 보고서 만들기**를 누른다.
2. 보고 기준일, 지역·시군구, 월간·분기·연간·직접 지정 기간, 기본·상세 유형을 선택한다. 필요한 중요 사업은 고정 지정한다.
3. **보고서 생성**을 누른다. 조건을 바꾸면 이전 내보내기를 숨기고 다시 생성하도록 안내한다.
4. 미리보기에서 주요 수치 근거를 확인하고 **인쇄 / PDF 저장**, HTML, 상세 CSV, 산출근거 JSON, 완성본 MD를 선택한다.

현재 정책 데이터 연결은 기존 시스템의 9·7 정책에 한정된다. 보고서 유형은 주요 사업 수와 본문 개별 사례 표시량을 조정하며, 집계표·전체 사업 붙임·JSON·CSV는 유지한다. 기본형에서도 미확보 항목을 삭제하지 않는다.

### 산식과 범위

- 누적 도달량은 기존 backend `_events(... cumulative=True)`와 같은 허용 후행 단계·사업 한도·사업별 최대값으로 산출한다. 원천·담당자 채택·추정·후행 도달 근거의 추가분을 순서대로 배분해 구성합이 중복되지 않게 한다.
- 목표는 `_schedule_targets`의 담당자 일정 우선, 최신 원천 판본, 날짜·물량 중복 제거, 사업 한도 규칙을 적용한다.
- 사업화·인허가·착공·공급·입주 전망은 **현재 대시보드 `PolicyStageFlow.projectedValue`를 그대로 호출**한다. 단계별 큰 실적/목표에서 출발하고 미래 목표 증가에 따른 단계 이동을 반영한다. 첨부 문서의 다른 간략 예시 산식으로 바꾸지 않는다.
- 준공은 그래프의 5단계와 별도로 사업별 `max(누적 도달, 연말 계획)`을 합산한다.
- 유형별 전망은 유형별 내부 부족분을 기초로 하므로 전체 전망과 재합산하지 않는다.
- 전체 달성률·잔여목표는 같은 도래 목표 대상의 실적이 모두 확보되고 도달 사업의 단계 목표가 누락되지 않은 경우만 산정한다. 미확보가 있으면 전체 값을 보류하고 비교 가능한 사업 부분의 목표·도달량·달성률을 별도 표로 공개한다.
- 단계별 누적은 같은 주택이 여러 단계에 등장한다. 단계 간 합산하지 않는다. 연간·분기 합계도 다시 합산하지 않는다.
- 정책 원문 전체 목표 135만호와 연결 사업 관리목표를 별도로 표시한다. 공식 브리프의 후속정책 통합 목표를 현재 실적이나 기존 목표에 덮어쓰지 않는다.
- 연말은 보고 기준일이 속한 연도의 12월 31일이다. 대시보드의 임의 보조 기준일을 연말로 잘못 표시하지 않는다.

### 인지 시점과 성능

보고서 API는 `HomeService.rows`의 기준일 KST 종료 전 `recorded_at`, 당시 유효 판본, 귀속 감사 이력 복원을 사용한다. 기준일만 프런트에서 바꾸고 최신 원장을 소급 사용하지 않는다. 미래 실제 기준일은 API에서 거부한다.

일반 대시보드 조회의 대규모 시장 통계와 그래프 스냅샷은 보고서에 필요하지 않아 전용 조회에서는 생략한다. 원장·집계 함수는 동일하다. 최초 과거 조회는 별도 계산이 필요하며, 일시적인 502·503·504 응답은 같은 기준일로 최대 3회 재시도한다. 제한시간을 넘으면 재조회 안내를 표시하고 임의 최신값을 대신 사용하지 않는다.

수집 완료시각은 선택 사업 원천의 성공 수집 배치 기준이다. 최신 판본 등록시각과 별도 표시하며, 둘 다 보고서 생성시각과 다르다.

## 미산출 및 해석 한계

- 실제 거주 세대수 원장이 없어 **실입주 자료 미확보**로 표시한다.
- 행정과제별 완료 근거가 연결되지 않아 전체·완료·진행 건수를 생성하지 않는다.
- 전월 보고서 기준본과 변경 전후 이력이 연결되지 않은 부분은 전월 개선/악화, 물량 증감 원인을 확정하지 않는다. 같은 현재 판본에서 사건일로 계산한 기간 증가와 구분한다.
- 정책 미연결 후보·수집/추출 대기·상충 후보 전체 현황은 보고서 API에 연결되지 않았다. 원천 미확보와 귀속 미확정을 별도 행으로 표시하며 확정 실적에 더하지 않는다.
- 주택 유형·공급형태가 미확정인 사업을 기관명만으로 공공분양·임대에 강제 배분하지 않는다.
- 지역이 시군구이면 프로그램별 시군구 목표 미배분 상태에서는 달성률을 보류한다. 개소·면적 단위 프로그램 목표를 호수로 변환하지 않는다.
- 기존 관리값은 보존한다. 공식 확인, 담당자 채택, 단계 추정의 구성을 공개하며 이를 모두 공식 사건으로 표현하지 않는다.
- 공식 비교의 32/32 사업 대응, 26/31 수량 비교, 10/10 통계 재계산, 185개 판정은 과거 각기 다른 범위의 검증 결과이다. 이번 변경에서 전체 정확도라고 재판정하지 않았다.
- 공급 원장의 모집 부분·정정/추가 모집 중복처리는 기존 대표사업/관리한도 규칙을 재사용한다. 독립 블록은 이름만으로 병합하지 않는다. 상충 원문의 재승인·데이터 정비는 수행하지 않았다.
