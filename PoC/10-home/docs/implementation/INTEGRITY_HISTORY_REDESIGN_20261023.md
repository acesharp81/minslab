# 데이터셋 개선 과정 화면 재구성

## 요청 및 반영

사용자 제공 시안을 기준으로 상단은 간결한 가로 흐름도, 하단은 상세 분석으로 분리했다. 기존 좌측 세로 도식·우측 고정 상세 구조를 교체했다. 첫 데이터셋 이후 날짜를 숨기는 기존 요청을 유지했다.

- 상단: V1~V6 원형 버전 노드, 연결선, 단계별 색상 점, 피드백 5개 카드, V6 결과 요약.
- 단계별 색상 점도 선택 가능. 데이터셋·조원 피드백·내부 재검증·패턴 규칙·데이터 보강의 기존 26개 선택 대상을 유지.
- 하단: 회차·검토 상태 → 선택 단계 요약 → 발견 사항/내부 재검증 → 수정 전후 카드 → 규칙/데이터 보강 → 근거 발췌.
- 노드 클릭 시 하단 상세로 이동. 흐름으로 돌아가기, 이전/다음 회차, 단계별 선택, 최종 결과에서 각 회차로 이동 지원.
- 색상·테두리·그림자·서체 크기·여백을 조정하고 선택 상태를 강조. 비선택 카드도 읽을 수 있는 대비 유지.
- PC에서는 전체 가로 흐름 표시. 좁은 화면에서는 도식 안에서만 좌우 스크롤하고 상세는 한 열로 표시.
- 키보드 포커스 및 선택 상태, 선택 결과 안내, 모션 감소 설정 지원.

## 파일 및 데이터 범위

`web/assets/integrity-history/index.html`, `history.css`, `history.js` 수정. `web/index.html`의 iframe 문서 버전 갱신.

`rounds.json`의 분석 내용·원문 발췌·파일 해시·날짜는 변경하지 않았다. ‘조원 피드백’에 묶인 외부 모델 조사자료의 성격은 기존 상세 기록대로 유지한다. 운영 원장·정책 물량·보고서 계산 변경 없음.
