# 공식 착공 발표와 HOME 데이터 대조표 — 발표자료용

> **후속 보완:** 외부 착공·공급·입주 근거15개 사례를 추가 대조한 최종 현재 공급은 **58,541호**, 착공은 **79,884호**다. [외부 근거 반영 결과](HOME_EXTERNAL_STAGE_EVIDENCE_APPLIED_20261020.md). 아래 수량은 각 보고서 작성 시점의 전후 기록으로 보존한다.


기준일: 2026-10-20 · 대상: 10월 공식 발표에서 언급된 8개 사업 · 단위: 호

**발표 핵심: HOME는 지구 단위 개략 발표를 블록·주택 유형·사업별 원문으로 대조하고, 확인된 실적과 계획·추정을 구별하여 관리한다. 수치의 근거와 차이의 발생 지점을 추적할 수 있다는 점이 데이터 신뢰성의 핵심이다.**

## 비교 해석 보정 — 전체 주택 착공과 개략량

- **계양 A17의 착공 비교 범위는 분양309호와 행복주택154호를 합친 전체463호다.** 임대의 향후 공급 일정은 착공에서 제외할 사유가 아니다. LH 공사 원천도 전체463호를 제시한다. 따라서 A6·A17·A16·A18의 전체 주택 착공 비교량은 **2,342호**이며 발표 약2,300호와 수량상 부합한다. 현재 원장의 A17 대표 분양 범위309호와 전체 공사 범위463호의 차이는 HOME 내부 집계 범위의 문제로 구분한다. 이 문서 보정으로 운영 DB의154호를 추가 가산한 것은 아니다.
- **교산 A2 1,115호는 발표 약1,100호와 수량상 부합한다.** 15호 차이만으로 블록 오매칭 또는 A3 변경이 필요하다고 판단하지 않는다. 다만 정부의 ‘올해 착공’ 표현과 LH 원천의2024년 착공일은 수량 반올림으로 해소되지 않으므로, 수량 부합과 기간 기준 확인을 별도로 표시한다.
- 발표는 개략량이므로 수십 호 차이를 곧바로 수집 오류로 해석하지 않는다. 다만 정부가 모든 항목에 같은 반올림 규칙을 적용했다고 확인한 것은 아니다. 특히 중계본동3,178과 약3,100은 엄밀한 백 호 단위 반올림 일치라는 표현보다 ‘개략 규모 근접’으로 쓴다.
