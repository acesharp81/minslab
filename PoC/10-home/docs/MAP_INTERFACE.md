# HOME 지도 화면 및 검증 — 2026-10-02

첨부 인터페이스의 지도·선택 사업 패널·하단 연도 전환 구조를 반영했습니다. 기존 상단 지표와 연도별 요약 카드는 통합지도로 교체했고, 사업별 연도 목표 표는 지도 아래 접기 영역에 유지했습니다.

## 현재 수집과 위치 연결

| 항목 | 실제 결과 |
| --- | ---: |
| 정책 사업 후보 | 150건 (서울 12 / 경기 138) |
| 공식 공동주택용지 도형 연결 지구 | 30곳 |
| 지구에 연결된 원천 사업 후보 | 106건 |
| 위치 미연결 원천 사업 후보 | 44건 |
| 별도 API 주소 관측점 | 43개 |
| 기존 API 표본 | 3,268건 유지 |

VWorld Data API의 `LT_C_LHBLPN`에서 LH 원천 지구명을 검색하고, `blocktype=공동주택`인 실제 도형만 보관합니다. 검색 범위는 `BOX(126.3,36.8,127.9,38.3)`, 좌표계는 EPSG:4326입니다. 전체 응답의 건수·페이지·식별자를 검사한 뒤 적재합니다. 지역 범위는 기존 서울·경기 사업 후보를 따릅니다.

공식 지구명의 행정적 접미사를 정리한 완전 일치로 연결합니다. 왕숙/왕숙2, 갈매/갈매역세권 같은 별도 지구를 접두어만으로 합치지 않습니다. 현재 106건의 연결이 모두 이 규칙에 일치하며 여러 지구에 중복 연결된 사업은 없습니다. 연결 상태는 `REVIEW`입니다.

각 지구 표식은 공동주택용지 도형의 `ST_PointOnSurface` 대표점입니다. 원본은 인증정보 제거 후 SHA-256으로 보존하고 화면용 도형만 약 4m 수준으로 단순화합니다. 도형은 공동주택용지이며 전체 사업 경계나 특정 A/B 블록 경계로 확정하지 않습니다. 지구 내 원천 사업을 선택 목록으로 구분합니다. 미연결 사업에 임의 좌표를 생성하지 않습니다.

## 화면 동작

- 현황 지도: 원천 기준일의 현재 상태와 공정률을 표시합니다. 공급계획과 공사 진행 상태는 실제 공급 달성으로 계산하지 않습니다.
- 연도별 목표: 당해연도와 향후 1~10년을 선택·재생합니다. 해당 연도에 등록된 원천 예정·관리자 목표 단계로 지구 표식과 하단 단계별 후보 건수를 표시합니다. 여러 단계는 별도 색으로 구분합니다.
- 우측 패널: 정책 필터에 따른 후보 건수·선택 연도 목표 확보 건수, 선택 사업의 기준일·계획호수·공정률·목표·근거·변경이력·목표 관리 진입을 제공합니다.
- 위치 미연결 목록: 44건도 선택하여 상세와 연도 목표를 조회합니다.
- 레이어: 공식 공동주택용지와 별도 API 주소 관측점을 켜고 끕니다. 주소 관측점은 정책 사업 표식·공급 실적과 분리합니다. 정책·사업 원천·단계·매핑 필터 시 정책에 연결되지 않은 관측점은 숨깁니다.
- 조회 기준일·지역·정책·검색과 목표 표시 조건을 기존 API 필터에 연결합니다. 과거 기준일에 이후 수집한 위치를 소급 표시하지 않습니다.

참고 이미지의 모의 공급량·달성률·6개월 지연·예측 일정을 생성하지 않습니다. 원천 계약 준공 예정은 입주 예정으로 바꾸지 않으며, 등록되지 않은 목표는 0호를 의미하지 않습니다. 공식 공급총량은 기존대로 확정 전입니다.

## 운영과 인증정보

기존 `POC10_VWORLD_API_KEY`를 재사용하므로 추가 API 키가 필요하지 않습니다. 지구 레이어는 수동 수집 원천 `vworld_district`로 등록하며 기본 24시간 수집과 API 표본 재수집에 포함하지 않습니다.

```bash
sudo docker exec poc10-home-api python -m scripts.collect --source vworld_district
```

브라우저는 HOME의 `/api/tiles/{z}/{x}/{y}.png`만 호출합니다. 서버가 고정된 VWorld Base WMTS 주소로 요청하고 PNG를 확인한 후 최대 256개·시간 단위 캐시를 사용합니다. 키·외부 인증 URL을 브라우저에 전달하지 않습니다. 줌 7~18과 타일 좌표 범위를 검사하고 redirect·비이미지 응답을 거부합니다. Leaflet 1.9.4는 MIT 라이선스와 함께 프로젝트 정적 자산으로 보관했습니다.
