# 정책 탭 패널 · 시군구 원그래프 · 독립 블록 그래프

## 화면

- 우측 패널의 첫 항목은 정책 모니터링입니다. 전체/9·7/1·29/8·13 탭을 선택하면 입체 그래프와 지도 사업 범위가 함께 바뀝니다. 과거 연도는 당시 존재한 정책과 귀속 미확인 자료를 표시합니다.
- 같은 항목 아래에 선택 정책·프로그램·지역 범위의 서울/경기 그래프를 나란히 표시합니다. 발표 정책 목표의 범위·지표와 서울·경기 검토 사업계획의 분모를 구분합니다.
- 확대 7~12에서는 **시군구 원그래프**를 지도 위에 직접 표시합니다. 흰 카드 배경 없이 12시부터 시계방향으로 현재 확인량과 +1/+2/+3년 전망을 채웁니다. 원 면적은 계획량에 비례하며 작은 수치의 최소 반경은 6px입니다. 이름·전체 계획·현재 누적 목표·미래 누적 비율과 툴팁을 제공합니다. 낮은 확대에서 겹치는 추가 수치 라벨은 숨기고 마우스/키보드 포커스에서 펼칩니다. 11단계 이상은 전체 라벨을 표시합니다.
- 확대 13~18에서는 현재 지도 범위의 **블록당 세로 막대 1개**를 투명 배경으로 표시합니다. 공급 계획, 공고 확인 비율, 누적 전망, 인허가/착공/준공/분양·모집/입주의 각 근거 상태를 보여 줍니다. 블록명·총량·현재량·목표량만 짧게 표시하고, 공사율과 단계별 일정은 마우스 상세 및 클릭 후 우측 상세에서 확인합니다. 실제 근거가 없는 단계·수치·전망 눈금은 화면에서 생략하며 예정월을 완료로 바꾸지 않습니다. 원본의 미확보 값은 유지합니다.
- 정책 패널은 확대에 관계없이 유지합니다. 지연 후보와 이행 확인 목록에서 사업을 선택하면 연결 지구의 블록 화면과 기존 원문 상세로 이동합니다.

## 공간정보

기존 HOME VWorld 키로 공식 `LT_C_ADSIGG_INFO` 시군구 경계를 새 원천 `vworld_municipality`로 수집했습니다. 원본은 인증정보를 제거한 응답·SHA-256·바이트 길이·manifest·수집 이력으로 보관합니다. 이 원천은 수동 수집이며 기존 정책/사업 자동수집과 분리합니다.

최초 임시 컨테이너 수집에서 원본 파일이 운영 볼륨에 보관되지 않아 해당 배치를 검증 실패로 명시했습니다. 운영 데이터 볼륨에 다시 수집하여 현재 56개 도형과 정상 원본의 해시·길이를 재검증했습니다. 보관하지 못한 최초 응답을 복원한 것으로 표시하지 않습니다.

서울 25개 자치구 + 경기 31개 시·군, **56개 경계**를 보관합니다. 경기도 일반구는 시 단위로 도형을 합치고 서울 자치구는 유지합니다. 공식 대표점에 지역 집계 원을 배치합니다. 사업 소재지가 원천에 명시되어 있으면 이를 사용하고, 없는 경우 같은 정확한 지구·블록의 원천 소재지나 공식 지구 대표점의 경계 포함 여부를 검토 연결합니다. 사업명 접두어만으로 지역을 추정하지 않습니다.

현재 150개 후보 중 **141건이 31개 시군구에 연결**, 나머지 **9건은 귀속 미확인**입니다. 개별 블록 좌표는 새로 추정하지 않으며 기존 75개 블록 묶음의 공식 지구 대표위치를 사용합니다. 행정 경계와 지구 도형은 현재 확보 자료로, 과거 경계 복원을 뜻하지 않습니다.

## 현재에서 누적하는 전망

`quantities.projection`은 동일 공급 단계의 현재 확인량에 **겹치지 않는 미이행 원천 예정량**을 더합니다. 예를 들어 현재 40호, +1년까지 예정 60호, +2년까지 예정 100호이면 전망은 100/140/140호입니다. 2년째에 이미 누적된 60호를 다시 더하지 않습니다. 입체 막대와 원그래프의 미래 색상 구간은 각 누적치 사이의 증가분만 채웁니다.

- 확인 공고가 이미 연결된 블록의 미래 모집 계획은 회차 대응이 불명확하므로 다시 더하지 않습니다.
- 계획 분모 미확보, 동일 블록 대응 미확인, 원천 예정량 미확보, 전체 계획보다 큰 예정량은 전망에서 제외하고 건수·물량·이유를 제공합니다.
- 실제 누적량이나 향후 일정이 미확보인 범위는 전망 비율도 미확보로 유지합니다. 입주·준공의 현재 실제량을 모집공고로 대체하지 않습니다.
- 관리자 연간 목표는 원천 예정과 따로 표시하며 중복 합산하지 않습니다.
- 현재 누적 목표는 확보 원천 일정의 기준월 이전 누적입니다. 일자를 모르는 기준월의 이행 경과를 확정하지 않습니다. 연간 관리자 목표를 임의로 월별 배분하지 않습니다.

현재 공급 기준의 비율 대상 공고 **17,864호** + 호수·블록·분모가 호환되는 예정 **4,239호** = 향후 1/2/3년 검토 누적 **22,103호**, 확보 전체 계획 71,416호 대비 **30.95%**입니다. 원래 미래 예정량 5,137호 중 분모 연결이 불명확한 898호는 이 전망에 제외합니다. 분모 미확보 공고 792호도 비율에서 제외하며 전체 연결 공고 18,656호는 별도로 계속 조회합니다. **이는 부분 수집 자료의 공고 기준 검토 전망이며 공식 정책 달성률·실제 보급률이 아닙니다.**

## 독립 블록 그래프 (2026-10-03 보완)

지구별 300px 폭의 스크롤 목록을 제거하고 블록별 **82×142px** 투명 세로 막대를 지도에 따로 표시합니다. A4·S1 등 블록명이 가장 크게 보이며 총 공급계획, 현재 누적 목표, 현재 확인량을 함께 비교합니다. 옅은 세로 막대는 전체 계획, 아래부터 채운 부분은 현재 확인량, 금색 가로 눈금은 누적 목표입니다. 향후 1·2·3년은 현재 확인량 위에 증가분만 쌓고 막대 오른쪽의 +1/+2/+3 눈금으로 표시합니다. 겹치는 눈금의 숫자만 이동시키며 실제 높이는 유지합니다.

전체 계획 막대의 폭은 **10px**입니다. 현재량·목표·전망이 미확보이면 해당 채움·수치·눈금·라벨을 생략합니다. `+N?`, 대시, `일정?`, 비율 미확보 문구를 표시하지 않으며 미확보를 0으로 바꾸지 않습니다. 추가 예정량·확보 단계별 날짜·공사율은 마우스 상세와 클릭 후 우측 상세에서 확인합니다. 관리자 목표는 원천 예정량과 구분해 상세에 표시합니다.

동일 본 모집공고와 최초 근거의 단일 예정월을 비교하여 **조기 / 정상(동월) / 지연**을 색과 문구로 구분합니다. 공고보다 나중에 기준일이 잡힌 수정 계획, 여러 공급 회차, 연간 기준일만 있는 계획으로 조기·정상을 확정하지 않습니다. 과거 월보다 늦은 공고는 기존의 지연 검토 후보로 남기고, 실적·기준 일정이 없으면 상태 색·문구를 생략합니다. 현재 확인량은 파란색으로 표시하며 이는 정상 일정 판정을 뜻하지 않습니다. 지연 검토 후보·이행 확인 목록은 우측 근거 검토 영역에서 조회합니다. 현재 수집 범위의 비교 가능한 지연 검토 후보는 2개 블록이며 조기·정상 확정 사례는 미확보입니다.

개별 블록 좌표는 미확정입니다. 그래프는 지구 대표점에 고정한 **화면상의 표식**이며 연결선으로 위치 근거를 보여 줍니다. 이 배치는 블록 좌표를 생성하거나 DB 공간정보를 변경하지 않습니다. 선택 지구의 블록을 우선 펼치고 그래프끼리 겹치지 않도록 배치합니다. 남양주왕숙 10개 블록을 동시에 표출했고, 화면에 모두 들어오지 않는 경우 추가 블록 수와 확대 버튼을 제공합니다. 확대할수록 주변 지구 수가 줄어 더 많은 블록 그래프를 볼 수 있습니다. 모바일에서는 같은 정보와 확대 동작을 유지합니다.
