## 화면

- 시설 팝업은 시설명·주소·실질 정보만 표시합니다. 반복적인 선택 블록 직선거리 문구를 제거했습니다.
- 표시 반경·최근접 지하철 예외·직선거리 산식·원천 링크·조회일·상세 연결 제한은 기본적으로 접힌 **입지 지표의 기준·원천**에 둡니다.
- 예정 시설의 긴 안내·미수집 안내 목록과 **병원, 마트** 묶음 제목은 제거했습니다. 병원·대형마트의 개별 버튼은 유지합니다.
- 입지 그래프도 설명과 출처를 접습니다. **고용률·사업체 수는 그대로 바로 보입니다.**
- 조회 실패는 ‘지금 조회할 수 없음’, 미연계 상세는 ‘미확보’로 표시합니다. 0이나 시설명에서 추정한 수치로 보정하지 않습니다.

## 유지관리

`GET /poc/home/api/map/facility-details`는 `kind`, `place_id`, 선택한 `project_id` 또는 `block_id` 중 하나를 받습니다. 선택 위치의 실제 POI 목록에서 ID와 종류를 대조하며 외부 URL·임의 주소를 받지 않습니다. 원천 호스트는 수집기 허용 목록으로 제한합니다.

상세 결과는 `status`, `fields[{label,value}]`, `source_name`, `source_url`, `source_key`, `as_of`, `collected_at`, `notes`, `evidence`로 반환합니다. 원문은 `data/raw/facility_details/`에 SHA-256 파일명으로 저장합니다. TOPIS 정류소의 읽기 전용 POST도 요청 매개변수·응답 원문을 보존합니다.

교통 상세는 10분, 기타 상세와 기관별 장소 목록은 24시간 메모리 캐시입니다. 일시 조회 실패는 1분 뒤 재시도할 수 있습니다. API 컨테이너 재시작 시 캐시는 초기화되며 원문은 유지합니다. 상세값을 사업 원장·주택 물량에 쓰지 않습니다.

병원 확장에는 [심평원 의료기관 상세 API](https://www.data.go.kr/data/15001699/openapi.do)의 활용승인과 기본 API 기관키 연결이 필요합니다. 기존 공통 키로 상세 서비스가 승인되었다고 간주하지 않습니다. 어린이집 추가 지역은 [어린이집정보공개포털 API](https://info.childcare.go.kr/info_html5/oais/openapi/OpenApiSlL.jsp) 또는 지역 공개 원천의 기관 식별자를 연결해야 합니다.

## 검증

`tests/test_facility_details.py`는 동명 학교·어린이집/주소 충돌, 반대 방향 정류소 모호성, 학생수·정원 구분, 시간표 방향·심야 분리, 공식 점포 주소·휴점일, 원천 연결 실패, 선택 위치 외 ID 거부를 검증합니다. 수서 지역 공식 원천을 실제 조회했고, 배포 화면에서 상세 팝업과 접힌 출처·고용률/사업체 수 노출을 확인합니다.
