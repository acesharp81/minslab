# 정책·프로그램·사업 보고서의 집계 기준

## 9·7 전체 목표 원장: 연도별 목표와 실적

9·7 전용 보고서의 Y축은 항상 **0–1,350,000호**다. 지역·블록 선택과 연결 사업만 보기에서도 축을 재조정하지 않는다. 대표 단계의 면적은 서로 배타적인 물량 원장이며, 위에 겹치는 선은 선택한 동일 단계의 누적 목표와 실적이다. 단계별 도달 누적량을 모두 더해 전체 원장을 만들지 않는다.

기본 비교는 원문 목표와 일치하는 착공(건설)이다. 2026–2030년 원문 연간 목표 269,000 / 246,000 / 250,000 / 249,000 / 335,000호와 누적 목표를 지역 착공 통계와 같은 연도에서 나란히 표시한다. 원문표 합계는 1,349,000호이므로 발표 목표와의 1,000호 차이는 미배분으로 남긴다. 연말 목표점을 연결하는 선은 시각적 보간이며 월간 공식 목표가 아니다.

`/api/policy-delivery`의 `yearly_comparisons`는 `policy`, `region:<시도명>`, `city:<시군구 ID>`, `project:<사업 ID>`별 비교 자료를 반환한다. `metrics` 아래 CONSTRUCTION / SUPPLY / BUSINESS / APPROVAL / COMPLETION 각각이 다음 정보를 갖는다.

- `target_points`: 공식 원문 또는 중복 제외한 연결 사업 원천 일정의 누적 목표, 날짜·출처·근거.
- `management_points`: 담당자가 입력한 누적 목표. 공식 원문 목표를 덮어쓰거나 연간 공급량처럼 합산하지 않는다.
- `actual_points`: 같은 단계의 확인 실적. 미래로 연장하지 않는다.
- `annual`: 연간·누적 목표, 연간·누적 실적, 담당자 누적 목표, 실제 확인 기준일 및 수집 상태를 묶은 11년 자료.

전체 수도권 착공 실적은 서울·경기·인천이 모두 있는 공통 월까지만 집계한다. 중간 월이 비면 이후 월을 이어 합산하지 않는다. 지역 통계는 동일 범위 비교용이고 9·7 정책에 개별 귀속이 확인된 사업 실적과는 다르다. 서울은 원문 개별 연간 목표가 있으나 경기·인천 개별 목표는 원문에서 미확보이므로 임의 배분하지 않는다.

공급은 연결 사업의 본 모집·분양 확인량과 같은 사업의 모집 예정량을 비교한다. 사업화·인허가는 해당 단계의 확인 사건이 있어야 실적을 표시한다. 준공은 준공 확인 사건 또는 원천 공정률 100% 확인을 사용하고, 공정률 50%를 준공 50% 호수로 변환하지 않는다. 입주는 시작일만 관리하여 호수 비교 기준에서 제외한다. 미래 연도의 실적과 확인 기록 없는 단계는 `null` / `미확보`다. 실제 원천이 제공한 0은 0으로 유지한다.

지도·그래프 연도 슬라이더는 캐시된 자료에서 면적, 목표·실적 선, 선택 연도 카드와 표 강조를 함께 갱신한다. 누적 목표 대비 비율은 **해당 연도 말 목표 대비 확인량**이며, 중간월 실적과 연말 목표의 차이만으로 지연이라고 판정하지 않는다. 출처와 계산 범위는 보고서 하단에서 확인한다.

정책현황은 공식 시군구 경계를 단순화하고 연결 사업계획 물량에 따라 높이를 부여한 경량 입체 지역 도식과 보고서를 사용한다. 면 높이는 실제 건물 층수나 현재 준공량이 아니다. 프로그램·사업의 상세 3D 지도와 기존 공급현황 지도는 별도로 유지한다. 화면은 개요와 지역 그래프 다음에 추진현황·가구 추계 비교를 배치한다. 정책→프로그램→사업은 고유 ID로 연결하며, 같은 이름의 프로그램도 서로 다른 ID이면 별도로 집계한다. 담당자 승인 전 REVIEW 연결도 표시하되 검토 상태를 항상 보인다.

## 공급 실적의 정의

공식 본 모집·분양공고가 확인된 세대수는 SUPPLY 단계의 공급 실적이다. 사업계획의 supply_units, 공사 공정률, 준공 예정 및 실입주는 공급 실적에 포함하지 않는다. 공고 정정·재공고는 원천 공고 ID(가능하면 주택관리번호)로 중복 제거한다.

- actual_supply_units: 연결된 고유 사업의 공고 확인 물량 전체. 계획호수가 없는 사업의 공고도 포함한다.
- actual_supply_period_units: 정책 발표일 이후의 공고 확인 물량. 정책 보고서의 주 실적이다. 발표 전 공고는 배경 맥락으로만 보인다.
- actual_supply_annual_units: 기준연도 공고 확인 물량.
- actual_supply_status=REVIEW: 공고 자체의 존재와 정책·프로그램·사업 귀속의 확정 여부를 구분한다.
- cumulative_observed_units: 기존 API의 목표 비교용 지표로, 계획호수가 있는 대상만 포함할 수 있다. 보고서의 전체 공급 실적으로 재사용하지 않는다.
- actual_delivery_units: 실제 준공·실입주 실적이 연결되지 않은 경우 null이다.

공식 정책 발표 목표는 원래 발표 범위와 지표(예: 인천 포함 수도권 착공)를 그대로 표시한다. 서울·경기 연결 사업계획 및 공고 실적과 직접 나누어 공식 정책 달성률을 만들지 않는다.

## 추진현황 누적 면적 그래프와 지역 집계

정책·프로그램·사업 보고서의 추진현황은 선택 연도 주변 4년을 월 단위로 확대해 보여주고, 바로 아래에서 현재 연도 중심 과거 5년·미래 5년의 11년 전체를 축소 그래프로 보여준다. 지도 연도 슬라이더가 선택 연도와 확대 구간을 바꾼다. 전체 연결 사업계획 물량을 다음 네 부분으로 나누어 보여준다. 정책 원문에서 발표한 공식 목표와 연결 사업계획 총량은 범위·지표가 다를 수 있으므로 혼합하지 않는다.

- 청록: 고유 공식 본 모집·분양공고 ID로 중복 제거한 공급 확인량. 정책은 발표일 이후 공고만 포함한다.
- 빨강: 원천의 모집·공급 예정월이 지났지만 해당 사업에 연결된 본 공고가 확인되지 않은 물량. **확정 지연이 아니라 검토 후보**다. 공고 원천 누락 또는 사업 연결 오류가 원인일 수 있다. 현재월의 예정은 월말까지 빨강으로 판정하지 않는다.
- 파랑: 기준월부터 선택 연도 말까지 원천 예정월이 확인된 향후 공급량. 같은 사업의 이미 확인된 공고량은 중복 계산하지 않는다.
- 회색: 전체 연결 사업계획 중 위 세 범주에 배치되지 않은 잔여 물량. 이는 공급 미착수 확정값이 아니라 일정·공고 귀속이 아직 확인되지 않은 계획이다.

가로축은 원천 예정월과 공식 공고월을 반영한 월별 누적 상태다. 곡선은 이웃 월의 확인값을 화면에서 부드럽게 잇는 시각적 보간이며, 월 사이의 실적이나 예정 물량을 새로 만들지 않는다. 상단 연도 머리글에는 해당 연도의 원천 모집·공급 예정량을 표시하고 근거가 없는 연도는 `예정량 미확보`로 둔다. 현재선은 조회 기준월을 사용한다. 미래 공고 실적은 현재 확인량에서 동결하고 향후 원천 일정만 추가한다. 자료에 전체 연결 계획 자체가 없으면 목표를 `미확보`로 표시하고 합계를 꾸며내지 않는다. 일정 자료가 없으면 지연을 0이라고 판정하지 않고 `판정 보류`로 표기한다.

시군구를 선택하면 `project_ids`, 중복 제외 `chart_target_ids`, 일정 근거가 있는 `chart_schedule_ids`를 해당 지역으로 좁혀 면적과 물량을 다시 계산한다. 같은 이름으로 다른 정책에 소속된 프로그램은 `program_id` 기준으로 별도 집계한다. 지도 연도 슬라이더는 그래프의 선택 연도와 추가 예정량·잔여 계획을 바꾼다. 지도 탭의 계획·준공·모집은 지역 도식의 높이 기준이고, 아래 추진현황은 언제나 본 공고를 공급 실적으로 사용한다. 공사 공정률과 준공 예정·입주 시작월은 이 공급 실적에 합산하지 않는다.

정책 도식은 시군구 공식 경계만 사용하고 배경 타일·도로·용지·블록 자료를 내려받지 않는다. 지도 범위는 서울·경기 전체 또는 선택 시도에 맞추며 휠 확대는 1~1.35배로 제한한다. 프로그램·사업 3D 지도에서는 시군구·지구 용지·블록 위치의 도형 역할을 구분하고 블록 점을 실제 경계로 표시하지 않는다.

정책 보고서는 `/api/area-context`의 시도별 1·2·3·4·5인 이상 일반가구, 연도별 인구, 같은 연도 주택 재고와 일반가구 차이를 연결 지역 범위로 합산한다. 공급현황 왼쪽 지역 패널은 인구(왼쪽 축), 일반가구·주택 재고(오른쪽 축)를 겹친 시계열과 연간 분양승인 막대(별도 하단 눈금)를 함께 보인다. 시군구 연간 분양승인 자료가 없으면 막대를 생략한다. 분양승인은 시도 전체·민간 포함 통계이며 정책별 본 공고 공급 실적과 별개다.

## 가구 수요 비교

/api/area-outlook의 시도별 주택 재고 기준값, 현재까지 관측된 준공량, 연도별 가구 추계를 사용한다. 미래 관측 준공량이 빈 값이면 현재까지 확인된 값을 기준선으로 유지한다. 해당 정책/프로그램에 연결된 사업의 향후 준공 예정량만 더한 참고 시나리오를 보인다. 입주 시작 예정월은 날짜로만 관리하며 물량으로 계산하지 않는다. 지연선은 확인된 예정 일정을 1년 이동한 가정이다.

이 시나리오는 예정 물량이 100% 주택 재고로 증가한다는 가정이며, 멸실·공실·다른 사업의 공급·사업 중복을 반영하지 않는다. 시군구 단위 가구 추계가 없으므로 시도 합계로만 비교한다. 일정 또는 추계가 없으면 미확보로 둔다.

## 화면과 API

- /api/policy-monitor: 정책 원문·발표 목표, 추출한 정책 개요, 정책 발표 이후 공급 실적.
- /api/policy-geo/schematic: 정책 보고서의 화면용 공식 시군구 경량 도형. 임의 공급 수치나 건물 형상을 포함하지 않는다.
- /api/policy-geo/metrics: 정책/프로그램 고유 ID, 중복 제외 집계, 원천 월별 일정(`schedule_events`), 공고 근거 ID·날짜.
- /api/mappings: 정책→프로그램→사업 연결 상태 및 담당자 검토 상태.
- /api/area-outlook: 시도 단위 가구 추계와 주택 재고 비교.
- /api/projects/{id} 및 /targets: 사업의 인허가·공사·공급·준공 원천 세부정보 확인.

프로그램·사업 목록은 화면당 약 10개 행 높이로 스크롤한다. 선택 시 같은 화면 흐름에서 해당 단위로 이동한다.

## 정책 지역 선택과 하단 집계

정책현황 입체 지역 도식에서 시군구를 누르면 하단 추진현황의 연결 사업계획 목표, 정책 발표 이후 본 모집·분양공고 실적, 11년 누적 추진현황 면적 그래프, 판정, 소속 프로그램 목록을 해당 시군구의 정책 연결 사업만으로 다시 계산한다. 지도 선택을 해제하면 서울·경기 전체로 돌아온다. 정책 발표의 공식 목표와 상단 개요는 정책 원문 범위를 유지하고, 지역 선택 후 하단에는 공식 정책 전체 목표 카드를 중복 표시하지 않는다.

시군구 목표는 해당 지역의 `by_scope.policy` 물량과 중복 제외된 `chart_target_ids`, 연도 일정은 `chart_schedule_ids`, 공고 실적은 정책 발표일 이후 고유 공고 근거 ID를 사용한다. 다른 원천의 같은 사업 후보나 상위 지구·하위 블록을 단순 합산하지 않는다. 인구·가구·주택 재고 이력은 `/api/area-context?region=...&municipality=...`로 같은 시군구를 조회한다. `/api/area-outlook`은 현재 시도 단위이므로 시군구 선택 시 미래 가구·공급 부족량을 만들지 않고 추계 미확보를 표시한다.

데이터 구조, 실제 수집 범위, 남은 공백 및 설계 원칙을 처음 보는 사람을 위한 독립 HTML 자료는 [HOME 아키텍처와 수집현황](HOME_ARCHITECTURE_AND_COLLECTION_20261010.html)이다. `python -m scripts.generate_architecture_html`로 운영 읽기 API의 최신 수치로 다시 생성할 수 있다.
