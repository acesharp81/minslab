# 공식 발표와 HOME의 차이 재검토: 날짜 차이와 인허가·착공 수집 누락

> 후속 최종 검증: [2026-10-19 최종 대조 보고서](analysis/HOME_FINAL_RECONCILIATION_20261019.md). 이 문서는 당시 검증 이력입니다. 혼합 기준시점·서면 수치 정정·추가 사업계획의 최신 결론은 최종 보고서를 우선합니다.

**검토일: 2026-10-19 · 대상: 10월 16일 공식 주택공급 발표, 9월 30일 발표한 8월 주택통계, 현재 HOME 수집 원장과 코드**

## 1. 결론: 통계 공개 시차와 실제 수집 부족이 함께 존재한다

**지금은 ‘날짜가 달라서 생긴 차이’라는 설명을 항목별로 좁히고, 일반 건축인허가·착공 원장의 수집 확대와 이미 수집한 착공 후보의 사업 연결을 우선해야 한다.** 같은 기간의 시도 통계는 정확히 맞지만, 이를 구성하는 개별 사업과 착공 사건을 모두 확보한 상태는 아니다.

담당자 승인값과 승인 연결은 **정확한 확정값**으로 사용한다. 이 보고서의 점검 대상은 승인값의 신뢰도가 아니라 **승인된 관리 대상 바깥의 수집 범위, 원문에서 추출하지 못한 항목, 사업 연결 여부, 공식 발표와의 집계 범위 차이**다. 이번 검토에서 수집 원장·담당자 승인·운영 프로그램을 변경하지 않았다.

### 지금 바로 추진할 조치

1. **공식 월별 통계 PDF/XLS를 대체 수집 경로로 추가한다.** 월별 인허가 누계와 주택유형·공공/민간 구성을 확보한다.
2. **일반 건축인허가 최초 전수 수집을 별도 작업으로 가속한다.** 현재 자동 운영의 1동/일 수준으로는 누락을 신속히 줄일 수 없다.
3. **올해 착공일이 있는 원장 행을 별도 검토 목록으로 올린다.** 우선 이번에 찾은 주거용 신축 44행의 주소·관리번호·사업 범위·세대수를 대조한다.
4. **신축매입·민간 정비·소규모 일반주택의 착공 근거를 보강한다.** 공공택지 공사 목록만으로 수도권 전체 착공을 재구성할 수 없다.
5. **공식 발표의 사업별 구성명세를 확보한다.** 9월~10월 추가 사건, 전월 정정, 유형별 포함·제외를 나눠 차이를 정산한다.

## 3. 착공 총계: 같은 기간에는 맞는다. 모든 사업을 확보했다는 뜻은 아니다

### 3.1 같은 기간·같은 지역·같은 지표로 검증

비교 기간은 모두 **2026년 1월~8월**, 단위는 **호**다. HOME DB의 월별 관측 72행을 시도·지표별로 8개월씩 합산했다. 같은 시도·지표·월의 중복은 없었다. 공식 PDF의 지역별 누계와 비교한 결과는 다음과 같다. [국토부 공식 원문 PDF, 7~10쪽](https://www.index.go.kr/unity/potal/FileDown.do?seq=17704&id=1229&div=1)

착공·준공·분양승인 **9개 비교 셀 모두 정확히 일치**한다. 이 결과는 해당 지역·기간의 총계 검증 결과이며 전체 사업 데이터의 정확도 100%를 의미하지 않는다. 분양승인 통계는 일반분양·임대·조합원분을 포함한 승인 통계로, 개별 입주자 모집공고 실적과 구별한다.

착공의 지역 합산도 **20,679 + 17,515 + 48,545 = 86,739호**로 공식 수도권 누계와 일치한다. 이는 수집한 시도 총계에서 특정 월이나 지역을 빼먹어서 값이 작아졌다는 설명을 지지하지 않는다.

### 3.2 왜 99,000호 이상과의 차이를 전부 ‘날짜 차이’라고 하면 안 되는가

공식 10월 발표는 **10월 둘째 주까지 99,000호 이상**을 제시한다. HOME의 월별 통계는 8월 말까지다. 따라서 종료일 차이는 실제로 존재한다. 그러나 다음 항목이 확보되지 않아 **99,000 − 86,739 = 12,261호**를 전부 9월 이후 순증 착공이라고 증명하지 못했다. 99,000은 ‘이상’이므로 차이도 **최소 12,261호**다. [10월 16일 공식 정책뉴스](https://www.korea.kr/news/policyNewsView.do?newsId=148973657)

| 남은 검증 | 필요한 자료 | 현재 결론 |
| --- | --- | --- |
| 기간 추가분 | 9월 및 10월 둘째 주까지의 실제착공일·호수 명세 | 미확보 |
| 과거 실적 정정 | 1~8월 동일 지표의 발표 판본별 수정 이력 | 이번 두 발표 사이 정정량 미확인 |
| 모집단 동일성 | 두 발표의 공공·민간·신축매입·일반주택 포함 기준 | 세부 구성명세로의 대조 미완료 |
| 중복 및 범위 조정 | 같은 블록·주택유형의 포함/제외와 사건 기준 | 미확인 |

정산해야 할 관계는 `공식 최신값 − 같은 기간 HOME 기준값 = 기간 추가 사건 + 기존 기간 정정 + 범위·정의 조정 + 미설명 차이`다. 각 항의 중복을 제거하고 나서만 원인별 호수를 제시한다. 현재는 ‘기간이 다르다’는 사실과 ‘차이가 모두 기간 때문이다’라는 결론을 구별해야 한다.

### 3.3 향후 최신 통계를 놓칠 수 있는 자동화 설정

서울·경기 `molit_statistics`는 현재 `manual_only=true`, 마지막 성공은 **10월 5일 17:31 KST**다. 인천 `incheon_statistics`는 자동 대상이며 **10월 19일 08:51 KST**에 성공했다. 이번에는 최신 공개월이 8월이어서 서울·경기 값이 공식 최신 기간과 맞지만, 다음 월 발표를 서울·경기 경로가 자동 추적한다는 보장은 없다.

인천 수집이 전국 응답 파일을 받을 수 있더라도, 현재 파서는 인천만 `statistic`으로 저장한다. 서울·경기 월별 행이 자동 갱신되는 것과 같지 않다. **통계 원천의 자동 실행, 최신 공개월 검사, PDF/XLS 대체 경로를 함께 연결**해야 한다. 근거: `sources.py`, `collection_jobs.enqueue_due`, `policy_907_sources.collect_incheon_statistics`, 현재 원천 API 응답.

## 4. 개별 착공: 미수집 지역과 이미 수집했지만 연결하지 못한 기록이 있다

### 4.1 지역별 수집 범위부터 충분하지 않다

분모는 현재 수집기가 대상으로 사용하는 법정동 명부다. 완료는 해당 법정동의 조회 페이지 확인을 뜻한다. 각 동의 주택 수가 다르므로 이 비율을 공급량 확보율로 해석하면 안 된다.

| 원천 | 조회 완료/대상 동 | 동 기준 조회율 | 미완료 동 |
| --- | ---: | ---: | ---: |
| 건축HUB 일반 건축인허가 | 8/2,907 | 0.28% | 2,899 |
| 건축HUB 주택인허가 | 2,535/2,629 | 96.42% | 94 |
| 9·7 인천 주택인허가 원천 | 65/278 | 23.38% | 213 |
| 건축HUB 동별·대지위치 파일럿 | 776/2,907 | 26.69% | 2,131 |
| 건축HUB 주거용 건축물대장 | 2,247/2,629 | 85.47% | 382 |
| 건축HUB 주거용 총괄표제부 · 사용승인·합필 참조 | 20/2,629 | 0.76% | 2,609 |

위 분모는 각 원천의 **마지막 성공 배치가 기록한 대상 범위**다. 예를 들어 총괄표제부의 현재 코드에는 인천 명부를 합치는 로직이 있지만, 마지막 배치 범위는 아직 2,629개로 기록돼 있다. 설정 확대와 실제 확대 수집 완료를 혼동하지 않는다.

일반 건축인허가는 **수도권 대상 중 서울 일부 8개 동만** 확인되어 있다. 이 API에서 현재 확보한 실제 원장 행은 14,821행이다. 원천 화면의 누적 레코드 14,822에는 `source_connection` 1행이 포함돼 있어, 원장 건수는 kind를 구분해 계산했다. 경기·인천의 일반 건축인허가는 이 원장의 지역 집계에 아직 없다.

인천 주택사업 인허가는 213개 동이 남아 있다. 서울·경기 주택사업 인허가는 많이 확대됐지만 94개 동이 남아 있다. 따라서 **착공일이 실린 원천을 아직 조회하지 않은 지역이 존재한다.** 그 지역의 실제 누락 사업 수·호수는 미수집 단계이므로 현재 숫자로 추산하지 않는다.

### 4.2 수집한 원장 안에서도 착공 후보가 사업 연결 밖에 있다

다음은 **2026-01-01~10-19 착공일 필드가 있는 원장 행**을 직접 조회한 결과다. 두 API의 행은 서로 같은 사업일 수 있어 합계를 고유 사업 수로 표시하지 않는다.

| 원장 종류 | 올해 착공일 보유 행 | 양수 세대수 행 | 세대수 0행 | 사업 식별 별칭 연결 | 근거 연결 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 주택사업 인허가 `permit` | 2,190 | 1 | 2,189 | 0 | 0 |
| 일반 건축인허가 `general_permit` | 67 | 45 | 22 | 0 | 0 |

### 4.3 자동 수집은 돌아가지만 초기 확대 속도가 느리다

일반 인허가 완료 동은 최근 성공 배치에서 **6 → 7 → 8개**로, 10월 18일·19일 KST에 하루 1개씩 늘었다. 설정상 이 원천의 기본 배치는 1개 동이며 자동 수집 주기는 1일이다. 남은 2,899개 동을 같은 속도로 채운다는 단순 산술은 2,899일이다. 이는 완료일 예측이 아니라 **현 기본 설정이 최초 범위 확대에 적절하지 않다는 설명**이다.

더구나 `building_scope.next_districts`는 배치 크기 1이고 미완료 동이 남아 있으면 재방문 몫이 0이 된다. 코드에 7일 재방문 기준이 있어도 이 조건에서는 완료 동의 정기 재조회가 뒤로 밀릴 수 있다. **초기 확대 작업과 변경 감시 작업을 별도 실행 용량으로 운영**해야 한다. API 허용량·페이지 수를 측정해 배치와 병렬도를 정하고, 실패한 동은 체크포인트에서 재개하는 기존 방식을 유지한다.

장기 지표는 다음과 같이 분리한다.

- **원천 가동 상태:** 최근 성공/실패. 현재 65/66 SUCCESS는 전수 확보율이 아니다.
- **조회 범위:** 대상 동·페이지·기간 중 완료/미완료와 마지막 재방문.
- **필드 충족:** 착공일, 주택 수, 유형, 사업 범위, 식별자의 확보 상태.
- **사업 연결:** 미연결 후보 수, 기존 사업 중복 해결 수, 승인 관계 반영 수.
- **동일 조건 대조:** 같은 기간·모집단·정의에서 일치/차이/미수집을 각각 표시.
- **미설명 차이:** 기간과 범위를 맞춘 뒤에도 남는 호수. 근거 없이 날짜 차이에 배정하지 않음.
