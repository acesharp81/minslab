## 1. 결론과 지금 해야 할 일

**실제로 빠져 있던 지역·자료 경로를 보완했다. 그러나 공식 발표와의 차이를 전부 수집 시차로 설명할 수는 없다.** 일부 수집기는 인천을 요청하지 않았고, 일반 건축 인허가는 내부 건수 상한으로 큰 법정동을 완료하지 못했다. 원천 접속 장애와 아직 조회하지 않은 법정동, 별도 공고 유형·계약 자료도 남아 있다.

우선 일반 인허가·대장·상세의 미조회 지역을 이어 수집하고, 신규 원문 후보를 기존 사업의 블록·주소·사건일과 대조해야 한다. 장기적으로는 성공 배치 수보다 **지역×기간×자료 종류별 확보 범위, 재방문 시각, 변경·취소 이력, 연결 완료 범위**를 관리해야 한다.

담당자 승인값은 정확한 관리값으로 보존했다. 이번 보완은 원천 확보 범위 확대이며, 새로 찾은 문서나 관측 건수를 주택 호수에 자동 가산하지 않는다.

## 2. Excel이 알려 준 것과 실제 수집의 차이

두 Excel에는 41개 컬럼의 후보 항목 1,174개가 있으며 공개본은 비공개 항목 11개를 제외한 1,163개다. 두 파일의 중복 항목을 합쳐 두 배의 수집량으로 계산하지 않았다. 출처 식별자는 98개, 중복 URL을 정리한 경로는 87개였다.

이는 수집 대상 설계 목록이다. 파일에 URL이나 항목이 적혀 있다는 사실과 해당 원문을 운영 원장에 확보했다는 사실은 다르다. 기존 출처 67개와 대조해 신규 공식 문서 경로 2개를 추가했고, 인증키 기반 API 수집기 27개를 별도 전수 점검했다.

### 3.1 중복 원문 사례

정비사업 CSV의 인천 남촌동 행이 원문 1,471행과 1,478행에 동일하게 반복돼 있었다. **내용까지 같은 행만 하나로 정리하고 두 원문 행 번호를 보존**했다. 따라서 인천 원문 68행은 고유 67행이다. 이름이 같지만 수치·내용이 다른 행은 이 규칙으로 삭제하지 않고 충돌로 처리한다.

### 3.2 지역 코드가 서로 다르다

| 시스템 | 인천 코드 | 처리 원칙 |
| --- | --- | --- |
| 일반 행정·LH·법정동 | 28 계열 | 해당 원천의 자치단체·법정동 코드 사용 |
| SGIS 통계 | 23 | 행정코드 28을 넣지 않음 |

단순히 모든 API에 같은 수도권 코드를 넣으면 범위가 맞지 않는다.

## 4. 추가한 공식 문서 수집

### 4.1 LH 부서별 연간 업무계획

[LH 공식 부서별 업무계획](https://www.lh.or.kr/board.es?mid=a10601040000&bid=0035&act=view&list_no=654637)의 2025·2026년 첨부 12개를 확보하고 HWPX 본문과 표 925개를 추출했다. 첨부 식별자·연도·제목, 원문 URL, 파일, SHA-256을 보존한다.

계획에는 전국/권역, 단년도/장기, 신규/누적 항목이 섞일 수 있다. 표를 확보했다는 이유로 정책 착공 실적을 생성하지 않는다. 사업·기간·단위 대조가 가능한 원문 후보로 사용한다. 계획연도 1월 1일은 정렬용 기준이며 발표일이나 착공일로 사용하지 않는다.

### 4.2 토지이음 고시

[토지이음 공식 고시 목록](https://www.eum.go.kr/web/gs/gv/gvGosiList.jsp)에서 서울·인천·경기, 2025-09-07부터 수집일까지의 목록을 수집한다. 최신 페이지를 다시 확인하면서 과거 페이지를 이어받고, 주택 관련 상세·첨부를 배치당 15건씩 확보한다. 변경·정정·취소 표지를 보존하며 원천 고시 번호 `seq`로 중복을 구분한다.

**실제 요청 검증 중 시군구 전체 조건 오류를 발견해 수정했다.** 경기도를 `select2=4100000000`, `selSggCd=4100000000`으로 요청하면 해당 기간 19건만 반환됐으나, 공식 화면 JavaScript의 전체 시군구 값은 `41`이다. 수정한 요청의 첫 페이지에서 50건과 광주·부천·수원·안성시 고시가 확인됐다. 이전 완료 체크포인트는 무효화하고 범위 버전 2로 다시 조회한다. 이전 317건 목록을 수도권 전체 목록이라고 보고하지 않는다.

첨부 다운로드는 원천이 요구하는 CP949 인코딩을 유지했다. PDF/HWPX는 본문을 추출하고, 이미지·스캔 PDF·기존 HWP는 원문 확보와 텍스트 추출 상태를 나눈다. 복잡한 도면 PDF는 시간·메모리 한도를 적용해 수집 작업 전체가 멈추지 않게 한다. 다운로드한 원문은 추출 실패와 관계없이 보존한다. OCR·구형 HWP 본문 추출과 사업별 사건 연결은 남은 작업이다.

최종 수집 건수와 잔여 상세는 아래 고정 스냅샷 표를 따른다. 목록 추가 수집에 따라 상세 대기 건수는 증가할 수 있다.

## 6. 공식 발표와의 차이를 설명하는 기준

**같은 1~8월 수도권 착공 86,739호의 통계 일치와 관리 사업별 착공 73,991호는 서로 다른 검증이다.** 전자는 같은 기간·시도·통계 정의의 총계를 확보했다는 뜻이고, 후자는 정책에 연결한 사업을 중복 정리해 추적한 값이다. 두 수치를 빼서 전부 미수집 주택 수라고 할 수 없다.

10월 발표의 올해 착공 9.9만호 이상, 연말 21.8만~23.5만호 범위와 비교할 때도 발표 대상 사업·블록, 연간 실적/기착공 포함 여부, 시점·단위를 맞춰야 한다. 원문의 전체 대상 명단과 연말 착공 예정 사업의 인허가·일정 연결이 완성되지 않아, 현재 원장만으로 전망의 실현 가능성을 확정할 수 없다.

| 차이 원인 | 이번 확인 결과 | 설명 가능한 범위 |
| --- | --- | --- |
| 수집 시점 차이 | 원천 공표일·최근 확인일을 별도 보존 | 같은 사업·같은 수량 범위에서 사건일/공표일을 대조한 경우에만 시차로 설명 |
