# HOME 공식 발표 대비 정확도·최신성·연계 범위 점검

**기준일: 2026-10-16 · 제1차 주택공급 정례브리핑 대조**

**지금 우선할 조치는 최신 목표·관측값의 버전 등록과 이미 보유한 원천의 사업 연결이다. 직접 수치 대조가 가능한 3개 항목은 발표 표시 정밀도에서 모두 부합했다. 그러나 숫자가 있는 기준 행 47개 중 직접 비교한 항목이 3개이므로, 이를 전체 데이터 정확도 100%로 표현할 수는 없다.**

담당자가 승인한 값과 연결은 **정확한 확정값**으로 전제했다. 기존 승인값·일정은 변경하지 않았다. 이번에는 공식 발표와의 수치 일치, 기준시점·대상 범위 차이, 목표 변경, 관리 미연결을 나누어 측정했다.

## 3. 측정 기준과 계산식

### 비교할 때 맞춘 조건

1. **단위:** 호·건·사업장·년·회/월·지수를 구분한다.
2. **사건:** 착공·분양모집·입주 및 목표·실적·전망을 구분한다.
3. **기간:** 2026 신규 착공과 이전 연도 착공, 관측 종료월·분기를 맞춘다.
4. **범위:** 수도권 전체·선택 정책·공공주택·유형·지구·블록·전체/부분을 구분한다.
5. **목표 버전:** 최초 9·7과 후속 통합 목표를 혼용하지 않는다.
6. **사업 관계:** 동명 다른 사업을 제외하고, 미공표 블록은 후보로 구분한다.

```text
호 단위 차이 = HOME 값 − 공식 발표 대표값
상대 차이(%) = (HOME 값 − 발표 대표값) / 발표 대표값 × 100
발표 정밀도 일치율 = 표시 단위에서 부합한 비교쌍 / 직접 대조 가능한 비교쌍
숫자 비교 가능 범위 = 직접 비교한 숫자 행 / 숫자가 있는 기준 행(47)
관리 목록 대응률 = 해당 사업명 자료가 관리 목록에 있는 발표 행 / 사업 발표 행(16)
```

기준표의 여러 지표는 상위·하위 집계가 중첩된다. 47은 독립적인 주택 표본의 수가 아니라 **숫자가 제시된 기준 행의 수**다. 비교 가능 범위 6.38%를 수도권 주택 확보율·사업 정확도로 해석하지 않는다.

미확보를 0으로 바꾸지 않았다. 다른 기간·범위의 값을 정확도의 실패 또는 성공으로 넣지 않았다. 집계에는 이미 사업 범위를 묶은 `portfolio_cohorts`를 사용했다. 같은 묶음의 동일 단계 승인값은 한 번만 세고, 여러 원천 이벤트나 전체·부분 물량을 중복 가산하지 않았다.

### 적용 경계

- 창릉의 비교 사건은 S03·S04의 승인 착공일 2026-04-15·2026-03-31이다. 공식 ‘10월 둘째 주’의 정확 종료일이 없어도 이 사건은 경계에 걸리지 않는다.
- 인천계양 1,289호는 현재 관리된 부분 범위의 대응량이다. 공식 2,300호의 전체 블록을 검증한 값으로 간주하지 않아 정확도 분모에서 뺐다.
- 원천에 관련 사업명이 있다는 사실은 같은 발표 사건·물량을 확정했다는 뜻이 아니다.
- ‘미등록·미집계’는 이번에 확인한 관리 데이터·정책·프로그램·통계·조회 경로에서 해당 발표의 동일 범위 값을 찾지 못했다는 뜻이다.
- 승인된 값의 최초 생성 방식이나 메타데이터는 이번 정확도 감점 사유로 사용하지 않았다.

## 6. 기준표의 포함관계와 표현 점검

- 제공된 CSV 37개·16개 행과 XLSX 대응 시트를 셀 단위로 대조했고 동일했다.

- 4분기 3기 분양 예시 1,100 + 500 + 400 = 2,000은 해당 합계와 맞는다.

- 공공분양 10,000 + 임대 5,000 이상은 총 15,000 이상 모집이다. 세 값을 다시 더하지 않는다.

- ‘이상’인 99,000·1,500,000·5,000은 하한이다. 이후 정확 집계가 더 커도 곧바로 오류로 판단하지 않는다.
