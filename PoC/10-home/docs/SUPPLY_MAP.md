# HOME 과거 자료·공급량 지도 — 2026-10-03 KST

## 표시 수정

기존 지도는 올해 이후 연도만 선택할 수 있었고, 과거 보고서는 별도 이력 화면에만 표시했습니다. 이제 지도에서 **자료 연도 2018~2026**을 선택하고, 하단에서 **2018~2036**의 과거 자료·향후 목표를 전환합니다. 정책별·프로그램별·지역별 선택은 공급량 표, 지도 표식, 지구 물량과 지역 카드에 함께 적용합니다.

`수집 조회일`은 그때까지 확보한 데이터의 knowledge cutoff(`as_of_date`)이고, 지도 안 `자료 연도`는 분석 자료의 연도(`analysis_year`)입니다. 과거 자료를 볼 때 수집 조회일을 2018년으로 변경할 필요가 없습니다. 실제 저장 시각을 과거로 소급하지 않습니다.

과거 사업은 해당 연도 말 이전 보고서 중 원천 사업 식별자별 마지막 보고만 사용합니다. 이후 정책 귀속이나 관리자 목표를 과거 보고에 붙이지 않습니다. 현재 사업 레코드는 덮어쓰지 않습니다. 오래된 마지막 보고 상태는 이후 이행 확인을 뜻하지 않습니다.

## 공급량의 의미

| 표시 | 집계·주의사항 |
| --- | --- |
| 정책 선언목표 | 공식 발표 당시 목표, 지리 범위와 착공/공급 지표를 함께 표시. 인천 포함 수도권 목표를 서울·경기 배분량으로 바꾸거나 여러 정책 목표를 합산하지 않음 |
| 확보 사업계획 | 현재 조회 범위에서 확인된 계획·계약 물량의 **검토 합계**, 공식 정책 총량 아님 |
| 현재 공급량 | 시행기관이 한국토지주택공사이고 지역·지구·블록이 정확히 맞는 마지막 본 모집공고의 공급세대수. 사업별 1개 본 공고, 정책 귀속·사업 연결 `REVIEW`. 사전·잔여·추가·무순위·복수 블록 공고, 계획량 초과·복수 사업 연결은 제외 |
| 실입주·정책 실적 | 이행 실적이 미확보이므로 `null` / 미확보. 공정률×호수, 지난 예정일, 준공 예정으로 추정하지 않음 |
| 향후 1~10년 내 | 기준월 이후부터 해당 미래 연도 말까지 **누적 원천 예정량**. 모집·공급 / 입주 / 준공을 선택하며 서로 합치지 않음 |
| 관리자 목표 | 해당 단계의 관리자 입력량을 원천 예정과 별도 표시. 원천에 더해서 이중 합산하지 않음 |
| 청약시장 참고 | 주택관리번호별 마지막 모집공고의 공급세대수와 입주 예정. 민간 포함·정책 미연결 자료로 지역 참고 패널에서 조회하며 정책 실적에 합산하지 않음 |

같은 지역·정규화한 지구명·블록이 정확히 일치할 때만 원천 중복을 다룹니다. 목표 물량은 공급계획을 우선하고 공사 물량을 중복 가산하지 않습니다. 복수 현장 계약, 불명확한 블록, 한 블록의 복수 공급계획·공사 기록은 보수적으로 제외합니다. 예정과 관리자 목표도 각각 동일 규칙으로 중복을 처리합니다. 분류별 집계 전에 조회 범위 전체에서 집계 대상을 결정하여 정책·프로그램·지역 합계가 전체 검토 합계와 일치하도록 합니다.

본 모집공고에 입주 예정월이 있으면 지도 계산에서 해당 사업의 입주 예정을 보완합니다. 같은 사업의 연간 계획과 공고 입주 예정은 이중 합산하지 않으며, 기존 입주 예정이 없는 경우 또는 원천 기준일 이후 발표된 공고를 반영합니다. 이전 공고로 더 최근의 연간 입주 계획을 덮어쓰지 않습니다. 공고량은 해당 공고에서 모집한 물량이며 전체 단지 입주 실적이 아닙니다. 정책 발표 이전 공고도 현재 검토 사업의 원천 현황에 포함될 수 있으므로 정책 목표 달성량으로 해석하지 않습니다. 사업 상세에서 연결한 모집공고의 날짜·명칭·세대수·수집 근거를 확인할 수 있습니다. 조회 계산만 수행하며 원래 notice의 `UNMAPPED` 상태나 정책 mapping을 자동 확정·수정하지 않습니다.

사업 목록은 원천 후보 전체를 유지하고 물량 표에서 집계 건수·제외 건수를 표시합니다. 원천 간 동일 사업의 담당자 확정과 공급묶음 모델은 후속 범위입니다. 일정·물량 미확보는 0호가 아닙니다. 미래 연도에 같은 수가 반복되는 것은 현재 확보된 일정의 누적 합이며 추가 공급이 없다는 예측이 아닙니다. 월 정밀도 일정 중 기준월, 당해연도 관리자 목표는 남은 기간의 물량을 확정할 수 없어 미래 합계에서 제외합니다.
