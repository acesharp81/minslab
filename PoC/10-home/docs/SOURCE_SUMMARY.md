# 출처와 수집현황 · 수집량 및 유형별 통계

2026-10-16. 기존 상단 제목 공간에 수집 출처·추출 데이터·연결 데이터를 표시합니다. 현재량은 큰 글씨, 오늘 수집량은 아래 작은 회색 글씨입니다. ‘소스 유형별 자세히 보기’에서 유형별 출처·행·컬럼·추출량·오늘 수집량·연결량을 조회합니다.

## 집계 정의

- 현재 출처: 등록 수집원 중 최신 저장 레코드가 있는 고유 출처 수. 등록만 되고 데이터가 없는 원천은 제외합니다.
- 현재 추출량: **출처·레코드 유형별 최신 행 수 × 해당 표의 고유 컬럼 수**를 합산합니다. 컬럼은 저장 payload의 최상위 필드입니다. 빈칸도 포함하고 중첩 객체·배열은 1컬럼으로 셉니다. 이전 리비전은 제외합니다. 서로 다른 자료 구조를 하나의 행×컬럼으로 곱하지 않습니다.
- 연결량: 사업 데이터로 정리되었거나 저장된 사업·근거 연결에서 참조하는 고유 원천 레코드 수입니다. 같은 원천이 여러 사업·단계에 연결되어도 1건입니다. 선택되지 않은 후보 목록과 해제·거절 링크는 제외합니다. 일시적인 화면 조회·지역 코드 조인은 연결량으로 세지 않습니다.
- 오늘: Asia/Seoul 당일 00:00 이후 완료한 성공 수집 배치의 `entity_ids`를 기준으로 합니다. 내용이 같아 새 리비전이 생기지 않은 재수집도 포함합니다. 같은 날 같은 레코드의 반복 수집은 1행입니다. 실패·미래 완료 배치는 제외합니다.
- 오늘 연결량: 오늘 수집된 원천 중 현재 사업 연결에 사용되는 고유 레코드 수입니다. 신규 연결 증감량과 다릅니다.

## 소스 유형

출처당 한 유형을 부여하므로 유형 합계와 상단 총계가 일치합니다. 모집공고·보도자료·뉴스 성격을 먼저 구분하고 나머지는 API 연계 여부, 공식 통계·파일·공간정보·문서·웹으로 분류합니다. API로 수집한 모집공고는 ‘분양·임대 입주자 모집공고’에만 포함합니다. 유형명 아래에는 어떤 자료에서 무엇을 가져오는지 설명하고, ‘실제 수집 자료 N개 보기’를 펼치면 현재 집계에 포함된 출처명과 원문 링크를 확인할 수 있습니다. 뉴스 등 현재 수집 자료가 없는 유형도 0건으로 표시합니다. 개별 원천 행에도 유형 표지가 표시됩니다.

## API·성능·갱신

`GET /poc/home/api/source-summary`는 `current`, `today`, `types`, `groups`, `definitions`, 한국시간 기준일·생성시각을 반환합니다. `GET /api/sources`는 각 원천에 `data_type`, `data_type_label`, `access_method`를 추가합니다. 통계는 전역 수집 원장 기준이며 화면의 사업·지역·과거 기준일 필터와 별도입니다.

PostgreSQL은 일관된 읽기 전용 스냅샷에서 집계합니다. 대용량 JSON의 컬럼 구조는 DB 안에서 계산하고 `data/runtime/source-summary-schemas.json`에 출처별 캐시를 저장합니다. 저장된 최신 행 수·리비전 시각 이후 새 원천 리비전을 먼저 확인하므로 변경된 출처만 다시 집계합니다. 같은 원천은 재파싱하지 않습니다. DB를 백업본으로 복원하거나 원장을 직접 수정했다면 이 캐시 파일을 삭제해 재생성합니다. 캐시는 삭제해도 다음 조회에서 재생성하며 수집 원장·연결을 수정하지 않습니다. API 응답은 기존 DB 변경 감지 캐시와 날짜별 키를 사용하여 수집·연결 변경과 자정 경계를 반영합니다.

프런트는 원천 목록과 통계를 병렬로 조회합니다. 통계 대기 중에도 원천 목록을 사용할 수 있으며 조회 실패는 0으로 대신하지 않습니다. 다른 화면에서는 요약과 상세를 숨깁니다.
