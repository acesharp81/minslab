기존 성공 배치의 완료 법정동을 건너뛰고, 신규 정책 대상지 우선으로 인허가·대장 각각 기본 20개 동씩 전 페이지를 수집한다. 배치마다 전량 검증 후 하나의 트랜잭션으로 저장한다. 빈 응답도 검증된 0건 조회로 범위 진행에 기록하며 공급 실적 0호로 바꾸지 않는다. 실패·호출량 제한·원천 건수 변경이면 중단하고 마지막 성공 배치를 보존한다. 재실행은 미완료 동부터 계속한다. 동별 10,000건 인허가 안전 한도를 넘는 경우 범위 분할 검토가 필요하다. 신규 키 신청보다 승인된 서비스의 호출 한도와 현재 응답을 먼저 확인한다. 전체 코드를 확보했다는 이유로 전체 정책 사업을 확보했다고 표시하지 않는다.

대량 적재에도 홈페이지 목록은 DB에서 페이지별로 조회하고, 개별 상세와 지도는 필요한 식별자만 읽는다. CSV와 과거 연도 집계는 순차 처리하여 전체 대장을 동시에 메모리에 올리지 않는다.

## 공개 원천에서 아직 확보하지 못한 과거 자료

LH 현행 공사현황 게시물은 2025~2026년 기준일만 제공한다. 이전 검색 결과에 남은 게시물 번호 724077은 현재 안내 페이지로 바뀌었으며, 남아 있는 첨부 PDF는 실제 내용이 **2025년 3월**이다. 이를 2018~2024년 공정 이력으로 처리하지 않았다. 이 게시물에 없는 과거 공정률을 모두 미공개로 간주했던 판단을 수정했다. LH 청약플러스 상세 이력 및 리츠 투자보고서에 별도 공개 원본이 있으며, 아래 수집기로 실제 확보했다. 그 밖의 누락 연도·블록과 계획 변경 이력은 추가 원본이 필요하다.

기관 자료 요청 시 필요한 범위는 다음과 같다. 외부 요청을 대신 발송하지 않았다.

- 필수 컬럼: 기관 사업코드, 지구명, 블록명, 시군구·법정동·지번, 계획 세대수, 기준 연월, 계획/실제 착공·준공·분양·입주일, 당시 계획 공정률/실제 공정률, 변경 사유·문서 번호.
- 요청 방식: 기관 사전정보공표의 누락 연도 자료 제공 또는 정보공개포털의 공개 가능한 원본 파일 제공 요청. 개인정보 명단은 제외.

단지정보 CSV 전국 6,217행을 조회하여 서울·경기 위치가 확인되는 1,815행을 저장했다. 비주거·집계성 자료 435행, 위치 미확인 또는 범위 밖 자료 3,967행은 제외했다. 본부명이나 서울시청·경기도청 대체 주소로 개별 사업 위치를 추정하지 않는다. 1,815행 중 **2018~2024년 입주지정 시작일 또는 준공일이 있는 자료는 355행**이다. 자료 연도 필터는 입주지정 시작일(없으면 준공일)을 사용하고, 일정이 없는 자료는 공개본 날짜로 조회한다. 예정일도 포함되므로 단지 일정이 실제 실입주량·당시 공정률을 입증하지 않는다. 원천 세대수 0은 검증 필요로 표시한다.

홈페이지 → **API 테스트 데이터**에서 위 세 유형과 자료 연도를 선택할 수 있다. 상세 창에서 지구·블록·원본 링크·세대수/공고 호수·예정일/단지 일정·공개본 기준·원본 SHA-256을 확인한다. 동일 조건의 CSV는 `district_name`, `block`, `total_units`, `move_in_plan_month`, `dates`를 포함한다. 데이터 검증과 API 연결 안내에도 실제 배치 상태 및 누락 범위를 표시한다. 승인 전 정책 공급 실적에 단순 합산하지 않는다.

현재 입주계획 페이지에는 2022~2026 첨부만 있고 2018~2021 파일은 미확보다. 공공분양 공급현황 XLSX에는 2018~2019가 없다. 과거 공정률은 아래 추가 수집으로 일부 확보했다. 2019·2022년 및 공개 이력 밖 블록의 공정률은 여전히 미확보다. 기존 통계·공고, 이번 과거 일정 확보와 구분하며 자료가 없다는 이유로 실적 0으로 표시하지 않는다. 정보공개 요청이나 기관에 메시지를 보내지는 않았다.

## 2026-10-03 실제 공정률 확보 및 화면 반영

기존 `lh_history`는 특정 게시물의 날짜가 있는 DOCX만 수집했다. 이를 근거로 2018~2024년 실제 공정률 전체를 미확보로 안내했던 범위 판단을 보완했다. 공식 [LH 공사진행현황](https://apply.lh.or.kr/lhapply/land/cwsttList.do?mi=1352)의 전국 168개 블록 2개 목록 페이지를 전부 점검하고, 서울·경기 93개 블록의 공개 상세 JSON 이력을 크롤링했다. `currPage`만 바꾸면 같은 페이지가 반복되므로 원본 페이징 폼의 `minSn`, `maxSn`, `prevListCo`, `searchPage`까지 사용하고 전체 건수·페이지 행수·사업코드 중복을 검증한다.

- `lh_progress`: 2020~2026 실제 공정률 관측 **550건**. 연도별 2020 12건, 2021 6건, 2023 6건, 2024 35건, 2025 140건, 2026 351건. 관측은 동일 블록의 날짜별 기록이며 주택 호수·서로 다른 사업 수가 아니다. 93개 블록 중 66개에 수집기간 내 이력이 있고, 14개는 공개 날짜 이력이 없으며 13개는 이력이 2018년 이전에 끝난다.
- 기존 주택 건축공사와 같은 지구·블록이면 별도 관측을 연결하고 원래 사업·목표·담당자 승인 상태를 덮어쓰지 않는다. 9개 신규 진행 사업 후보를 추가했으며 자동 매칭은 기존 승인 흐름으로 이어진다. 이전에 이미 완료된 재고를 신규 정책 목표로 추가하지 않는다.
- `lh_reit_progress`: [NHF 제6호 2018년 공식 투자보고서](https://www.lh.or.kr/boardDownload.es?bid=0028&list_no=651950&seq=1) 20쪽의 하남미사 A24 **2018-12-31 기준 100%**를 추가 확보했다. 보고기간 말과 제출일 2019-04-01, 준공 예정일을 구분한다. 한 리츠의 한 공개본이며 전체 리츠 확보를 의미하지 않는다.
- 이번 추가 관측은 합계 **551건**, 이 중 2018~2024년 **60건**. 기존 2025~2026 DOCX 이력 641건과 합쳐 홈페이지 과거 공사 이력은 1,192건이다. 이후 갱신으로 달라질 수 있으므로 화면의 실제 배치 상태를 기준으로 한다.

위례 A2-7은 2024년 사진들을 2026-06-29에 일괄 등록했다. 동일 등록일에 여러 관측이 있고 원본 파일명에 4자리 연도와 기준월이 명시된 경우 해당 월을 월 정밀도로 저장한다(`date_precision=MONTH`, 원본 월 `report_period`, 원 등록일 `source_registration_date`). `report_date`의 월초 값은 월 정렬·연도 필터용이며 실제 관측일을 1일로 확정한 것이 아니다. 화면에는 월만 표시하고 날짜 근거를 명시한다. 일반 관측의 등록일은 촬영일과 구분하여 안내하며, 파일명의 임의 숫자나 오타를 날짜로 추정하지 않는다. 현재 단지 세대수를 과거 관측의 계획 세대수로 복사하지 않는다.

하도급 계약현황 PDF도 직접 대조했다. 일부 검색 결과가 공정률처럼 보였지만 원본 헤더는 **낙찰율(%)**이었다. 이를 실제 공정률로 적재하지 않았다. 후분양 공정률 기준과 예정 준공일도 실제 공정률이나 실입주량으로 환산하지 않는다.

조회: 홈페이지 **정책 흐름·과거 자료 → 자료연도 → 실제 공정률·과거 공사 이력**. 원본 링크, 당시 공정률, 블록, 날짜 근거를 확인하고 **공정률 CSV**로 같은 조회 조건을 내려받는다. 정책별 시계열은 연결된 관측을 계획 막대 아래 실제 공정률로 표시하고, 사업 조회·지도 상세는 별도 공정률 기준일을 표시한다. 수집 원천·데이터 검증·API 연결 안내에도 배치 상태를 반영했다.

API 키는 추가로 필요하지 않다. `lh_progress`와 `lh_reit_progress`는 앱 시작 시 및 24시간 주기로 공개 원본을 갱신한다. 원본 SHA-256, 수집시각, 관측 식별자 및 변경 판본을 보존한다. **2019·2022년 및 SH·GH 실제 공정률 전체는 이번 자료로 확보되지 않았다.** 빈 연도에 이전 값이나 0%를 채우지 않는다. 조회 목록 전체 확보와 서울·경기 정책 사업 전체 확보는 별개다.

검증: 백엔드 162개 테스트 통과. 공개 운영 화면에서 2018년 100%, 2024년 양주회천 38.22%, 위례 기준월/등록일 구분, 정책 시계열 연결, CSV, 모바일 가로 넘침 및 JavaScript 오류를 확인했다. `scripts/check-lh-progress.cjs`로 재검증할 수 있다.
