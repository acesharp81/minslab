# HOME 운영 인계·남은 작업 — 2026-10-10

## 사용자가 지금 할 일

1. **추가 API 키 신청·등록은 없음.** 신청한 [주택인허가정보](https://www.data.go.kr/data/15136560/openapi.do)의 서비스키는 기존 `POC10_BUILDING_HUB_SERVICE_KEY`로 재사용해 동별·대지위치 실호출을 검증했다. 설정값은 `PoC/10-home/.env`에 두고 `.env.example`에는 넣지 않는다. 다른 기존 키의 변수·신청처는 [`HOME_API_CONNECTIONS_20261010.md`](HOME_API_CONNECTIONS_20261010.md)에 있다.
2. **담당자 검토:** 홈페이지 `공급 현황 → 데이터 검증 → 실사업 정체성·공식 계획 고시`에서 LH 준공예정 연결 제안 105건의 동일 사업 여부를 확인한다. 특히 호수 차이 58건은 먼저 원문/사업번호를 대조한다. 확정·변경·해제할 때 확인 근거와 공식 HTTPS 원문 URL을 입력한다. 기존 `정책–프로그램–사업 연결`의 정책–프로그램 16건과 프로그램–사업 266건도 별도로 검토한다. 제안 상태의 자료는 확정 실적으로 승격되지 않는다.
3. **원고시 자료 제공 가능 시:** 서울/경기 공식 최초 지정·변경·해제 고시 원문 또는 공고번호 목록을 제공하면 계획의 사건 이력과 사업 귀속을 확대할 수 있다. 현재는 서울 공덕1, 경기 고양창릉 변경 고시 각 1건만 검증했다. 제공은 선택사항이며, 확보되지 않은 사건은 `미확보`로 유지한다.

## 시스템 측 후속 작업

- 건축HUB 상세를 2,629개 대상 법정동으로 이어받아 수집하고, endpoint×법정동 조회 완결성과 사업 모집단 완결성을 따로 표시한다. 현재 운영 기본값은 하루 8개 법정동이며 `POC10_BUILDING_DETAIL_DONGS_PER_BATCH`로 1~8개 설정 가능하다.
- 미연계 LH 준공예정 76건의 공식 사업번호·주소·위치 교차근거를 확보한다. 두 건의 계획 고시는 아직 사업에 연결되지 않았다.
- 정책 공식 목표/승인 기준선, 사업별 중복 없는 공급묶음, 연도·단계별 계획과 실제 측정값을 별도 모델로 만든 다음 기존 지도/시계열과 수치·출처를 shadow 비교한다. 원천 근거가 없는 물량은 생성하지 않는다.
- 원천 별 수집 성공, 최신성, 누락/변경 판본과 원고시 후속 변경을 주기적으로 감시한다. 새 키나 이용 조건이 실제 필요하다고 확인되면 그때 신청 링크·변수·검증법을 추가한다.

최신 배포 및 검증 숫자는 [`HOME_IMPLEMENTATION_STATUS_20261010.md`](HOME_IMPLEMENTATION_STATUS_20261010.md), 장기 단계와 집계 계약은 [`HOME_FINAL_APPLICATION_PLAN.md`](HOME_FINAL_APPLICATION_PLAN.md)를 참조한다.
