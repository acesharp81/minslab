# 10월 공식 발표의 8개 착공 사업과 HOME 심층 대조 보고서

> **최종 처리 변경:** 비공식 원문 확인분을 담당자 확인 완료로 채택하여5개 블록2,853호를 착공에 반영했다. 현재 누적79,884호·연말 계획92,574호. 아래의 후보·미가산 서술은 변경 전 검토 이력이다. [최종 확인 완료 내역](HOME_NONOFFICIAL_CONFIRMATION_APPLIED_20261020.md)과 [최종 대조표](HOME_THREE_NEWTOWN_FINAL_COMPARISON_20261020.md)를 사용한다.


검증·반영 기준일: 2026-10-20. 수량 단위: 호.

## 1. 검증 결론

기존 비교표의 차이를 모두 ‘수집 시점 차이’로 설명할 수는 없다. 이번 재검증에서는 **별도 공식 수집 경로의 누락, 비교 대상 블록의 차이, 전체 건설호수와 분양 공고 호수의 차이, 계획과 실제 착공의 구분, 정부 서면과 발언의 상충**을 확인했다.

서울 정비사업 3곳은 10월 브리핑과 별개의 지자체 공식 자료로 사업명·착공 상태·물량을 대조했다. 신림2와 흑석11은 실제 착공일까지 추가 확보하여 기존 사업에 근거를 연결했다. 중계본동은 기착공 상태와 3,178호를 독립 확인했으나 정확한 착공일은 확보하지 못했다.

신도시 일부는 이전 표가 공식 발표와 다른 블록을 비교했을 가능성이 크다. 민간참여 사업의 상반기 착공 보도와 공식 공모 계획을 교차 대조하면 왕숙2 A6·A7, 대장 A9, 계양 A16·A18이 추가 비교 후보로 드러난다. **해당 보도 확인은 담당자 검토 이력으로 기록했으며, 공식 실제 착공 원문과 10월 발표의 구성 명세까지 확인한 것으로 처리하지 않았다.**

따라서 이번 검증은 기존 수량의 근거를 강화하고 비교표의 잘못된 설명을 바로잡은 작업이다. HOME 정책 관리 누적 착공은 **77,031호**, 연말 계획 기준 누적 예상량은 **92,574호**로 유지된다. 비공식 확인 후보와 공식 계획만 있는 후보를 실적에 일괄 가산하지 않았다.

## 2. 비교 기준과 기록 방식

공식 수치는 [10월 공식 별첨 PDF 4쪽](https://www.fsc.go.kr/comm/getFile?srvcId=BBSTY1&upperNo=87948&fileTy=ATTACH&fileNo=3)과 [공식 브리핑 발언](https://www.korea.kr/briefing/policyBriefingView.do?newsId=156785506)의 개략량이다. 정확한 블록별 명세와 동일한 모집단이라는 전제가 있어야 HOME와 엄밀한 차감을 할 수 있다.

HOME 정책 누적에는 정책에 연결된 과거 착공도 포함된다. 반면 공식 발표의 ‘올해 착공’ 비교에는 해당 연도·기간과 인정 기준을 적용해야 한다. 과거 착공을 누적 원장에서 삭제할 이유는 없지만, 이를 공식 당해 실적과 같은 열에서 비교하면 오해가 생긴다.

각 근거는 다음처럼 기록한다.

| 기록 | 의미 | 이 기록만으로 주장할 수 없는 것 |
| --- | --- | --- |
| 담당자 확인 - 공식 자료: 기관·문서·URL | 담당자 대행이 공식 원문과 기존 사업을 대조 | 모든 공식 통계의 동일 모집단에 포함된다는 주장 |
| **담당자 확인 - 비공식 자료: 매체·일자·기사·URL** | 비공식 출처의 사업·블록·물량을 담당자 대행이 확인 | 정부 원장 대조 완료, 정확한 사건일 확보, 공식 발표 구성 확정 |
| 공식 계획자료 확인 | 계획에 사업·호수·예정 시기가 기재 | 실제 착공 완료 |
| 기착공 관측일 확인 | 그 날짜까지 착공 상태라는 근거 확보 | 관측·발표일이 실제 착공일이라는 주장 |

‘담당자 확인’은 이번 사용자 지시에 따른 대행 검토를 뜻한다. 시행기관 담당자에게 직접 확인받았다는 의미가 아니다. 비공식 여부는 매체의 정보 정확성을 단정하는 등급이 아니라 **출처의 성격**을 표시한다.

이전 비공식 보조 근거인 연남동 설계사 소개도 같은 형식으로 정비했다. 전체 내역과 미검증 검색 후보를 구별한 기준은 [비공식 근거 표시 정비 보고서](HOME_NONOFFICIAL_REVIEW_LABELS_20261020.md)에 정리했다.

### 수집상 원인에 대한 정정

기존 서울 정비사업 수집 경로인 정보몽땅의 해당 보유 자료는 철거 등 이전 상태에 머물러 있었다. 별도 구청 사업 페이지, 서울시 착공 표, 보도자료 본문의 사업별 착공 정보는 추가로 수집할 수 있었다. 따라서 이번 3건을 두고 ‘공개 자료가 없어서 날짜를 얻지 못했다’고 설명하면 부정확하다. **추가 공식 경로를 확보하여 보완한 수집·연계 공백**으로 기록한다.

A3 1,100호라는 숫자가 공식 개략량과 같다는 이유만으로 발표의 실제 착공 대상이라고 확정할 수는 없다.

### 인천계양: A6 누락 설명 정정, A17 임대154호 범위 문제

이전 비교표의 ‘A17 463호만 직접 확인’은 A6 663호의 연결된 공정 근거를 빠뜨린 설명이었다. A6는 기존 승인 사업에 원천이 연결되어 있으며, 공정 관측으로 착공 상태를 뒷받침한다. 관리 추정일8월29일은 정확한 착공일로 표현하지 않는다.

[LH 인천계양 A17 공식 모집공고](https://apply.lh.or.kr/lhapply/apply/wt/wrtanc/selectWrtancInfo.do?aisTpCd=39&ccrCnntSysDsCd=02&mi=1027&panId=0000061179&uppAisTpCd=39)는 전체463호 중 공공분양309호와 향후 행복주택154호를 구분한다. 현재 선택한 정책 사업은309호이므로 전체 공사463호와 집계 범위가 다르다.

| 관점 | 계산 | 해석 |
| --- | ---: | --- |
| 기존 두 블록의 전체 공사량 | A17 463 + A6 663 = **1,126** | 원천 전체블록 규모 대조 |
| 두 정책 사업의 현재 채택량 | A17 309 + A6 663 = **972** | 위1,126과 같은 숫자가 아님 |
| A17 유형 차이 | 463 − 309 = **154** | 공식 원문에 존재하는 임대 물량. 위치·사업명 미상 때문이 아닌 집계 범위 검토 항목 |
| 추가 비공식 후보 | A16 434 + A18 782 = **1,216** | 실제 착공 공식 원문 미확보 |
| 조건부 비교 구성 | 1,126 + 1,216 = **2,342** | 약2,300의 가능한 구성 설명. **확정 실적·현재 HOME 합계 아님** |

A17의463호와309호를 별도 사업량으로 함께 더하면 중복이다. 전체 공사463을 대표 사업으로 관리할지,309와154를 겹치지 않게 관리할지 정한 후 근거·단계별 적용 범위를 일치시켜야 한다. 이번에는 승인된309를 자동으로463으로 바꾸지 않았다.

## 6. 원문 파일까지 확인한 수집 한계

[LH 건설공사 현황 파일](https://www.lh.or.kr/boardDownload.es?bid=0007&list_no=654682&seq=14)을 다시 내려받아 파일 내부 형식과 건축 행을 검사했다. 이번 수집 판본은2026-07-01 기준 **DOCX**다. 확장자 추정이나 과거 문서의 ‘PDF’ 표기에 의존하지 않고 ZIP 내부 `word/document.xml`을 읽어 대상 지구51개 행을 추출했다.

해당 판본의 건축·호수 행에는 왕숙2 A6·A7, 대장 A9, 계양 A16·A18이 없었다. 따라서 이 파일에 관한 한 단순히 파서가 존재하는5개 행을 누락했다고 설명할 수 없다. 다만 이 사실만으로 다른 LH 공개 경로에도 실제 착공 자료가 없다고 주장할 수는 없다.

현재 LH 공정 수집기는 공개 목록을 탐색한다. 이번5개 블록의 누락 원인을 ‘등록 사업만 조회하도록 잘못 제한했다’고 단정할 근거는 없다. 별도 민간참여 시행·착공 자료와 GH 경로의 보완이 필요한 상태다.
