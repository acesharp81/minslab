# 정책 기원부터 누적 수집 — 2026-10-02

수집 기간을 모니터링 정책에 연결된 사업의 기원부터 현재까지로 조정했습니다. 최초 연도는 공식 자료에서 확인된 **3기 신도시 2018년**, **도심 공공주택 복합사업 2021년**이며, 공통 수집 시작은 **2018-01-01**입니다. 현재 관리하는 9·7/1·29/8·13 정책의 발표일은 그대로 유지합니다. 기존 사업의 기원과 최신 정책 채택 시점을 합치거나 과거 정책이 현재 유효하다고 확정하지 않습니다.

근거: [3기 신도시 최초 계획 발표(2018-12-19)](https://www.korea.kr/news/policyNewsView.do?newsId=148856563), [창릉·대장 추가 발표(2019-05-07)](https://www.korea.kr/news/policyNewsView.do?newsId=148860598), [3080+ 도입 방안(2021-02-04)](https://www.korea.kr/news/policyNewsView.do?newsId=148883564), [도심복합 첫 후보지(2021-03-31)](https://www.korea.kr/news/policyNewsView.do?newsId=148885699), [9·7 후속 도심복합 시즌2(2025-10-21)](https://www.korea.kr/news/policyNewsView.do?newsId=148952578).

## 조정한 수집

- 청약공고: 최근 3년 제한을 제거하고 2018년부터 서울·경기 × 연도별로 전체 페이지를 수집합니다. 각 연도·지역의 `matchCount`, 페이지 수·중복 식별자·공고 날짜를 검증합니다. 결과 없는 연도는 `NO_RESULTS_UNVERIFIED`로 남기며 공급 실적 0으로 단정하지 않습니다.
- 인허가: 기존 법정동별 500건 제한을 해제하고 개포·고덕·진관·이의·다산·덕풍동의 전체 조회 페이지를 수집합니다. 법정동당 안전 상한은 10,000건이며 초과 시 분할 수집을 요구합니다. 원천의 과거 허가·착공·생성일을 보존합니다. 시작 이전 자료도 지우지 않습니다.
- 과거 정책: 기원·후속조치 공식 자료 5건을 `policy_event`로 보관합니다. 현재 정책 3건과 합쳐 연도별 흐름 8건을 조회합니다. 최초 발표일·제도 도입 연도를 법적 시행일로 바꾸지 않습니다.
- LH 공사: 공개 DOCX 첨부의 모든 확보 기준일을 `project_report`로 누적합니다. 현재 2025-01-01~2026-07-01의 격월 보고서 10개, 서울·경기 주택 건축공사 641행을 보관했습니다. 기준일별 자료는 같은 사업이 반복될 수 있으며 행 수를 고유 사업 수로 합산하지 않습니다.

과거 DOCX에 등장한 `1,424.00` 같은 정수형 소수 표기는 1,424로 읽습니다. 소수부가 있는 호수는 반올림하지 않고 검토 오류로 처리합니다. 조회 결과가 없는 연도의 짧은 정상 JSON도 JSON schema를 확인한 뒤 처리합니다.

## 홈페이지 조회와 날짜

[HOME 정책 흐름·과거 자료](https://www.minslab.kr/poc/home/#history)에서 2018년부터 자료연도를 선택하고 정책 흐름, 당시 공정률·상태, 기준일별 보고서와 원천 근거를 확인합니다. 보고서는 페이지당 100행으로 조회하며 지역·검색을 연동합니다. 정책 필터는 연결 검토가 가능한 현재 사업의 과거 보고서에 적용하고, 정책에 연결되지 않은 API 표본은 해당 정책 수치에 합산하지 않습니다.

`자료연도`는 원천 발표·허가·보고서 날짜이고, 기존 `기준일`은 그날까지 실제 저장한 지식 상태입니다. 오늘 수집한 2018년 문서를 2018년에 수집한 것처럼 소급하지 않습니다. `recorded_at`은 실제 저장 시각으로 남깁니다. 과거 보고서를 적재해도 현재 사업 150건의 상태·공정률과 목표 revision을 덮어쓰지 않습니다. 기존 지도 30개 지구·106개 위치 연결은 유지합니다.

## 운영

```bash
sudo docker exec poc10-home-api python -m scripts.collect --history
sudo docker exec poc10-home-api python -m scripts.collect --samples
```

공식 최신 원천 7개와 과거 원천 2개는 시작 시·24시간마다 갱신하고, API는 기존 관리자 요청 수집을 유지합니다. 같은 날짜·내용의 과거 보고서는 새 revision을 만들지 않으며 신규 첨부 기준일은 누적합니다. 추가 API 키는 필요하지 않습니다.

`POC10_NOTICE_START_DATE=2018-01-01`, `POC10_PERMIT_DISTRICT_LIMIT=0`을 HOME 전용 설정에 반영했습니다. 공고 시작일이 정책 기원보다 늦게 설정되어도 기원 연도의 자료를 제외하지 않습니다. 원천 응답은 키 제거·SHA-256 저장을 유지합니다.
