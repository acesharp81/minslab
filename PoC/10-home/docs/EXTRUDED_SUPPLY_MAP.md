# 확대 단계별 입체 공급 막대와 물량 CSV

후속 변경: 정책 입체 그래프는 우측 정책 탭 패널로 이동했습니다. 지도 자체는 시군구 원그래프와 블록 가로 막대로 전환하고, 미래 전망은 현재 확인량에 누적합니다. 최신 설계·검증은 [POLICY_MAP_MONITOR.md](POLICY_MAP_MONITOR.md)를 확인하세요. 아래는 최초 입체 지도 구현 당시의 기록입니다.

2026-10-03 사용자 요청과 신규 물량 CSV 승인에 따라 HOME에 반영합니다. 기존 VWorld 키와 Leaflet을 사용하며 추가 API 키는 필요 없습니다. 막대는 입체 SVG로 표시합니다.

## 지도 구성

| 확대 수준 | 표시 | 위치의 의미 |
| --- | --- | --- |
| 7~9 | 정책 요약, 프로그램 선택 시 프로그램 요약 | 지도 고정 카드, 사업 좌표가 아님 |
| 10~12 | 서울·경기 시도별 막대 | 공식 지구 대표점에 연결한 시도 집계 |
| 13~18 | 현재 지도 범위의 지구 내 블록별 막대 | 지구 대표위치, 개별 블록 좌표 미확보 명시 |

확대·축소 시 자동 전환하며 정책/시도/블록 버튼으로도 이동합니다. 정책·프로그램·지역 선택과 자료 연도·기간·일정 상태 필터를 함께 적용합니다. 물량 상세 표는 접어서 지도를 우선 표시합니다. 지연/이행 확인 목록에서 사업을 선택하면 위치가 확보된 지구의 블록 화면과 근거 상세로 이동합니다. 같은 지구의 여러 블록은 스크롤 가능한 카드에 각각 표시합니다.

## 막대의 기준

- 전체 높이 = **각 단위에서 확보한 전체 사업계획량의 100%**. 절대 물량은 숫자로 비교합니다. 정책 발표 목표는 범위/지표와 함께 별도로 표시하며 수도권 목표를 서울·경기 사업계획량의 분모로 쓰지 않습니다.
- 파란 채움 = 모집·공급 기준의 동일 계획 모집단에 연결된 LH 본 모집공고량. 비율은 **공고 확인 비율의 하한·연결 검토**이며 실제 보급률이 아닙니다. 입주/준공 기준에서는 실제 이행 자료가 없어 채움·비율을 미확보로 표시합니다.
- 옅은 부분 = 남은 계획과 실적 미확인 부분. 공고나 실제 이행 자료가 없다고 0호로 표시하지 않습니다.
- 금색 선 = 조회 연도의 기준월 **이전** 원천 예정월까지 누적 목표. 원천 예정월에 일자가 없으므로 기준월은 경과 판단에서 제외합니다. 연간 관리자 목표는 월별 배분하지 않고 별도로 표시합니다. `cumulative_goal_units`는 확보 일정의 과거 연도도 포함한 누적이며 CSV에 제공합니다.
- +1/+2/+3년 눈금 = 선택한 모집·입주·준공 기준의 각 미래 연도 말까지 누적 예정량. **현재 공고량에 더한 예상 실적이 아닙니다.** 원천과 관리자 목표도 합산하지 않습니다. 같은 값의 라벨을 벌려 표시합니다. 계획량을 넘는 예정량은 숫자를 보존하고 눈금은 상단에 표시하며 범위 확인 문구를 붙입니다.
- 계획량 미확보 공고는 현재 공고량에 포함하지만 비율에서 제외합니다. 현재 검토 공고 18,656호 중 792호가 해당하여 비율 대상 공고는 17,864호입니다. 확보 계획 71,416호 대비 확인 비율은 25.01%이며 실제 보급률은 미확보입니다.
- 전체 계획, 원천 일정, 관리자 목표 각각의 전역 중복 제외 결정을 모든 분류·블록 집계에 유지합니다. 원천 간 물량 범위 차이도 숨기지 않습니다.

## 지연 판정

모집·공급에서 일자까지 확보한 원천 계획이 공고 전에 설정되어 있고 예정월보다 실제 본 모집공고월이 늦으면 **공고월 지연 확인 · 연결 검토**로 표시합니다. 연간 계획은 기준일이 연도까지만 확인되므로 계획월보다 공고월이 늦어도 **지연 후보 · 계획 발표 이력 확인**으로 표시합니다. 현재 성남복정2 A1과 시흥거모 A5는 2026년 계획월 7월 대비 본 공고월 8월로 한 달 차이의 후보입니다. 여러 공급 회차에는 한 본 공고를 임의 배정하지 않습니다. 이전 공고가 더 최근 연간 계획에 대응한다고 확정하지 않습니다.

예정월이 지났으나 대응 실제 이행을 확인하지 못한 사업은 **이행 확인 필요**로 표시합니다. 준공·입주는 실제 이행 자료가 없으므로 예정일 경과만으로 확정 지연을 만들지 않습니다. 공사 보고서 기준일과 수집일도 구분합니다.

## CSV

`GET /poc/home/api/map/supply.csv`는 공개 읽기 전용입니다. 기존 조회 필터와 `analysis_year`, `measure`, `horizon`, `schedule_status`, `group_by=all|policy|program|region`, `group_id`를 지원합니다. 결과에 없는 그룹과 미래 자료 연도는 422로 거부합니다.

화면의 **물량 CSV**는 선택 분류의 요약과 그에 속한 블록 상세를 내보냅니다. 그룹 선택 시 전역 중복 제외 결정을 유지하면서 해당 그룹의 수치·사업 ID·원문 근거만 내보냅니다. 과거 연도에서도 다운로드할 수 있습니다. 기존 현재 사업 목표 CSV는 별도로 제공합니다.

UTF-8 BOM, 다운로드 파일명, 미확보 빈 칸 유지, 수식 접두문자 이스케이프를 적용합니다. 목표·공고·실보급 미확보·확인 비율·올해 목표·경과 목표·관리자 목표·지연/이행 확인·기간별 예정·원문 URL·좌표 기준·조회 시점·검토 상태를 포함합니다. API 키는 서버에만 보관합니다.

## 검증

현재 후보 150건에서 블록 명칭을 확인한 96개 묶음을 구성하고 75개에 지구 대표위치를 연결했습니다. 21개 묶음은 위치 미연결입니다. 블록 명칭이 없는 사업은 블록으로 추정하지 않고 기존 목록과 정책/지역 요약에서 관리합니다. 2025년은 당시 보고서의 마지막 원천 상태로 별도 계산하며 현재와 동일한 모집단의 시계열을 주장하지 않습니다.

HOME 자동 테스트 **74개 통과**. 누락 실적 유지, 기준월 처리, 공고 지연과 연도 정밀도의 후보 구분, 다회차 제외, 이후 수정 계획의 소급 지연 금지, 실제 입주와 공고 분리, 블록 중복 제외, 연간 목표 미배분과 목표 모집단 유지, 역사 조회와 CSV 필터·근거 범위·BOM·수식 방어를 검증합니다.

공개 Chromium 1600×1100 및 모바일 390×844에서 확대 3단계·9개 자료 연도·2025/2018 조회·모집/입주 전환·프로그램 선택·현재/과거 CSV를 검사했습니다. 지역별 향후 10년 CSV는 시도 요약 20행 + 블록 상세 960행입니다. 콘솔·지도 타일 오류 0, 모바일 페이지 가로 넘침 없음.
