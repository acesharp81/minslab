# SH 두 API 연결·수집 검증

2026-10-03. 사용자가 신청한 두 데이터셋은 별도의 SH 관리 재고 파일이 아니라 공공데이터포털에서 파일 변환 Open API로 제공하는 자료입니다. 저장된 키로 두 서비스 모두 HTTP 200을 확인하고 SH 전용 환경변수 `POC10_SH_SERVICE_KEY`에 적용했습니다. 키 값은 기록하지 않습니다.

| 원천 | 공개본 기준일 | 전체 조회 행 수 | 의미 |
| --- | --- | ---: | --- |
| [SH 주택분양 정보 15008820](https://www.data.go.kr/data/15008820/fileData.do) | 2019-08-26 | 6 | 지구·단지 계획, 2015년 예정월 포함 |

| [SH 공공재개발·재건축 15124798](https://www.data.go.kr/data/15124798/fileData.do) | 2023-11-02 | 16 | 사업 위치·전체 및 임대 계획 세대수·과거 추진현황 |

공식 메타데이터 `https://infuser.odcloud.kr/oas/docs?namespace={dataset_id}/v1`에서 기준일과 API 경로를 확인합니다. 허용 호스트·데이터셋·경로·기준일을 검증하고 API의 `page`, `perPage`, `totalCount`, `currentCount`와 실제 행 수를 대조합니다. 최신 경로를 하드코딩하지 않습니다. 인증·스키마·중복·페이지 실패 시 마지막 정상 데이터를 유지합니다.

같은 사업이 공개본에 반복되므로 **20행을 사업 20개로 세거나 물량을 합산하지 않습니다.** 최신 4행의 합계는 사전청약 1,265 + 본청약 421 = 1,686세대입니다. 이미 포함된 사전·본청약을 합계에 다시 더하지 않습니다. 재개발·재건축 임대 세대수도 전체 세대수의 일부이며, 미제공 세대수는 미확보로 유지합니다. 공급 예정월은 실제 공급·준공·입주일이 아닙니다.

재개발·재건축 페이지 갱신일과 공개본 기준일은 다릅니다. API 공개본 기준일 **2023-11-02**와 원래 추진현황을 표시하며 2026년 현재 사업 단계로 확정하지 않습니다. 2019 공개본의 2015 예정월도 보존합니다. 원천이 공개하지 않은 연도의 자료를 생성하지 않습니다.

홈페이지 `API 테스트 데이터`에서 `SH 분양 공급계획` / `SH 재개발·재건축 사업`과 자료 연도를 선택합니다. 상세 화면에는 공개본·최신 여부·예정월·사전/본청약·임대 부분·원천 추진현황·경고·revision·원본 SHA-256이 표시됩니다. CSV는 같은 필터와 원래 필드 `native_fields`를 제공합니다. `API 연결 안내`에는 실제 성공 건수·시각·공개본별 건수를 표시합니다.

SH 자료는 정책 연결 검토 전의 API 원천으로 저장합니다. 기존 사업 150건에 바로 중복 추가하거나 정책 공급 실적으로 합산하지 않습니다. 사업 조회·지도·자동 정책 매칭에 편입하려면 LH·청약홈과 단지/블록을 대조하고 최신 추진·실제 공급 근거를 연결해야 합니다. 이미 승인 대기 중인 기존 사업의 통계 반영 규칙은 그대로 유지됩니다.

재수집:

```bash
sudo docker exec poc10-home-api python -m scripts.collect --samples --source sh_supply_plan
sudo docker exec poc10-home-api python -m scripts.collect --samples --source sh_redevelopment
```

API 응답은 인증정보를 제거한 후 전용 data 볼륨에 저장합니다. 공개 manifest URL에서 키를 제거합니다. 자동 일일 웹/파일 수집과 구분하여 관리자 요청 또는 위 명령으로 갱신합니다.

검증: 전체 Python 테스트 120개 통과. 공개 브라우저 `scripts/check-sh-apis.cjs`에서 두 서비스 성공·20/16행·4개 자료 연도·최신 4행·중복 합계 방지·상세 근거·연도별 CSV·기존 정책 사업 150건 유지·콘솔 오류 0을 확인했습니다.
