# 지역여건과 추진현황의 화면 구성

기준: 2026-10-15. 시장·수급 비교는 **공급현황 → 지역여건**(`#supply-conditions`)에 모읍니다. 기존 9개 지표와 정책 화면의 1·2·3·4인 이상 가구 변화를 함께 표시합니다. 정책 → 비교 지역 → 시군구 순서로 선택하며, 정책을 바꾸면 지역·시군구 범위를 초기화하고 해당 정책 원장과 지역 통계를 다시 조회합니다. 연결된 정책 원장이 있는 9·7 정책만 활성화하고 다른 정책은 비활성으로 표시합니다. 주제별로 관련 지표를 묶습니다. 두 지표 주제는 데스크톱 2열, 세 지표 주제는 3열이며, 중간 폭에서는 최대 2열, 모바일에서는 1열입니다.

| 내부 주제 | 그래프·차트 배치 순서 |
| --- | --- |
| 가구 구성과 주택 기반 | 1·2·3·4인 이상 가구 변화 → 주택보급률과 공급 배치 |
| 주택시장과 수급 | 아파트 매매가격 변동률 → 전체·준공 후 미분양 |
| 공급 실적과 구성 | 인허가·착공·준공과 장기 평균 → 월별·누계 착공실적 → 공공주택·비아파트 공급 구성 |
| 향후 공급과 목표 | 향후 입주예정물량과 공급 공백 → 장기 수요·적정 공급·부족분 → 과거 실적 대비 목표 규모 |

정책·지역·시군구·연도·평균 기간 선택은 네 주제에 공통으로 적용합니다. 개별 카드 번호는 없애고 주제별 번호·제목으로 구분하며, 수치·원천 확장은 유지합니다.

메뉴는 공급현황(공급현황 지도·지역여건), 추진현황(정책·프로그램·사업), 데이터관리(출처와 수집현황·정책-프로그램-사업 연결·사업별 수집연계), 매뉴얼(사용법·요구사항정의)로 구성합니다. 대주제에는 동일한 선 스타일의 지도·진행 체크·데이터베이스·책 SVG 아이콘을 사용합니다.

정책·프로그램 추진현황은 3×2 통계 배열을 유지합니다. 둘째 행 가운데는 **가구 증가와 공급 일정 비교**, 마지막은 **인구·가구 변화와 주택 재고**입니다. 가구 규모별 변화와 9개 지역 비교 카드는 추진현황에서 제거합니다. 정책의 선택 범위 프로그램은 지역·블록 상세 자료 바로 위의 **선택 범위의 프로그램 펼쳐보기**에 접어 두고, 프로그램의 소속 사업 목록은 유지합니다. 사업 추진현황의 소득 분포는 원천의 6개 연소득 구간별 비중 막대로 표시하고 평균·중위소득과 PIR 수치를 유지합니다.

가구 증가 비교는 선택 원장의 확인된 준공 예정일을 날짜별로 중복 제거하고 사업 총량 한도 안에서 반영합니다. 시도 주택 재고·가구 추계와 비교하는 참고 시나리오이며 시군구 미래 가구 추계 미확보는 별도로 표시합니다. 산출 가정은 접어서 조회합니다.

지도에는 추가 규모 원을 사용하지 않습니다. 가격 지도는 상승/하락을 색 계열로, 공급계획 규모를 색 진함으로 표현합니다. 주택보급률은 100% 이상을 초록, 미만을 빨강으로 나누며 100%와의 차이가 클수록 진해지고 15%p 이상은 가장 진한 색입니다. 가격 지도의 진함은 현재 표시 지역 중 최대 사업계획 대비 상대 규모입니다.

옹진군 도서는 왼쪽 아래의 별도 축척 지도에 표시합니다. 본 지도는 옹진군 도서 경계를 제외하고 화면에 맞춰 본토·강화·영종 등 나머지 지역을 확대합니다. 도서도 동일한 색 기준과 지역 선택을 유지하며, 지역 통계나 공급 물량은 제외하지 않습니다.

숫자·그래프와 판단 질문은 기본 표시합니다. 상세 수치 표·정의·산식·원천 링크는 각 카드의 **수치·기준·원천** 확장에 둡니다.

## 원천과 갱신

`reb_apartment_price`는 별도 인증 없이 한국부동산원 공개 통계 화면의 읽기 전용 조회를 사용합니다. 공개 미리보기 최근 10개월의 수도권 시도·공표 시군구 지수를 수집합니다. 2026-10-15 확인은 622개 지역×월 관측치, 최근 2026-08, 지수 기준 `2026.06=100`입니다. 원문 요청·응답과 SHA-256은 `data/raw/reb_apartment_price`에 보존하고, 일별 수집 대상으로 등록했습니다.

공식 API 활용승인을 받았다고 설명하지 않습니다. [R-ONE 공식 통계 화면](https://www.reb.or.kr/r-one/portal/stat/easyStatPage/A_2024_00045.do)을 조회한 자료입니다. 월 변동률은 게시 지수의 반올림 정밀도에 영향을 받습니다. 서로 다른 판본·기준시점·불연속 월을 연결하지 않으며 12개월 자료가 없으면 전년 동월 가격 변동률을 만들지 않습니다.

원문 장기 평균·유형별 착공·장기 수요·적정 공급·부족분·목표 배율은 [2025-09-07 주택공급 확대방안](https://eiec.kdi.re.kr/policy/materialView.do?num=270716)의 인쇄 1·2·3·43쪽을 대조한 고정 참고 자료입니다. `backend/data/housing_indicator_reference.json`에 발표일·원문 URL·검증 PDF 해시와 함께 둡니다. 이를 현재 월 통계나 경기·인천 개별 배분량으로 바꾸지 않습니다.

## 집계 계약

- 정책 원장/연결 사업 전체 선택을 구분하며 프로그램은 저장된 프로그램 ID, 사업은 저장된 원천 연결 ID로 한정합니다.
- 시군구의 가격·주택 재고는 실제 지역 자료를 사용합니다. 시군구 주택보급률 공식값이 없을 때 공식 지도는 시도 참고 배경, 최신 산출 지도는 시군구 자체 수치입니다.
- 시군구 인허가·착공·준공 통계가 없는 경우 시도 전체 실적으로 표시합니다. 시군구 목표와 나눠 달성률·배율을 만들지 않습니다.
- 연간 월 자료는 같은 지역의 공통 확보 월만 합산합니다. 12개월이 모두 있어야 완결 연도입니다. 평균에는 현재 부분 연도를 넣지 않습니다.
- 정책 확정 착공은 정책 귀속과 단계 근거가 확인되고 추정 표시가 없는 관측입니다. 미확보는 빈 계열이며 지역 통계·담당자 추정을 정책 인정 실적으로 채우지 않습니다.
- 향후 일정은 동일 사업의 같은 날짜 중복을 제거하고 총량 한도로 나눕니다. 일정 미확보는 전체 공급이 0이라는 뜻이 아닙니다. 준공 예정·입주 예정은 합산하지 않습니다.
- 지연은 도래 목표 대비 측정 부족률 2% 이상, 주의는 0% 초과~2% 미만입니다. 사업별 여러 단계 중 가장 높은 위험 상태를 우선하고, 같은 상태에서는 최대 갭 하나를 표시하여 중복을 줄입니다. 미측정은 지연 0 실적으로 보정하지 않습니다.
- 분류는 같은 원장에 저장된 연결 원천의 시행기관·명시된 사업 유형을 사용합니다. 서로 다른 사업명 유사성을 이용해 분류하지 않고 연결 원천 간 유형 상충은 미분류로 둡니다.
- 정책 목표의 부족분 보완 규모는 전체 연간 목표가 아니라 원문 과거 착공 추세와의 차이로 비교합니다. 실제 달성률과 구분합니다.
- 장기 수요·부족분은 가구·소득·멸실을 포함한 원문 연간 개념입니다. 주택 재고−가구 수의 단순 차이를 수요 부족량으로 부르지 않습니다.
- 프로그램·사업의 과거 추진 실적 모집단이 지역 전체 통계와 다르면 단순 배율을 보류합니다. 원문 정책 1.7배는 별도 참고로 남깁니다.

## 인천 통계 표시 수정

인천 자료는 수집돼 있었으나 `policy-report.js`의 과거 제외 조건과 미확보 문구가 남아 있었습니다. 실제 확인은 인천 인구·주택 재고·가구 규모별 통계 2018~2025, 시도 장래가구 2026~2036입니다. 화면에서 인천을 포함하고 현재 정책 경계로 선택한 시군구도 해당 원천 지역에 연결합니다. 2026 행정구역 개편 후 지역을 과거 경계의 숫자로 임의 재배분하지 않습니다.

2025 인천 원천 참고: 인구 3,093,590명, 일반가구 1,296,146가구, 다가구 반영 주택수 1,288,291호. 최신 산출 보급률 99.4%이며 공식 공표값과 구분합니다.

## 코드·API·검증

- API: `GET /poc/home/api/housing-indicators` — `kind`, `scope_id`, `region`, `municipality_id`, `as_of_date`, `year`, `baseline_years`, `portfolio`.
- 계산: `backend/housing_indicators.py`. 공급 원장·통계·재고·미분양·가격을 읽고 기존 입력값을 변경하지 않습니다. DB 판본 변경을 따르는 조회 캐시를 사용합니다.
- 화면: `web/assets/housing-indicators.js`, `housing-indicators.css`. `SupplyConditions`가 별도 화면을 구성하고 `PolicyReport.statisticsDemographics`가 선택 범위의 가구 규모별 차트를 연결합니다. `policy-907.js`와 `project-information.js`에는 지역 비교 카드를 붙이지 않습니다.
- 회귀 검증: `tests/test_housing_indicators.py` — 판본/연속 월, 부분 연도·평균, 미분양 포함관계, 정책 인정/추정 구분, 일정 중복·한도, 단계별 임계값, 범위/단위 불일치, 공공·주택 유형의 ID 연결, 공개 API 검증.
- 관리 비교 검증: `tests/js/policy-report-projection.test.cjs` — 준공 예정 날짜 중복·사업 용량 한도, 시군구 추계 보류, 일정 미확보와 종료된 화면의 비동기 갱신 방지.
- 화면 검증: 9개 카드·지도/차트·접힌 원천, 비교 조건 변경, 월별/누계, 공식/산출 전환, 메뉴 그룹·아이콘·선택 상태, 3×2 관리 통계·접힌 프로그램 목록·소득 막대와 PIR 유지, 좁은 화면의 가로 넘침과 블록 목록 물량 위치.
