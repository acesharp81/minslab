> **최종 처리 변경:** 비공식 원문 확인분을 담당자 확인 완료로 채택하여5개 블록2,853호를 착공에 반영했다. 현재 누적79,884호·연말 계획92,574호. 아래의 후보·미가산 서술은 변경 전 검토 이력이다. [최종 확인 완료 내역](HOME_NONOFFICIAL_CONFIRMATION_APPLIED_20261020.md)과 [최종 대조표](HOME_THREE_NEWTOWN_FINAL_COMPARISON_20261020.md)를 사용한다.

표준 형식: **담당자 확인 - 비공식 자료: 기관·매체, 문서·기사명, 일자(확보된 경우), 출처 URL.**

‘담당자 확인’은 사용자 지시에 따른 담당자 대행 검토 이력이다. 기관 담당자에게 직접 확인받았거나 비공식 원문이 공식 실적 자료로 바뀌었다는 의미는 아니다. 각 자료가 확인하는 범위와 현재 집계 반영 여부를 함께 기록한다.

## 이전 기록 점검 범위와 미확인 후보

현재 DB의 문서 근거·사업·연결·담당자 입력·일정·수집 조사 기록과 이전 검토 보고서·보존 원문 목록을 대조했다. 비공식 자료의 URL이 있다는 이유만으로 모두 담당자 확인 완료라고 표기하지 않았다.

- **수집 조사 기록401건**에 포함된 `primary=false` 검색 후보는 **515개**이며, 모두 기존 확인 상태가 ‘원문 후보 · 내용 미검증’이었다. 이 수는 중복 URL을 포함한 후보 항목 수로,515개 사업이나 확인 완료 출처 수가 아니다. 기존 분류기의 `primary=false`가 모든 개별 사이트의 비공식성을 판정했다는 뜻도 아니다.
- 어떤 조사 기록에 공식 문서 연결이 존재하더라도, 함께 들어 있는 비공식 검색 후보의 내용까지 확인한 것은 아니다. 미검증 후보에는 ‘담당자 확인’을 붙이지 않았다.
- 공식 iH 공고 본문에 민간 견본주택·설계·홍보 사이트 주소가 포함된 경우가 있었다. 실제 수집 원천은 공식 공고이므로 공고 전체를 비공식 자료로 재분류하지 않았다.
- 국토부 브이월드, 지방의회, 공공 연구기관 등 일반적인 `.go.kr` 형태가 아닌 공식 경로를 도메인 모양만 보고 비공식 자료로 바꾸지 않았다.

이번에 확인한 과거 보조 근거 중 누락된 표기는 연남동 설계사 소개다. 이를 별도 담당자 검토 문서로 저장하고 기존 검토 보고서에도 표시했다. 검색 후보를 확인 완료로 승격하거나 기존 정책·프로그램 연결을 바꾸지 않았다.
