D. 확인이 필요한 사항

기능 결함

F-06의 최초 일정 기준선, F-07의 병목/조치, F-08의 기관 역할, F-12의 시나리오 격리는 코드·업무 모델을 추가해야 한다. API 키만 늘려서 해결되지 않는다.

자료 확보

실사업 목록과 단계 원문, SH·GH 공정 이력, 실제 입주 시작/입주량, 변경 일정·사유, 지역별 세분화 추계의 공개·제공 범위를 확인해야 한다. 없으면 담당자 입력과 기관 연계가 필요하다.

현재 원천 장애

iH는 timeout/HTTP 실패로 첫 성공이 없다. 인증키 미신청이나 원천0호로 단정할 수 없다. 건축HUB 상세는 컬럼 형식 변화이며 API 키 추가보다 파서·실응답 재검증이 우선이다.

행정·정책 정의

135만 목표의 포함사업/착공 귀속, 단계별 도달 기준, 최초 약속 일정의 효력, 분양·모집 실적과 입주 시작/실입주량의 정의를 운영 주체와 합의해야 한다. 이는 구현 결함과 별도다.

미확정 자동 연결의 활용

사용자가 승인 대기 연결도 통계에 포함하도록 이미 결정했다. 이를 유지하면서 “검토포함”과 “공식/담당자 확인”을 나란히 표시해야 한다. 공개 가능한 정보 범위와 최종 승인 권한은 운영기관이 정한다.

외부 협업·권한

기존 관리자 인증 검증은 가능했으나 실제 부처/기관 계정·입력 책임·협의 회신·정기 제공 협약 및 비공개 데이터 접근 가능 여부는 이번 점검만으로 확인 불가이다.

추가 인증

이번 진단과 Y축 수정에 추가 키는 필요하지 않았다. 전국/기관 확대 때 새 서비스가 확인되면 실제 엔드포인트·신청 링크·env 변수·권한을 별도 목록으로 확정해야 한다.

검증 근거·제한

  • 이번 관련 백엔드 회귀82개 통과. 격리 DB·네트워크 차단 테스트이며 운영 DB에 테스트 데이터를 넣지 않았다.
  • 읽기 전용 브라우저 점검: 선택 지역/사업 축, 11년 슬라이더, 전체 복원, 2D, 단계 근거 검토, 실제 사업 상세. 콘솔 오류 없음.
  • 기존 정책 UI 검사도 통과. 관리 입력 테스트의 POST는 가로채 실제 운영 저장을 하지 않았다.
  • 운영 API 점검은 2026-10-12 스냅샷이다. 자동 수집으로 이후 수량과 상태는 달라질 수 있다.
  • 저장소/동작 검증은 실제 행정기관의 원본 제공·담당자 승인·협의 업무가 완료됐음을 보증하지 않는다.
  • 관련 기능 없는 항목은 파일/스키마/API 검색과 현재 서비스 구조로 판정했다. 모든 파일에 신규 테스트를 추가하거나 미구현 기능을 시연 데이터로 채우지 않았다.
