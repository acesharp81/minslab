## 4. 담당자 입장에서 확인한 연결

이름의 글자 유사도만으로 정책을 새로 배정하지 않았다. 기존 승인 사업의 정책·프로그램 귀속은 유지하고 **물리적 범위와 동일 호수**가 확인되는 공식 계획 근거를 연결했다.

연결 기록에는 시도, 정규화 지구명, 분할을 보존한 블록 코드, 기존 승인 호수, 원천 호수, 원천 세부 행 ID·판본, 주택유형, 계획일, URL, 확인 주체·사유를 저장했다. `AA13-1`과 `AA13-2`, `갈매`와 `갈매역세권`은 같은 키로 합치지 않는다.

**연결 확인은 해당 원문이 같은 사업을 설명한다는 확인이다.** 원천별 예정일이 다를 때 기존 승인 계획을 자동 대체한다는 의미가 아니다. 기존 승인 일정 300개 사업 × 6단계 = **1,800건**, 사업 관리값 및 정책 연결의 보호 해시가 작업 전후 동일함을 확인했다.

다음은 유보했다.

- **의정부법조타운 S3:** 같은 준공예정 공개본에 동일 544호가 2029-02-28과 2029-09-30으로 기재된 두 행이 있다. 어느 날짜를 채택할지 원문 범위 정리가 필요해 두 신규 확인을 보류했다.
- **인천검단 AA19:** 부동산원 자료의 이름에는 영구임대가 표시되지만 물량은 전체 블록 1,323호다. 기존 국민임대 991호·영구임대 332호와 범위가 달라 영구임대 1,323호로 연결하지 않았다.
- 나머지 동일 물리적 키가 없거나 단일 승인 대상·같은 호수·계획일이 확인되지 않는 자료는 원천 자료로 보존했다. 미연결 자료를 전부 신규 사업으로 만들지 않았다.

## 6. 연말 예상량을 어떻게 해석해야 하나

현재 9·7 관리 범위는 원천 사업 208건을 묶은 153개 집계 단위다. 이 범위에 승인된 단계별 계획을 적용한다. 착공 연말 예상량 **80,800호**는 해당 관리 범위의 12월 말 누적 계획이다.

- 수도권 전체의 올해 신규 착공 전망 21.8만~23.5만 호와 모집단·기간 정의가 다르다.
- 관리 사업마다 일정이 등록돼 있다는 사실만으로 수도권 전체의 계획사업을 수집했다고 볼 수 없다.
- LH 건설공사 현황은 이미 계약·공정에 올라온 사업 중심이다. 아직 계약 전인 연말 착공 후보는 연간 업무계획, 사업승인 고시, 발주·계약 변경, 기관 착공예정 명세에서 추가 확보해야 한다.
- 이번 보강은 입주·공급·준공 계획과 계약 참고자료가 중심이다. 이를 착공 실적으로 자동 추가하지 않았다.
