- PoC7 상단 모델 예산: OpenAI 공통 잔여량. Solar 원장은 같은 중앙 예산 서비스에서 기록한다. OpenRouter·Mistral의 기존 표시도 유지합니다.
- PoC11 워크스페이스 상단: 같은 공통 잔여량을 작은 3그룹 패널로 표시합니다. 초기화 시각·정확한 잔여량은 도움말에서 확인하며 모델을 누르면 공용 사용량 상세로 이동합니다. 로그인 후 표시합니다.

중앙 원장에 접속하지 못하면 잔여량을 미확인으로 표시하고 신규 모델 호출을 차단합니다. 소진을 무제한 또는 미확인을 잔액 0으로 바꿔 표시하지 않습니다.

## 세 역할 운영

[세 AI 작업자 설명](AI_AGENTS.md)이 최신 실행·승인 계약이다. 수집의 기존 07시 예약을 유지하고 알고리즘·업무담당은 별도 모델/예약을 선택한다. mini/Nemotron의 선택적인 정밀 검토는 애매한 건만 수행한다. 같은 원문/판본/규칙/모델 구성/담당자 판단의 완료 분석은 다시 호출하지 않는다.

PoC10 일 $2·월 $30 등 설정은 공통 예산 안의 추가 작업 상한이다. 현재 Solar 무제한 사용은 이 상한을 소모하지 않으며 표준 단가 추정액은 계속 기록한다. OpenAI·OpenRouter의 원자적 공통 제한은 그대로 유지한다. 자료 연결은 검증된 공식 근거에만 허용하고 실제 단계/물량 확정은 별개다.

## Solar 유료 키로 전환할 때

현재 중앙 게이트웨이와 HOME API/AI worker의 `SHARED_SOLAR_UNLIMITED=true`는 사용자 확인에 따른 **현재 키의 운영 설정**이다. 키 문자열만으로 무제한 여부를 추측하지 않는다. 경제성 비교는 이 할인 없이 표준 단가로 수행한다.

유료 키 전환 전 예약을 끄고 진행 중 호출·미정산 outbox를 마친다. 중앙과 HOME의 `SHARED_SOLAR_UNLIMITED=false`를 맞추고, 확인된 운영 예산을 `SHARED_SOLAR_BUDGET_USD` 및 HOME 누적 한도에 설정한다. 현재 지원 범위는 0 초과 $110 이하이며 더 큰 범위는 별도 설정 검증 변경이 필요하다. **새 결제 기간을 뜻하는 별도 `SHARED_SOLAR_GRANT_ID`**를 사용해 무제한 기간의 가상 비용을 새 유료 예산에서 차감하지 않는다. 이전 원장 기록은 삭제하지 않는다. 공유 키/기간 변경은 PoC7·10·11을 함께 확인한다. 재시작 후 한도·잔여율과 소액 호출 차감 확인 뒤 예약을 복원한다.

## 유지관리 계약

기존 `poc07-openrouter-gateway`에 아래 인증 API를 추가했습니다. 모델 키·원문은 예산 API로 보내지 않습니다.

- `GET /internal/budget/status`: 공통 잔여량·사용·예약·미확정·초기화 정보.
- `POST /internal/budget/reserve`: 요청 ID, 프로젝트, 모델, 입력/출력 상한으로 원자적 예약.
- `POST /internal/budget/settle`: 같은 요청 ID로 실제 사용량 또는 거절/미확정 정산.
- 인증: 서버 전용 `x-minslab-meter-token`. 브라우저로 전달하지 않습니다.

PoC7은 기존 PostgreSQL 그룹 원장에 직접 예약합니다. PoC10/11은 HTTP로 동일 행을 예약합니다. PoC11의 이전 PG 예약은 기존 코드로 정산할 수 있어 미전송 outbox를 잃지 않습니다. 각 클라이언트는 정산 이력을 먼저 로컬 저장하고 재전송하며 동일 ID가 중복 차감되지 않습니다. 진행 중·미확정 예약을 시간이 지났다는 이유로 자동 해제하지 않습니다.

중앙 migration `0061_shared_model_budgets`는 `shared_model_reservations`, `shared_solar_grant_usage`를 추가합니다. 기존 OpenAI 그룹/크레딧 원장을 초기화하지 않습니다. 기존 중앙 Solar 계측 이력도 이벤트 ID로 중복 없이 포함합니다. PoC10 업무 DB의 승인·매핑 schema 변경은 없습니다.

Docker에서는 외부 네트워크 `minslab-ai-budget`에 기존 게이트웨이와 HOME API/AI 작업자만 추가 연결합니다. 각 DB의 기존 네트워크는 유지합니다. 네트워크 생성 후 중앙 migration → 게이트웨이 → API/AI 작업자 순서로 적용합니다. 구성은 각 프로젝트 compose와 `.env.example`에 명시했습니다. PoC11은 호스트의 내부 게이트웨이 포트를 사용합니다. 기존 API 키는 각 프로젝트의 서버 환경에만 보관하고 새 키를 발급하거나 노출하지 않습니다.

PoC10 `data/runtime/ai-collection.sqlite3`의 실행/정산 outbox, 원문 보관 경로, 중앙 PostgreSQL 예산 원장을 함께 백업해야 합니다. 장애 복원 시 사용량 원장을 오래된 값으로 되돌리면 잔여량이 부풀려지므로 별도 대조가 필요합니다. 키를 재설정해도 기존 사용량은 유지합니다.

## 2026-10-30 표시·성능 보완

HTML `style` 속성의 막대 너비는 서비스 CSP에 의해 차단됐다. 신뢰된 스크립트가 DOM의 `style.width`를 설정하도록 바꿔 CSP를 완화하지 않고 정확한 잔여율과 처리 진행률을 표시한다. 0%·50%·100%·미확인, 실측 4.1% 크레딧과 78.4% 토큰을 브라우저에서 확인했다. 전체 한도는 중앙 원장의 `limit`, 잔여율은 `remaining/limit`을 사용하고 실제 제공사 잔액으로 표현하지 않는다.

AI 분석 이력만 저장되는 경우에는 정책 조회 캐시를 재생성하지 않는다. 원천·담당자 확인·매핑·연결 근거의 실질적인 변경은 계속 캐시를 무효화한다. 상세 측정은 [CPU·로딩·화면 검증](evidence/LOADING_CPU_20261030/README.md)을 참고한다.
