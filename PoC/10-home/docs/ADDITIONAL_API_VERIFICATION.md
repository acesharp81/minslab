## 수집·집계 기준

건축물대장은 개포·고덕·진관·이의·다산·덕풍동에서 각 100개 원천 행을 조회한 뒤 주거용 용도만 보관합니다. 전체 법정동 모집단 수집이 아닙니다. 큰 대장 PK를 문자열로 보관하고 `hhldCnt` 세대수, `fmlyCnt` 가구수, `hoCnt` 호수를 구분합니다. 세대수가 0이어도 호수를 대신 합산하지 않습니다. 과거 사용승인·기존 재고를 포함하며 사용승인일을 신규 준공량·실입주일로 확정하지 않습니다. 원천 레코드 생성일과 허가·착공·사용승인일을 상세에서 각각 조회합니다.

LH는 분양 05·임대 06과 서울 11·경기 41의 4개 조합에서 2018-01-01~2026-10-03을 명시하여 35개 전체 페이지를 조회했습니다. `ALL_CNT`와 실제 페이지 크기·식별자 중복을 검증합니다. 원천 3,281건 중 어린이집 공고 230건과 인천·김포 복수지역 공고 1건은 표시에서 제외하고 인증정보를 제거한 원문·배치 제외 건수를 보존합니다. 표시하는 3,050건은 정정·재공고를 포함한 공고 레코드이며 공급 호수나 고유 사업 수가 아닙니다. 목록에 공급량이 없으므로 미확보로 유지합니다.

LH 기간 조회는 **공고게시일 `PAN_NT_ST_DT`** 기준입니다. 예를 들어 원천 공고일 `PAN_DT=20171205`, 게시일 `PAN_NT_ST_DT=2018.05.30`인 정정 공고는 2018년 자료로 조회하며 두 날짜를 모두 보존합니다. 원천 공고일을 게시일 필터에 대입해 정상 과거 자료를 배제하지 않습니다.

통계누리는 통계표별 최신 공개 기간 메타데이터를 먼저 읽습니다. 월별은 2개월씩 조회하여 1,000개 원천 행 제한을 준수합니다. 서울·경기 및 총계/총계 조합만 선택하고 민간·공공 소계를 다시 합산하지 않습니다. 조회한 모든 기간·지역 총계 확보를 확인했습니다.

| 지표 | 통계표 / 양식 | 보관 건수 | 대상 기간 |
| --- | --- | ---: | --- |
| 월별 준공 | 5372 / 1 | 208 | 201801~202608 |
| 월별 착공 | 5386 / 1 | 208 | 201801~202608 |
| 연간 인허가 | 626 / 125 | 16 | 2018~2025 |

월별 인허가 5375 API는 시험한 공식 양식에서 INFO-300(개방 취소)을 반환해 정상 제공되는 연간 인허가를 사용합니다. 미공개 월이나 API 자료 없음은 0호로 생성하지 않습니다. 시도 총계에는 민간 사업도 포함되므로 특정 정책의 달성량·블록 공급량에 직접 합산하지 않습니다. 준공 원천 지표명 `사용검사실적`도 함께 보존합니다.

## 조회·운영

[HOME](https://www.minslab.kr/poc/home/)의 `API 테스트 데이터`에서 6개 유형, 자료 연도, 지역, 검색과 페이지 이동을 사용합니다. `자료 연도`는 원천 날짜 기준이며 상단 기준일은 당시 HOME에 저장돼 있던 정보 기준입니다. 지금 수집한 2018년 자료는 현재 기준일에서 자료 연도 2018을 선택하면 보입니다. 상단 기준일을 2018년으로 바꾸어 당시 수집한 것으로 표시하지 않습니다.

- `GET /poc/home/api/samples?kind=statistic&source_year=2018`: 50개 총계(월별 48 + 연간 2).
- `GET /poc/home/api/samples?kind=lh_notice&source_year=2018`: 370개 과거 공고.
- `GET /poc/home/api/samples/{id}`: 원천 날짜·집계 의미·변경이력·응답 SHA-256.
- `GET /poc/home/api/samples/export.csv?kind=statistic&source_year=2018`: 같은 필터의 CSV, 통계 주기·지표·원천 날짜·경고 포함.
- `GET /poc/home/api/connections`: 실제 배치 결과로 3개 신규 서비스 CONNECTED, 정상 수집 건수·최근 성공 시각 표시.

API는 수동 수집이며 기존 자동 웹·파일 수집과 분리합니다. 개별 재수집은 HOME 컨테이너에서 다음 명령으로 실행합니다.

```bash
python -m scripts.collect --samples --source building_register
python -m scripts.collect --samples --source lh_notice
python -m scripts.collect --samples --source molit_statistics
```

## 검증 기록

단위·저장·API 회귀 테스트 **111개 통과**. 인증 오류·지역/기간 불일치·페이지 중복·재공고 날짜·기존 재고·호수/세대수 구분·통계 소계 중복·미확보 값·키 echo 제거·재수집 멱등성·CSV·원천 연도 조회를 확인했습니다.

새 원천 파일 208개에서 인증정보 제거와 SHA-256을 대조했습니다. 신규 DB revision 3,802건·배치 manifest·공개 원천 응답에도 키 값이 없고, 통계 API가 반환하는 `cert_id`는 공개 payload에 저장하지 않습니다. `.env`와 실행 설정 파일 권한은 600입니다.

공개 브라우저 검증은 `scripts/check-additional-apis.cjs`, 정책 대시보드 회귀는 `scripts/check-policy-workflow.cjs`, 지도 회귀는 `scripts/check-map-monitor.cjs`로 수행합니다. 승인 테스트를 위해 운영 매칭 상태를 변경하지 않습니다.

세 공개 브라우저 검증 모두 PASS. 신규 3개 서비스 연결 확인, 2018년 통계 50건·LH 공고 370건의 자료 연도 조회, 상세 근거·같은 필터 CSV, 기존 정책 5개·지도 탭 6개·시군구 경계 56개·표출 31개·블록 막대·향후 누적 전망·과거 CSV를 확인했습니다. 콘솔 오류·지도 타일 오류 0, 모바일 가로 넘침 없음. 스크린샷은 `/tmp/home-additional-api-check`, `/tmp/home-policy-workflow-check`, `/tmp/home-monitor-check`에 보관합니다.

공식 명세: [건축물대장](https://www.data.go.kr/data/15134735/openapi.do), [LH 공고](https://www.data.go.kr/data/15058530/openapi.do), [통계누리 API 안내](https://stat.molit.go.kr/portal/api/info.do), [통계표 목록](https://stat.molit.go.kr/portal/api/apiList.do).

## 2026-10-05 연도별 공급 비교 보강
