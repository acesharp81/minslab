수집기: `backend/area_stats.py`. 실행: `python -m scripts.collect --source sgis_area`, `--source kosis_housing`, `--source kosis_household_size`, `--source kosis_employment`, `--source kosis_household_forecast`. 자동 수집 주기는 `POC10_COLLECTION_INTERVAL_SECONDS`를 따릅니다. SGIS는 첫 실행에 2018년부터 최신 제공 연도까지 수집하고, 이후 최신 제공 연도를 다시 조회하며 새 연도가 공개되면 추가합니다. 수집한 원본은 인증값을 제거해 `data/raw/`에 보존하고, 정규화한 값은 `home_revision(kind='area_stat')`에 출처·연도·행정코드와 함께 저장합니다. 인증 토큰 응답 자체는 저장하지 않습니다.

경기도 SGIS의 수원시 장안구 등 하위 구역은 수원시로 합산합니다. 합산 대상 중 하나라도 값이 비공개·결측이면 해당 합계는 `미확보`로 표시합니다. 시도 고용률은 시군구 비율의 단순 평균을 내지 않습니다. KOSIS 취업자·경제활동인구는 원천의 천명 단위를 명으로 환산하며 정밀도는 100명입니다. SGIS 종사자는 **사업체 소재지**, KOSIS 취업자는 **거주지** 기준이므로 합산하거나 직접 차감할 수 없습니다. SGIS 산업 대분류는 업종이며 개인의 직종·직업 분류가 아닙니다.

API: `GET /poc/home/api/area-context?region=경기도&municipality=수원시&year=2026`, 선택 목록 `GET /poc/home/api/area-places`. `municipality`를 생략하면 시도 전체이며, 응답은 관측 인구·가구 시계열, 반기별 고용 시계열, 시도 장래가구추계를 분리합니다. 공급 실적·정책 달성률 계산에는 쓰지 않습니다. 원천별 기준 시점이 다르고, 장래가구는 관측값이 아닌 추계입니다.

## 주택 재고와 가구 비교

별도 **인구·가구·고용 분석** 화면과 지도 정보창에서 가장 최근의 **같은 연도** 주택 재고와 일반가구를 비교합니다. 재고−가구가 양수이면 `통계상 여유`, 음수이면 `통계상 부족`으로 표시합니다. 이는 공가·임대료·입지·거주 가능 여부·정책별 신규 공급 실적을 반영한 실제 수급 부족량이 아닙니다. 2025년 말 공식 시군구 통계가 현재 비교 기준입니다. 다가구 구분거처 반영 주택 재고의 시군구 시계열은 2024–2025년만 확보되어 2018–2023년을 0 또는 추정값으로 연결하지 않습니다. 별도로 확보한 2018–2025년 주택총조사 `주택_계`는 다른 기준의 관측 시계열로 그래프에 표시하지만, 보정 재고를 대체하거나 `재고−가구` 비교·미래 전망에 넣지 않습니다. 시도는 국토교통부 공식 주택보급률 연속자료로 2018–2023년까지 확인할 수 있습니다.

경기도의 시·구 계층을 함께 더하면 중복되므로 KOSIS의 **시 합계 행만** 사용합니다. 서울 25개 구와 경기 31개 시군의 2024·2025년 행 수를 확인한 후 적재합니다. 2024년 시도 합계는 국토교통부의 반올림된 주택보급률 기초 수량과 대조합니다. 2026년 기준 화면에서 인구·주택 재고·가구는 2025년, 취업자는 2026년 상반기까지 확보됩니다. 사업체 종사자·산업별 종사자는 2024년까지이므로 화면에 각 원천 연도를 따로 표시합니다.

## 2026-10-05 가구원수·공급 흐름·장래 수급 비교

기존 KOSIS 키로 `DT_1JC1516`을 2018~2025년 매년 조회해 서울 25개 구·경기 31개 시군 및 두 시도 합계 58개 지역 × 8년 = 464개 행을 저장했다. 1·2·3·4인 가구를 각각 보관하고, 5·6·7인 이상을 합친 5인 이상을 별도 표시한다. 모든 행에서 각 규모별 합계가 공식 일반가구 총수와 일치하는지 검사한다. 적재된 464개 지역·연도 행 전체를 기존 `DT_1JC1515` 일반가구 총수와 대조해 불일치 0건을 확인했다. 인구·가구·고용 분석 화면에서 연도별 절대수 막대와 2018년 대비 증감·구성비를 확인한다.

같은 화면의 과거 공급 흐름은 [국토부 공식 분양승인·준공 실적](ANNUAL_SUPPLY.md) 중 선택한 시도의 2018~현재 연도별 물량을 별도 막대로 표시한다. 시군구 선택 시에는 **시도 전체 공급 실적**임을 명시한다. 인허가·착공은 연도별 공급 비교 메뉴에서 확인한다.

미래 비교는 **최근 관측 주택 재고**(현재 2025년)와 [국토부 당해연도 관측 준공](https://stat.molit.go.kr/portal/cate/statMetaView.do?hRsId=468), HOME에 연결된 사업의 **중복·용량 충돌을 제외한 준공 예정량**, KOSIS의 **시도 장래가구추계**를 서로 구분한 시나리오다. 2026년 준공은 1~8월까지만 반영하고 나머지는 0으로 확정하지 않는다. 2027년 이후 사업별 준공 일정이 미확보인 지역·연도는 시나리오 선과 차이를 비워 둔다. 준공은 멸실 차감 전의 총량이며 예정 변경, 민간 미래사업 미연계, 공실·거주 가능성도 반영하지 않으므로 그래프의 '산술상 적음/많음'은 공식 수급 부족·여유 확정치가 아니다. 시군구 장래가구 추계가 연결되지 않아 시군구 선택 중에도 미래 그래프는 해당 **시도 전체**로 표시한다.

API: `GET /poc/home/api/area-context?region=경기도&municipality=수원시&year=2026`의 `household_size`, `GET /poc/home/api/area-outlook?region=경기도`. 원본 수집: `sudo docker exec poc10-home-api python -m scripts.collect --source kosis_household_size`. 추가 API 키는 필요하지 않다.
