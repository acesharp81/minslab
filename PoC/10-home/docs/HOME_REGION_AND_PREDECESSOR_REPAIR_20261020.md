# 인천 지역 표기 및 사업화·인허가 추정 빈칸 정비

기준일:2026-10-20. 사용자 요청에 따른 반영 결과다.

## 1. 인천 지역 표기

인천55개 원천 사업 기록을 점검했다.14건은 수집 파서가 인천 행에도 ‘서울(구 확인 필요)’를 기본값으로 넣었고,15건은 ‘지역 상세 확인 필요’,12건은 ‘인천광역시(구 확인 필요)’였다. 구중구·서구를 유지한 기록도 있었다. 이55건에는 연결 해제·검토 상태의 원천 기록도 포함된다.

표시 지역을 원천의 지구·주소·상세 URL과 조회일의 행정구역에 맞게 정규화했다. 과거 원천 표기는 `source_municipality`와 이력으로 보존하고, 화면과 정책 집계가 같은 표시 지역을 사용하도록 했다.

| 대상 | 2026년7월 이후 표시 |
| --- | --- |
| 검단 | 검단구 |
| 영종 | 영종구 |
| 송림 | 제물포구 |
| 검암·가정2·석남·거북이기지·청라 | 서해구 |
| 계양 | 계양구 |
| 부평 | 부평구 |
| 도화 | 미추홀구 |
| 송도 | 연수구 |

제물포역 도심공공복합사업의 **미추홀구**, 남인천우체국의 **남동구**처럼 명시된 유효 소재지는 우선 보존했다. ‘제물포’라는 사업명만 보고 제물포구로 바꾸던 정책 표시 로직도 수정했다. 과거6월30일까지의 조회는 개편 전 구역명을 구분한다. 단순‘서구’·‘중구’만 있고 구체적 지구가 없는 경우에는 어느 신설구인지 임의로 결정하지 않는다.

인천도시공사 프로그램4개의 `iH` 약칭은 **인천도시공사(iH)**로 풀어 표시했다. 프로그램 ID·정책 연결·유형·사업 구성·물량은 유지했다.

근거: [인천시 현행 행정구역](https://www.incheon.go.kr/IC040102), [행정체제 개편 개요](https://www.incheon.go.kr/IC01070101). 좌표를 새로 만든 작업은 아니다.

## 2. 사업화·인허가 빈칸 추정 입력

승인된 정책 사업230건을 점검해 **46개 사업**의 목표38건과 현재 관리 추정70건을 보완했다. 기존 소요기간 모형과 수집 일정·선후 관계를 재사용했다.

| 항목 | 처리 |
| --- | --- |
| 이미 채워진 담당자 날짜·수량 | 보존. 일부만 빈 경우 해당 필드만 보완 |
| 수집 실적·관리 목표가 있는 경우 | 기존 일정을 기준으로 선행 사업화·인허가를 추정 |
| 목표 물량이 부분 범위인 경우 | 기존 부분 물량을 새 추정의 상한으로 사용. 시흥거모A4는340호 기준 |
| 미래·원천상 미진행 등22개 단계 | 현재 실적으로 생성하지 않고 미도래·미진행 또는 미관측 상태를 구별 |
| 기록 | 담당자 대행·사유·추정 규칙·선후 산식·`inferred=true`·필드별 근거 저장 |
| 변경하지 않은 항목 | 착공·공급·입주 진행값, 기존 정책/프로그램 연결, 원천 사업 총량 |

사업화·인허가 입력은 원천이 새로 수집되었다는 뜻이 아니라 **담당자가 관리 추정을 보완한 것**이다. 수집 원문0건 표시가 이 추정 때문에 공식 원문 확보로 바뀌지는 않는다.

| 현재 관리 측정량 | 보완 전 | 보완 후 | 차이 |
| --- | ---: | ---: | ---: |
| 사업화 | 94,218 | **151,098** | +56,880 |
| 인허가 | 88,056 | **97,889** | +9,833 |

위 증가는 관리 추정의 보완이다. 독립 공식 인허가 통계가 증가했다거나 새 실제 승인 사건을 그만큼 수집했다는 뜻은 아니다. 착공은 이 추정 보완으로 증가하지 않았으며, 이후 별도 비공식 원문 확인 완료 연결로2,853호가 증가한 내역은 [별도 보고서](HOME_NONOFFICIAL_CONFIRMATION_APPLIED_20261020.md)에 구분했다.
