신규 자료 검토: 무엇을 확인하고 결정하는가

2026-10-26 · 자료를 고르면 담당자가 결정할 질문을 먼저 제시합니다.

  1. 원문 확인: 각 자료의 구역·단지, 물량, 사건과 일정을 확인하는 세 가지 항목을 안내합니다.
  2. 현재 데이터 대조: 이름이 유사한 사업의 등록 지역·계획량·정책·연결 상태를 제시하고, 이전 판단 사유는 펼쳐서 확인합니다. 유사 이름은 동일 사업으로 확정하지 않습니다.
  3. 처리 선택: 기존 사업 자료 연결 / 새 사업 등록 검토 / 근거 추가 확인을 위한 보류 / 관련 없는 자료 제외 중 선택합니다. 필요한 입력란만 표시합니다.

자료별 질문 예시

  • 면목·사당: 원문의 해당 구역은 기존 사업인가, 신규 등록 검토가 필요한가?
  • 신길4 등: 기존 보류·검토 사유를 새 원문이 해소하는가?
  • 제물포: 기존 사업과 동일한 구역의 이주·착공 계획 자료인가?
  • 구월2: 지구 전체 자료인가, 개별 블록에 연결할 자료인가?
  • 수서: 대상 단지들이 기존 수서 사업 범위에 포함되는가?
  • 시흥거모 S1: 기존 공급 자료와 같은 공고인가?

안내는 수집 제목을 바탕으로 한 검토 질문입니다. 본문·주소·물량·일정의 검증 완료로 표시하지 않습니다. 성북동 자료가 수서 사업을 유사 후보로 제시하던 분류를 분리했습니다.

자료 연결 승인은 근거 자료의 연결이며, 정책 귀속·호수·실적을 자동 변경하지 않습니다. 사업 등록 검토는 후속 등록 대기에 남습니다. 운영 검토 결과를 자동 승인하지 않았습니다.

검증: 관련 테스트 45개 통과. 실제 화면 열람 및 기존 정책 연결 이동, 격리 SQLite에서 승인→보류→등록 대기 저장과 이력·연결 해제 검증. 운영 데이터에는 테스트 승인을 저장하지 않았습니다.
