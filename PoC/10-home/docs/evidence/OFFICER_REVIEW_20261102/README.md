## 본문 품질 한계

현재 판본 본문 문자열 90건, 요약 수준 2건, 문자열 미보유 11건, 부족/목록 등 유효본문 미확보 4건이다. **90건은 모든 첨부·법정 근거 검증 완료 건수가 아니다.** 현재 저장본문·재조회 본문·공식 첨부 복구를 각각 구분해서 기록했다. 과거 승인 기록만으로 오늘 재확인했다고 표시하지 않았다. 명단 첨부는 내려받지 않았다.

등록 대기 45건은 새 원장 등록 완료가 아니다. 보류 32건은 사업/자산ID, 최신 원문·변경 전후 내용, 대상별 분해 등 필요한 확인사항을 상세에 남겼다. 미확인 날짜·실적은 추정해서 입력하지 않았다.

## CSV·JSON 사용법

`데이터 관리 → 신규 자료 검토`에서 상태·검색·우선순위를 선택한다.

- **현재 목록 CSV**: 현재 필터의 63열 CSV.
- **전체 상태 CSV**: 필터를 무시하고 모든 상태.
- **현재 목록 근거 JSON**: CSV와 동일한 필터, `publication-review-evidence-2` 구조.

CSV에는 통합 유효본문·출처·품질·판본별 메타데이터, 외부 권고와 담당자 판단, 인용 사실, 단위·범위, 단계별 일정, 미확인 항목, 동일/정정/후속 사건, 확정 자료 연결·실적 합산 여부를 추가했다. 원래 탐색 문서 본문만 비어 있다고 ‘본문 미보유’로 오인하지 않도록 수정했다.

JSON의 `facts`는 현재 원문/판단 판본과 본문 해시가 맞는 확인 기록만 제공한다. 사실 유형은 CONTEXT/QUANTITY/DATE, 시간 성격은 REFERENCE/PLANNED/SCHEDULED/REPORTED_ACTUAL이다. REPORTED_ACTUAL도 별도 실적 입력 승인을 뜻하지 않는다. 날짜 정밀도 DAY/MONTH/YEAR와 모집차수 범위를 함께 제공한다. 과거 평가 전체는 이력으로 보존하되 현재 유효 사실로 채택하지 않는다.

개인 식별번호·개인 연락처·명단 영역을 내보내기에서 제외하고 CSV 수식 실행을 방어한다. 다운로드는 버튼을 누를 때 DB에 저장된 자료만 읽는다. 외부 원문 수집이나 LLM 호출을 유발하지 않는다.
