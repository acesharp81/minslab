# 세 작업자 · 공유 사용량 적용 검증

- `home-tests.txt`: HOME 기존 수집/예산/캐시 및 새 역할 경계 64개 통과.
- `shared-tests.txt`: 7개 통과. 별도 신규 임시 Postgres의 공유 원장·게이트웨이 테스트. 운영 DB/접속정보 미사용.
- `model-probes.json`: 후보 5개 모델 실제 가상 문장 구조화 응답. Solar/mini/5.4/Terra와 Nemotron 3.5 무료 성공. 이전 Nemotron 3 무료 경로는 공급자 404로 교체. 품질 벤치마크 또는 모든 실제 공고 정확도 검증을 의미하지 않는다.
- `browser-live.json`, `agents-desktop.png`, `agents-mobile.png`: 실제 HOME 화면. 역할 순서/허용 모델/5개 사용량 표시/잔여율 막대 일치/390px 모바일 넘침 없음/개별 CSV 합본 일치. 당시 수집 69행 + 업무담당 13행 = 합본 82행. 이는 기존 수집 이력과 기존 사람 보류를 포함한 조회이며, 새 AI가 모두 판단한 건수로 표현하지 않는다.
- `deployment.json`: 기존 이미지에 관련 파일만 덧씌워 배포한 이미지/복구용 이전 컨테이너 기록. 비밀정보 없음.

기존 수집 예약/설정/실행·승인 이력은 유지했다. 새 알고리즘·업무담당은 직접 실행 가능하며 예약은 기본 끔이다. 일반 자료 수집이나 업무 승인 전체를 검증 목적으로 자동 실행하지 않았다. 테스트는 오프라인 fixture·신규 임시 DB·가상 모델 요청·실제 화면 조회로 구분했다.

규칙 자동 배포, 독립 인터넷 재검색, 단계별 실적 확정은 구현된 것으로 주장하지 않는다. 현재 알고리즘은 진단/개선안, 업무담당은 엄격한 공식 자료 연결과 단계 보류까지 수행한다. 원장/새 역할 테스트 71개와 프록시 5개가 통과했다. 재시작 후 정책 조회는 최초 약 5.3초, 이후 76ms였으며 에이전트 상태 조회는 11~38ms였다(`performance.json`). 운영 계약은 [AI_AGENTS.md](../../AI_AGENTS.md).

자동 승인 검토가 운영 DB 접속정보를 사용하는 테스트 실행을 차단해, 운영과 무관한 신규 임시 Postgres 컨테이너 방식으로 변경했다. 새 컨테이너는 테스트 종료 후 삭제했다.
