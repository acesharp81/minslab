# 주택파동 미연결 98개 사업의 「9·7 주택공급 확대방안」 연계 가능성 검토의견서

- **검토일:** 2026-11-05
- **검토자료:** `붙여넣은 텍스트(1)(1).txt` (CSV 형식, 98개 고유 사업ID, 데이터 내보내기 2026-11-04 22:32:21 UTC)
- **검토대상 정책:** 정부 관계부처 합동 「주택공급 확대방안」, **2025-09-07 발표**
- **검토 성격:** 사업 원천자료(사용자 제공)와 9·7 정책 공식 발표·정책 세부 과제를 대조한 **연계 권고안**. 실제 DB의 정책ID 변경·사업실적 반영은 수행하지 않음.

## 1. 결론

**정책 관련성은 있으나, 제출된 자료만으로 9·7 정책에 직접 귀속이 확정된 개별 블록·조합 사업은 0건이다.** 9·7 원문에 **지구명**이 명시된 3기 신도시 소속 블록 3건은 우선 연결 검토 대상이지만, 이 3건도 블록별 공식 귀속과 2026~2030 착공실적은 미확인 상태이다.

### 판단상 주의할 점

1. **정책-사업의 관련성**, **사업의 정책대상 공식 확정**, **9·7 공급목표 실적 반영**은 서로 다른 행정 판단이다. 한 단계가 충족됐다고 다음 단계가 자동 승인되는 것은 아니다.
2. 9·7 공급목표는 **2026~2030년 수도권 135만 호 '착공'**으로 관리한다. 단순 사업존재, 정비구역 등재, 기존 공급계획 호수, 분양공고로 착공실적을 인정하지 않는다.
3. 본 자료의 `현재 정책 ID`는 98건 전부 `UNASSIGNED`이고, 9·7 정책의 **실제 내부 정책ID나 하위 프로그램ID는 제공되지 않았다.** 문서의 정책명은 제안된 분류명이며, 내부 ID를 임의로 생성하거나 입력해서는 안 된다.
4. 각 사업의 원천 URL이 제공되어 있지만 원문 98개 전부의 판본·첨부·행정상태까지 재조회한 것은 아니다. 지구명, 사업유형 수준의 검토와 개별 사업 귀속에 필요한 확인을 분리했다.
5. 「서울시 정비사업 정보몽땅」의 **정비사업 목록이나 9·7 정책 첨부의 유형별 현황 지도**에 나타난다는 사유만으로 9·7 대책의 사업별 추진명단으로 간주할 수 없다.

## 4. 도심 정비사업 39건 판단 기준

**C유형 39건은 정책과제 '관련성 참조'는 가능**하지만, 9·7 이후 신규 발굴사업·정책지원 확정사업이라고 판단한 것은 아니다. 아래 각 사업의 기준은 다음과 같다.

- `재개발·재건축 · 정책 귀속 검토` **28건**: 9·7 정책 「정비사업 제도 종합 개편」과 *유형상 관련*. 서울시 정비사업 등록정보는 사업존재·단계 증거이지 9·7 귀속증거가 아니다.
- `소규모 주택정비 · 정책 귀속 검토` **11건**: 9·7 정책 「소규모주택정비사업 활성화」와 *유형상 관련*. 개별 사업이 1.8만 호 착공목표의 일부인지 검증 필요.
- 재개발 등 28건에는 서로 다른 정비사업 유형이 섞여 있을 수 있으므로 코덱스에서 서울시 정비사업 API의 최신 사업유형·단계를 별도로 재조회할 것.
- 실제 제도개선 수혜·일정단축·2026~2030 착공기준 충족을 **별도 적용 근거**로 확인한 사업만 `POLICY_IMPLEMENTATION_CANDIDATE`로 상향할 것.

1. **동일 소재지 사업ID 중복 가능성:** `서울특별시 광진구 자양동 217-3번지`(`PRO_ebd9721f3af044a479120d5b`)와 `자양동 217-3`(`PRO_f516203c4840cef5b6c1627c`)는 주소가 동일하다. *중복 확정이 아니라 대조 대상*이며, 건축 인허가 고유번호·허가일자·대지좌표·건축물 유형을 확인해야 한다.
2. **호수 미확인:** 98건 중 91건은 확인된 호수가 비어 있다. 무리하게 공급호수를 추정해서 정책의 공급계획·착공실적에 합산하지 않는다.
3. **일반 건축허가 근거의 제한:** 51건은 사업별 세부 원천이 아니라 동일한 공공데이터 API 소개 URL을 증빙으로 기록했다. 데이터포털 서비스의 존재가 **개별 건축사업 및 정책 귀속 근거를 보증하는 것은 아니다**. 원시 허가 레코드 ID를 추가해야 한다.
4. **정책명/프로그램명 혼동:** `CONFIRMED`는 현재 분류값의 저장상태이지 9·7 정책 귀속의 증거가 아니다. 사업 원천 확인, 기존 프로그램 분류 확인, 정책 관련성 승인, 정책실적 승인은 각각 다른 상태값으로 관리해야 한다.
5. **정책기간 적합성:** 특히 오래전에 사업을 시작한 정비사업을 2025-09-07 발표 이후 신규 9·7 대책 사업으로 간주하지 않는다. 2026~2030 착공예정일 및 해당 정책수단 실제 적용 확인을 선행한다.

## 7. 코덱스에 전달할 변경 요청

### P0. 잘못된 자동 정책 귀속 차단

- `사업유형 == 소규모정비/재개발/재건축/일반주택건설`이라는 이유만으로 `policy_id = 9.7`로 변경하지 않는다.
- **3기 신도시 지구 매칭**으로 확인한 정책 관련성도 지구/블록 계층을 유지한다. 정책에 지구명만 있으면 블록별 성과 편입 `false`.
- 정책 귀속 유효 조건에 `policy_evidence_id`, `evidence_scope`(지구·블록·개별사업), `policy_mechanism`, `effective_period`, `verification_status`, `approved_by`, `approved_at`을 포함한다.
- 정책과제 **관련성 참고 링크**는 프로젝트의 `policy_id`를 변경하지 않는 별도 다대다 관계로 제공한다.

### P1. 증빙 수집 및 승인 체계

- 공공택지 A/B 6건: LH 지구/블록 코드, 착공연도, 9·7 이후 이행관리 대상·직접시행 전환 내역 확인.
- C 39건: 실제 적용된 정비사업 규제특례, 인허가 개선/단축, 정부 지원 또는 2026~2030 정책목표 편입 근거가 있을 때만 정책 이행대상으로 상향.
- D 53건: 9·7 정비사업/공공택지 실적 데이터에서는 제외. 일반 주택공급 통계에 반영할지는 별도 근거와 산정기준에 따라 결정.
- `원문 출처`가 일반 API 소개 페이지인 경우 `PER_PROJECT_EVIDENCE_MISSING`으로 자동 표시.
- 동일 부지/동일 블록에 여러 사업ID가 있을 경우 `duplicate_candidate`를 생성하고 심사 이전 중복 집계 방지.

### P2. 데이터 구조 제안

```yaml
project_policy_relation:
```

**권장 정책 링크 구분:**

- `POLICY_REFERENCE`: 정책의 관련 제도과제 표시용. 실제 `policy_id` 상속 없음.
- `POLICY_TARGET`: 공식 정부 정책/이행명단에서 특정 지구·블록·사업의 집계대상 확인 및 승인.
- `POLICY_ACTUAL_START`: 사업 단위 착공 사실·일자·물량·중복여부 확인 후 승인.

### 수용시험(회귀검사)

1. 98개 고유 사업ID 모두 결과표에 한 번씩 포함; A=3, B=3, C=39, D=53.
2. 사용자 제공 98개 `현재 정책 ID=UNASSIGNED`를 변경 없이 재현하고, 내부 정책/프로그램 ID를 임의 발급하지 않음.
3. 9·7 정책 참고 링크 생성과 정책 실적 승인 상태가 별도 관리됨.
4. 6개 LH 블록의 4,022호와 연남동 82호가 9·7 착공실적에 자동 합산되지 않음.
5. 자양동 217-3의 2개 사업ID는 중복후보로 경고하되 임의 병합하지 않음.
6. 서울 정비사업 목록 또는 일반 인허가 API URL만으로 `POLICY_TARGET=VERIFIED`가 생성되지 않음.
7. `CONFIRMED` 53건이 정책 귀속 확정으로 잘못 해석되지 않음.
8. 외부 정책 근거가 지구까지만 명시되면 하위 블록에 자동으로 9·7 정책 실적 확정 상태가 전파되지 않음.

## 8. 종합 권고

**당장 실행할 수 있는 것은 45건(A+B+C)에 대한 '9·7 정책 과제 관련성' 표시를 검토하는 것**이다. 그러나 이를 전부 `정책 소속 사업`으로 변경해서는 안 된다. 특히 분명한 지구 언급이 있는 3건만 우선적으로 **정책-지구 관련 링크**를 담당자가 검토하고, 나머지 42건은 관련 정책수단을 보여주는 참조 관계로 유지하는 것이 바람직하다.

**최종 정책ID 확정 0건, 9·7 착공실적 승인 0건**을 현 단계의 보수적인 검토결과로 제시한다.
