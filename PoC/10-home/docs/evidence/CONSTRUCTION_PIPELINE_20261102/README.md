## 반영한 기능

1. `stage_proposal` 별도 판본: 현재 관리값·새 근거·인용·원천 판본·보류 사유·처리 이력.
2. 신규 자료 검토의 **단계별 실적 반영 검토**: 여섯 단계별 후보 수, 기존값 비교, 원문 확인, 관리자 승인·제외, 확정값 정정 확인.
3. 승인 시 기존 사업·단계 누적값을 대체하며 중복 가산하지 않는다. 원문·사업·프로필·정책 연결 판본이 바뀌면 승인 충돌 처리한다. 관측 확인일은 실제 사건일과 별도 보존한다.
4. 단계별 판단보류 CSV 및 기존 수집/업무담당 통합 CSV에 실적 검토 건 포함. 통합 CSV 266행 중 실적 검토 138행을 확인했다. 다른 역할의 같은 자료가 별도 사유로 포함될 수 있다.
5. 업무담당자는 승인된 자료도 단계 근거를 검토한다. 원문·본문·사업 판본이 같은 처리 결과는 모델을 재호출하지 않고 처리 한도를 다른 자료에 사용한다. 공식 HTML 원문 복구는 실행당 최대 3건이다.
6. 검증 조건을 만족한 AI 제안만 자동 반영한다. 사람이 보류한 자료, 비공식 출처, 부분·잔여·재모집, 미래 예정일, 실제 일자 미확보, 인용 불일치, 기존 확정 실적과 충돌은 자동 확정하지 않는다.

공식 원문의 본문 확보 실패, 독립 공식 근거 탐색, 사업 동일성/물량 미확보 등은 여전히 확인이 필요할 수 있다. 모델 출력만으로 이 조건을 충족했다고 간주하지 않는다. 이번 점검은 유료 모델을 호출하지 않았으며 새 코드의 실모델 야간 실행 결과는 다음 실행 이력에서 확인해야 한다.
