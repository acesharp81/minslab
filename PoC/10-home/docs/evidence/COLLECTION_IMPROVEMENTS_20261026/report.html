1. 이번 변경

  • LH·iH 공식 보도자료 목록, 서울시 공식 보도자료 RSS, 뉴시스 경제·수도권 RSS를 매시간 조회한다. 최신 목록·현재 피드 중 최근 30일의 주택·사업 단계 키워드가 있는 제목·게시일·원문 링크를 후보로 보관한다.
  • 신규 탐색 작업은 수집 단계에서 완료한다. 자동 연결·실적 스냅샷 작업을 시작하지 않으며 facts는 빈 배열, 호수는 미확정 상태로 유지한다.
  • LH 상세 공고는 추출 내용이 동일하고 HTML 원문 파일·해시만 달라진 경우 기존 개정판을 유지한다. 최신 응답은 수집 배치의 원문·해시에 남는다. 호수·날짜·공고 판본·파서 버전 등 내용 변경은 기존처럼 새 개정판을 만든다. 시흥하중 A1·시흥거모 S-1의 실제 최신 응답도 원문 해시만 달라 기존 판본(132·128)을 유지함을 별도로 확인했다.
  • 토지이음 보관 첨부를 배치당 4개까지 복구한다. HWP는 hwp5txt, 스캔 PDF·이미지는 한국어 OCR을 사용한다. 시간·메모리·파일 크기 제한을 적용하고 원문 SHA-256 검증 후 처리한다. 구버전 추출물은 원문 해시가 같을 때 재사용한다.
  • OCR은 최대 4쪽의 검토용 초안이며 OCR_REVIEW_REQUIRED로 표시한다. 지형도면과 실패 자료는 완료로 처리하지 않는다. 실패는 7일 후 재시도하며 남은 추출 대기가 있으면 보충 수집을 계속한다.
  • 수집 화면에 자동 수집 경로와 보관 문서 발행처를 구분했다. API와 별도로 동작하는 수집 작업자의 상태를 확인해 자동 수집 표시를 바로잡았다.
