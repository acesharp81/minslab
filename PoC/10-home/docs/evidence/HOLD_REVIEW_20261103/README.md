# AI 보류자료 278개 대상 교차검토 — 2026-11-03

사용자 첨부 독립 검토의견의 자료 140건·단계 후보 138건을 모두 현재 원장과 대조했다. 처리 전 306개 역할별 기록, 278개 고유 대상, 28개 중복 대상은 첨부 집계와 일치했다. 외부 모델의 의견은 업무담당자 지식 보조자료이며 동료의 데이터셋 검증과 구분한다.

## 처리 결과

- 공개 원문 43건 재조회, 그중 LH 보도자료 6건은 공개 PDF 본문까지 추출했다. 유효 본문 26건을 보충했다. 개인정보 명단 첨부는 수집하지 않았다.
- 미검토 19건 처리: 후속 자료 연결 승인 1, 동일 사업 등록대기 1, 개별 사업 연결 제외 8, 근거 보완 보류 9.
- 기존 121건의 업무판단은 다시 승인하거나 철회하지 않았다. 전체 278개에 외부 권고·내부 대조 결과·남은 확인사항을 판본 고정 이력으로 저장했다.
- 자료 140건의 유효 본문은 125건이며 15건은 미확보/불충분하다. 본문 보유는 첨부 완전성이나 실적 검증 완료를 뜻하지 않는다.
- 단계 138건은 모두 실적 반영 보류를 유지했다. 실제 저장 본문은 1건뿐이고 137건은 없다. 동일 사건 후보 6개 그룹(14개 제안), 서로 다른 일자·물량 후보 2개 그룹을 확인했다. 원천/사업 판본 경고는 83건, 사업 동일성 미확정은 123건이었다.

과천지식정보타운 S12의 행복주택 1,424호 보도는 LH 공식 12172 PDF 및 기존 임대공급계획 사업과 대조하여 해당 사업에 자료만 연결했다. 동일 이름의 건설계약 사업에 중복 연결하지 않았다. 면목동542-7 정비계획 보도는 기존 면목역세권 등록후보와 같은 명칭으로 정리했으며 사업을 신규 생성하지 않았다.

외부 의견의 LH 12180 ‘정책 참고’ 권고는 보완했다. 공식 PDF에 망원동 청년형 신축매입 168호, 2025년 5월 착공, 2026년 말 준공 예정, 2027년 상반기 모집 예정이 있어 구체 사업 식별 대상으로 보류했다. 월 단위 날짜를 임의의 사건일로 만들거나 예정 준공을 실적으로 올리지 않았다.

## 시스템 보완

- AI 작업자·단계 검토에 **외부 의견 교차검토**를 표시한다. 원천/업무판단/보충 본문 판본이 달라지면 다시 확인하도록 표시한다.
- **외부 검토용 · 대상별 통합 CSV**를 추가했다. 같은 자료를 한 행으로 묶되 원래 역할별 분석을 JSON에 보존한다. 기존 역할별 CSV도 유지한다.
- 단계 CSV에 저장 본문, 미확보 상태, 원천 참조·해시·근거 위치 메타데이터, 직접 인용 일치 여부, 동일 사건 및 다른 값 후보ID를 포함한다. 없는 본문/첨부 정보는 생성하지 않는다.
- 같은 사업·단계의 상이한 값 후보가 남아 있으면 자동 실적 반영을 차단한다. 동일 후보의 출처를 삭제하지 않으며 실적은 증분 합산하지 않는다.
- 수동 본문 복구 후 남아 있는 수집 오류에는 재분석 필요 표시를 추가했다. 기존 담당자 판단을 분석 완료로 위장하지 않는다.
- 단계 근거의 객체/배열 자료형 차이로 업무담당 목록 전체가 실패하던 렌더링 문제를 수정했다.
