반영 사항

  • 지도 집계의 같은 중첩 자료에 대한 반복 deepcopy를 요청 내부 직렬화 복사로 바꾸었습니다. 결과 사이의 변경 격리는 유지합니다.
  • 정책 그래프가 소비하는 착공 통계만 읽고, 화면에서 버리는 출처 진단 계산을 생략했습니다. 전체 진단 API는 유지합니다.
  • 미연결 신규 공고만 추가될 때 정책 그래프 전체를 다시 계산하지 않습니다. 저장된 연결, 담당자 수정, 연결 원문 수정 및 통계 수정은 다음 조회에서 반영됩니다.
  • 개별 사업 조회는 해당 사업의 두 단계 근거만 읽습니다. 전체 사업의 대용량 근거 후보 목록을 함께 읽지 않습니다.
  • 신규 자료 검토 등 독립 화면은 공통 정책·출처 목록 조회를 기다리지 않고 시작합니다.

검증 및 한계

정책·현황·매핑·개별 사업 API의 변경 전후 응답을 재귀 대조했습니다. 정책 13곳과 매핑 7곳의 자동 수집 시각만 갱신되었고, 그 외 값은 모두 일치했습니다. 최종 브라우저 5회 실행 모두 화면 표시 성공, JavaScript 오류와 HTTP 실패가 없었습니다.

관련 정책·캐시·집계·조회 테스트 79개, 추가 사업·메뉴 테스트 40개, 사업 상세 테스트 20개가 통과했습니다(중복 포함). JavaScript 문법과 git diff 공백 검사도 통과했습니다. 과거 인지시점 조회, 통계 분류 변경, 승인 직후 캐시 갱신, 단일 사업과 전체 조회의 근거 일치도 검증했습니다.

배포 중 검증에서 JSON 서브쿼리가 30초 제한에 걸리는 문제를 발견해, 연결 ID를 한 번 읽은 후 조회하도록 수정했습니다. 최종 배포에서 해당 오류는 재현되지 않았습니다. 최초 정책 집계는 여전히 약 7초 걸리며 모든 화면이 즉시 표시되는 수준은 아닙니다.
