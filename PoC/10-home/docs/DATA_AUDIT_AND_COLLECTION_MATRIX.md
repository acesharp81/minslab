## 저장 구조와 관리자 화면

기존 home_revision은 원천과 판본 보존용으로 유지한다. 별도 home_policy, home_policy_version, home_policy_document, home_policy_measure, home_policy_target, home_project_event, home_policy_project_link, home_building, home_building_project_link, home_area_stat, home_area_boundary, home_dataset_coverage 테이블을 둔다. 정책 목표에는 단위·단계·지역·대상 유형·공식/관리자/추정 여부를 필수로 기록한다. 정책–사업 링크는 다대다로, 관계 유형(기원 프로그램/직접 대상/후속 개정/참고), 적용 기간·호수, 자동 제안 근거·점수, 검토/승인/제외, 승인자를 가진다. 동일 호수가 여러 정책에 걸쳐도 총 공급량은 한 번만 센다.

관리 화면은 정책 목록 → 발표·개정 원문과 목표 → 자동 매칭 후보 → 원문 문구·사업코드·지구/블록·지도 위치·중복 후보 비교 → 담당자 승인 순서가 적합하다. 기존 요구대로 미승인 후보는 통계에 포함하되 화면에서 검토 포함/승인만 필터와 중복 제거 근거를 제공한다. 최초 프로그램과 뒤이은 정책 발표를 동시에 연결할 수 있어야 한다.

## 검증·화면 적용 순서

1. 원천 × 연도 × 지역 × 단계별 원천 행, 적재 행, 사업 연결 행, 승인 행, 호수, 미확보 사유를 보여주는 커버리지 표를 만든다. 조회 성공 0건과 조회 실패/미수집을 분리한다.
2. 정책 총량과 서울·경기 연결 사업 계획의 대상 범위·지표가 같은지 확인한 뒤 그래프에 사용한다. 공식 연도 목표가 없으면 추정 균등선과 명확히 분리한다.
3. 사업 생애 이력(2018년 이후 확보분)과 정책 시행 후 귀속 실적을 별도 탭으로 표시한다. 연도별 계획·공고·준공·입주를 별도 계열로 구성한다.
4. 건물 도형과 대장·블록 경계를 연결해 사용승인된 사업 아파트부터 실제 외곽선/높이로 바꾼다. 연결 전 가상 아파트는 가상으로 표시한다. 현재 선택 블록 반경 300–1000m·최대 5,000동 조회 제한은 화면 범위별 타일·캐시로 개선한다.
5. 인구·가구·산업별 종사자·거주지 취업자를 시도/시군구 지도와 시계열에 배경 지표로 더한다. 각 지표의 관측 기준년·공표일·공간 범위·거주지/사업장 기준을 표시한다.

새 인증: [SGIS 개발자센터](https://sgis.kostat.go.kr/developer/html/openApi/api/intro.html)에서 테스트 키 신청 후 운영키로 전환하며 HOME 환경변수 POC10_SGIS_CONSUMER_KEY, POC10_SGIS_CONSUMER_SECRET을 사용한다. [KOSIS 공유서비스](https://kosis.kr/openapi/index/index.jsp) 인증키는 POC10_KOSIS_API_KEY로 둔다. 행안부 주민등록 통계는 공개 CSV로 우선 검증한다. 현재 VWorld 건물 조회와 기존 HOME 원천에는 새 키가 필요하지 않다. S-Map 고품질 3D의 외부 서비스용 API·라이선스는 확인 전까지 연계를 확정하지 않는다.
