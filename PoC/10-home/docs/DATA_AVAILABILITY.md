# HOME 데이터 공백 판정과 운영

기준: 2026-10-10. 화면의 빈칸은 0호나 사업 미착수로 해석하지 않는다. 운영 최종 확인: 건축HUB 기본 인허가 1,090/2,629개, 주거용 건축물대장 1,082/2,629개, 인허가 동·필지 상세 258/2,629개 법정동을 조회했다. 공동주택 단지·필지 사용승인 참조 24,835행과 GH 사용검사·승인 관련 PDF 7건을 별도 저장했다. 사업 후보 266건 중 실제 입주 호수 연결은 0건이며, 원천에 없는 값을 0호로 표시하지 않는다. `/poc/home`의 **데이터 검증 → 빈칸 원인 · 수집 진행**은 저장된 원천 revision, 마지막 수집 배치와 공식 조회 범위를 함께 보여준다. 조회 조건이 있으면 사업 근거 확보 건수는 그 조건의 사업 후보를 기준으로 한다.

| 상태 | 판정 근거 | 의미 |
|---|---|---|
| 확보 | 해당 연도·시도 원천 revision 존재 | 그 원천의 기록을 저장했다. 사업 전수·정책 귀속 완료는 아님 |
| 원본 행 없음 | 연도 범위를 포함한 LH 첨부 전체를 조회했고 다른 시도 행은 있으나 선택 시도 행이 없음 | 해당 **첨부에서** 행을 찾지 못했다. 공급 0호 또는 정책사업 부재를 뜻하지 않음 |
| 원천 미공표 | 수집한 공식 멸실 첨부 목록의 최신 연도 이후 | 현재 확인한 e-나라지표 첨부에 새 연도가 없음. 다른 게시 경로는 별도 확인 |
| 미입수 | 수집 이력은 있으나 해당 연도·시도 저장 증거 없음 | 원천 발표 여부, 검색 범위, 지역 식별, 수집 누락을 확인해야 함 |
| 수집 미시작 | 해당 수집 작업·연결기가 아직 실행되지 않음 | 계획된 수집 과제. 실제 사업 미착수와 무관 |
| 수집 실패 | 첫 성공 배치 없이 최신 시도가 실패 | 오류 수정 후 재시도. 이전 성공 자료가 있으면 해당 자료는 보존 |
| 범위 일부 | 법정동 API의 완료 동 수가 전체 동 수보다 적음 | 완료 동의 페이지 조회와 서울·경기 전체 동 조회는 구분 |

사업의 `계획·지정` 단계는 **실제 착공 여부 미확인**으로 표시한다. `미착수 확인`은 원천의 명시적 미착수 상태와 근거 URL이 모두 있을 때만 허용한다. 사업별 실제 입주 호수도 값과 증거 URL이 함께 있어야 확보로 판정한다. 공고 공급호수, 입주 예정 호수, 건축물대장 재고를 실제 입주로 대체하지 않는다.

## 새로 연결한 공식 멸실 자료

[e-나라지표 주택멸실현황](https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=2839)의 정책자료 첨부 목록에서 **2018~2024년 연도별 XLSX**를 내려받아 서울·경기 시도 행을 수집한다. 수집기는 `backend/demolition.py`에 있으며 매 배치마다 제목/연도, 열 이름, 시도 2행, 주택 유형 합계가 총계와 일치하는지 검증한다. 원본은 SHA-256과 함께 `data/raw/molit_demolition/`에 보존하고 `home_revision`의 `statistic` 행에 `statistic_metric=멸실`, `statistic_period=연도`, `units=연간 멸실 호수`, `demolition_breakdown=주택 유형별 호수`로 저장한다. API 키는 필요 없다.

연도별 공급 비교에서는 `멸실`을 별도 지표로 고르고 CSV로 받을 수 있다. 같은 연도에 준공 12개월과 멸실 연간 원본이 모두 있을 때만 `준공−멸실`을 **산술 참고값**으로 표시한다. 통계 보정, 다가구 환산, 공실과 입주 여부를 반영하지 않으므로 공식 주택 재고 증감이나 실제 공급량이 아니다. 공개 첨부가 시도 단위라 시군구/블록 멸실량은 미입수로 유지한다. 2025년 이후는 현 첨부 목록에서 미공표 상태다.

## 2018~2025년 시군구 주택총조사 추가 확보

[KOSIS 인구·가구·주택 통계표 `DT_1IN1502`](https://kosis.kr/statisticsList/mass/mass_list.jsp?org_id=101&process=statHtml&tbl_id=DT_1IN1502&vw_cd=MT_ZTITLE)의 `T310(주택_계)`을 기존 KOSIS 키로 조회한다. 서울 25구·경기 31시군과 두 시도 합계를 **매년 58개 행, 2018~2025년 총 464개 지역·연도 값**으로 검증한다. 원천 항목·연도·공표 수정일을 `census_housing_units`로 별도 보존하고, 데이터 검증에 `주택총조사 주택수` 별도 행으로 표시한다. 이 수치는 `DT_1MH2090`의 다가구 구분거처 반영 주택 재고와 집계 기준이 달라, 2018~2023년 `housing_units` 결측이나 수급차 계산에 대체하지 않는다. 재수집: `python -m scripts.collect --source kosis_housing`.

## 재수집과 우선 후속 작업

- 공식 멸실: `python -m scripts.collect --source molit_demolition` (연도별 첨부 목록을 다시 읽어 새 공개본을 확인).
- 인허가·건축물대장: `python -m scripts.collect --expand-building --rounds 1` (법정동 체크포인트부터 재개). 기본 24시간 자동 수집에도 각각 최대 20개 동씩 포함한다.
- 인허가 동·필지 상세: `python -m scripts.collect --expand-building-details --rounds 1` (기본 8개 동/배치, 환경변수 `POC10_BUILDING_DETAIL_DONGS_PER_BATCH`).
- 단위별 공백: 데이터 검증의 연도 매트릭스, 수집 원천의 마지막 시도/성공, 원천 검증 자료의 자료연도와 원문을 순서대로 대조한다. 성공 배치도 서울·경기 전체 사업 모집단을 뜻하지 않는다.

다음 확보 과제는 별도 정의의 주택총조사 주택수는 2018~2025년 확보했으나 다가구 구분거처 반영 시군구 과거 주택 재고와 장래가구 공식 추계, SH·GH 실제 공정 이력, 사업별 실제 입주량, 정책·계획 고시의 최초 지정부터 변경 이력, LH 과거 첨부의 지역·연도 공백이다. 공식 시군구 단위 원천이 없는 항목을 시도 총계에서 임의 배분하지 않는다.

## GH 사용검사·사용승인 원문 확보

2026-10-10 운영 수집 결과: 목록 9/9건 조회, 관련 PDF 7건 적재(사용검사·사용승인 후보 5건, 임시/준공인가 전 허가 2건). PDF 본문을 읽을 수 있는 것은 3건이고, 그중 최종 사용검사·승인 2건에서 명시된 발급일·허가번호를 추출했다. [원본 레코드 조회](https://www.minslab.kr/poc/home/api/samples?kind=gh_completion_evidence&page_size=20)에서 확인할 수 있다.

[GH 입주안내 공개 목록](https://apply.gh.or.kr/cs/sr/sr7900/selectNoticeList.do)에서 사용검사·사용승인·준공인가전/임시사용허가 게시물을 조회하고 첨부 PDF의 SHA-256, 게시일, 식별번호, 본문 추출 가능 여부, 명시된 발급일·허가번호를 `gh_completion_evidence`로 저장한다. 원문 PDF는 `data/raw/gh_completion_evidence/`에 보존한다. 재수집: `python -m scripts.collect --source gh_completion_evidence`. 목록상 시군구와 PDF의 개별 건물/공구 범위가 다를 수 있으므로 사업·블록 연결은 `REVIEW`로 남긴다. 사용검사/사용승인은 **실제 입주 호수**를 증명하지 않으며, 준공인가전·임시사용허가는 최종 준공으로 집계하지 않는다. 별도 API 키는 필요 없다.

## 공동주택 단지·필지 사용승인 참고자료

[한국부동산원 공동주택 단지 식별정보](https://www.data.go.kr/data/15106861/fileData.do)의 2026-08-31 공개 CSV를 실제로 확인했다. 전국 307,834행 중 서울·경기 189,885행, 그중 **2018년 이후 사용승인일이 있는 24,835행**(서울 11,530, 경기 13,305)을 식별했다. 단지고유번호·필지고유번호 쌍은 이 범위에서 중복이 없고, 대상 지역의 사용승인일 누락은 5행이다. 수집 시 `complex_approval_reference`로 **별도** 저장하고 단지/필지 식별자·명칭·주소·세대수·사용승인일과 원본 해시를 보존한다. 파일 공개 범위는 공시대상 공동주택 단지로, 모든 주택 승인/준공 또는 실제 입주 전수가 아니다. 동일 사업의 복수 단지·필지 행이 있을 수 있으므로 세대수를 정책 실적에 단순 합산하지 않는다. 별도 API 키는 필요 없다. 대용량 파일은 마지막 성공 뒤 7일이 지나면 자동 갱신하고, 즉시 재수집하려면 `python -m scripts.collect --source complex_approval_reference`를 실행한다.
