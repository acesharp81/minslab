## 대시보드

- 핵심 지표: 수집 사업 후보, 선택한 기간의 향후 목표 확보, 확대 API 데이터, 일정 미확보.
- 당해연도 2026과 **2027~2036 (+1~+10년)**을 열로 배치. 1·3·5·10년 전환, 연도별 사업 후보 요약과 연도 선택, 목표 확보/일정 미확보/예정 경과/관리자 목표 필터.
- 행마다 사업명·지역·원천·정책 매핑, 현재 단계·원천 기준일·공정률, 전체 계획 호수와 연도별 일정 표시. 사업명·연도 헤더는 스크롤 중 고정.
- 공급·계약 준공·입주 예정의 의미를 색상과 근거로 구분. 예정 경과는 실제 이행 확인 항목이며 실제 공급·준공 달성을 단정하지 않음.
- 원천 공급계획은 면적 행을 해당 예정월별로 합산하고 반복 총세대수를 더하지 않음. 미확보 호수는 NULL, 목표 미등록은 `NOT_SET`이며 0호나 완료율로 변환하지 않음.
- 연도별 CSV는 지역·검색·정책·원천·단계·매핑·기간과 표시 조건·선택 연도의 사업 필터를 적용. API 목록은 100개씩 페이지 이동, CSV는 해당 조건의 전체 데이터를 다운로드.

현재 향후 목표 확보 사업 후보는 **96개**, 모든 일정 미확보는 **11개**입니다. 원천 일정 기준 2027년 38개(계약 준공 28 / 입주 10), 2028년 46개(준공 42 / 입주 4), 2029년 12개(준공 12). 이는 원천 사업 후보 건수이며 정책 실적·고유 사업·준공 확정 수·공급총량이 아닙니다. 2030~2036은 목표 미등록으로 표시합니다.

## 관리자 연도별 목표

사용자가 선택한 ‘공식 일정 + 관리자 목표 입력’ 방식으로 구현했습니다. 관리자 로그인 → 공급 현황 → 사업의 **목표 관리**에서 당해연도와 향후 10년을 편집합니다.

- 연도별 목표 단계: 계획 / 인허가 / 착공 / 공급 / 준공 / 입주.
- 목표 호수 선택 입력: 공란은 미확보, 0은 명시한 목표 값으로 구분.
- 근거·메모 필수, HTTPS 근거 URL 선택. 원천 예정과 관리자 목표를 함께 표시하되 자동으로 덮어쓰지 않음.
- 미등록 선택으로 해당 관리자 목표 해제. 이전 revision과 감사이력 보존, 과거 기준일 읽기 전용.
- 별도 `goal` revision과 `TARGETS_UPDATED` 감사이력. 프로젝트별 잠금·`revision_no` 비교로 동시 수정 시 409, 동일 저장은 unchanged.
- 부모 관리자 세션·동일 출처·내부 서명으로 저장 보호. 공개 사용자는 읽기만 가능. 목표 변경 감사는 과거 정책 매핑 재현에서 제외.

운영 데이터에 임의 관리자 목표를 만들지 않았습니다. 최초 관리자 등록 사업은 0건이며 확인한 원천 예정만 표시합니다. 목표 입력은 실제 실적이나 공식 공급총량을 바꾸지 않습니다. 기존 사업 후보 150개·정책 3개·공식 공급총량 NULL을 유지했습니다.

## 검증

- HOME **30개**, 부모 사이트·프록시 **30개** 테스트 통과. 확대 페이지 누락/중복 검사, 10개 미래 연도와 당해연도, 월별 면적 물량·미확보 값, 계약 준공의 의미, 목표 인증·입력 검증·낙관적 잠금·revision·과거 재현, 매핑 감사 분리, 페이지와 CSV 조건 확인.
- 공개 Chromium 1440×1000 / 390×844에서 연도별 표·연도 선택·기간 전환·미확보 필터·목표 상세·CSV·확대 표본 페이지·유형 필터 확인. 콘솔·JavaScript·리소스 오류와 페이지 전체 가로 넘침 없음.
- 관리자 입력 화면은 메모리 mock으로 단계·호수·근거 입력과 저장 후 표시를 검증. 실제 DB 저장·충돌·과거 이력은 독립 SQLite API 테스트로 검증했으며 운영 사업에 테스트 목표를 저장하지 않음.
- 확대 수집을 다시 실행해 청약 398·인허가 2,818·이번 배치 주소 40개 모두 unchanged 확인. 누적 API 레코드 3,268개 유지. API snapshot 126개와 누적 manifest 182개에서 인증정보 비노출·실제 SHA-256 일치 검증, 공개 CSV·API에서도 키 비노출 확인. 운영 관리자 목표 레코드는 0개 유지.

실행: `sudo docker exec poc10-home-api python -m scripts.collect --samples`. 설정과 목표 운영 절차는 [OPERATIONS.md](OPERATIONS.md)를 참고하세요.
