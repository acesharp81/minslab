정책 연결을 검토하기 전의 API 표본입니다.

청약홈·LH 공고는 정책 기원인 2018년부터 서울·경기 전체 조회 페이지를 수집합니다. 인허가·건축물대장은 공식 서울·경기 전체 법정동을 대상으로 미수집 동부터 이어서 수집합니다. 완료·잔여 범위는 데이터 검증에서 확인하며 건축물대장에는 기존 재고가 포함됩니다. 통계누리는 2018년부터 월별 착공·준공과 연간 인허가 총계입니다. 지역 전체 통계·공고 건수·사용승인일은 개별 정책 공급 실적과 구분합니다. 과거 자료의 대상 기간과 이번 수집일도 구분하여 표시합니다. SH 분양계획은 2019·2020·2023·2026년 공개본을 구분하며 공개본 간 물량을 합산하지 않습니다. SH 재개발·재건축 추진현황은 2023년 11월 기준이며 현재 상태 확인이 필요합니다. LH 공공분양 2020~2025 공급현황(공고 호수), 2022~2026 입주계획(예정 호수), 현재 단지정보의 과거 준공·입주지정 날짜도 조회합니다. 단지 일정에는 미래 예정일이 포함되며 당시 실제 공정률·실입주량과 구분합니다. LH 입주계획 2018~2021 공개본은 아직 미확보입니다. SH 관리현황 2024~2026년 파일과 GH 재건축 매입임대 현황은 별도 재고로 조회하며 신규 정책 실적에 합산하지 않습니다.
