처리

  • 인허가에 준공이 비어 있으면 건축물대장에서 실제 준공 건물 찾기
  • 재개발은 준공 뒤 지번이 바뀌어 동 전체 대장에서 허가일·필지·세대수로 대조
  • 등급: 강(허가일 일치)·지번 → 자동 확정 / 중·약 → 사람 확인
  • 확인 결과는 대장 관리번호로 연결표에 고정 (다시 돌려도 유지)
  • SH가 입주시킨 단지는 입주개시일을 준공으로
결과: 대장으로 준공 확정 19건 · 확인 필요 15건 (예: 정릉풍림아이원 1996 승인 → 2005 준공) · SH 단지 주소·이름이 인허가와 달라 중복으로 생기던 2건을 구역 고시 지번으로 합침 (래미안 포레카운티 · e편한세상 보문)

코드 연결: 계획(P-) ↔ 사업(SB-)

연결 근거

  • 지번: 사업 필지 = 구역 고시 지번 (정보몽땅은 대표지번)
  • 이름: 구역 이름 열쇠 같음 (장위6, 장위11-4)
  • 경계: 사업 위치가 구역 경계 안
  • 면적(보조): 같은 시군구·법정동 + 사업 필지 면적 합 ≈ 고시 면적 (0.5% 안) · 이것만 있으면 검토 필요 (삼선5 0.16%)
  • 구역 열쇠는 keys.py 한 곳에서만 만듦 — '구역' 글자 없는 이름(삼선제5주택재개발)·괄호 속 구역(e편한세상(보문4))도 읽음
  • 근거 둘 이상 → 자동 · 근거 하나 → 날짜·규모로 판단 (구역 고시 기간에 승인 + 30세대 이상이면 자동)
  • 구역 해제 뒤 허가, 지정 5년 넘게 전 허가 → 같은 땅의 다른 건물로 보고 참고

공개 데이터만으로는 실시간성을 확보할 수 없는 이유

  • 착공·준공 실적이 가장 늦음: 건축HUB는 9월 이후 기록이 없어 약 5~6주 늦고, 재개발은 착공일 칸이 아예 비어 있음 (장위6: 2024.03 착공인데 빈칸) → 지연 판정이 서류 예정일에 의존
  • 진행 단계 자료가 분기·연 단위: 추진현황은 최대 5개월, SH 관리현황은 최대 1년 2개월 늦음
  • 정보몽땅 API가 종료되어 엑셀 내려받기에 의존 (화면 구조가 바뀌면 수집이 깨짐)
  • 지금 지연·주의 4건(석관특계2 · 안암동5가 15-27 · 초행지붕-정릉-2 · 하월곡동 18-11)은 웹·고시·API 재조회로도 착공 여부를 확인할 수 없었음
  • 준공 전 매입약정 주택, 정비구역 지정 전 후보지, 사업별 정부 약속 일정·목표 물량은 공개 데이터에 없음

담당자 통합 대시보드가 채울 것

  • 착공·준공 실적: 구청 건축과·주택과가 착공신고·사용검사 시점에 바로 입력 → 6주 시차와 빈칸 해소
  • 정비사업 단계 변경: 관리처분·이주·철거·착공을 구청 주거정비과가 인가 시점에 입력 → 분기 자료 대체
  • 공공 물량 확정: LH·SH가 매입약정·인수 세대를 입력 → 재개발 임대가 '민간임대'로 남는 문제 해소
  • 지연 사유와 조치: 자동 판정(서류 기준) 옆에 담당자가 사유·조치·확인일을 기록
  • 공개 API는 자동 수집으로 계속 받아 담당자 입력과 대조 → 입력 누락·불일치를 검사 목록으로
